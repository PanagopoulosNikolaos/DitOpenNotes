# Signal Propagation: Curated Resources and Reference Guide

A curated guide of primary textbooks, electromagnetics simulation software, standard radio propagation ITU recommendations, and online resources for Signal Propagation and Antenna Systems (Course Code 304).

---

## 1. Foundational Textbooks

- **Antenna Theory: Analysis and Design (3rd & 4th Editions)**  
  *Author:* Constantine A. Balanis.  
  *Annotation:* The international standard reference for fundamental antenna parameters, vector potentials, wire antennas, aperture antennas, horns, microstrip patches, reflector systems, and antenna measurements.

- **Antennas for All Applications**  
  *Authors:* John D. Kraus and Ronald J. Marhefka.  
  *Annotation:* Comprehensive applied text emphasizing physical concepts, practical wire antennas, helical antennas, broadband arrays, and radio astronomy instruments.

- **Wireless Communications: Principles and Practice**  
  *Author:* Theodore S. Rappaport.  
  *Annotation:* The classic guide for wireless propagation mechanisms, large-scale path loss models, log-distance path loss, small-scale multipath fading, and link budgets.

---

## 2. Simulation Tools and Computational Electromagnetics

- **NEC-2 / 4NEC2 (Numerical Electromagnetics Code)**  
  *URL:* `https://www.qsl.net/4nec2/`  
  *Description:* Industry-standard method-of-moments (MoM) simulation engine for analyzing wire antennas, ground plane interactions, radiation patterns, and input impedance.

- **Scikit-RF (`skrf`)**  
  *URL:* `https://scikit-rf.org/`  
  *Description:* Python package for RF and Microwave engineering, offering network analysis, Smith Chart plotting, Touchstone S-parameter file parsing, and transmission line calculations.

- **OpenEMS**  
  *URL:* `https://openems.de/`  
  *Description:* Free and open-source Finite-Difference Time-Domain (FDTD) electromagnetic field solver.

---

## 3. Standards and Regulatory Bodies

- **ITU-R Radiocommunication Sector Recommendations**  
  *URL:* `https://www.itu.int/itu-r/`  
  *Description:* International telecommunications standards for radio wave propagation modeling, atmospheric attenuation (P.676), rain attenuation (P.838), and terrestrial link engineering.
