# Ασκήσεις Εμπέδωσης: Απώλειες Ελεύθερου Χώρου και Προϋπολογισμός Ζεύξης

## Άσκηση 1: Εφαρμογή του Τύπου Μετάδοσης Friis
### Εκφώνηση:
Δορυφορική ζεύξη καθόδου (Downlink) λειτουργεί σε συχνότητα $f = 12\text{ GHz}$ (μπάντα Ku) σε απόσταση γεωστατικής τροχιάς $d = 36,000\text{ km}$.
- Ισχύς πομπού δορυφόρου: $P_t = 40\text{ W}$ ($+46\text{ dBm}$)
- Κέρδος κεραίας εκπομπής: $G_t = 34\text{ dBi}$
- Κέρδος επίγειας κεραίας λήψης: $G_r = 42\text{ dBi}$
- Πρόσθετες ατμοσφαιρικές απώλειες (καθαρός ουρανός): $L_{atm} = 0.8\text{ dB}$

Να υπολογιστούν:
1. Οι απώλειες ελεύθερου χώρου (FSPL) σε $\text{dB}$.
2. Η ισοδύναμη ισότροπα ακτινοβολούμενη ισχύς (EIRP) του δορυφόρου σε $\text{dBW}$ και $\text{dBm}$.
3. Η λαμβανόμενη ισχύς $P_r$ στον επίγειο σταθμό σε $\text{dBm}$ και σε $\text{pW}$ ($10^{-12}\text{ W}$).

### Λύση:
1. **Απώλειες Ελεύθερου Χώρου:**
   $$\text{FSPL (dB)} = 32.44 + 20 \log_{10}(d_{\text{km}}) + 20 \log_{10}(f_{\text{MHz}})$$
   $$\text{FSPL (dB)} = 32.44 + 20 \log_{10}(36000) + 20 \log_{10}(12000)$$
   $$\text{FSPL (dB)} = 32.44 + 91.13 + 81.58 = 205.15\text{ dB}$$

2. **EIRP:**
   $$\text{EIRP (dBm)} = P_t (\text{dBm}) + G_t (\text{dBi}) = 46 + 34 = 80\text{ dBm}$$
   $$\text{EIRP (dBW)} = 80 - 30 = 50\text{ dBW}$$

3. **Λαμβανόμενη Ισχύς $P_r$:**
   $$P_r (\text{dBm}) = \text{EIRP (dBm)} - \text{FSPL (dB)} + G_r (\text{dBi}) - L_{atm} (\text{dB})$$
   $$P_r (\text{dBm}) = 80 - 205.15 + 42 - 0.8 = -83.95\text{ dBm}$$

   Σε Watts:
   $$P_r = 10^{(-83.95 - 30)/10} = 10^{-11.395}\text{ W} = 4.03 \times 10^{-12}\text{ W} = 4.03\text{ pW}$$

## Άσκηση 2: Υπολογισμός 1ης Ζώνης Fresnel και Εμποδίου
### Εκφώνηση:
Σε επίγεια ζεύξη συχνότητας $f = 2.4\text{ GHz}$ συνολικού μήκους $d = 10\text{ km}$, υπάρχει λόφος σε απόσταση $d_1 = 4\text{ km}$ από τον πομπό ($d_2 = 6\text{ km}$).
1. Υπολογίστε την ακτίνα $r_1$ της πρώτης ζώνης Fresnel στη θέση του λόφου.
2. Πόση είναι η ελάχιστη απαιτούμενη απόσταση καθαρού ύψους (Clearance) πάνω από την κορυφή του λόφου ώστε να αποφευχθούν απώλειες διάθλασης ($60\%$ της $r_1$);

### Λύση:
1. **Μήκος κύματος:**
   $$\lambda = \frac{c}{f} = \frac{3 \times 10^8}{2.4 \times 10^9} = 0.125\text{ m}$$
2. **Ακτίνα 1ης Ζώνης Fresnel:**
   $$r_1 = \sqrt{\frac{\lambda \cdot d_1 \cdot d_2}{d_1 + d_2}} = \sqrt{\frac{0.125 \times 4000 \times 6000}{10000}} = \sqrt{\frac{3000000}{10000}} = \sqrt{300} \approx 17.32\text{ m}$$
3. **Ελάχιστη Απαιτούμενη Απόσταση (Clearance):**
   $$\text{Clearance}_{60\%} = 0.6 \times r_1 = 0.6 \times 17.32\text{ m} \approx 10.39\text{ m}$$
