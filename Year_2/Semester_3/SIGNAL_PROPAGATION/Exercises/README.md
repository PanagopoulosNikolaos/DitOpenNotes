## Pedagogical Objectives

1. **Analytical Integration:** Develop competency evaluating surface integrals of angular radiation intensity $U(\theta, \phi)$ over $4\pi$ steradians.
2. **Impedance and Efficiency:** Relate antenna physical dimensions and input resistance to radiated versus ohmic dissipated power.
3. **Phased Array Synthesis:** Formulate array factors for $N$-element antenna arrays and calculate progressive phase excitations required for electronic beam steering.
