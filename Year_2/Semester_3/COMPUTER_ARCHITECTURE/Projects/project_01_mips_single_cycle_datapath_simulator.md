# Εξαμηνιαίο Project 1: Προσομοιωτής Μονοπατιού Δεδομένων MIPS (Single-Cycle MIPS Datapath Simulator)

## 1. Στόχος του Project
Ανάπτυξη ενός λογισμικού προσομοίωσης σε C++ ή Python που υλοποιεί έναν επεξεργαστή MIPS 32-bit μονού κύκλου. Ο προσομοιωτής θα αναγιγνώσκει αρχεία μηχανικού κώδικα (hexadecimal/binary machine code), θα εκτελεί τις εντολές και θα εμφανίζει την κατάσταση των καταχωρητών και της μνήμης σε κάθε κύκλο.

---

## 2. Υποστηριζόμενο Σύνολο Εντολών
Ο προσομοιωτής πρέπει να υποστηρίζει πλήρως τις παρακάτω εντολές:
- **Αριθμητικές / Λογικές (R-Type):** `add`, `addu`, `sub`, `subu`, `and`, `or`, `nor`, `slt`, `sll`, `srl`
- **Εντολές Άμεσης Σταθεράς (I-Type):** `addi`, `addiu`, `andi`, `ori`, `slti`, `lui`
- **Πρόσβασης Μνήμης (I-Type):** `lw`, `sw`, `lb`, `sb`
- **Διακλάδωσης (I-Type):** `beq`, `bne`
- **Άλματος (J-Type & R-Type):** `j`, `jal`, `jr`

---

## 3. Αρχιτεκτονικά Υποσυστήματα προς Υλοποίηση
1. **Instruction Memory (IMEM):** Πίνακας $64\text{ KB}$ για αποθήκευση του εκτελέσιμου δυαδικού αρχείου.
2. **Register File (REG):** 32 καταχωρητές των 32-bit (με τον καταχωρητή `$0` κλειδωμένο στο 0).
3. **Control Unit (CTRL):** Συνδυαστικό κύκλωμα παραγωγής όλων των σημάτων ελέγχου.
4. **Arithmetic Logic Unit (ALU):** Υλοποίηση πράξεων και παραγωγή των flags (Zero flag, Overflow).
5. **Data Memory (DMEM):** Πίνακας $64\text{ KB}$ για αποθήκευση δεδομένων με υποστήριξη ευθυγράμμισης λέξης (word alignment).

---

## 4. Δομή Εξόδου και Παραδοτέα
- **Έξοδος Κονσόλας:** Μετά από κάθε εντολή (κύκλο), εκτύπωση του τρέχοντος $PC$, της εντολής σε assembly format, και των τιμών των τροποποιημένων καταχωρητών.
- **Κώδικας:** Πλήρως τεκμηριωμένος πηγαίος κώδικας σε C++ (με `Makefile`) ή Python (με `requirements.txt`).
- **Σουίτα Δοκιμών (Testbench):** Τουλάχιστον 3 προγράμματα MIPS assembly (π.χ. ταξινόμηση πίνακα, υπολογισμός παραγοντικού, αναζήτηση).
- **Τεχνική Αναφορά:** Ανάλυση αρχιτεκτονικής σχεδίασης, παραδοχές και διαγράμματα ροής.
