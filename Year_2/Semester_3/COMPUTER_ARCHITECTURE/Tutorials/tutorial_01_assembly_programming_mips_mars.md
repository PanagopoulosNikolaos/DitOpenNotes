# Εργαστηριακός Οδηγός 1: Προγραμματισμός σε Συμβολική Γλώσσα MIPS με τον Προσομοιωτή MARS

## 1. Σκοπός Εργαστηρίου
Εξοικείωση με το περιβάλλον προσομοίωσης MARS (MIPS Assembler and Runtime Simulator), τη συγγραφή προγραμμάτων MIPS Assembly, την εκτέλεση βήμα-προς-βήμα (step-by-step execution), την παρακολούθηση καταχωρητών και την κατανόηση των κλήσεων συστήματος (`syscall`).

---

## 2. Βασικές Κλήσεις Συστήματος (MARS Syscalls)

| Λειτουργία | Κωδικός στο `$v0` | Ορίσματα Εισόδου | Αποτέλεσμα / Έξοδος |
|---|---|---|---|
| Print Integer | 1 | `$a0` = ακέραιος προς εκτύπωση | Εμφάνιση στην κονσόλα |
| Print String | 4 | `$a0` = διεύθυνση συμβολοσειράς | Εμφάνιση string |
| Read Integer | 5 | — | `$v0` = ο ακέραιος που πληκτρολογήθηκε |
| Exit Program | 10 | — | Τερματισμός εκτέλεσης |

---

## 3. Εργαστηριακή Άσκηση: Υπολογισμός Παραγοντικού ($n!$)

### 3.1 Περιγραφή
Γράψτε ένα πρόγραμμα σε MIPS assembly που διαβάζει έναν θετικό ακέραιο $n$ από τον χρήστη και υπολογίζει το παραγοντικό του ($n!$) μέσω αναδρομικής ή επαναληπτικής διαδικασίας.

### 3.2 Πλήρης Κώδικας MIPS (Επαναληπτική Υλοποίηση)
```assembly
.data
    prompt:     .asciiz "Eisagete enan thetiko akeraio n: "
    result_msg: .asciiz "To paragontiko n! einai: "
    newline:    .asciiz "\n"

.text
.globl main

main:
    # 1. Εκτύπωση μηνύματος προτροπής
    li   $v0, 4
    la   $a0, prompt
    syscall

    # 2. Ανάγνωση ακεραίου n
    li   $v0, 5
    syscall
    move $s0, $v0        # $s0 = n

    # 3. Αρχικοποίηση μεταβλητών
    li   $s1, 1          # $s1 = result = 1
    li   $t0, 1          # $t0 = counter i = 1

fact_loop:
    bgt  $t0, $s0, print_res   # Αν i > n, έξοδος από το loop
    mul  $s1, $s1, $t0         # result = result * i
    addi $t0, $t0, 1           # i = i + 1
    j    fact_loop

print_res:
    # 4. Εκτύπωση μηνύματος αποτελέσματος
    li   $v0, 4
    la   $a0, result_msg
    syscall

    # 5. Εκτύπωση αποτελέσματος
    li   $v0, 1
    move $a0, $s1
    syscall

    # 6. Εκτύπωση αλλαγής γραμμής
    li   $v0, 4
    la   $a0, newline
    syscall

    # 7. Τερματισμός προγράμματος
    li   $v0, 10
    syscall
```

---

## 4. Βήματα Εκτέλεσης στο MARS
1. Ανοίξτε το MARS (`java -jar Mars.jar`).
2. Δημιουργήστε νέο αρχείο (`File -> New`) και επικολλήστε τον παραπάνω κώδικα.
3. Επιλέξτε **Run -> Assemble** (πλήκτρο `F3`).
4. Παρατηρήστε τα παράθυρα **Registers** (δεξιά) και **Data Segment / Text Segment** (κέντρο).
5. Εκτελέστε το πρόγραμμα βήμα-προς-βήμα (πλήκτρο `F7`) παρακολουθώντας τις αλλαγές στους καταχωρητές `$s0`, `$s1` και `$t0`.
