# Εργαστηριακός Οδηγός 2: Προσομοίωση Διασωλήνωσης και Κρυφής Μνήμης

## 1. Σκοπός Εργαστηρίου
Εργαστηριακή κατανόηση της διασωλήνωσης εντολών, της ανίχνευσης κινδύνων δεδομένων (hazards), της χρήσης προώθησης (forwarding) και της ανάλυσης επιδόσεων κρυφής μνήμης (Hit/Miss rate) με εργαλεία προσομοίωσης αρχιτεκτονικής (όπως το εργαλείο Data Cache Simulator στο MARS / DineroIV).

## 2. Προσομοίωση Διασωλήνωσης και Κινδύνων

### 2.1 Απόσπασμα Κώδικα προς Ανάλυση
Θεωρούμε την ακόλουθη ακολουθία εντολών:
```assembly
I1: lw   $t0, 0($s0)
I2: add  $t1, $t0, $s1
I3: sub  $t2, $s2, $t0
I4: sw   $t1, 4($s0)
```

### 2.2 Διάγραμμα Χρονισμού Χωρίς Forwarding
Χωρίς υποστήριξη Forwarding, η ανάγνωση ενός καταχωρητή στο στάδιο ID μπορεί να γίνει μόνο αφού ολοκληρωθεί η εγγραφή στο στάδιο WB (κύκλος 5).

| Εντολή | CC1 | CC2 | CC3 | CC4 | CC5 | CC6 | CC7 | CC8 | CC9 |
|---|---|---|---|---|---|---|---|---|---|
| I1: `lw` | IF | ID | EX | MEM | WB | | | | |
| I2: `add` | | IF | stall | stall | ID | EX | MEM | WB | |
| I3: `sub` | | | | | IF | ID | EX | MEM | WB |
| I4: `sw` | | | | | | IF | ID | EX | MEM |

*Σημείωση:* Απαιτούνται 2 κύκλοι stall για την I2 ώστε να διαβάσει την τιμή του `$t0` μετά το WB της I1.

### 2.3 Διάγραμμα Χρονισμού Με Forwarding
Με μονάδα Forwarding (MEM/WB -> ALU input):
- Η I1 διαθέτει τα δεδομένα στο τέλος του MEM (CC4).
- Η I2 χρειάζεται τα δεδομένα στην είσοδο του EX (CC4). Επομένως, απαιτείται **μόνο 1 κύκλος stall** (Load-Use delay).

| Εντολή | CC1 | CC2 | CC3 | CC4 | CC5 | CC6 | CC7 | CC8 |
|---|---|---|---|---|---|---|---|---|
| I1: `lw` | IF | ID | EX | MEM | WB | | | |
| I2: `add` | | IF | ID | stall | EX | MEM | WB | |
| I3: `sub` | | | IF | stall | ID | EX | MEM | WB |
| I4: `sw` | | | | | IF | ID | EX | MEM |

## 3. Εργαστηριακή Άσκηση Προσομοίωσης Cache

### 3.1 Ρύθμιση Παραμέτρων Cache
- Μέγεθος Cache: $64\text{ Bytes}$
- Μέγεθος Μπλοκ: $8\text{ Bytes}$
- Οργάνωση: Direct Mapped (Άμεση Χαρτογράφηση)
- Αριθμός Γραμμών: $N = \frac{64}{8} = 8\text{ γραμμές}$
- Κατανομή Bits Διεύθυνσης (16-bit διευθύνσεις):
  - Offset: $\log_2(8) = 3\text{ bits}$ (Bits 0-2)
  - Index: $\log_2(8) = 3\text{ bits}$ (Bits 3-5)
  - Tag: $16 - 3 - 3 = 10\text{ bits}$ (Bits 6-15)

### 3.2 Ακολουθία Προσβάσεων
Υπολογίστε αν οι προσβάσεις είναι Hit ή Miss για τις διευθύνσεις byte: `0x0004`, `0x000C`, `0x0008`, `0x0044`, `0x0004`.

1. `0x0004` (Δυαδικό: `0000 0000 0000 0100`): Tag = 0, Index = 0, Offset = 4 -> **Compulsory Miss** (φορτώνεται μπλοκ 0 στο Set 0).
2. `0x000C` (Δυαδικό: `0000 0000 0000 1100`): Tag = 0, Index = 1, Offset = 4 -> **Compulsory Miss** (φορτώνεται μπλοκ 1 στο Set 1).
3. `0x0008` (Δυαδικό: `0000 0000 0000 1000`): Tag = 0, Index = 1, Offset = 0 -> **Hit** (το μπλοκ 1 βρίσκεται ήδη στο Set 1).
4. `0x0044` (Δυαδικό: `0000 0000 0100 0100`): Tag = 1, Index = 0, Offset = 4 -> **Conflict Miss** (αντικαθιστά το μπλοκ 0 στο Set 0).
5. `0x0004` (Δυαδικό: `0000 0000 0000 0100`): Tag = 0, Index = 0, Offset = 4 -> **Conflict Miss** (είχε αντικατασταθεί).
