# Παραδείγματα: Ανάλυση Διευθύνσεων και Αντιστοίχιση σε Κρυφή Μνήμη

## Παράδειγμα 1: Ανάλυση 32-bit Διεύθυνσης σε 2-way Set Associative Cache

### Δεδομένα Συστήματος:
- Μέγεθος Cache: $32\text{ KB}$
- Block Size: $64\text{ Bytes}$
- Οργάνωση: 2-way Set Associative
- Διεύθυνση Προσπέλασης: `0x7FFF08C4`

### Αναλυτικά Βήματα Επίλυσης:
1. **Υπολογισμός Παραμέτρων:**
   - Πλήθος Blocks = $\frac{32 \times 1024}{64} = 512\text{ blocks}$
   - Πλήθος Sets = $\frac{512}{2} = 256\text{ sets}$
   - Offset bits = $\log_2(64) = 6\text{ bits}$ (Bits 0-5)
   - Index bits = $\log_2(256) = 8\text{ bits}$ (Bits 6-13)
   - Tag bits = $32 - 8 - 6 = 18\text{ bits}$ (Bits 14-31)

2. **Δυαδική Μετατροπή της Διεύθυνσης `0x7FFF08C4`:**
   ```
   7    F    F    F    0    8    C    4
   0111 1111 1111 1111 0000 1000 1100 0100
   ```

3. **Διαχωρισμός Πεδίων:**
   - **Tag (Bits 31-14):** `0111 1111 1111 1111 00` $\rightarrow$ `0x1FFFC`
   - **Index (Bits 13-6):** `00 1000 11` $\rightarrow$ `0010 0011` $\rightarrow$ `0x23` (Δεκαδικό: 35)
   - **Offset (Bits 5-0):** `00 0100` $\rightarrow$ `000100` $\rightarrow$ `0x04` (Δεκαδικό: 4)

4. **Συμπέρασμα:**
   Το δεδομένο της διεύθυνσης `0x7FFF08C4` θα αναζητηθεί στην **Ομάδα (Set) 35** της cache. Αν το Tag `0x1FFFC` ταιριάζει με μία από τις 2 γραμμές του Set 35 και το αντίστοιχο Valid bit είναι `1`, έχουμε Cache Hit και ανακτάται η 4η θέση byte του μπλοκ.
