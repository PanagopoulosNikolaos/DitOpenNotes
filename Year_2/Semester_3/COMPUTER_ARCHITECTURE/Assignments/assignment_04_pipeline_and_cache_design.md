# Εργασία 4: Σχεδιασμός Μονάδας Διασωλήνωσης και Ανάλυση Επιδόσεων Cache

## 1. Περιγραφή Εργασίας
Σκοπός της παρούσας εργασίας είναι η εις βάθος μελέτη των μηχανισμών διασωλήνωσης (pipelining) και των τεχνικών βελτιστοποίησης της ιεραρχίας μνήμης σε επεξεργαστές RISC.

---

## 2. Μέρος Α: Ανάλυση Εξαρτήσεων και Επιτάχυνσης (Speedup)
Δίνεται το παρακάτω τμήμα κώδικα MIPS:
```assembly
loop:
    lw   $t1, 0($s0)
    addi $t2, $t1, 10
    sw   $t2, 0($s0)
    addi $s0, $s0, 4
    bne  $s0, $s1, loop
```

### Ζητούμενα:
1. Εντοπίστε όλες τις εξαρτήσεις δεδομένων τύπου RAW (Read-After-Write).
2. Σχεδιάστε το διάγραμμα ροής εκτέλεσης για 2 επαναλήψεις του βρόχου σε επεξεργαστή 5 σταδίων:
   - Χωρίς μηχανισμό Forwarding.
   - Με πλήρη μηχανισμό Forwarding (EX/MEM -> EX, MEM/WB -> EX).
3. Υπολογίστε το πλήθος κύκλων ανά εντολή (CPI) για τις δύο περιπτώσεις.

---

## 3. Μέρος Β: Σχεδιασμός Κρυφής Μνήμης L1 & L2
Σύστημα επεξεργαστή διαθέτει 32-bit διευθύνσεις και ιεραρχία μνήμης 2 επιπέδων:
- **L1 Cache:** 32 KB, 4-way Set Associative, μέγεθος γραμμής (block size) 64 Bytes, χρόνος προσπέλασης 1 κύκλος, Hit Rate = 94%.
- **L2 Cache:** 512 KB, 8-way Set Associative, μέγεθος γραμμής 64 Bytes, χρόνος προσπέλασης 10 κύκλοι, Local Hit Rate = 80%.
- **Κύρια Μνήμη (Main Memory):** Χρόνος προσπέλασης 120 κύκλοι.

### Ζητούμενα:
1. Υπολογίστε τον αριθμό των bits για τα πεδία Tag, Index και Offset για τις μνήμες L1 και L2.
2. Υπολογίστε το συνολικό μέγεθος υλικού (συμπεριλαμβανομένων των Valid bits, Dirty bits και Tag bits) για την L1 Cache.
3. Υπολογίστε τον Μέσο Χρόνο Πρόσβασης στη Μνήμη (AMAT) σε κύκλους ρολογιού.
