# Πρότυπο Διαγώνισμα Εξάσκησης: Αρχιτεκτονική Υπολογιστών

## Θέμα 1: Αρχιτεκτονική MIPS και Μορφότυπα Εντολών (2.5 Μονάδες)
1. **(1.5 Μονάδες)** Μετατρέψτε το ακόλουθο απόσπασμα C σε αποδοτικό κώδικα MIPS Assembly:
   ```c
   while (arr[i] == k) {
       arr[i] = arr[i] * 2;
       i += 1;
   }
   ```
   (Υποθέστε ότι ο πίνακας `arr` έχει διεύθυνση βάσης στον `$s0`, το `i` βρίσκεται στον `$s1` και το `k` στον `$s2`).
2. **(1.0 Μονάδα)** Εξηγήστε γιατί η εντολή `jal` (Jump and Link) χρησιμοποιεί μορφότυπο J-Type και ποια είναι η λειτουργία του καταχωρητή `$ra` (`$31`).

## Θέμα 2: Σχεδιασμός Datapath και Μονάδα Ελέγχου (2.5 Μονάδες)
1. **(1.5 Μονάδες)** Θεωρήστε τον επεξεργαστή MIPS μονού κύκλου. Ποιες τιμές πρέπει να λάβουν τα σήματα ελέγχου `RegDst`, `ALUSrc`, `MemtoReg`, `RegWrite`, `MemRead`, `MemWrite`, `Branch` για την εντολή `lw $t0, 16($s1)`;
2. **(1.0 Μονάδα)** Αν ο χρόνος καθυστέρησης της μνήμης αυξηθεί κατά $50\text{ ps}$, ποια θα είναι η νέα ελάχιστη περίοδος ρολογιού του συστήματος και ποια εντολή θα επηρεάσει άμεσα;

## Θέμα 3: Διασωλήνωση και Κίνδυνοι (Hazards) (2.5 Μονάδες)
Δίνεται ο παρακάτω βρόχος εντολών:
```assembly
loop:
    lw   $t0, 0($a0)
    add  $t1, $t0, $a1
    sw   $t1, 0($a0)
    addi $a0, $a0, 4
    bne  $a0, $a2, loop
```
1. **(1.5 Μονάδες)** Εντοπίστε όλους τους κινδύνους (hazards) για μία επανάληψη του βρόχου και σχεδιάστε το διάγραμμα σταδίων (IF, ID, EX, MEM, WB) με και χωρίς Data Forwarding.
2. **(1.0 Μονάδα)** Πώς μπορεί ένας compiler (βελτιστοποιητής κώδικα) να αναδιατάξει τις εντολές του βρόχου ώστε να εξαλείψει πλήρως τις καθυστερήσεις τύπου Load-Use;

## Θέμα 4: Οργάνωση Κρυφής Μνήμης (2.5 Μονάδες)
Σύστημα υπολογιστή με διευθύνσεις 32 bits διαθέτει Cache μεγέθους $128\text{ KB}$, 4-way Set Associative, με μέγεθος μπλοκ $64\text{ Bytes}$.
1. **(1.5 Μονάδες)** Υπολογίστε τα bits για τα πεδία Tag, Set Index και Offset.
2. **(1.0 Μονάδα)** Εάν ο επεξεργαστής εκτελεί πρόγραμμα με L1 Miss Rate = $3\%$, L1 Hit Time = $1\text{ κύκλος}$ και Miss Penalty = $80\text{ κύκλοι}$, υπολογίστε τον μέσο χρόνο προσπέλασης μνήμης (AMAT).

---

## Ενδεικτικές Απαντήσεις & Λύσεις

### Λύση Θέματος 1:
```assembly
loop:
    sll  $t0, $s1, 2      # $t0 = i * 4
    add  $t1, $s0, $t0    # $t1 = &arr[i]
    lw   $t2, 0($t1)      # $t2 = arr[i]
    bne  $t2, $s2, exit   # Αν arr[i] != k, έξοδος

    sll  $t2, $t2, 1      # arr[i] * 2 (ολίσθηση αριστερά κατά 1 bit)
    sw   $t2, 0($t1)      # arr[i] = arr[i] * 2
    addi $s1, $s1, 1      # i += 1
    j    loop
exit:
```

### Λύση Θέματος 2:
1. Σήματα ελέγχου για `lw`: `RegDst=0`, `ALUSrc=1`, `MemtoReg=1`, `RegWrite=1`, `MemRead=1`, `MemWrite=0`, `Branch=0`.
2. Η εντολή `lw` διέρχεται από όλα τα στάδια (IF, ID, EX, MEM, WB) και καθορίζει το critical path. Επομένως, η περίοδος ρολογιού θα αυξηθεί κατά $50\text{ ps}$.

### Λύση Θέματος 3:
1. Load-Use hazard μεταξύ `lw $t0` και `add $t1, $t0, $a1`. Με forwarding απαιτείται 1 bubble.
2. Αναδιάταξη κώδικα από τον compiler:
   ```assembly
   loop:
       lw   $t0, 0($a0)
       addi $a0, $a0, 4      # Τοποθετείται ανάμεσα σε lw και add
       add  $t1, $t0, $a1
       sw   $t1, -4($a0)     # Προσαρμογή offset
       bne  $a0, $a2, loop
   ```
   Με την παραπάνω αναδιάταξη εξαλείφεται πλήρως το Load-Use stall!

### Λύση Θέματος 4:
1. Lines = $128\text{ KB} / 64\text{ B} = 2048$. Sets = $2048 / 4 = 512$.
   - Offset = $\log_2(64) = 6\text{ bits}$.
   - Index = $\log_2(512) = 9\text{ bits}$.
   - Tag = $32 - 9 - 6 = 17\text{ bits}$.
2. $\text{AMAT} = 1 + (0.03 \times 80) = 1 + 2.4 = 3.4\text{ κύκλοι ρολογιού}$.
