# Διάλεξη 2: Μονοπάτι Δεδομένων (Datapath) και Μονάδα Ελέγχου (Control Unit)

## 1. Δομή Επεξεργαστή Μονού Κύκλου (Single-Cycle Processor)
Σε έναν επεξεργαστή μονού κύκλου, κάθε εντολή εκτελείται ακριβώς σε έναν κύκλο ρολογιού. Η περίοδος του ρολογιού καθορίζεται από τη μεγαλύτερη διαδρομή καθυστέρησης (critical path), συνήθως την εντολή `lw` (Load Word).

---

## 2. Στάδια Εκτέλεσης Εντολής
Η επεξεργασία κάθε εντολής διέρχεται από 5 βασικά στάδια:
1. **Ανάκληση Εντολής (Instruction Fetch - IF):**
   - Ανάγνωση εντολής από τη μνήμη εντολών στη διεύθυνση που δείχνει ο απαριθμητής προγράμματος ($PC$).
   - Υπολογισμός $PC_{new} = PC + 4$.
2. **Αποκωδικοποίηση & Ανάγνωση Καταχωρητών (Instruction Decode - ID):**
   - Αποκωδικοποίηση των πεδίων της εντολής.
   - Ανάγνωση των τιμών των καταχωρητών πηγής ($rs, rt$) από το Register File.
   - Επέκταση προσήμου (Sign Extension) για τα 16 bits της άμεσης σταθεράς.
3. **Εκτέλεση / Υπολογισμός Διεύθυνσης (Execution - EX):**
   - Χρήση της Αριθμητικής και Λογικής Μονάδας (ALU) για πράξεις, υπολογισμό διεύθυνσης μνήμης ή υπολογισμό συνθήκης διακλάδωσης.
4. **Πρόσβαση στη Μνήμη (Memory Access - MEM):**
   - Ανάγνωση δεδομένων από τη μνήμη δεδομένων (`lw`) ή εγγραφή δεδομένων (`sw`).
5. **Επανεγγραφή Αποτελέσματος (Write Back - WB):**
   - Εγγραφή του αποτελέσματος (από ALU ή μνήμη) στον καταχωρητή προορισμού ($rd$ ή $rt$).

---

## 3. Μονάδα Ελέγχου (Control Unit)
Η μονάδα ελέγχου παράγει τα σήματα ελέγχου βάσει του κωδικού λειτουργίας (opcode) και του πεδίου συνάρτησης (funct).

### 3.1 Πίνακας Σημάτων Ελέγχου
| Εντολή | RegDst | ALUSrc | MemtoReg | RegWrite | MemRead | MemWrite | Branch | ALUOp |
|---|---|---|---|---|---|---|---|---|
| R-Type | 1 | 0 | 0 | 1 | 0 | 0 | 0 | 10 |
| `lw` | 0 | 1 | 1 | 1 | 1 | 0 | 0 | 00 |
| `sw` | X | 1 | X | 0 | 0 | 1 | 0 | 00 |
| `beq` | X | 0 | X | 0 | 0 | 0 | 1 | 01 |

- **RegDst:** Επιλέγει τον καταχωρητή προορισμού (`0` -> $rt$, `1` -> $rd$).
- **ALUSrc:** Επιλέγει τη 2η είσοδο της ALU (`0` -> καταχωρητής 2, `1` -> sign-extended άμεση σταθερά).
- **MemtoReg:** Επιλέγει την τιμή εγγραφής στο Register File (`0` -> αποτέλεσμα ALU, `1` -> δεδομένα μνήμης).
- **RegWrite:** Ενεργοποιεί την εγγραφή στο Register File.
- **MemRead / MemWrite:** Ενεργοποιεί την ανάγνωση/εγγραφή στη μνήμη δεδομένων.
- **Branch:** Ενεργοποιεί τη δυνατότητα διακλάδωσης αν $Zero = 1$ από την ALU.

---

## 4. Κρίσιμη Διαδρομή και Περίοδος Ρολογιού
Έστω οι ακόλουθες καθυστερήσεις μονάδων υλικού:
- Μνήμη Εντολών / Δεδομένων: $200\text{ ps}$
- Register File (Read/Write): $100\text{ ps}$
- ALU και Αθροιστές: $200\text{ ps}$
- Μονάδα Ελέγχου και πολυπλέκτες: $30\text{ ps}$

### Υπολογισμός Χρόνου ανά Εντολή:
- **R-type:** $T_{R} = T_{IF} + T_{ID} + T_{EX} + T_{WB} = 200 + 100 + 200 + 100 = 600\text{ ps}$
- **`sw`:** $T_{sw} = T_{IF} + T_{ID} + T_{EX} + T_{MEM} = 200 + 100 + 200 + 200 = 700\text{ ps}$
- **`lw`:** $T_{lw} = T_{IF} + T_{ID} + T_{EX} + T_{MEM} + T_{WB} = 200 + 100 + 200 + 200 + 100 = 800\text{ ps}$

Σε επεξεργαστή μονού κύκλου, η περίοδος του ρολογιού πρέπει να είναι τουλάχιστον ίση με τη χειρότερη περίπτωση ($T_{lw} = 800\text{ ps}$), οδηγώντας σε υποαξιοποίηση των ταχύτερων εντολών. Αυτός ο περιορισμός επιλύεται με τη χρήση Διασωλήνωσης (Pipelining).
