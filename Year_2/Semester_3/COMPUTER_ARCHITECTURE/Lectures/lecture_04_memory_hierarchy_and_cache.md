# Διάλεξη 4: Ιεραρχία Μνήμης και Κρυφή Μνήμη (Cache Memory)

## 1. Η Αρχή της Τοπικότητας (Principle of Locality)
Η αποδοτικότητα της ιεραρχίας μνήμης βασίζεται σε δύο μορφές τοπικότητας:
1. **Χρονική Τοπικότητα (Temporal Locality):** Εάν μια διεύθυνση μνήμης προσπελαστεί, είναι πολύ πιθανό να προσπελαστεί ξανά σύντομα (π.χ. μεταβλητές σε βρόχους, μετρητές).
2. **Χωρική Τοπικότητα (Spatial Locality):** Εάν μια διεύθυνση μνήμης προσπελαστεί, είναι πολύ πιθανό να προσπελαστούν σύντομα γειτονικές διευθύνσεις (π.χ. διαδοχικά στοιχεία πίνακα, διαδοχικές εντολές προγράμματος).

---

## 2. Ιεραρχία Μνήμης (Memory Hierarchy)
Η ιεραρχία οργανώνεται σε επίπεδα, από τα ταχύτερα και ακριβότερα στα πιο αργά και οικονομικά:
1. Καταχωρητές Επεξεργαστή (Registers) — < 1 ns, μερικά KB
2. Επίπεδο L1 Cache — 1-2 ns, δεκάδες KB
3. Επίπεδο L2 Cache — 3-10 ns, εκατοντάδες KB έως λίγα MB
4. Επίπεδο L3 Cache (κοινή για όλους τους πυρήνες) — 10-20 ns, δεκάδες MB
5. Κύρια Μνήμη (Main Memory - DRAM) — 50-100 ns, δεκάδες GB
6. Δευτερεύουσα Μνήμη (SSD / HDD) — ms / μs, TBs

---

## 3. Οργάνωση Κρυφής Μνήμης (Cache Mapping Techniques)

Μια διεύθυνση μνήμης 32-bit διαιρείται σε 3 πεδία:
```
+-------------------+-------------------+-------------------+
|    Tag (Ετικέτα)  |   Index (Δείκτης) |  Offset (Μετατόπιση)|
+-------------------+-------------------+-------------------+
```

### 3.1 Άμεση Χαρτογράφηση (Direct Mapped Cache)
- Κάθε μπλοκ της κύριας μνήμης αντιστοιχίζεται σε ακριβώς μία συγκεκριμένη γραμμή της cache.
$$\text{Line Index} = (\text{Block Address}) \pmod{\text{Total Cache Lines}}$$
- **Πλεονέκτημα:** Απλή και πολύ γρήγορη αναζήτηση.
- **Μειονέκτημα:** Υψηλό ποσοστό συγκρούσεων (conflict misses).

### 3.2 Πλήρως Συσχετιστική Μνήμη (Fully Associative Cache)
- Ένα μπλοκ μπορεί να τοποθετηθεί σε οποιαδήποτε γραμμή της cache.
- **Πλεονέκτημα:** Ελαχιστοποίηση conflict misses.
- **Μειονέκτημα:** Ακριβό κύκλωμα παράλληλης σύγκρισης όλων των Tags.

### 3.3 Συσχετιστική κατά Ομάδες (N-way Set Associative Cache)
- Η cache χωρίζεται σε $S$ ομάδες (sets), όπου κάθε ομάδα περιέχει $N$ γραμμές (ways).
$$\text{Set Index} = (\text{Block Address}) \pmod{S}$$
- Αποτελεί τη χρυσή τομή μεταξύ κόστους, ταχύτητας και απόδοσης (π.χ. 2-way, 4-way, 8-way).

## 4. Πολιτικές Εγγραφής (Write Policies)

### 4.1 Write-Through vs. Write-Back
- **Write-Through:** Κάθε εγγραφή ενημερώνει ταυτόχρονα την cache και την κύρια μνήμη (χρήση write buffer για μείωση καθυστέρησης).
- **Write-Back:** Η εγγραφή γίνεται μόνο στην cache. Η κύρια μνήμη ενημερώνεται μόνο όταν το μπλοκ αντικατασταθεί (χρήση Dirty Bit).

### 4.2 Write Allocate vs. No-Write Allocate
- **Write Allocate:** Σε περίπτωση write miss, το μπλοκ φορτώνεται στην cache και ακολουθεί η εγγραφή.
- **No-Write Allocate:** Σε write miss, η εγγραφή γίνεται απευθείας στην κύρια μνήμη χωρίς φόρτωση στην cache.

## 5. Μέση Χρονική Καθυστέρηση Πρόσβασης (AMAT)
$$\text{AMAT} = \text{Hit Time} + (\text{Miss Rate} \times \text{Miss Penalty})$$

### Παράδειγμα:
- $\text{Hit Time} = 1\text{ κύκλος}$
- $\text{Miss Rate} = 5\% = 0.05$
- $\text{Miss Penalty} = 100\text{ κύκλοι}$
$$\text{AMAT} = 1 + (0.05 \times 100) = 1 + 5 = 6\text{ κύκλοι}$$
