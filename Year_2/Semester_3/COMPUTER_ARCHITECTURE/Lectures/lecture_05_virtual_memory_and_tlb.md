# Διάλεξη 05: Εικονική Μνήμη και Μονάδα Μετάφρασης Διευθύνσεων (TLB)

## 1. Εισαγωγή στην Εικονική Μνήμη (Virtual Memory)
Η εικονική μνήμη επιτρέπει την εκτέλεση προγραμμάτων των οποίων ο λογικός χώρος διευθύνσεων υπερβαίνει τη διαθέσιμη φυσική μνήμη RAM. Επιπλέον, παρέχει απομόνωση και προστασία μεταξύ διεργασιών.

- **Εικονική Διεύθυνση (Virtual Address - VA):** Παράγεται από την CPU κατά την εκτέλεση εντολών.
- **Φυσική Διεύθυνση (Physical Address - PA):** Η πραγματική διεύθυνση στα ολοκληρωμένα κυκλώματα της RAM.
- **Σελίδες (Pages):** Μπλοκ σταθερού μεγέθους στον εικονικό χώρο (συνήθως 4 KB).
- **Πλαίσια Σελίδων (Page Frames):** Μπλοκ αντίστοιχου μεγέθους στη φυσική μνήμη.

---

## 2. Πίνακες Σελίδων (Page Tables)
Ο Πίνακας Σελίδων είναι η δομή δεδομένων που αντιστοιχίζει έναν Εικονικό Αριθμό Σελίδας (VPN) σε έναν Φυσικό Αριθμό Πλαισίου (PFN).

- **Διάσπαση Εικονικής Διεύθυνσης (για σελίδες 4 KB = $2^{12}$ B):**
  - **Offset:** 12 bits (αμετάβλητο κατά τη μετάφραση).
  - **Virtual Page Number (VPN):** Τα υπόλοιπα $32 - 12 = 20\text{ bits}$ (σε 32-bit αρχιτεκτονική).
- **Περιεχόμενα Εγγραφής Πίνακα Σελίδων (PTE):**
  - Physical Frame Number (PFN)
  - Valid bit (1 αν η σελίδα βρίσκεται στη RAM, 0 αν είναι στο δίσκο)
  - Dirty/Modified bit (ένδειξη αν έγινε εγγραφή)
  - Reference/Access bit (για αλγορίθμους αντικατάστασης, π.χ. LRU)
  - Protection/Permission bits (Read, Write, Execute)

---

## 3. Translation Lookaside Buffer (TLB)
Η αναζήτηση στον πίνακα σελίδων απαιτεί επιπλέον πρόσβαση στη μνήμη RAM. Για την επιτάχυνση, χρησιμοποιείται η **TLB**, μια μικρή, ταχύτατη associative cache για πρόσφατες μεταφράσεις διευθύνσεων.

- **TLB Hit:** Η μετάφραση VPN $\to$ PFN βρίσκεται στην TLB (χρόνος: 1 κύκλος).
- **TLB Miss:** Απαιτείται Page Table Walk για εύρεση του PTE στη μνήμη RAM (ή χειρισμός από λειτουργικό σύστημα / hardware).
- **Page Fault (Σφάλμα Σελίδας):** Το Valid bit του PTE είναι 0. Η σελίδα πρέπει να μεταφερθεί από το δίσκο στη RAM (διακοπή λειτουργικού συστήματος, χρόνος: εκατομμύρια κύκλοι).

---

## 4. Αποτελεσματικός Χρόνος Πρόσβασης (EAT)
Αν $t_{\text{TLB}}$ είναι ο χρόνος πρόσβασης στην TLB, $t_{\text{RAM}}$ ο χρόνος RAM και $h_{\text{TLB}}$ το ποσοστό επιτυχίας:
$$\text{EAT} = h_{\text{TLB}} \cdot (t_{\text{TLB}} + t_{\text{RAM}}) + (1 - h_{\text{TLB}}) \cdot (t_{\text{TLB}} + 2 \cdot t_{\text{RAM}})$$
