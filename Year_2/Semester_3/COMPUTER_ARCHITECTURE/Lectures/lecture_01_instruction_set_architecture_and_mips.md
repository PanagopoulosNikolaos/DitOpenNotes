# Διάλεξη 1: Αρχιτεκτονική Συνόλου Εντολών (ISA) και Αρχιτεκτονική MIPS

## 1. Εισαγωγή στην Αρχιτεκτονική Συνόλου Εντολών (ISA)
Η Αρχιτεκτονική Συνόλου Εντολών (Instruction Set Architecture - ISA) αποτελεί τη διεπαφή (interface) μεταξύ του υλικού (hardware) και του λογισμικού (software). Καθορίζει τον τρόπο με τον οποίο ο επεξεργαστής εκτελεί εντολές, διαχειρίζεται τη μνήμη και αλληλεπιδρά με τους καταχωρητές.

### 1.1 Βασικά Χαρακτηριστικά ISA
- **Μοντέλο Καταχωρητών (Register Set):** Αριθμός, μέγεθος και ρόλος των καταχωρητών γενικού και ειδικού σκοπού.
- **Τρόποι Διευθυνσιοδότησης (Addressing Modes):** Άμεση (Immediate), Άμεση Καταχωρητή (Register Direct), Έμμεση Βάσης (Base/Displacement), Σχετική με PC (PC-relative).
- **Τύποι Δεδομένων:** Ακέραιοι (8-bit, 16-bit, 32-bit, 64-bit), Κινητής Υποδιαστολής (IEEE 754).
- **Μορφότυπα Εντολών (Instruction Formats):** Σταθερού ή μεταβλητού μήκους.

---

## 2. RISC vs. CISC
| Χαρακτηριστικό | RISC (Reduced Instruction Set Computer) | CISC (Complex Instruction Set Computer) |
|---|---|---|
| Μήκος Εντολών | Σταθερό (συνήθως 32 bits) | Μεταβλητό (1 έως 15 bytes) |
| Πρόσβαση στη Μνήμη | Μόνο μέσω εντολών Load/Store | Άμεση πρόσβαση από αριθμητικές εντολές |
| Χρόνος Εκτέλεσης Εντολής | 1 κύκλος ρολογιού (σε ιδανική διασωλήνωση) | Πολλαπλοί κύκλοι ανά εντολή |
| Καταχωρητές | Μεγάλος αριθμός (π.χ. 32 καταχωρητές) | Περιορισμένος αριθμός |
| Παραδείγματα | MIPS, ARM, RISC-V | x86, x86-64 |

---

## 3. Η Αρχιτεκτονική MIPS 32-bit
Ο MIPS32 είναι μια κλασική αρχιτεκτονική RISC τύπου Load-Store.

### 3.1 Καταχωρητές MIPS
Ο MIPS διαθέτει 32 καταχωρητές γενικού σκοπού 32-bit (`$0` έως `$31`):
- `$zero` (`$0`): Πάντα διατηρεί την τιμή 0 (hardwired to 0).
- `$v0 - $v1` (`$2 - $3`): Τιμές επιστροφής συναρτήσεων και κωδικοί κλήσεων συστήματος (syscalls).
- `$a0 - $a3` (`$4 - $7`): Ορίσματα συναρτήσεων.
- `$t0 - $t9` (`$8-$15`, `$24-$25`): Προσωρινοί καταχωρητές (caller-saved).
- `$s0 - $s7` (`$16 - $23`): Αποθηκευμένοι καταχωρητές (callee-saved).
- `$gp` (`$28`), `$sp` (`$29`), `$fp` (`$30`), `$ra` (`$31`): Global Pointer, Stack Pointer, Frame Pointer, Return Address.

## 4. Μορφότυπα Εντολών MIPS (Instruction Formats)
Κάθε εντολή MIPS έχει μέγεθος ακριβώς 32 bits (4 bytes).

### 4.1 R-Type (Register Format)
Χρησιμοποιείται για αριθμητικές και λογικές πράξεις μεταξύ καταχωρητών.

| opcode (6 bits) | rs (5 bits) | rt (5 bits) | rd (5 bits) | shamt (5 bits) | funct (6 bits) |
|---|---|---|---|---|---|
| `000000` | Πηγή 1 | Πηγή 2 | Προορισμός | Shift Amount | Συνάρτηση πράξης |

- Παράδειγμα: `add $t0, $s1, $s2` -> `$t0 = $s1 + $s2`

### 4.2 I-Type (Immediate Format)
Χρησιμοποιείται για πράξεις με άμεση σταθερά, εντολές Load/Store και διακλαδώσεις υπό συνθήκη.

| opcode (6 bits) | rs (5 bits) | rt (5 bits) | immediate / offset (16 bits) |
|---|---|---|---|
| Κωδικός λειτουργίας | Καταχωρητής βάσης/πηγής | Καταχωρητής προορισμού/ελέγχου | Σταθερά 16-bit (σημοδοτημένη) |

- Παράδειγμα 1: `addi $t0, $s0, 4` -> `$t0 = $s0 + 4`
- Παράδειγμα 2: `lw $t1, 8($s0)` -> `$t1 = Memory[$s0 + 8]`
- Παράδειγμα 3: `beq $t0, $t1, label` -> Διακλάδωση αν `$t0 == $t1`

### 4.3 J-Type (Jump Format)
Χρησιμοποιείται για άλματα άνευ όρων.

| opcode (6 bits) | address (26 bits) |
|---|---|
| `000010` (j) ή `000011` (jal) | Διεύθυνση προορισμού (ψευδο-άμεση) |

- Η διεύθυνση στόχου υπολογίζεται ως: `Target = (PC + 4)[31:28] || (address << 2)`

## 5. Παράδειγμα Μετάφρασης C σε MIPS Assembly

### Κώδικας C:
```c
int array[10];
int sum = 0;
for (int i = 0; i < 10; i++) {
    sum += array[i];
}
```

### Ισοδύναμος Κώδικας MIPS:
```assembly
# $s0: διεύθυνση βάσης του array
# $s1: sum
# $t0: i

        li   $s1, 0           # sum = 0
        li   $t0, 0           # i = 0
        li   $t1, 10          # όριο επανάληψης = 10

loop:
        slt  $t2, $t0, $t1    # $t2 = 1 αν i < 10, αλλιώς 0
        beq  $t2, $zero, end  # αν i >= 10, έξοδος από το loop

        sll  $t3, $t0, 2      # $t3 = i * 4 (offset σε bytes)
        add  $t4, $s0, $t3    # $t4 = &array[i]
        lw   $t5, 0($t4)      # $t5 = array[i]

        add  $s1, $s1, $t5    # sum += array[i]
        addi $t0, $t0, 1      # i++
        j    loop

end:
```
