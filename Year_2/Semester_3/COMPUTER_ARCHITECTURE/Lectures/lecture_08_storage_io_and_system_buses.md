# Διάλεξη 08: Συστήματα Αποθήκευσης, Είσοδος/Έξοδος (I/O) και Δίαυλοι

## 1. Ιεραρχία Δευτερεύουσας Αποθήκευσης
Η δευτερεύουσα αποθήκευση διατηρεί δεδομένα μόνιμα (non-volatile) με πολύ μεγαλύτερη χωρητικότητα αλλά χαμηλότερη ταχύτητα από τη RAM.

- **Μαγνητικοί Δίσκοι (HDDs):**
  - Μηχανικά μέρη: κεφαλές ανάγνωσης/εγγραφής, πλατό (platters), άξονας περιστροφής.
  - Χρόνος Προσπέλασης: $\text{Access Time} = \text{Seek Time} + \text{Rotational Latency} + \text{Transfer Time}$.
- **Μνήμες Στερεάς Κατάστασης (SSDs - NAND Flash):**
  - Ηλεκτρονική αποθήκευση χωρίς κινητά μέρη.
  - Δομή: Σελίδες (pages, π.χ. 4-16 KB) και Μπλοκ (blocks, π.χ. 128-512 σελίδες).
  - Περιορισμός: Η εγγραφή απαιτεί προηγούμενη διαγραφή σε επίπεδο ολόκληρου μπλοκ (Erase-before-Write).
  - Flash Translation Layer (FTL): Αναλαμβάνει Wear Leveling και Garbage Collection.

## 2. Μηχανισμοί Επικοινωνίας Εισόδου/Εξόδου (I/O)
- **Προγραμματισμένη Ε/Ε (Polling / Programmed I/O):**
  - Η CPU ελέγχει συνεχώς σε βρόχο την κατάσταση της συσκευής (Status Register).
  - Απλό στην υλοποίηση, αλλά σπαταλά υπολογιστικούς κύκλους CPU (Busy-Waiting).
- **Ε/Ε Κατευθυνόμενη από Διακοπές (Interrupt-Driven I/O):**
  - Η CPU αναθέτει την εργασία στη συσκευή και συνεχίζει άλλες εργασίες.
  - Η συσκευή παράγει σήμα διακοπής (Interrupt Request - IRQ) όταν τα δεδομένα είναι έτοιμα.
  - Ο επεξεργαστής εκτελεί τον αντίστοιχο χειριστή διακοπής (Interrupt Service Routine - ISR).
- **Άμεση Πρόσβαση στη Μνήμη (Direct Memory Access - DMA):**
  - Ένας εξειδικευμένος ελεγκτής DMA μεταφέρει μπλοκ δεδομένων απευθείας μεταξύ συσκευής και κύριας μνήμης RAM, χωρίς διαρκή παρέμβαση της CPU.
  - Η CPU ειδοποιείται μέσω μίας διακοπής μόνο κατά την ολοκλήρωση ολόκληρης της μεταφοράς.

## 3. Δίαυλοι Συστήματος και Διασυνδέσεις (System Buses & Interconnects)
- **Παράλληλοι vs. Σειριακοί Δίαυλοι:**
  - Οι παλαιότεροι παράλληλοι δίαυλοι (π.χ. PCI, ATA) περιόριζαν τη συχνότητα λόγω clock skew και παρεμβολών (cross-talk).
  - Οι σύγχρονες διασυνδέσεις (PCIe, SATA, USB) χρησιμοποιούν point-to-point διαφορικές σειριακές συνδέσεις υψηλής ταχύτητας (differential signaling) με πολλαπλές λωρίδες (lanes).
- **Πρωτόκολλο PCI Express (PCIe):**
  - Αρχιτεκτονική στρωμάτων: Transaction Layer, Data Link Layer, Physical Layer.
  - Κλιμάκωση εύρους ζώνης με λωρίδες ($x1, x4, x8, x16$).
