# Ασκήσεις Εμπέδωσης: Συμβολική Γλώσσα MIPS και Κωδικοποίηση Εντολών

## Άσκηση 1: Κωδικοποίηση Εντολής R-Type σε Δεκαεξαδικό
### Εκφώνηση:
Δίνεται η εντολή MIPS:
```assembly
sub $t0, $s1, $s2
```
Γνωρίζοντας ότι:
- Opcode για R-Type: `000000` ($0x00$)
- Funct για `sub`: `100010` ($0x22$)
- `$t0` είναι ο καταχωρητής `$8` (`01000`)
- `$s1` είναι ο καταχωρητής `$17` (`10001`)
- `$s2` είναι ο καταχωρητής `$18` (`10010`)
- `shamt`: `00000`

Να βρεθεί η 32-bit δυαδική και η 8-ψήφια δεκαεξαδική αναπαράσταση της εντολής στη μνήμη.

### Λύση:
1. Διάταξη πεδίων R-Type: `opcode (6) | rs (5) | rt (5) | rd (5) | shamt (5) | funct (6)`
2. Αντικατάσταση τιμών:
   - `opcode` = `000000`
   - `rs` (`$s1`) = `10001`
   - `rt` (`$s2`) = `10010`
   - `rd` (`$t0`) = `01000`
   - `shamt` = `00000`
   - `funct` = `100010`
3. Συνένωση δυαδικών ψηφίων (32 bits):
   `000000 10001 10010 01000 00000 100010`
   Ομαδοποίηση ανά 4 bits:
   `0000 0010 0011 0010 0100 0000 0010 0010`
4. Μετατροπή σε δεκαεξαδική μορφή:
   - `0000` -> `0`
   - `0010` -> `2`
   - `0011` -> `3`
   - `0010` -> `2`
   - `0100` -> `4`
   - `0000` -> `0`
   - `0010` -> `2`
   - `0010` -> `2`
   **Αποτέλεσμα:** `0x02324022`

## Άσκηση 2: Υπολογισμός Offset Διακλάδωσης (I-Type Branch Offset)
### Εκφώνηση:
Έστω ότι η εντολή `beq $s0, $s1, target` βρίσκεται στη διεύθυνση μνήμης `0x00400014` και η ετικέτα `target` βρίσκεται στη διεύθυνση `0x00400030`. Ποια τιμή (σε δεκαδική και δεκαεξαδική μορφή) θα τοποθετηθεί στο πεδίο `immediate` (16 bits) της εντολής `beq`;

### Λύση:
1. Ο τύπος υπολογισμού της διεύθυνσης στόχου σε διακλάδωση MIPS είναι:
   $$\text{Target Address} = (PC + 4) + (\text{offset} \times 4)$$
2. Στη φάση ID της `beq`, ο $PC$ έχει ήδη αυξηθεί κατά 4:
   $$PC + 4 = \text{0x00400014} + 4 = \text{0x00400018}$$
3. Η διαφορά διευθύνσεων σε bytes είναι:
   $$\Delta = \text{0x00400030} - \text{0x00400018} = 48 - 24 = 24\text{ bytes}$$
4. Ο αριθμός των λέξεων (offset) είναι:
   $$\text{offset} = \frac{24}{4} = 6\text{ λέξεις}$$
5. Σε δεκαεξαδική μορφή 16-bit: `0x0006`.
