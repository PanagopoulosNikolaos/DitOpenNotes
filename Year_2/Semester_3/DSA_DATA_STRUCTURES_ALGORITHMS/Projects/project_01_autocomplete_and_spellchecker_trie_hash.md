# Εξαμηνιαίο Project 1: Μηχανή Αυτόματης Συμπλήρωσης και Ορθογραφικού Ελέγχου με Χρήση Trie και Hash Table

## 1. Στόχος του Project
Σχεδιασμός και υλοποίηση σε C++ ή Python μιας ολοκληρωμένης μηχανής αυτόματης συμπλήρωσης κειμένου (Autocomplete System) και προτάσεων διόρθωσης ορθογραφίας (Spellchecker), ικανής να επεξεργάζεται λεξικά δεκάδων χιλιάδων λέξεων με υπολογιστική απόκριση πραγματικού χρόνου ($< 5\text{ ms}$).

---

## 2. Απαιτούμενες Δομές Δεδομένων & Αλγόριθμοι
1. **Δέντρο Προθεμάτων (Trie / Prefix Tree):**
   - Γρήγορη εισαγωγή λέξεων και συχνοτήτων εμφάνισης.
   - Εύρεση όλων των λέξεων που μοιράζονται κοινό πρόθεμα $P$ σε χρόνο $O(|P| + k)$, όπου $k$ το πλήθος των αποτελεσμάτων.
2. **Ουρά Προτεραιότητας (Min-Heap / Max-Heap):**
   - Επιλογή των Top-K πιο συχνών λέξεων για το autocomplete.
3. **Αλγόριθμος Απόστασης Levenshtein (Edit Distance) με Δυναμικό Προγραμματισμό:**
   - Για λέξεις με τυπογραφικά λάθη, αναζήτηση προτάσεων με edit distance $\le 2$.
4. **Πίνακας Κατακερματισμού (Hash Table):**
   - Άμεσος έλεγχος ύπαρξης λέξης στο λεξικό σε $O(1)$.

---

## 3. Λειτουργικές Απαιτήσεις
- **Φόρτωση Λεξικού:** Ανάγνωση αρχείου κειμένου (π.χ. `dictionary.txt` με ζεύγη `λέξη συχνότητα`).
- **Διεπαφή CLI:**
  - Εντολή `search <prefix>`: Εμφάνιση των 5 πιο δημοφιλών λέξεων που ξεκινούν με το πρόθεμα.
  - Εντολή `check <word>`: Έλεγχος ορθότητας και εμφάνιση προτεινόμενων διορθώσεων αν είναι λανθασμένη.
  - Εντολή `insert <word>`: Δυναμική προσθήκη νέας λέξης.
  - Εντολή `benchmark`: Μέτρηση χρόνου εκτέλεσης 10.000 αναζητήσεων και μέτρηση χρήσης μνήμης RAM.
