# Data Structures and Algorithms: Curated Resources and Reference Guide

A curated reference guide of core textbooks, visualization platforms, algorithmic problem repositories, and standard documentation for Data Structures and Algorithms (Course Code 305).

---

## 1. Foundational Textbooks

- **Introduction to Algorithms (CLRS)**  
  *Authors:* Thomas H. Cormen, Charles E. Leiserson, Ronald L. Rivest, and Clifford Stein.  
  *Annotation:* The global standard reference for rigorous asymptotic proofs, divide-and-conquer recurrences, advanced tree structures, amortized analysis, and graph theory.

- **Data Structures and Algorithm Analysis in C++**  
  *Author:* Mark Allen Weiss.  
  *Annotation:* Outstanding undergraduate textbook providing clean C++ implementations of balanced trees, priority queues, hashing, sorting networks, and disjoint set structures.

- **The Algorithm Design Manual**  
  *Author:* Steven S. Skiena.  
  *Annotation:* A practical engineering guide with emphasis on algorithm modeling, cataloging standard algorithmic problems, and practical implementation trade-offs.

---

## 2. Interactive Visualizations and Learning Tools

- **VisuAlgo**  
  *URL:* `https://visualgo.net/`  
  *Description:* Interactive step-by-step animations of sorting algorithms, BST and AVL tree rotations, graph traversals, Dijkstra, and minimum spanning trees.

- **USFCA Data Structure Visualizations (David Galles)**  
  *URL:* `https://www.cs.usfca.edu/~galles/visualization/Algorithms.html`  
  *Description:* Intuitive visual simulations of open-addressing hash tables, heaps, B-Trees, and AVL trees.

---

## 3. Reference Standards and Libraries

- **C++ Standard Template Library (STL) Reference**  
  *URL:* `https://en.cppreference.com/w/cpp/container`  
  *Description:* Authoritative specification of container complexities, iterator invariants, and memory models for `std::vector`, `std::list`, `std::map`, `std::unordered_map`, and `std::priority_queue`.
