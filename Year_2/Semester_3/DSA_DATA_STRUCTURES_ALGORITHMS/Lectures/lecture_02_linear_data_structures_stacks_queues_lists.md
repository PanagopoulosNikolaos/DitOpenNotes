# Διάλεξη 2: Γραμμικές Δομές Δεδομένων (Πίνακες, Συνδεδεμένες Λίστες, Στοίβες, Ουρές)

## 1. Συνδεδεμένες Λίστες (Linked Lists)
Μια συνδεδεμένη λίστα είναι μια δυναμική γραμμική δομή δεδομένων αποτελούμενη από κόμβους. Κάθε κόμβος περιέχει το στοιχείο δεδομένων και έναν δείκτη (pointer) στον επόμενο κόμβο.

### 1.1 Μονά vs. Διπλά Συνδεδεμένες Λίστες
- **Μονά Συνδεδεμένη (Singly Linked List):** Κάθε κόμβος έχει δείκτη `next`.
- **Διπλά Συνδεδεμένη (Doubly Linked List):** Κάθε κόμβος έχει δείκτες `next` και `prev`, επιτρέποντας αμφίδρομη διάσχιση.
- **Κυκλική Λίστα (Circular Linked List):** Ο τελευταίος κόμβος δείχνει ξανά στον πρώτο (head).

### 1.2 Χρονική Πολυπλοκότητα Πράξεων:
| Πράξη | Πίνακας (Array) | Μονά Συνδεδεμένη Λίστα |
|---|---|---|
| Πρόσβαση βάσει δείκτη (Index Access) | $O(1)$ | $O(n)$ |
| Εισαγωγή στην αρχή (Prepend) | $O(n)$ | $O(1)$ |
| Εισαγωγή στο τέλος (Append) | $O(1)$ amortized | $O(1)$ (με tail pointer) |
| Διαγραφή γνωστού κόμβου | $O(n)$ | $O(1)$ (σε doubly linked list) |
| Αναζήτηση στοιχείου | $O(n)$ ($O(\log n)$ αν είναι ταξινομημένος) | $O(n)$ |

## 2. Στοίβα (Stack - LIFO: Last-In, First-Out)
Δομή όπου η εισαγωγή και η εξαγωγή στοιχείων πραγματοποιούνται αποκλειστικά από την κορυφή (Top).

### 2.1 Βασικές Πράξεις:
- `push(x)`: Εισαγωγή στοιχείου $x$ στην κορυφή ($O(1)$).
- `pop()`: Αφαίρεση και επιστροφή του κορυφαίου στοιχείου ($O(1)$).
- `top()` / `peek()`: Επιστροφή κορυφαίου στοιχείου χωρίς αφαίρεση ($O(1)$).
- `isEmpty()`: Έλεγχος αν η στοίβα είναι κενή ($O(1)$).

### 2.2 Εφαρμογές:
- Αξιολόγηση και μετατροπή εκφράσεων (Infix σε Postfix).
- Διαχείριση κλήσεων συναρτήσεων (Call Stack).
- Αναίρεση πράξεων (Undo mechanism).
- Έλεγχος ισορροπίας παρενθέσεων (Bracket matching).

---

## 3. Ουρά (Queue - FIFO: First-In, First-Out)
Δομή όπου η εισαγωγή γίνεται στο τέλος (Rear/Tail) και η εξαγωγή από την αρχή (Front/Head).

### 3.1 Βασικές Πράξεις:
- `enqueue(x)`: Εισαγωγή στοιχείου $x$ στο πίσω μέρος ($O(1)$).
- `dequeue()`: Αφαίρεση και επιστροφή του στοιχείου από την αρχή ($O(1)$).
- `front()`: Επιστροφή πρώτου στοιχείου ($O(1)$).

### 3.2 Κυκλικός Πίνακας (Circular Array Queue):
Για αποφυγή μετακίνησης στοιχείων κατά το `dequeue`, χρησιμοποιείται modulo αριθμητική:
$$\text{rear} = (\text{rear} + 1) \pmod{\text{Capacity}}$$
$$\text{front} = (\text{front} + 1) \pmod{\text{Capacity}}$$
