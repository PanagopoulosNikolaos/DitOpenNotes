## Άσκηση 1: Εφαρμογή Αλγορίθμου Dijkstra
### Εκφώνηση:
Δίνεται κατευθυνόμενος βεβαρημένος γράφος με κορυφές $V = \{A, B, C, D, E\}$ και ακμές:
- $(A, B) = 6$, $(A, D) = 1$
- $(D, B) = 2$, $(D, E) = 1$
- $(B, E) = 2$, $(B, C) = 5$
- $(E, C) = 5$

Να υπολογιστούν τα συντομότερα μονοπάτια και οι αποστάσεις από την κορυφή-πηγή $A$ προς όλες τις κορυφές αναλυτικά ανά βήμα του αλγορίθμου Dijkstra.

### Λύση:
1. **Αρχικοποίηση:**
   - $d[A] = 0, \quad d[B] = \infty, \quad d[C] = \infty, \quad d[D] = \infty, \quad d[E] = \infty$
   - $Visited = \emptyset$

2. **Βήμα 1:**
   - Επιλογή κορυφής με ελάχιστη απόσταση: **$A$** ($d[A] = 0$).
   - $Visited = \{A\}$.
   - Χαλάρωση ακμών από $A$:
     - $d[B] = \min(\infty, 0 + 6) = 6$ (μέσω $A$)
     - $d[D] = \min(\infty, 0 + 1) = 1$ (μέσω $A$)

3. **Βήμα 2:**
   - Επιλογή κορυφής: **$D$** ($d[D] = 1$).
   - $Visited = \{A, D\}$.
   - Χαλάρωση ακμών από $D$:
     - $d[B] = \min(6, 1 + 2) = 3$ (μέσω $D$)
     - $d[E] = \min(\infty, 1 + 1) = 2$ (μέσω $D$)

4. **Βήμα 3:**
   - Επιλογή κορυφής: **$E$** ($d[E] = 2$).
   - $Visited = \{A, D, E\}$.
   - Χαλάρωση ακμών από $E$:
     - $d[C] = \min(\infty, 2 + 5) = 7$ (μέσω $E$)

5. **Βήμα 4:**
   - Επιλογή κορυφής: **$B$** ($d[B] = 3$).
   - $Visited = \{A, D, E, B\}$.
   - Χαλάρωση ακμών από $B$:
     - $d[C] = \min(7, 3 + 5) = 7$ (παραμένει 7)
     - $d[E] = \min(2, 3 + 2) = 2$ (παραμένει 2)

6. **Βήμα 5:**
   - Επιλογή κορυφής: **$C$** ($d[C] = 7$).
   - $Visited = \{A, D, E, B, C\}$. Ολοκλήρωση.

**Τελικές Ελάχιστες Αποστάσεις και Μονοπάτια:**
- $A \rightarrow A$: Κόστος $0$, Μονοπάτι: $[A]$
- $A \rightarrow D$: Κόστος $1$, Μονοπάτι: $[A, D]$
- $A \rightarrow E$: Κόστος $2$, Μονοπάτι: $[A, D, E]$
- $A \rightarrow B$: Κόστος $3$, Μονοπάτι: $[A, D, B]$
- $A \rightarrow C$: Κόστος $7$, Μονοπάτι: $[A, D, E, C]$

## Άσκηση 2: Κατασκευή MST με Αλγόριθμο Kruskal
### Εκφώνηση:
Δίνεται μη κατευθυνόμενος γράφος με ακμές και βάρη:
$(A, B): 4, \quad (A, C): 2, \quad (B, C): 1, \quad (B, D): 5, \quad (C, D): 8, \quad (C, E): 10, \quad (D, E): 2, \quad (D, F): 6, \quad (E, F): 3$

Να κατασκευαστεί το Ελάχιστο Συνδετικό Δέντρο (MST) με τον αλγόριθμο Kruskal.

### Λύση:
1. **Ταξινόμηση ακμών κατά αύξον βάρος:**
   1. $(B, C): 1$
   2. $(A, C): 2$
   3. $(D, E): 2$
   4. $(E, F): 3$
   5. $(A, B): 4$
   6. $(B, D): 5$
   7. $(D, F): 6$
   8. $(C, D): 8$
   9. $(C, E): 10$

2. **Επεξεργασία Ακμών (Union-Find):**
   - Προσθήκη $(B, C)$ [1]: Έγκυρη.
   - Προσθήκη $(A, C)$ [2]: Έγκυρη (σύνολο $\{A, B, C\}$).
   - Προσθήκη $(D, E)$ [2]: Έγκυρη (σύνολο $\{D, E\}$).
   - Προσθήκη $(E, F)$ [3]: Έγκυρη (σύνολο $\{D, E, F\}$).
   - Έλεγχος $(A, B)$ [4]: Απορρίπτεται (δημιουργεί κύκλο $A-B-C$).
   - Προσθήκη $(B, D)$ [5]: Έγκυρη (ενώνει τα $\{A, B, C\}$ και $\{D, E, F\}$).
   - Συνολικές επιλεγμένες ακμές: $V - 1 = 6 - 1 = 5$ ακμές. Ο αλγόριθμος τερματίζει.

**Συνολικό Βάρος MST:** $1 + 2 + 2 + 3 + 5 = 13$.
