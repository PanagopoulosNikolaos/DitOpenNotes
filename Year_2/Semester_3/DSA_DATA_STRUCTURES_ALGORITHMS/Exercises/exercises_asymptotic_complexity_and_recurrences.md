# Ασκήσεις Εμπέδωσης: Ασυμπτωτική Πολυπλοκότητα και Αναδρομικές Εξισώσεις

## Άσκηση 1: Εύρεση Πολυπλοκότητας Εμφωλευμένων Βρόχων
### Εκφώνηση:
Να υπολογιστεί η ασυμπτωτική χρονική πολυπλοκότητα $\Theta$ για το ακόλουθο απόσπασμα αλγορίθμου:
```python
def compute_sum(n):
    total = 0
    i = 1
    while i <= n:
        j = 1
        while j <= n:
            total += (i * j)
            j = j * 2
        i = i + 1
    return total
```

### Λύση:
1. **Εξωτερικός βρόχος (`while i <= n`):**
   - Η μεταβλητή `i` ξεκινά από το 1 και αυξάνεται κατά 1 σε κάθε επανάληψη μέχρι το $n$.
   - Εκτελείται ακριβώς $n$ φορές.
2. **Εσωτερικός βρόχος (`while j <= n`):**
   - Η μεταβλητή `j` ξεκινά από το 1 και διπλασιάζεται σε κάθε επανάληψη ($j = 1, 2, 4, 8, \dots, 2^k$).
   - Σταματά όταν $2^k > n \implies k = \lfloor \log_2 n \rfloor + 1$.
   - Εκτελείται $\Theta(\log n)$ φορές για κάθε τιμή του `i`.
3. **Συνολικές Πράξεις:**
   $$T(n) = \sum_{i=1}^{n} \Theta(\log n) = n \cdot \Theta(\log n) = \Theta(n \log n)$$

## Άσκηση 2: Επίλυση Αναδρομών με Master Theorem και Δέντρο Αναδρομής
### Εκφώνηση:
Να επιλυθούν οι παρακάτω αναδρομικές σχέσεις:
1. $T(n) = 4 T(n/2) + n^2$
2. $T(n) = 3 T(n/3) + O(1)$
3. $T(n) = 2 T(n/4) + \sqrt{n} \log n$

### Λύση:
1. **$T(n) = 4 T(n/2) + n^2$:**
   - $a = 4, b = 2 \implies n^{\log_b a} = n^{\log_2 4} = n^2$.
   - $f(n) = n^2 = \Theta(n^{\log_2 4})$.
   - Εφαρμόζεται η **Περίπτωση 2** του Master Theorem (με $k=0$):
     $$T(n) = \Theta(n^2 \log n)$$

2. **$T(n) = 3 T(n/3) + O(1)$:**
   - $a = 3, b = 3 \implies n^{\log_3 3} = n^1 = n$.
   - $f(n) = O(1) = O(n^{1 - \epsilon})$ για $\epsilon = 1 > 0$.
   - Εφαρμόζεται η **Περίπτωση 1** του Master Theorem:
     $$T(n) = \Theta(n)$$

3. **$T(n) = 2 T(n/4) + \sqrt{n} \log n$:**
   - $a = 2, b = 4 \implies n^{\log_4 2} = n^{1/2} = \sqrt{n}$.
   - $f(n) = \sqrt{n} \log n = \Theta(n^{\log_4 2} \log^1 n)$ (με $k=1$).
   - Εφαρμόζεται η γενικευμένη **Περίπτωση 2** του Master Theorem:
     $$T(n) = \Theta(\sqrt{n} \log^2 n)$$
