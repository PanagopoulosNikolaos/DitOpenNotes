# Data Structures and Algorithms: Exercises & Numerical Problem Sets

Quantitative problem sets, asymptotic derivations, recurrence solving, and tree rotation drills for **Data Structures and Algorithms (Course Code: 305)**.

---

## Solved Drills and Problem Sets

| Problem Set | Topics Covered | Key Concepts |
|:---|:---|:---|
| [`exercises_asymptotic_complexity_and_recurrences.md`](exercises_asymptotic_complexity_and_recurrences.md) | Asymptotic notation proofs ($O, \Omega, \Theta$), Master Theorem applications, recursion tree analysis, and mathematical induction substitution method. | Formal $\epsilon$-$\delta$ / constant factor bounding, divide-and-conquer recurrences, polynomial dominance, and non-homogeneous recurrences. |
| [`exercises_binary_search_trees_and_avl_rotations.md`](exercises_binary_search_trees_and_avl_rotations.md) | Binary Search Tree (BST) operations, three-case node deletions (leaf, single child, two children with inorder successor), and AVL balance factor restorations. | Height-balancing invariant $|h_L - h_R| \le 1$, single rotations (LL, RR), double rotations (LR, RL), and cascading rebalancing up to tree root. |

---

## Pedagogical Objectives

1. **Rigorous Asymptotic Proofs:** Establish mathematical bounds using the formal definitions of big-$O$, $\Omega$, and $\Theta$, eliminating subjective growth rate assumptions.
2. **Recurrence Resolution:** Master multiple analytical techniques (Master Theorem, tree expansion, induction) to analyze divide-and-conquer algorithms.
3. **Dynamic Balance Invariants:** Trace tree rotations step-by-step to understand how self-balancing search trees maintain guaranteed $O(\log n)$ worst-case operational time.
