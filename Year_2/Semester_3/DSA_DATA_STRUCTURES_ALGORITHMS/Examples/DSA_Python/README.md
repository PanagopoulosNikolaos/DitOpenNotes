## Δομές Δεδομένων

### Πίνακες (Arrays)
- **DynamicArray**: Αυτόματα επαυξανόμενος πίνακας με προσάρτηση O(1) κατά μέσο όρο (amortized)
- **StaticArray**: Υλοποίηση πίνακα σταθερού μεγέθους

**Πολυπλοκότητες Χρόνου:**
- Πρόσβαση: O(1)
- Αναζήτηση: O(n)
- Εισαγωγή στο τέλος: O(1) κατά μέσο όρο (δυναμικός)
- Εισαγωγή σε θέση: O(n)

### Συνδεδεμένες Λίστες (Linked Lists)
- **SinglyLinkedList**: Κάθε κόμβος δείχνει στον επόμενο
- **DoublyLinkedList**: Κάθε κόμβος δείχνει στον επόμενο και τον προηγούμενο

**Πολυπλοκότητες Χρόνου:**
- Πρόσβαση: O(n)
- Αναζήτηση: O(n)
- Εισαγωγή στην αρχή: O(1)
- Εισαγωγή στο τέλος: O(n) για μονή, O(1) για διπλή
- Διαγραφή: O(n)

### Στοίβες (Stacks)
- **ArrayStack**: Στοίβα με χρήση λίστας της Python
- **LinkedStack**: Στοίβα με χρήση συνδεδεμένης λίστας
- **StackApplications**: Ισορροπημένες παρενθέσεις, αντιστροφή συμβολοσειράς, αποτίμηση postfix

**Πολυπλοκότητες Χρόνου:**
- Push: O(1)
- Pop: O(1)
- Peek: O(1)

### Ουρές (Queues)
- **ArrayQueue**: Βασική ουρά με χρήση λίστας
- **CircularQueue**: Κυκλική ουρά σταθερού μεγέθους
- **LinkedQueue**: Ουρά με χρήση συνδεδεμένης λίστας
- **Deque**: Ουρά διπλής κατεύθυνσης

**Πολυπλοκότητες Χρόνου:**
- Enqueue: O(1)
- Dequeue: O(1) (εκτός από την ArrayQueue που είναι O(n))
- Front: O(1)

### Πίνακες Κατακερματισμού (Hash Tables)
- **HashMapChaining**: Επίλυση συγκρούσεων με αλυσίδωση
- **HashMapLinearProbing**: Ανοιχτή διευθυνσιοδότηση με γραμμική εξερεύνηση
- **HashSet**: Υλοποίηση συνόλου με χρήση χάρτη κατακερματισμού

**Πολυπλοκότητες Χρόνου:**
- Εισαγωγή: O(1) κατά μέσο όρο, O(n) το χειρότερο
- Διαγραφή: O(1) κατά μέσο όρο, O(n) το χειρότερο
- Αναζήτηση: O(1) κατά μέσο όρο, O(n) το χειρότερο

### Δέντρα (Trees)
- **BinaryTree**: Βασικό δυαδικό δέντρο με διασχίσεις
- **BinarySearchTree**: Δυαδικό δέντρο αναζήτησης με εισαγωγή/διαγραφή/αναζήτηση
- **AVLTree**: Αυτο-ισορροπούμενο δυαδικό δέντρο αναζήτησης

**Πολυπλοκότητες Χρόνου (BST):**
- Αναζήτηση: O(log n) κατά μέσο όρο, O(n) το χειρότερο
- Εισαγωγή: O(log n) κατά μέσο όρο, O(n) το χειρότερο
- Διαγραφή: O(log n) κατά μέσο όρο, O(n) το χειρότερο

**Πολυπλοκότητες Χρόνου (AVL):**
- Αναζήτηση: O(log n)
- Εισαγωγή: O(log n)
- Διαγραφή: O(log n)

### Γράφοι (Graphs)
- **GraphAdjacencyList**: Αποδοτικός σε μνήμη για αραιούς γράφους
- **GraphAdjacencyMatrix**: Γρήγορη εύρεση ακμής για πυκνούς γράφους
- **WeightedGraph**: Υποστηρίζει σταθμισμένες ακμές με αλγόριθμους συντομότερου μονοπατιού

**Λειτουργίες:**
- Διάσχιση BFS: O(V + E)
- Διάσχιση DFS: O(V + E)
- Ανίχνευση Κύκλου: O(V + E)

## Αλγόριθμοι

### Αλγόριθμοι Ταξινόμησης

| Αλγόριθμος | Καλύτερη | Μέση | Χειρότερη | Χώρος | Σταθερός |
|-----------|------|---------|-------|-------|--------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | Ναι |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | Όχι |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Ναι |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | Όχι |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Ναι |
| Counting Sort | O(n+k) | O(n+k) | O(n+k) | O(k) | Ναι |
| Radix Sort | O(d·n) | O(d·n) | O(d·n) | O(n+k) | Ναι |

### Αλγόριθμοι Αναζήτησης

| Αλγόριθμος | Καλύτερη | Μέση | Χειρότερη | Απαιτήσεις |
|-----------|------|---------|-------|--------------|
| Linear Search | O(1) | O(n) | O(n) | Καμία |
| Binary Search | O(1) | O(log n) | O(log n) | Ταξινομημένος πίνακας |
| Jump Search | O(1) | O(√n) | O(√n) | Ταξινομημένος πίνακας |
| Interpolation | O(1) | O(log log n) | O(n) | Ταξινομημένος, ομοιόμορφος |
| Exponential | O(1) | O(log n) | O(log n) | Ταξινομημένος |
| Ternary | O(1) | O(log n) | O(log n) | Ταξινομημένος |

### Αλγόριθμοι Γράφων

**Συντομότερο Μονοπάτι:**
- **Αλγόριθμος Dijkstra**: O((V + E) log V) - μη αρνητικά βάρη
- **Αλγόριθμος Bellman-Ford**: O(V · E) - δέχεται αρνητικά βάρη

**Ελάχιστο Γεννητικό Δέντρο (Minimum Spanning Tree):**
- **Αλγόριθμος Prim**: O(E log V) - αναπτύσσει το MST από κορυφή
- **Αλγόριθμος Kruskal**: O(E log E) - ταξινομεί τις ακμές, χρησιμοποιεί Union-Find

**Μέγιστη Ροή (Maximum Flow):**
- **Αλγόριθμος Ford-Fulkerson**: O(E · max_flow) - χρησιμοποιεί DFS
- **Αλγόριθμος Edmonds-Karp**: O(V · E²) - χρησιμοποιεί BFS

## Παραδείγματα Χρήσης

### Χρήση Δομών Δεδομένων

```python
from DSA_Python.data_structures import DynamicArray, BinarySearchTree, HashMapChaining

# Δυναμικός Πίνακας
arr = DynamicArray()
arr.append(10)
arr.append(20)
print(arr[0])  # Έξοδος: 10

# Δυαδικό Δέντρο Αναζήτησης
bst = BinarySearchTree()
bst.insert(50)
bst.insert(30)
bst.insert(70)
print(bst.search(30))  # Έξοδος: True
print(bst.inorder_traversal())  # Έξοδος: [30, 50, 70]

# Χάρτης Κατακερματισμού
hash_map = HashMapChaining()
hash_map["apple"] = 5
hash_map["banana"] = 7
print(hash_map["apple"])  # Έξοδος: 5
```

### Χρήση Αλγόριθμων

```python
from DSA_Python.algorithms import SortingAlgorithms, SearchingAlgorithms
from DSA_Python.algorithms import ShortestPathAlgorithms

# Ταξινόμηση
arr = [64, 34, 25, 12, 22, 11, 90]
sorted_arr = SortingAlgorithms.quick_sort(arr)
print(sorted_arr)  # Έξοδος: [11, 12, 22, 25, 34, 64, 90]

# Αναζήτηση
sorted_arr = [2, 5, 8, 12, 16, 23, 38, 45]
index = SearchingAlgorithms.binary_search(sorted_arr, 23)
print(index)  # Έξοδος: 5

# Αλγόριθμοι Γράφων
graph = {
    'A': [('B', 4), ('C', 2)],
    'B': [('C', 1), ('D', 5)],
    'C': [('D', 8), ('E', 10)],
    'D': [('E', 2)],
    'E': []
}
distances, _ = ShortestPathAlgorithms.dijkstra(graph, 'A')
print(distances)  # Συντομότερες αποστάσεις από το A σε όλες τις κορυφές
```
