### Ερώτημα 1.Α: Έλεγχος Ακολουθίας Αναζήτησης σε ΔΔΑ
Αναζητούμε το κλειδί `4321` και δίνεται η προτεινόμενη ακολουθία κόμβων που εξετάστηκαν:
$$6, \quad 7, \quad 8, \quad 9, \quad 1023, \quad 34564, \quad 4832, \quad 4321$$

#### Απάντηση:
Η ακολουθία είναι **ΣΩΣΤΗ (Έγκυρη)**.

#### Αιτιολόγηση:
Σε ένα Δυαδικό Δέντρο Αναζήτησης (ΔΔΑ), κάθε σύγκριση περιορίζει το έγκυρο διάστημα τιμών $(L, R)$ για όλους τους επόμενους απογόνους στο υποδέντρο αναζήτησης:

1. **Αρχικό διάστημα:** $(-\infty, +\infty)$.
2. **Στον κόμβο 6:** $4321 > 6 \implies$ Μετάβαση δεξιά. Νέο διάστημα: $(6, +\infty)$.
3. **Στον κόμβο 7:** $7 \in (6, +\infty)$ και $4321 > 7 \implies$ Μετάβαση δεξιά. Νέο διάστημα: $(7, +\infty)$.
4. **Στον κόμβο 8:** $8 \in (7, +\infty)$ και $4321 > 8 \implies$ Μετάβαση δεξιά. Νέο διάστημα: $(8, +\infty)$.
5. **Στον κόμβο 9:** $9 \in (8, +\infty)$ και $4321 > 9 \implies$ Μετάβαση δεξιά. Νέο διάστημα: $(9, +\infty)$.
6. **Στον κόμβο 1023:** $1023 \in (9, +\infty)$ και $4321 > 1023 \implies$ Μετάβαση δεξιά. Νέο διάστημα: $(1023, +\infty)$.
7. **Στον κόμβο 34564:** $34564 \in (1023, +\infty)$ και $4321 < 34564 \implies$ Μετάβαση αριστερά. Νέο διάστημα: $(1023, 34564)$.
8. **Στον κόμβο 4832:** $4832 \in (1023, 34564)$ (έγκυρο!) και $4321 < 4832 \implies$ Μετάβαση αριστερά. Νέο διάστημα: $(1023, 4832)$.
9. **Στον κόμβο 4321:** $4321 \in (1023, 4832)$ (έγκυρο!). Το στοιχείο εντοπίστηκε επιτυχώς.

Επειδή κανένας κόμβος δεν παραβίασε τα όρια αναζήτησης που επέβαλαν οι προηγούμενοι πρόγονοί του, η ακολουθία είναι απόλυτα συμβατή με την ιδιότητα του ΔΔΑ.

### Ερώτημα 1.Β: Τάξη Συνάρτησης $F(n) = 100 - 7n + 2n^2 + 3n^3$

Ζητείται να αποδειχθεί αναλυτικά ότι $F(n) = O(n^3)$ (και $\Theta(n^3)$).

#### Απόδειξη Άνω Φράγματος ($O(n^3)$):
Σύμφωνα με τον ορισμό:
$$
\exists c > 0, n_0 > 0 : 0 \le F(n) \le c \cdot n^3 \quad \forall n \ge n_0
$$
Για κάθε $n \ge 1$:
$$
F(n) = 100 - 7n + 2n^2 + 3n^3 \le 100 + 2n^2 + 3n^3
$$
Επειδή για $n \ge 100$ ισχύει $100 \le n \le n^3$ και $2n^2 \le 2n^3$:
$$
F(n) \le n^3 + 2n^3 + 3n^3 = 6n^3 \quad \forall n \ge 100
$$
Επιλέγοντας $c = 6$ και $n_0 = 100$, έχουμε $F(n) \le 6n^3$, άρα **$F(n) = O(n^3)$**.

#### Απόδειξη Κάτω Φράγματος ($\Omega(n^3)$):
Για $n \ge 3$, ισχύει $7n \le n^3 \implies -7n \ge -n^3$. Επίσης $100 > 0$ και $2n^2 > 0$:
$$
F(n) = 100 - 7n + 2n^2 + 3n^3 \ge 3n^3 - 7n \ge 3n^3 - n^3 = 2n^3 \quad \forall n \ge 3
$$
Επιλέγοντας $c_1 = 2$ και $n_0 = 3$, έχουμε $F(n) \ge 2n^3$, άρα **$F(n) = \Omega(n^3)$**.

**Τελικό Συμπέρασμα:** $F(n) = \Theta(n^3)$ (Τάξη μεγέθους $n^3$, κυβική).

### Ερώτημα 2.Α: Ενδοδιατεταγμένη Διάσχιση (In-order)
Σε οποιοδήποτε έγκυρο Δυαδικό Δέντρο Αναζήτησης, η ενδοδιατεταγμένη διάσχιση ($L \to N \to R$) παράγει πάντοτε τα στοιχεία σε **αύξουσα ταξινομημένη σειρά**.

Ακολουθώντας τους δείκτες του δέντρου:
1. Αριστερό υποδέντρο της ρίζας 30:
   - Από το 3 μεταβαίνουμε στο 10, έπειτα στο 27, αριστερά στο 14, και δεξιά στο 16.
   - Σειρά: `3, 10, 14, 16, 27`.
2. Ρίζα: `30`.
3. Δεξί υποδέντρο της ρίζας 30:
   - Αριστερός κλάδος του 57: `35 -> 46` με παιδιά `37` και `47` $\implies 35, 37, 46, 47$.
   - Κόμβος `57`.
   - Δεξιός κλάδος του 57: `76` με αριστερό παιδί `74`, δεξί `94` με παιδιά `89, 99` $\implies 74, 76, 89, 94, 99$.

**Αποτέλεσμα Ενδοδιατεταγμένης Διάσχισης:**
$$3, \quad 10, \quad 14, \quad 16, \quad 27, \quad 30, \quad 35, \quad 37, \quad 46, \quad 47, \quad 57, \quad 74, \quad 76, \quad 89, \quad 94, \quad 99$$

### Ερώτημα 2.Β: Μέγιστος Αριθμός Εξεταζόμενων Στοιχείων σε Δέντρο AVL ($n = 100$)

Ο μέγιστος αριθμός στοιχείων που εξετάζονται σε μία αναζήτηση αντιστοιχεί στο μήκος της μεγαλύτερης διαδρομής από τη ρίζα προς το βαθύτερο φύλλο, δηλαδή ισούται με:
$$
\text{Μέγιστος Αριθμός Συγκρίσεων} = h_{\max} + 1
$$
όπου $h_{\max}$ είναι το μέγιστο δυνατό ύψος δέντρου AVL με $n = 100$ κόμβους (με τη σύμβαση ύψους φύλλου $= 0$).

#### Υπολογισμός Ελάχιστων Κόμβων $N(h)$ ανά Ύψος $h$:
Ένα δέντρο AVL ύψους $h$ έχει το μέγιστο δυνατό ύψος για δεδομένο πλήθος κόμβων όταν περιέχει τον **ελάχιστο** δυνατό αριθμό κόμβων $N(h)$:
$$
N(h) = N(h - 1) + N(h - 2) + 1, \quad \text{με } N(0) = 1, N(1) = 2
$$
- $h = 0 \implies N(0) = 1$
- $h = 1 \implies N(1) = 2$
- $h = 2 \implies N(2) = 2 + 1 + 1 = 4$
- $h = 3 \implies N(3) = 4 + 2 + 1 = 7$
- $h = 4 \implies N(4) = 7 + 4 + 1 = 12$
- $h = 5 \implies N(5) = 12 + 7 + 1 = 20$
- $h = 6 \implies N(6) = 20 + 12 + 1 = 33$
- $h = 7 \implies N(7) = 33 + 20 + 1 = 54$
- $h = 8 \implies N(8) = 54 + 33 + 1 = 88$
- $h = 9 \implies N(9) = 88 + 54 + 1 = 143$

#### Εύρεση Μέγιστου Ύψους:
Για $n = 100$:
$$
N(8) = 88 \le 100 < 143 = N(9)
$$
Άρα ένα δέντρο AVL με 100 κόμβους μπορεί να έχει μέγιστο ύψος **$h_{\max} = 8$**.

#### Συμπέρασμα:
Ο μέγιστος αριθμός στοιχείων που πρέπει να εξεταστούν είναι:
$$
h_{\max} + 1 = 8 + 1 = \mathbf{9 \text{ στοιχεία (κόμβοι)}}
$$

### Ερώτημα 4.Α: Εκτέλεση Selection Sort για 2 Περάσματα
Αρχικός Πίνακας:
$$A = [28, \quad 0, \quad 25, \quad 4, \quad 9, \quad 27], \quad n = 6$$

#### 1ο Πέρασμα ($i = 0$):
- `cur_min = 0` (τιμή `28`).
- Σύγκριση με $j = 1 \dots 5$:
  - $j = 1: A[1] = 0 < 28 \implies cur\_min = 1$.
  - $j = 2: A[2] = 25 > 0$.
  - $j = 3: A[3] = 4 > 0$.
  - $j = 4: A[4] = 9 > 0$.
  - $j = 5: A[5] = 27 > 0$.
- Εναλλαγή: `swap(A[0], A[1])` (ανταλλαγή 28 και 0).
- **Μορφή πίνακα μετά το 1ο πέρασμα:**
  $$A = [\mathbf{0}, \quad 28, \quad 25, \quad 4, \quad 9, \quad 27]$$

#### 2ο Πέρασμα ($i = 1$):
- `cur_min = 1` (τιμή `28`).
- Σύγκριση με $j = 2 \dots 5$:
  - $j = 2: A[2] = 25 < 28 \implies cur\_min = 2$.
  - $j = 3: A[3] = 4 < 25 \implies cur\_min = 3$.
  - $j = 4: A[4] = 9 > 4$.
  - $j = 5: A[5] = 27 > 4$.
- Εναλλαγή: `swap(A[1], A[3])` (ανταλλαγή 28 και 4).
- **Μορφή πίνακα μετά το 2ο πέρασμα:**
  $$A = [\mathbf{0}, \quad \mathbf{4}, \quad 25, \quad 28, \quad 9, \quad 27]$$

### Ερώτημα 4.Β: Συνάρτηση `selection_sort_descending` σε C++

Για φθίνουσα ταξινόμηση, σε κάθε πέρασμα $i$ εντοπίζουμε το **μέγιστο** στοιχείο του μη ταξινομημένου τμήματος και το τοποθετούμε στη θέση $i$:

```cpp
#include <utility>

/**
 * Sorts an array in descending order using the selection sort algorithm.
 *
 * Args:
 *     arr (int[]): The array to be sorted.
 *     n (int): The number of elements in the array.
 */
void selection_sort_descending(int arr[], int n) {
    for (int i = 0; i < n - 1; ++i) {
        int cur_max = i; // Assumes current index holds maximum value
        
        for (int j = i + 1; j < n; ++j) {
            if (arr[j] > arr[cur_max]) {
                cur_max = j; // Tracks index of strictly larger element
            }
        }
        
        if (cur_max != i) {
            std::swap(arr[i], arr[cur_max]); // Places largest remaining element at index i
        }
    }
}
```
