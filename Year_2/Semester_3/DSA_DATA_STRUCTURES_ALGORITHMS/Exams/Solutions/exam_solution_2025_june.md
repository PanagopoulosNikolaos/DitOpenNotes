## Άσκηση 1: Χρονική Πολυπλοκότητα (Big-O)

### Ερώτημα 1.α
```cpp
for (int i = 0; i < n; i++) {
    for (int j = n; j > i; j--) {
        sum += i + j;
    }
}
```
- Ο εξωτερικός βρόχος εκτελείται για $i = 0, 1, 2, \dots, n - 1$ ($n$ φορές).
- Για κάθε τιμή του $i$, ο εσωτερικός βρόχος εκτελείται για $j$ από $n$ προς τα κάτω μέχρι $i + 1$, δηλαδή εκτελείται ακριβώς $n - i$ φορές.
- Συνολικός αριθμός επαναλήψεων $T(n)$:
  $$
  T(n) = \sum_{i=0}^{n-1} (n - i) = n + (n - 1) + (n - 2) + \dots + 1 = \frac{n(n + 1)}{2} = \frac{n^2}{2} + \frac{n}{2}
  $$
- **Χρονική Πολυπλοκότητα:** **$O(n^2)$** (Τετραγωνική).

---

### Ερώτημα 1.β
```cpp
for (int i = 1; i <= n; i *= 2) {
    sum += i;
}
```
- Η μεταβλητή ελέγχου ξεκινά από $i = 1$ και διπλασιάζεται σε κάθε επανάληψη ($i = 1, 2, 4, 8, \dots, 2^k$).
- Ο βρόχος τερματίζει όταν $2^k > n \iff k > \log_2 n$.
- Συνολικός αριθμός επαναλήψεων: $\lfloor \log_2 n \rfloor + 1$.
- **Χρονική Πολυπλοκότητα:** **$O(\log n)$** (Λογαριθμική).

---

### Ερώτημα 1.γ
```cpp
for (int i = 0; i < n; i++) {
    sum += i * i;
}
```
- Ο βρόχος εκτελείται για $i = 0, 1, 2, \dots, n - 1$ με βήμα $+1$, εκτελώντας μια απλή αριθμητική πράξη κόστους $O(1)$ ανά επανάληψη.
- Συνολικός αριθμός επαναλήψεων: $n$.
- **Χρονική Πολυπλοκότητα:** **$O(n)$** (Γραμμική).

## Άσκηση 2: Δυαδικό Δέντρο Αναζήτησης (BST)

Αρχική ακολουθία εισαγωγής: `[50, 25, 75, 15, 30, 60, 85]`.

### Αρχική Κατασκευή BST:
- Εισαγωγή 50: Ρίζα.
- Εισαγωγή 25: $25 < 50 \implies$ Αριστερό παιδί του 50.
- Εισαγωγή 75: $75 > 50 \implies$ Δεξί παιδί του 50.
- Εισαγωγή 15: $15 < 50, 15 < 25 \implies$ Αριστερό παιδί του 25.
- Εισαγωγή 30: $30 < 50, 30 > 25 \implies$ Δεξί παιδί του 25.
- Εισαγωγή 60: $60 > 50, 60 < 75 \implies$ Αριστερό παιδί του 75.
- Εισαγωγή 85: $85 > 50, 85 > 75 \implies$ Δεξί παιδί του 75.

```
          50
        /    \
      25      75
     /  \    /  \
   15   30  60   85
```

---

### Ερώτημα 2.α: Εισαγωγή του στοιχείου 28
- Σύγκριση με 50: $28 < 50 \implies$ Αριστερά (στο 25).
- Σύγκριση με 25: $28 > 25 \implies$ Δεξιά (στο 30).
- Σύγκριση με 30: $28 < 30 \implies$ Αριστερό παιδί του 30.

```
          50
        /    \
      25      75
     /  \    /  \
   15   30  60   85
       /
      28
```

---

### Ερώτημα 2.β: Διαγραφή του στοιχείου 25
Ο κόμβος `25` έχει δύο παιδιά (`15` και `30`).
- Εντοπίζουμε τον **Ενδοδιατεταγμένο Διάδοχο (In-order Successor)**, ο οποίος είναι το ελάχιστο στοιχείο του δεξιού υποδέντρου του 25:
  - Μεταβαίνουμε στο 30 και κινούμαστε αριστερά στο `28`.
- Αντικαθιστούμε την τιμή του 25 με το 28.
- Διαγράφουμε τον αρχικό κόμβο 28 (ο οποίος είναι φύλλο).

```
          50
        /    \
      28      75
     /  \    /  \
   15   30  60   85
```

---

### Ερώτημα 2.γ: Διασχίσεις Δέντρου (για το τελικό δέντρο)
- **Προδιατεταγμένη (Pre-order, $N \to L \to R$):**
  `50, 28, 15, 30, 75, 60, 85`
- **Ενδοδιατεταγμένη (In-order, $L \to N \to R$):**
  `15, 28, 30, 50, 60, 75, 85` *(Πλήρως ταξινομημένη)*
- **Μεταδιατεταγμένη (Post-order, $L \to R \to N$):**
  `15, 30, 28, 60, 85, 75, 50`

*(Σημείωση: Αν οι διασχίσεις ζητούνται στο αρχικό δέντρο πριν τις αλλαγές: Pre-order: 50, 25, 15, 30, 75, 60, 85 | In-order: 15, 25, 30, 50, 60, 75, 85 | Post-order: 15, 30, 25, 60, 85, 75, 50).*

## Άσκηση 3: Εισαγωγή σε Δέντρο AVL και Περιστροφές

Εισαγωγή των στοιχείων: `[20, 10, 30, 25, 40, 35]`

1. **Εισαγωγή 20:** Ρίζα `20` ($BF = 0$).
2. **Εισαγωγή 10:** Αριστερά του 20 ($BF(20) = +1, BF(10) = 0$).
3. **Εισαγωγή 30:** Δεξιά του 20 ($BF(20) = 0$).
4. **Εισαγωγή 25:** Αριστερά του 30 ($BF(20) = -1, BF(30) = +1$).
5. **Εισαγωγή 40:** Δεξιά του 30 ($BF(20) = -1, BF(30) = 0, BF(40) = 0$).
6. **Εισαγωγή 35:**
   - Εισάγεται ως αριστερό παιδί του 40.
   - Επανυπολογισμός υψών και $BF$:
     - $BF(40) = +1$
     - $BF(30) = h(25) - h(40) = 0 - 1 = -1$
     - $BF(20) = h(10) - h(30) = 0 - 2 = -2$ $\implies$ **Ανισορροπία στον κόμβο 20!**
   - Έλεγχος τύπου ανισορροπίας:
     - Κόμβος 20: $BF = -2$ (κλίση δεξιά).
     - Δεξί παιδί 30: $BF = -1$ (κλίση δεξιά).
     - **Τύπος: Right-Right (RR) ανισορροπία.**
   - **Διόρθωση:** **Απλή Αριστερή Περιστροφή (Left Rotation)** γύρω από τον κόμβο 20:
     - Ο κόμβος 30 ανέρχεται ως νέα τοπική ρίζα.
     - Ο κόμβος 20 γίνεται αριστερό παιδί του 30.
     - Το αριστερό παιδί του 30 (`25`) επανασυνδέεται ως δεξί παιδί του 20.
     - Ο κόμβος 40 (με το παιδί του 35) παραμένει δεξί παιδί του 30.

**Τελικό Δέντρο AVL:**
```
        30 (BF = 0)
       /    \
(BF=0)20     40 (BF = +1)
     /  \    /
    10  25  35
```
Όλα τα $BF \in \{-1, 0, +1\}$. Το δέντρο είναι πλήρως ισοζυγισμένο!

## Άσκηση 4: Διαγραφή από Δέντρο AVL

Δίνεται το δέντρο AVL:
```
      35
     /  \
   25    40
  /  \
 20  30
```

- **Διαγραφή κόμβου 30:**
  - Ο κόμβος 30 είναι φύλλο. Αποσυνδέουμε τον δεξιό δείκτη του κόμβου 25.
- **Έλεγχος Παραγόντων Ισοζυγίου:**
  - Κόμβος 20: $h = 0, BF = 0$.
  - Κόμβος 25: αριστερό ύψος $h(20) = 0$, δεξιό ύψος $=-1 \implies BF(25) = 0 - (-1) = +1$. Ύψος $h(25) = 1$.
  - Κόμβος 40: φύλλο, $h = 0, BF = 0$.
  - Ρίζα 35: αριστερό ύψος $h(25) = 1$, δεξιό ύψος $h(40) = 0 \implies BF(35) = 1 - 0 = +1$. Ύψος $h(35) = 2$.
- **Συμπέρασμα:** Όλοι οι κόμβοι έχουν $BF \in \{-1, 0, +1\}$. Δεν απαιτείται καμία περιστροφή.

**Τελικό Δέντρο μετά τη διαγραφή:**
```
      35
     /  \
   25    40
  /
 20
```

## Άσκηση 5: Κατασκευή Ελάχιστου Σωρού (Min Heap)

Στοιχεία: `[55, 40, 65, 20, 50]`

1. **Εισαγωγή 55:**
   - Πίνακας: `[55]`
2. **Εισαγωγή 40:**
   - Εισαγωγή στο τέλος (θέση 1): `[55, 40]`
   - Γονέας: θέση 0 (`55`). Επειδή $40 < 55$, εναλλαγή (swap).
   - Πίνακας: `[40, 55]`
3. **Εισαγωγή 65:**
   - Εισαγωγή στη θέση 2: `[40, 55, 65]`
   - Γονέας: θέση 0 (`40`). Επειδή $65 \ge 40$, καμία αλλαγή.
4. **Εισαγωγή 20:**
   - Εισαγωγή στη θέση 3 (παιδί του 55): `[40, 55, 65, 20]`
   - Γονέας στη θέση 1 (`55`): $20 < 55 \implies$ εναλλαγή $\implies [40, 20, 65, 55]$.
   - Γονέας στη θέση 0 (`40`): $20 < 40 \implies$ εναλλαγή $\implies [20, 40, 65, 55]$.
5. **Εισαγωγή 50:**
   - Εισαγωγή στη θέση 4 (δεξί παιδί του 40): `[20, 40, 65, 55, 50]`
   - Γονέας στη θέση 1 (`40`): Επειδή $50 \ge 40$, καμία αλλαγή.

**Τελικός Ελάχιστος Σωρός:**
- Διάταξη Πίνακα: `[20, 40, 65, 55, 50]`
- Δομή Δέντρου:
```
          20
        /    \
      40      65
     /  \
    55  50
```

## Άσκηση 6: Διαγραφή Ρίζας από Ελάχιστο Σωρό

Αρχικός σωρός:
```
      20
     /  \
   35    40
  /  \
 50  60
```
Πίνακας: `[20, 35, 40, 50, 60]`

### Βήματα Αποκατάστασης:
1. **Αφαίρεση ρίζας (20):** Αντικατάσταση της ρίζας με το τελευταίο στοιχείο του σωρού (`60`).
   Πίνακας: `[60, 35, 40, 50]`
   ```
         60
        /  \
      35    40
     /
    50
   ```
2. **Καταβύθιση (siftDown) στη Ρίζα (θέση 0):**
   - Παιδιά του 60: αριστερό `35` (θέση 1), δεξί `40` (θέση 2).
   - Μικρότερο παιδί: $\min(35, 40) = 35$.
   - Επειδή $35 < 60$, ανταλλάσσουμε το 60 με το 35.
   ```
         35
        /  \
      60    40
     /
    50
   ```
3. **Καταβύθιση (siftDown) στη θέση 1:**
   - Μοναδικό παιδί του 60: αριστερό `50` (θέση 3).
   - Επειδή $50 < 60$, ανταλλάσσουμε το 60 με το 50.
   ```
         35
        /  \
      50    40
     /
    60
   ```
4. Ο κόμβος 60 είναι πλέον φύλλο. Ο σωρός έχει αποκατασταθεί πλήρως.

**Τελικός Πίνακας:** `[35, 50, 40, 60]`.

## Άσκηση 7: Πίνακας Κατακερματισμού (Hashing)

Δεδομένα: $m = 10$, $h(k) = k \pmod{10}$, κλειδιά: `[10, 20, 30, 25, 35, 45]`.

### Αρχικοί κατακερματισμοί:
- $h(10) = 10 \pmod{10} = 0$
- $h(20) = 20 \pmod{10} = 0$
- $h(30) = 30 \pmod{10} = 0$
- $h(25) = 25 \pmod{10} = 5$
- $h(35) = 35 \pmod{10} = 5$
- $h(45) = 45 \pmod{10} = 5$

---

### α) Αλυσίδες (Separate Chaining)
Κάθε θέση του πίνακα διατηρεί συνδεδεμένη λίστα:
- Θέση 0: `10 -> 20 -> 30` (ή με εισαγωγή στην αρχή: `30 -> 20 -> 10`)
- Θέση 5: `25 -> 35 -> 45` (ή `45 -> 35 -> 25`)
- Όλες οι υπόλοιπες θέσεις (1, 2, 3, 4, 6, 7, 8, 9) είναι κενές (`nullptr`).

---

### β) Γραμμική Ανίχνευση (Linear Probing): $h(k, i) = (h(k) + i) \pmod{10}$
1. `10`: $h(10) = 0 \implies$ Θέση 0.
2. `20`: $h(20) = 0$ (σύγκρουση) $\implies (0 + 1) \pmod{10} = 1 \implies$ Θέση 1.
3. `30`: $h(30) = 0$ (σύγκρουση στις θέσεις 0, 1) $\implies (0 + 2) \pmod{10} = 2 \implies$ Θέση 2.
4. `25`: $h(25) = 5 \implies$ Θέση 5.
5. `35`: $h(35) = 5$ (σύγκρουση) $\implies (5 + 1) \pmod{10} = 6 \implies$ Θέση 6.
6. `45`: $h(45) = 5$ (σύγκρουση στις θέσεις 5, 6) $\implies (5 + 2) \pmod{10} = 7 \implies$ Θέση 7.

**Πίνακας:**
`[0: 10, 1: 20, 2: 30, 3: _, 4: _, 5: 25, 6: 35, 7: 45, 8: _, 9: _]`

---

### γ) Τετραγωνική Ανίχνευση (Quadratic Probing): $h(k, i) = (h(k) + i^2) \pmod{10}$
1. `10`: $h(10) = 0 \implies$ Θέση 0.
2. `20`: $h(20) = 0$ $\implies (0 + 1^2) \pmod{10} = 1 \implies$ Θέση 1.
3. `30`: $h(30) = 0$, $i=1 \implies 1$ (κατειλημμένη), $i=2 \implies (0 + 2^2) \pmod{10} = 4 \implies$ Θέση 4.
4. `25`: $h(25) = 5 \implies$ Θέση 5.
5. `35`: $h(35) = 5$ $\implies (5 + 1^2) \pmod{10} = 6 \implies$ Θέση 6.
6. `45`: $h(45) = 5$, $i=1 \implies 6$ (κατειλημμένη), $i=2 \implies (5 + 2^2) \pmod{10} = 9 \implies$ Θέση 9.

**Πίνακας:**
`[0: 10, 1: 20, 2: _, 3: _, 4: 30, 5: 25, 6: 35, 7: _, 8: _, 9: 45]`

---

### δ) Διπλός Κατακερματισμός (Double Hashing): $h(k, i) = (h_1(k) + i \cdot h_2(k)) \pmod{10}$
όπου $h_1(k) = k \pmod{10}$ και $h_2(k) = 7 - (k \pmod 7)$.

1. `10`: $h_1(10) = 0 \implies$ Θέση 0.
2. `20`: $h_1(20) = 0$ (σύγκρουση).  
   $h_2(20) = 7 - (20 \pmod 7) = 7 - 6 = 1$.  
   $i=1 \implies (0 + 1 \times 1) \pmod{10} = 1 \implies$ Θέση 1.
3. `30`: $h_1(30) = 0$ (σύγκρουση).  
   $h_2(30) = 7 - (30 \pmod 7) = 7 - 2 = 5$.  
   $i=1 \implies (0 + 1 \times 5) \pmod{10} = 5 \implies$ Θέση 5.
4. `25`: $h_1(25) = 5$ (σύγκρουση, θέση 5 κατειλημμένη από το 30!).  
   $h_2(25) = 7 - (25 \pmod 7) = 7 - 4 = 3$.  
   $i=1 \implies (5 + 1 \times 3) \pmod{10} = 8 \implies$ Θέση 8.
5. `35`: $h_1(35) = 5$ (σύγκρουση).  
   $h_2(35) = 7 - (35 \pmod 7) = 7 - 0 = 7$.  
   $i=1 \implies (5 + 1 \times 7) \pmod{10} = 12 \pmod{10} = 2 \implies$ Θέση 2.
6. `45`: $h_1(45) = 5$ (σύγκρουση).  
   $h_2(45) = 7 - (45 \pmod 7) = 7 - 3 = 4$.  
   $i=1 \implies (5 + 1 \times 4) \pmod{10} = 9 \implies$ Θέση 9.

**Πίνακας:**
`[0: 10, 1: 20, 2: 35, 3: _, 4: _, 5: 30, 6: _, 7: _, 8: 25, 9: 45]`

## Άσκηση 8: Δέντρο Huffman και Δυαδικοί Κωδικοί

Συχνότητες: `A: 10, B: 4, C: 6, D: 2, E: 3, F: 7` (Σύνολο = 32)

### Διαδικασία Κατασκευής (Συγχώνευση Ελάχιστων Κόμβων):
1. Ταξινόμηση συχνοτήτων:
   $$D(2), \quad E(3), \quad B(4), \quad C(6), \quad F(7), \quad A(10)$$
2. Συγχώνευση των δύο μικρότερων $D(2)$ και $E(3)$:
   - Νέος κόμβος $(DE)$ με βάρος $2 + 3 = 5$.
   - Ενεργοί κόμβοι: $B(4), \quad (DE)(5), \quad C(6), \quad F(7), \quad A(10)$.
3. Συγχώνευση των δύο μικρότερων $B(4)$ και $(DE)(5)$:
   - Νέος κόμβος $(BDE)$ με βάρος $4 + 5 = 9$.
   - Ενεργοί κόμβοι: $C(6), \quad F(7), \quad (BDE)(9), \quad A(10)$.
4. Συγχώνευση των δύο μικρότερων $C(6)$ και $F(7)$:
   - Νέος κόμβος $(CF)$ με βάρος $6 + 7 = 13$.
   - Ενεργοί κόμβοι: $(BDE)(9), \quad A(10), \quad (CF)(13)$.
5. Συγχώνευση των δύο μικρότερων $(BDE)(9)$ και $A(10)$:
   - Νέος κόμβος $(ABDE)$ με βάρος $9 + 10 = 19$.
   - Ενεργοί κόμβοι: $(CF)(13), \quad (ABDE)(19)$.
6. Τελική συγχώνευση $(CF)(13)$ και $(ABDE)(19)$:
   - Ρίζα με συνολικό βάρος $13 + 19 = 32$.

### Διάγραμμα Δέντρου Huffman:
*(Σύμβαση: Αριστερή διακλάδωση = 0, Δεξιά διακλάδωση = 1)*

```
                   (32)
                 /      \
             0 /          \ 1
            (13)          (19)
           /    \        /    \
        0 /    1 \    0 /    1 \
        C(6)    F(7)  (BDE:9)  A(10)
                      /     \
                   0 /     1 \
                    B(4)    (DE:5)
                            /    \
                         0 /    1 \
                          D(2)   E(3)
```

### Δυαδικοί Προθεματικοί Κωδικοί (Huffman Codes):

| Χαρακτήρας | Συχνότητα | Διαδρομή Δέντρου | Δυαδικός Κωδικός | Μήκος (bits) |
|:---:|:---:|:---|:---:|:---:|
| **A** | 10 | Δεξιά $\to$ Δεξιά | `11` | 2 |
| **C** | 6 | Αριστερά $\to$ Αριστερά | `00` | 2 |
| **F** | 7 | Αριστερά $\to$ Δεξιά | `01` | 2 |
| **B** | 4 | Δεξιά $\to$ Αριστερά $\to$ Αριστερά | `100` | 3 |
| **D** | 2 | Δεξιά $\to$ Αριστερά $\to$ Δεξιά $\to$ Αριστερά | `1010` | 4 |
| **E** | 3 | Δεξιά $\to$ Αριστερά $\to$ Δεξιά $\to$ Δεξιά | `1011` | 4 |

**Έλεγχος Συνολικού Μήκους Μηνύματος:**
$$
L = (10 \times 2) + (6 \times 2) + (7 \times 2) + (4 \times 3) + (2 \times 4) + (3 \times 4) = 20 + 12 + 14 + 12 + 8 + 12 = 78\text{ bits}
$$
(Σε σχέση με σταθερό κωδικό 3 bits/χαρακτήρα: $32 \times 3 = 96\text{ bits} \implies \approx 18.75\%$ συμπίεση).
