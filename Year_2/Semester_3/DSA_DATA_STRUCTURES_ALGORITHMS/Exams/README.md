# Θέματα και Διαγωνίσματα Εξετάσεων: Δομές Δεδομένων και Αλγόριθμοι

Ο κατάλογος αυτός περιλαμβάνει επαναληπτικά διαγωνίσματα προσομοίωσης και πρωτότυπα θέματα παλαιότερων εξεταστικών περιόδων.

---

## Περιεχόμενα

* **[practice_exam_01.md](practice_exam_01.md)**: Πρότυπο διαγώνισμα προσομοίωσης με πλήρεις και αναλυτικές λύσεις:
  - **Θέμα 1:** Ασυμπτωτική ανάλυση και Master Theorem ($T(n)$).
  - **Θέμα 2:** Δέντρα AVL, περιστροφές και διαγραφή κόμβου με δύο παιδιά σε BST.
  - **Θέμα 3:** Max-Heap, μέθοδος `buildMaxHeap`, εξαγωγή μεγίστου και διπλός κατακερματισμός.
  - **Θέμα 4:** Τοπολογική ταξινόμηση σε DAG και σύγκριση αλγορίθμων Dijkstra / Bellman-Ford.
