## Μέρος 1 (Ερωτήματα 1 - 4)

### Άσκηση 1 (1,5 Βαθμός)
Για καθεμία από τις παρακάτω συναρτήσεις, να υπολογίσετε τη χρονική πολυπλοκότητα (Big O):

**α)** *(0,5 βαθμός)*
```cpp
for (int i = 0; i < n; i++) {
    for (int j = n; j > i; j--) {
        sum += i + j;
    }
}
```

**β)** *(0,5 βαθμός)*
```cpp
for (int i = 1; i <= n; i *= 2) {
    sum += i;
}
```

**γ)** *(0,5 βαθμός)*
```cpp
for (int i = 0; i < n; i++) {
    sum += i * i;
}
```

### Άσκηση 7 (2,5 Βαθμοί)
Με συνάρτηση κατακερματισμού $h(k) = k \pmod{10}$ και πίνακα μεγέθους $m = 10$, εισάγετε τα κλειδιά:
$$[10, 20, 30, 25, 35, 45]$$
δημιουργώντας τον πίνακα κατακερματισμού με τις εξής τεχνικές:
- **α)** Αλυσίδες (Separate Chaining) *(0,5 βαθμός)*
- **β)** Γραμμική Ανίχνευση (Linear Probing) *(0,5 βαθμός)*
- **γ)** Τετραγωνική Ανίχνευση (Quadratic Probing) *(0,5 βαθμός)*
- **δ)** Διπλό Κατακερματισμό (Double Hashing) με $h_2(k) = 7 - (k \pmod 7)$ *(1 βαθμός)*

κατασκευάστε το βέλτιστο δέντρο Huffman (Huffman Tree) και εξάγετε τους δυαδικούς κωδικούς (binary prefix codes) για κάθε χαρακτήρα. *(1,5 βαθμός)*
