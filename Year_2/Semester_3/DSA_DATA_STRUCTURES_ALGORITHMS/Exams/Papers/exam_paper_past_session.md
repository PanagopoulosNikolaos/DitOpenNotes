## Θέμα 1

### Ερώτημα Α
Υπάρχει ένα Δυαδικό Δέντρο Αναζήτησης (ΔΔΑ), που περιέχει ακεραίους αριθμούς και δεν γνωρίζετε τη δομή του. Αναζητούμε να βρούμε εάν υπάρχει στο ΔΔΑ ο αριθμός `4321`. Ένας συνάδελφός σας λέει ότι προέκυψε η επόμενη ακολουθία αναζήτησης:
$$6, 7, 8, 9, 1023, 34564, 4832, 4321$$

Η ακολουθία είναι λάθος ή σωστή και γιατί; Αιτιολογήστε πλήρως την απάντησή σας βασιζόμενοι στην ιδιότητα του ΔΔΑ.

### Ερώτημα Β
Βρείτε αναλυτικά την τάξη της συνάρτησης:
$$F(n) = 100 - 7n + 2n^2 + 3n^3$$
υπολογίζοντας το Big-$O$ και τεκμηριώνοντας με τις σταθερές του ορισμού.

## Θέμα 4 (Εργαστήριο)

### Ερώτημα Α
Δίνεται ο πίνακας:
$$A = [28, 0, 25, 4, 9, 27]$$
στον οποίο εφαρμόζεται ο αλγόριθμος **Ταξινόμηση με Επιλογή (Selection Sort)**, ο οποίος δίνεται πιο κάτω. Ο αλγόριθμος εφαρμόζεται για **2 περάσματα**:

```cpp
for (i = 0; i < 2; i++) { // 2 passes
    cur_min = i;
    for (j = i + 1; j < n; j++)
        if (A[j] < A[cur_min])
            cur_min = j;
    swap(A[i], A[cur_min]);
}
```

Ποια θα είναι η μορφή του πίνακα μετά τα δύο περάσματα; Δείξτε αναλυτικά την τιμή του πίνακα μετά το 1ο και μετά το 2ο πέρασμα.

### Ερώτημα Β
Η πιο πάνω συνάρτηση Selection Sort ταξινομεί έναν πίνακα κατά αύξουσα σειρά.  
Γράψτε μια νέα συνάρτηση σε C/C++ με όνομα `selection_sort_descending` η οποία θα ταξινομεί τον πίνακα κατά **φθίνουσα σειρά**.
