# Εργασίες: Αντικειμενοστραφής Προγραμματισμός

Ο κατάλογος αυτός περιέχει το πρακτικό υλικό εξάσκησης και το μεγάλο εξαμηνιαίο project του μαθήματος.

---

## Περιεχόμενα

* **[Basics/](Basics/)**: 60 διαβαθμισμένες ασκήσεις εξάσκησης σε C++:
  - Ασκήσεις 1-3: Βασική εκτύπωση και I/O (`001_exercise.cpp` - `003_exercise.cpp`).
  - Ασκήσεις 4-6: Μεταβλητές και τύποι δεδομένων (`004_exercise.cpp` - `006_exercise.cpp`).
  - Ασκήσεις 7-9: Έλεγχος ροής if/else και switch (`007_exercise.cpp` - `009_exercise.cpp`).
  - Ασκήσεις 10-12: Βρόχοι επανάληψης for και while (`010_exercise.cpp` - `012_exercise.cpp`).
  - Ασκήσεις 13-15: Πίνακες (`013_exercise.cpp` - `015_exercise.cpp`).
  - Ασκήσεις 16-18: Συναρτήσεις και πέρασμα παραμέτρων (`016_exercise.cpp` - `018_exercise.cpp`).
  - Ασκήσεις 19-21: Δείκτες και αναφορές (`019_exercise.cpp` - `021_exercise.cpp`).
  - Ασκήσεις 22-24: Διανύσματα std::vector (`022_exercise.cpp` - `024_exercise.cpp`).
  - Ασκήσεις 25-27: Χάρτες std::map (`025_exercise.cpp` - `027_exercise.cpp`).
  - Ασκήσεις 28-30: Κλάσεις και αντικείμενα (`028_exercise.cpp` - `030_exercise.cpp`).
  - Ασκήσεις 31-33: Κατασκευαστές και καταστροφείς (`031_exercise.cpp` - `033_exercise.cpp`).
  - Ασκήσεις 34-36: Ο δείκτης this (`034_exercise.cpp` - `036_exercise.cpp`).
  - Ασκήσεις 37-39: Ενθυλάκωση και αφαίρεση (`037_exercise.cpp` - `039_exercise.cpp`).
  - Ασκήσεις 40-42: Κληρονομικότητα και πολυμορφισμός (`040_exercise.cpp` - `042_exercise.cpp`).
  - Ασκήσεις 43-45: Διαχείριση μνήμης σε σωρό και στοίβα (`043_exercise.cpp` - `045_exercise.cpp`).
  - Ασκήσεις 46-60: Γενικές συνθετικές ασκήσεις αντικειμενοστραφούς σχεδίασης (`046_exercise_general.cpp` - `060_exercise_general.cpp`).
