# Διάλεξη 08: Σχεδιαστικά Πρότυπα (Design Patterns) στη C++

## 1. Εισαγωγή στα Σχεδιαστικά Πρότυπα
Τα σχεδιαστικά πρότυπα (Gang of Four - GoF) αποτελούν δοκιμασμένες, επαναχρησιμοποιήσιμες αρχιτεκτονικές λύσεις σε κοινά προβλήματα σχεδίασης αντικειμενοστραφούς λογισμικού. Διακρίνονται σε τρεις κύριες κατηγορίες:
1. **Δημιουργικά (Creational):** Μηχανισμοί δημιουργίας αντικειμένων με ευελιξία και απομόνωση.
2. **Δομικά (Structural):** Σύνθεση κλάσεων και αντικειμένων σε μεγαλύτερες δομές.
3. **Συμπεριφοράς (Behavioral):** Επικοινωνία και ανάθεση ευθυνών μεταξύ αντικειμένων.

---

## 2. Δημιουργικά Πρότυπα (Creational Patterns)

### 2.1 Πρότυπο Singleton (Meyers' Singleton)
Εξασφαλίζει ότι μια κλάση έχει ένα μοναδικό στιγμιότυπο καθ' όλη τη διάρκεια εκτέλεσης, παρέχοντας καθολικό σημείο πρόσβασης. Στη σύγχρονη C++, η τοπική static μεταβλητή είναι εγγυημένα thread-safe (Magic Statics):
```cpp
class DatabaseManager {
public:
    static DatabaseManager& getInstance() {
        static DatabaseManager instance; // Thread-safe από C++11
        return instance;
    }

    DatabaseManager(const DatabaseManager&) = delete;
    DatabaseManager& operator=(const DatabaseManager&) = delete;

private:
    DatabaseManager() = default;
};
```

### 2.2 Πρότυπο Factory Method
Ορίζει μια διεπαφή για τη δημιουργία αντικειμένου, αναθέτοντας την απόφαση για το ποια συγκεκριμένη κλάση θα στιγμιοποιηθεί στις υποκλάσεις.

---

## 3. Δομικά Πρότυπα (Structural Patterns)

### 3.1 Πρότυπο Adapter (Προσαρμογέας)
Μετατρέπει τη διεπαφή μιας κλάσης σε μια άλλη διεπαφή που αναμένουν οι πελάτες, επιτρέποντας σε ασύμβατες κλάσεις να συνεργαστούν.

### 3.2 Πρότυπο Decorator (Διακοσμητής)
Προσθέτει δυναμικά νέες λειτουργίες σε ένα αντικείμενο κατά τον χρόνο εκτέλεσης (runtime), χωρίς να τροποποιεί την αρχική κλάση και αποφεύγοντας την έκρηξη υποκλάσεων.

---

## 4. Πρότυπα Συμπεριφοράς (Behavioral Patterns)

### 4.1 Πρότυπο Observer (Παρατηρητής)
Ορίζει μια εξάρτηση ένα-προς-πολλά: όταν η κατάσταση ενός αντικειμένου αλλάζει, όλοι οι εξαρτημένοι παρατηρητές ειδοποιούνται και ενημερώνονται αυτόματα.
- Χρησιμοποιείται σε συστήματα διαχείρισης συμβάντων (GUI events, Model-View-Controller, pub/sub).

### 4.2 Πρότυπο Strategy (Στρατηγική)
Ορίζει μια οικογένεια αλγορίθμων, ενθυλακώνει τον καθένα σε ξεχωριστή κλάση και τους καθιστά εναλλάξιμους κατά τον χρόνο εκτέλεσης (π.χ. στρατηγικές ταξινόμησης, αλγόριθμοι συμπίεσης δεδομένων, μέθοδοι πληρωμής).
