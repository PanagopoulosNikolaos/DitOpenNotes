# Object-Oriented Programming: Curated Resources and Reference Guide

A curated guide of core textbooks, standards, tools, and code repositories for Object-Oriented Programming in C++ (Course Code 302).

---

## 1. Foundational Textbooks

- **C++ Crash Course: A Fast-Paced Introduction**  
  *Author:* Josh Lospinoso.  
  *Annotation:* A thorough modern C++ textbook introducing types, memory layout, RAII, smart pointers, templates, and the STL with clear systems-level explanations.

- **Effective Modern C++ (42 Specific Ways to Improve Your Use of C++11 and C++14)**  
  *Author:* Scott Meyers.  
  *Annotation:* Essential reading for mastering `auto`, universal references, move semantics, lambda captures, and concurrency idioms.

- **Design Patterns: Elements of Reusable Object-Oriented Software**  
  *Authors:* Erich Gamma, Richard Helm, Ralph Johnson, and John Vlissides (Gang of Four).  
  *Annotation:* The landmark software engineering reference defining creational, structural, and behavioral object-oriented patterns.

---

## 2. Compilers, Profilers, and Build Tools

- **GCC / Clang Toolchains**  
  *Description:* Modern standards-compliant C++ compilers with AddressSanitizer (`-fsanitize=address`) and UndefinedBehaviorSanitizer (`-fsanitize=undefined`).

- **Valgrind Memcheck**  
  *URL:* `https://valgrind.org/`  
  *Description:* Instrumentation framework for memory debugging, memory leak detection, and cache profiling.

- **Compiler Explorer (Godbolt)**  
  *URL:* `https://godbolt.org/`  
  *Description:* Interactive web tool for examining assembly output and vtable layouts generated by diverse C++ compilers.

---

## 3. Official Documentation and Communities

- **CppReference**  
  *URL:* `https://en.cppreference.com/`  
  *Description:* The definitive community-maintained reference for the C++ standard library, language keywords, containers, and algorithms.

- **C++ Core Guidelines**  
  *Editors:* Bjarne Stroustrup and Herb Sutter.  
  *URL:* `https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines`  
  *Description:* Modern best practices on resource management, interface design, class hierarchies, and error handling.
