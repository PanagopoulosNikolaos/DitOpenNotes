# Σημειώσεις: Διαχείριση Μνήμης, RAII και Smart Pointers σε C++

## 1. Τμήματα Μνήμης σε C++ (Memory Layout)
1. **Στοίβα (Stack):** Αυτόματη δέσμευση/αποδέσμευση μεταβλητών εμβέλειας (scope), ταχύτατη πρόσβαση, περιορισμένο μέγεθος (κίνδυνος Stack Overflow).
2. **Σωρός (Heap / Free Store):** Δυναμική δέσμευση με `new` / `malloc` και χειροκίνητη αποδέσμευση με `delete` / `free`.
3. **Data / BSS Segment:** Καθολικές (global) και στατικές (static) μεταβλητές.
4. **Text / Code Segment:** Ο μεταγλωττισμένος δυαδικός κώδικας του προγράμματος (μόνο για ανάγνωση).

---

## 2. Το Ιδίωμα RAII (Resource Acquisition Is Initialization)
Το RAII αποτελεί το σήμα κατατεθέν της ασφαλούς σχεδίασης σε C++:
- Η δέσμευση ενός πόρου (μνήμη, file handle, socket, mutex) γίνεται μέσα στον **Constructor**.
- Η αυτόματη και εγγυημένη απελευθέρωση του πόρου γίνεται μέσα στον **Destructor**.
- Με αυτόν τον τρόπο, ακόμα και αν παραχθεί εξαίρεση (exception), η αυτόματη εκτύλιξη στοίβας (stack unwinding) καλεί τους destructors όλων των τοπικών αντικειμένων, αποτρέποντας διαρροές πόρων.

## 3. Κατηγορίες Smart Pointers της `<memory>`

### 3.1 `std::unique_ptr<T>`
- Μοντέλο αυστηρά μοναδικής ιδιοκτησίας.
- Δεν επιτρέπεται η αντιγραφή (`deleted copy constructor`), επιτρέπεται μόνο η μετακίνηση (`std::move`).
- Μηδενικό overhead σε χρόνο και μνήμη (Zero-Cost Abstraction).
- Δημιουργία με `std::make_unique<T>(args...)`.

### 3.2 `std::shared_ptr<T>`
- Μοντέλο συνιδιοκτησίας με μετρητή αναφορών (Reference Count).
- Το αντικείμενο διαγράφεται αυτόματα όταν ο μετρητής αναφορών φτάσει στο 0.
- Δημιουργία με `std::make_shared<T>(args...)`.

### 3.3 `std::weak_ptr<T>`
- Δείκτης παρατήρησης χωρίς ιδιοκτησία (δεν αυξάνει το reference count).
- Χρησιμοποιείται για να σπάσει κυκλικές εξαρτήσεις (`shared_ptr` cycles) και για caches.
- Μετατρέπεται σε `shared_ptr` μέσω της `lock()` για ασφαλή προσπέλαση.
