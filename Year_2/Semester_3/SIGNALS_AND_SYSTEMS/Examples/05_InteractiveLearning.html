Οπτικοποίηση Απόκρισης Συστήματος

y(t) = System[x(t)]

1. Επιλογή Τύπου Συστήματος

$$y(t) = f(x(t))$$

2. Ρύθμιση Παραμέτρων

Ελέγχει τη χρονική αμεταβλητότητα (μετατοπίσεις t)

3. Ιδιότητες Συστήματος

  • Γραμμικότητα ✗ Μη Γραμμικό
  • Χρονική Αμεταβλητότητα ✗ Μεταβαλλόμενο στο Χρόνο
  • Αιτιατότητα ✓ Αιτιατό
  • Μνήμη Στατικό
  • Ευστάθεια (BIBO) ✓ Ευσταθές
  • Ταξινόμηση —

4. Δοκιμές Επαλήθευσης

📚 Αναφορά Ιδιοτήτων

Γραμμικότητα:
α·x₁(t) + β·x₂(t) → α·y₁(t) + β·y₂(t)

Χρονική Αμεταβλητότητα:
x(t-t₀) → y(t-t₀) (μετατόπιση εισόδου = μετατόπιση εξόδου)

Αιτιατότητα:
y(t) depends only on x(τ), τ ≤ t

Ευστάθεια BIBO:
|x(t)| ≤ M → |y(t)| ≤ N
