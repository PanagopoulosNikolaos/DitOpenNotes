# Διάλεξη 1: Εισαγωγή και Ταξινόμηση Σημάτων

## 1. Ορισμός Σήματος και Συστήματος
- **Σήμα (Signal):** Μια συνάρτηση μίας ή περισσότερων ανεξάρτητων μεταβλητών που φέρει πληροφορία για την κατάσταση ή τη συμπεριφορά ενός φυσικού φαινομένου.
- **Σύστημα (System):** Μια φυσική ή υπολογιστική οντότητα που δέχεται ένα ή περισσότερα σήματα εισόδου (διέγερση - excitation) και παράγει αντίστοιχα σήματα εξόδου (απόκριση - response).

---

## 2. Ταξινόμηση Σημάτων

### 2.1 Συνεχούς Χρόνου (CT) vs. Διακριτού Χρόνου (DT)
- **Σήμα Συνεχούς Χρόνου:** $x(t)$, όπου $t \in \mathbb{R}$ (αναλογικά σήματα).
- **Σήμα Διακριτού Χρόνου:** $x[n]$, όπου $n \in \mathbb{Z}$ (ακολουθίες δειγμάτων).

### 2.2 Περιοδικά vs. Μη Περιοδικά Σήματα
- Ένα σήμα συνεχούς χρόνου $x(t)$ είναι περιοδικό με θεμελιώδη περίοδο $T_0 > 0$ εάν:
  $$x(t + T_0) = x(t), \quad \forall t \in \mathbb{R}$$
  Η θεμελιώδης κυκλική συχνότητα είναι $\omega_0 = \frac{2\pi}{T_0}$.
- Ένα σήμα διακριτού χρόνου $x[n]$ είναι περιοδικό με ακέραια περίοδο $N > 0$ εάν:
  $$x[n + N] = x[n], \quad \forall n \in \mathbb{Z}$$

### 2.3 Σήματα Ενέργειας vs. Σήματα Ισχύος
- **Ολική Ενέργεια Σήματος ($E$):**
  $$E_{CT} = \int_{-\infty}^{\infty} |x(t)|^2 \, dt, \quad E_{DT} = \sum_{n=-\infty}^{\infty} |x[n]|^2$$
- **Μέση Ισχύς Σήματος ($P$):**
  $$P_{CT} = \lim_{T \to \infty} \frac{1}{2T} \int_{-T}^{T} |x(t)|^2 \, dt, \quad P_{DT} = \lim_{N \to \infty} \frac{1}{2N+1} \sum_{n=-N}^{N} |x[n]|^2$$
- Εάν $0 < E < \infty \implies P = 0$ (Σήμα Ενέργειας, π.χ. παλμός).
- Εάν $0 < P < \infty \implies E = \infty$ (Σήμα Ισχύος, π.χ. ημιτονοειδές περιοδικό σήμα).

### 2.4 Άρτια και Περιττά Σήματα
Κάθε σήμα $x(t)$ αναλύεται μονοσήμαντα σε άρτιο $x_e(t)$ και περιττό $x_o(t)$ μέρος:
$$x(t) = x_e(t) + x_o(t)$$
$$x_e(t) = \frac{x(t) + x(-t)}{2} \quad [x_e(-t) = x_e(t)]$$
$$x_o(t) = \frac{x(t) - x(-t)}{2} \quad [x_o(-t) = -x_o(t)]$$

## 3. Βασικά Σήματα Αναφοράς
1. **Μοναδιαία Βηματική Συνάρτηση (Unit Step Function):**
   $$u(t) = \begin{cases} 1, & t \ge 0 \\ 0, & t < 0 \end{cases}, \quad u[n] = \begin{cases} 1, & n \ge 0 \\ 0, & n < 0 \end{cases}$$
2. **Συνάρτηση Δέλτα Dirac / Μοναδιαία Κρουστική (Dirac Delta / Unit Impulse):**
   $$\delta(t) = 0 \text{ για } t \ne 0, \quad \int_{-\infty}^{\infty} \delta(t) \, dt = 1, \quad \delta[n] = \begin{cases} 1, & n = 0 \\ 0, & n \ne 0 \end{cases}$$
3. **Ιδιότητα Δειγματοληψίας (Sifting Property):**
   $$\int_{-\infty}^{\infty} x(t) \delta(t - t_0) \, dt = x(t_0)$$
