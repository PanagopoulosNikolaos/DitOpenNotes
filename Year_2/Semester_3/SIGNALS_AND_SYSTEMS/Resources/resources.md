# Signals and Systems: Curated Resources and Reference Guide

A curated guide of primary textbooks, interactive simulation tools, computational software packages, and reference materials for Signals and Systems (Course Code 303).

---

## 1. Foundational Textbooks

- **Signals and Systems (2nd Edition)**  
  *Authors:* Alan V. Oppenheim, Alan S. Willsky, and S. Hamid Nawab.  
  *Annotation:* The definitive international reference text covering continuous and discrete signals, LTI system analysis, convolution, Fourier series/transforms, Laplace transforms, and sampling theory.

- **Signals and Systems**  
  *Authors:* Fatos Tunay Yarman Vural.  
  *Annotation:* Comprehensive presentation of linear system properties, transform methods, and time/frequency domain representations.

- **Think DSP: Digital Signal Processing in Python**  
  *Author:* Allen B. Downey.  
  *Annotation:* A hands-on, code-first introduction to signal processing in Python using sound generation, spectral analysis, and convolution.

---

## 2. Computational Software and Libraries

- **SciPy Signal Processing Subpackage (`scipy.signal`)**  
  *URL:* `https://docs.scipy.org/doc/scipy/reference/signal.html`  
  *Description:* Python library offering state-of-the-art functions for continuous and discrete convolution, filter design, frequency response analysis, and LTI state-space simulation.

- **NumPy**  
  *URL:* `https://numpy.org/`  
  *Description:* Core numerical computing library for multidimensional array manipulation and vectorized signal math.

- **Matplotlib**  
  *URL:* `https://matplotlib.org/`  
  *Description:* Comprehensive plotting library for rendering time-domain waveforms, phase portraits, and frequency spectra.
