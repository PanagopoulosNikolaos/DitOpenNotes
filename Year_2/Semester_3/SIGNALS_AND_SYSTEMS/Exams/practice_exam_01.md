## Ενδεικτικές Απαντήσεις & Λύσεις

### Λύση Θέματος 1:
1. Το σήμα είναι περιοδικό (άθροισμα δύο συνιστωσών με συχνότητες $f_1 = 50\text{ Hz}$ και $f_2 = 150\text{ Hz}$). Ενέργεια $E = \infty$. Μέση ισχύς $P = \frac{A_1^2}{2} + \frac{A_2^2}{2} = \frac{4^2}{2} + \frac{2^2}{2} = 8 + 2 = 10\text{ W}$.
2. $x_e(t) = \frac{e^{-2t}\cos(5t) + e^{2t}\cos(-5t)}{2} = \cos(5t) \frac{e^{2t} + e^{-2t}}{2} = \cosh(2t)\cos(5t)$.
   $x_o(t) = \frac{e^{-2t}\cos(5t) - e^{2t}\cos(5t)}{2} = -\sinh(2t)\cos(5t)$.

### Λύση Θέματος 2:
1. $y(t) = \int_0^t e^{-2\tau} d\tau = \frac{1 - e^{-2t}}{2}$ για $0 \le t \le 1$.
   Για $t > 1$: $y(t) = \int_{t-1}^t e^{-2\tau} d\tau = \frac{e^{-2(t-1)} - e^{-2t}}{2} = \frac{e^2 - 1}{2} e^{-2t}$.
2. (α) Γραμμικό (το ολοκλήρωμα είναι γραμμικός τελεστής), (β) Χρονικά Αμετάβλητο, (γ) **Μη αιτιατό** (εξαρτάται από μελλοντικές τιμές έως $t+2$), (δ) **BIBO ευστάθες** (αν $|x(t)| \le M$, τότε $|y(t)| \le \int_{t-2}^{t+2} M d\tau = 4M < \infty$).

### Λύση Θέματος 3:
1. $X(j\omega) = \int_{-\infty}^0 e^{3t} e^{-j\omega t} dt + \int_0^\infty e^{-3t} e^{-j\omega t} dt = \frac{1}{3 - j\omega} + \frac{1}{3 + j\omega} = \frac{6}{\omega^2 + 9}$.
2. Σε $\omega_0 = 3\text{ rad/s}$: $H(j3) = \frac{1}{4 + j3}$.
   Μέτρο $|H(j3)| = \frac{1}{\sqrt{4^2 + 3^2}} = \frac{1}{5} = 0.2$.
   Φάση $\angle H(j3) = -\arctan(3/4) \approx -36.87^\circ = -0.6435\text{ rad}$.
   Έξοδος: $y(t) = 0.2 \cos(3t - 0.6435)$.

### Λύση Θέματος 4:
1. $H(s) = \frac{s + 2}{s^2 + 4s + 3} = \frac{s + 2}{(s + 1)(s + 3)}$.
   Μηδενικό: $s = -2$. Πόλοι: $s = -1, s = -3$.
   Ανάλυση σε απλά κλάσματα: $H(s) = \frac{0.5}{s + 1} + \frac{0.5}{s + 3}$.
   Κρουστική απόκριση (για αιτιατό σύστημα): $h(t) = 0.5 (e^{-t} + e^{-3t}) u(t)$.
2. Ένα σύστημα είναι αιτιατό αν η ROC είναι δεξιό ημιεπίπεδο πέρα από τον δεξιότερο πόλο ($\text{Re}\{s\} > \sigma_{max}$). Είναι ευστάθες αν η ROC περιέχει τον φανταστικό άξονα $j\omega$. Για να ισχύουν ταυτόχρονα, όλοι οι πόλοι πρέπει να έχουν αυστηρά αρνητικό πραγματικό μέρος.
