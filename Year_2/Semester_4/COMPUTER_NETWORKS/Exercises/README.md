# Λυμένες Ασκήσεις Δικτύων Υπολογιστών

## Περίληψη Καταλόγου
Θεματικές σειρές ασκήσεων για την εμπέδωση της διδαχθείσας ύλης των δικτύων. Εστιάζει σε υπολογισμούς καθυστέρησης, υποδικτύωση (subnetting), διαγράμματα καταστάσεων TCP και αλγορίθμους δρομολόγησης.

## Περιεχόμενα Καταλόγου
- [subnetting_and_vlsm.md](subnetting_and_vlsm.md) — Ασκήσεις διαχωρισμού διευθύνσεων IP σε υποδίκτυα μεταβλητού μήκους μάσκας (VLSM).
- [delay_and_bandwidth_calculations.md](delay_and_bandwidth_calculations.md) — Υπολογισμοί καθυστέρησης άκρου σε άκρο και γινομένου εύρους-καθυστέρησης (BDP).
