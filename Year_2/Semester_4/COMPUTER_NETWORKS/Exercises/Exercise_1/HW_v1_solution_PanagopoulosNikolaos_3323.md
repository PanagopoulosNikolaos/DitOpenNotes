**Explanation:**
This section tracks diagnostic messages (such as Ping or Errors). The output shows 40 received and 44 sent "destination unreachable" messages, meaning that your system or a remote computer attempted to connect to a port that was not open.

#### TCP Statistics
```bash
netstat -s -p tcp # data dump command
netstat -s | awk '/^Tcp:/,/^Udp:/' # filtered 
```
```bash
ice@ice:~$ netstat -s | awk '/^Tcp:/,/^Udp:/'
Tcp:
    1319 active connection openings
    127 passive connection openings
    10 failed connection attempts
    17 connection resets received
    31 connections established
    86226 segments received
    93222 segments sent out
    368 segments retransmitted
    0 bad segments received
    990 resets sent
Udp:
```
**Explanation:**
This tracks reliable handshake-based connections. It shows how many connections were initiated (active) versus accepted (passive). The "retransmitted" count is a key health metric — a high number here indicates a poor connection or packet loss.

**Explanation:**
This tracks connectionless traffic (such as DNS or streaming). "Unknown port" means packets arrived for an application that was not running. "Receive buffer errors" usually mean the system was too busy to process the data, causing small data losses.

**Why does RTT change on every attempt?**
- The round-trip time (RTT) changes on every attempt because it is a dynamic estimate rather than a fixed value. It is affected by varying network conditions (congestion, routing) that fluctuate at the millisecond level. Each packet represents a distinct and independent measurement.

**Observation / parameter explanation:**
- The -s parameter is used to specify the ICMP echo request payload size in bytes. The default size is 1472 bytes, which is the maximum payload size that can be sent without fragmentation.
**Does the average latency increase? If so — transmission time or propagation time?**
- Yes, average latency increases with packet size. This is because larger packets require more transmission time to be sent over the network link.
**Why does command (d) fail?**
- The command fails because the payload size exceeds the Maximum Transmission Unit (MTU) or ICMP protocol limits without fragmentation being possible, and because the total IP packet size exceeds the 65,535-byte limit.

### Bonus — RFC 1149 & script.py

#### iii) RFC 1149: Pigeon vs Internet
According to **RFC 1149 (IP over Avian Carriers)**, a carrier pigeon can indeed transport data. 
- **Latency:** Pigeons have an extremely high RTT (can be hours), making them unsuitable for online gaming or video calls.
- **Bandwidth:** If a pigeon carries a 1TB microSD card, the effective bandwidth for transferring a massive amount of data can be higher than a slow Internet connection. 
- **Conclusion:** The Internet is faster for small data and real-time interaction (low latency), but a pigeon can excel at transferring huge data volumes over long distances if high-speed infrastructure is lacking.
- **Real-World Example (Winston the Pigeon):** In 2009, **Unlimited IT** in South Africa proved this theory. An employee complained that data moved faster by pigeon than over ADSL. To prove it, Winston the pigeon carried a 4 GB microSD card over a distance of 60 miles in 1 hour and 8 minutes. Including copy time, the process took ~2 hours and 6 minutes. In the same timeframe, Telkom's ADSL connection had transferred only 4% of the data.


#### script.py
```python

import subprocess
import re
import numpy as np
import matplotlib
try:
    matplotlib.use('TkAgg')
except ImportError:
    matplotlib.use('Agg')

import matplotlib.pyplot as plt

def pingTargets(targets: list, sizes: list, count: int = 30) -> dict:
    """
    Executes ping searches for multiple hosts with varying payload sizes.

    Args:
        targets (list): Hostnames or IP addresses to reach.
        sizes (list): Integer list of payload sizes in bytes.
        count (int): Number of ICMP echoes to transmit per target/size.

    Returns:
        dict: Hierarchical dictionary containing min, avg, max RTT statistics.
    """
    results = {}
    for target in targets:
        results[target] = {}
        for size in sizes:
            cmd = ["ping", "-s", str(size), "-c", str(count), target]
            process_result = subprocess.run(cmd, capture_output=True, text=True)
            
            match = re.search(r"(\d+\.?\d*)/(\d+\.?\d*)/(\d+\.?\d*)", process_result.stdout)
            if match:
                results[target][size] = {
                    "min": float(match.group(1)),
                    "avg": float(match.group(2)),
                    "max": float(match.group(3))
                }
            else:
                results[target][size] = None
    return results

def displayResults(results: dict, targets: list, sizes: list):
    """
    Prints a formatted table of the collected RTT metrics.

    Args:
        results (dict): Population data containing the ping statistics.
        targets (list): The list of targets to include in the table.
        sizes (list): The list of packet sizes to include in the table.
    """
    print(f"{'Target':<20} {'Size':>6} {'Min':>8} {'Avg':>8} {'Max':>8}")
    print("-" * 55)
    for target in targets:
        for size in sizes:
            if results.get(target) and results[target].get(size):
                r = results[target][size]
                print(f"{target:<20} {size:>6} {r['min']:>8.2f} {r['avg']:>8.2f} {r['max']:>8.2f}")

def visualizeResults(results: dict, targets: list, sizes: list):
    """
    Generates a 3D bar chart representing the Average RTT across targets and sizes.

    Args:
        results (dict): Population data containing the ping statistics.
        targets (list): Valid hostnames used as one axis.
        sizes (list): Integer sizes used as the second axis.
    """
    fig = plt.figure(figsize=(12, 8))
    ax = fig.add_subplot(111, projection='3d')

    x_positions = np.arange(len(targets))
    y_positions = np.arange(len(sizes))
    x_positions, y_positions = np.meshgrid(x_positions, y_positions)
    
    x_flattened = x_positions.flatten()
    y_flattened = y_positions.flatten()
    z_bottom = np.zeros_like(x_flattened)
    
    rtt_values = []
    for s_idx, size in enumerate(sizes):
        for t_idx, target in enumerate(targets):
            val = results[target][size]["avg"] if results[target][size] else 0
            rtt_values.append(val)
    
    ax.bar3d(x_flattened, y_flattened, z_bottom, 0.5, 0.5, rtt_values, shade=True, color='skyblue')

    ax.set_xticks(np.arange(len(targets)))
    ax.set_xticklabels(targets)
    ax.set_yticks(np.arange(len(sizes)))
    ax.set_yticklabels([f"{s} B" for s in sizes])
    ax.set_zlabel('Avg RTT (ms)')
    ax.set_title('3D Average RTT Analysis per Target and Packet Size')

    plt.savefig('images/rtt_3d_analysis.png')
    print("\nVisualization saved to images/rtt_3d_analysis.png")
    plt.show()

if __name__ == "__main__":
    target_list = ["google.com", "youtube.com", "wikipedia.org", "uoi.gr"]
    size_list = [56, 512, 1024]
    packet_count = 30 

    ping_data = pingTargets(target_list, size_list, packet_count)
    displayResults(ping_data, target_list, size_list)
    visualizeResults(ping_data, target_list, size_list)
```
