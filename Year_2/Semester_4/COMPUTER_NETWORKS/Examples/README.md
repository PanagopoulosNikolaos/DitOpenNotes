# Computer Networks: Code Examples

This directory provides practical, runnable implementations demonstrating network socket communication, protocol modeling, and transport layer primitives.

| File | Language / Type | Description |
|:---|:---|:---|
| [`examples_socket_programming_tcp_udp.py`](examples_socket_programming_tcp_udp.py) | Python 3 | Self-contained multi-threaded TCP echo server/client and connectionless UDP echo server/client |
| [`examples_socket_programming_walkthrough.md`](examples_socket_programming_walkthrough.md) | Markdown | Detailed walkthrough explaining socket lifecycles, TCP vs. UDP semantics, and execution instructions |
| [`Lect-Exercises.md`](Lect-Exercises.md) | Markdown | Lecture example problem set on transmission, propagation, and queuing delays |
| [`Lect-Exercises-solutions.md`](Lect-Exercises-solutions.md) | Markdown | Complete worked solutions for lecture example problem sets |
| [`Lect-Exercises.pdf`](Lect-Exercises.pdf) | PDF | Slide handouts for lecture examples |
