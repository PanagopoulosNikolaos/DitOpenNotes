# Εργαστηριακός Οδηγός 1: Ανάλυση Πακέτων Δικτύου με το Wireshark

## 1. Σκοπός Εργαστηρίου
Σκοπός της εργαστηριακής άσκησης είναι η εξοικείωση με το εργαλείο ανάλυσης πρωτοκόλλων Wireshark, η σύλληψη (capture) δικτυακής κίνησης και η εξέταση των δομών δεδομένων στα επίπεδα Εφαρμογής (HTTP/DNS), Μεταφοράς (TCP/UDP), Δικτύου (IPv4/ICMP) και Ζεύξης (Ethernet II).

---

## 2. Προετοιμασία και Εγκατάσταση
Σε περιβάλλον Linux/Ubuntu:
```bash
sudo apt-get update
sudo apt-get install -y wireshark tshark
sudo usermod -aG wireshark $USER
```

---

## 3. Φίλτρα Σύλληψης και Εμφάνισης (Capture & Display Filters)

### Φίλτρα Εμφάνισης (Display Filters)
- `tcp.port == 80`: Εμφάνιση μόνο της κίνησης HTTP.
- `ip.addr == 192.168.1.1`: Εμφάνιση πακέτων όπου η IP πηγής ή προορισμού είναι η δηλωθείσα.
- `tcp.flags.syn == 1 && tcp.flags.ack == 0`: Εντοπισμός αιτημάτων έναρξης σύνδεσης TCP (SYN).
- `dns.qry.name contains "dit"`: Εντοπισμός ερωτημάτων DNS που περιέχουν τη συμβολοσειρά "dit".
- `icmp`: Παρακολούθηση πακέτων ping echo request/reply.

---

## 4. Βήμα-προς-Βήμα Εργαστηριακή Διαδικασία

### Βήμα 4.1: Ανάλυση της Χειραψίας TCP (3-Way Handshake)
1. Εκκινήστε τη σύλληψη στη διεπαφή `eth0` ή `wlan0`.
2. Στο τερματικό, εκτελέστε αίτημα προς έναν απομακρυσμένο web server:
   ```bash
   curl -I http://example.com
   ```
3. Σταματήστε τη σύλληψη και εφαρμόστε το φίλτρο `tcp.port == 80`.
4. Εντοπίστε τα τρία διαδοχικά πακέτα:
   - **Πακέτο 1 [SYN]:** Εξετάστε το `Sequence Number = 0 (relative)`, τα TCP Options (MSS, Window Scale, SACK Permitted).
   - **Πακέτο 2 [SYN, ACK]:** Εξετάστε το `Acknowledgment Number = 1` (ισούται με Client ISN + 1).
   - **Πακέτο 3 [ACK]:** Εξετάστε την επιβεβαίωση και το μέγεθος του ανακοινωθέντος παραθύρου.

### Βήμα 4.2: Ανάλυση Ανταλλαγής DNS
1. Εφαρμόστε το φίλτρο `dns`.
2. Εκτελέστε:
   ```bash
   dig www.uop.gr +trace
   ```
3. Παρατηρήστε την αναδρομική επίλυση διευθύνσεων, το πεδίο Transaction ID, τα Flags (QR, Opcode, AA, RD, RA) και τις απαντήσεις τύπου A και CNAME.
