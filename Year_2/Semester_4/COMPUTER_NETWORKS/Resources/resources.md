# Computer Networks: Curated Resources and Reference Guide

A curated reference guide of authoritative textbooks, standard specifications, network simulation platforms, and packet analysis tools for Computer Networks (Course Code 403).

---

## 1. Foundational Textbooks

- **Computer Networking: A Top-Down Approach**  
  *Authors:* James F. Kurose and Keith W. Ross.  
  *Annotation:* The definitive undergraduate reference for modern networking, covering application-layer protocols down to the physical layer, with emphasis on delay modeling, TCP congestion control, and routing algorithms.

- **Computer Networks**  
  *Authors:* Andrew S. Tanenbaum, Nick Feamster, and David J. Wetherall.  
  *Annotation:* A comprehensive engineering guide detailing physical layer signaling, data link layer framing, sliding window protocols, and network layer architecture.

- **TCP/IP Illustrated, Volume 1: The Protocols**  
  *Author:* W. Richard Stevens.  
  *Annotation:* An essential systems-level guide illustrating real-world protocol interactions, packet headers, and kernel socket states through network traces.

---

## 2. Network Simulation and Analysis Tools

- **Wireshark Network Protocol Analyzer**  
  *URL:* `https://www.wireshark.org/`  
  *Description:* Industry-standard packet capture and packet dissection utility for live protocol inspection and delay analysis.

- **Cisco Packet Tracer**  
  *URL:* `https://www.netacad.com/courses/packet-tracer`  
  *Description:* Comprehensive network simulation and modeling software for designing topologies, configuring Cisco IOS switches/routers, and testing VLANs.

- **Mininet**  
  *URL:* `http://mininet.org/`  
  *Description:* Software-defined networking emulator that creates virtual networks of OpenFlow switches, controllers, and Linux hosts on a single system.

---

## 3. Protocol Specifications (IETF RFCs)

- **RFC 791:** Internet Protocol (IPv4) Specification.
- **RFC 793:** Transmission Control Protocol (TCP) Specification.
- **RFC 768:** User Datagram Protocol (UDP) Specification.
- **RFC 2328:** OSPF Version 2 Routing Specification.
- **RFC 5681:** TCP Congestion Control (Slow Start, Congestion Avoidance, Fast Retransmit, Fast Recovery).
