# Computer Networks (Mindmap)

* **Network at the Edge**
  * End Systems
    * Network as a service
    * Client program
    * Host / Central node
    * Peer-to-peer networks
  * Network Access
    * Wired system connection
    * Wireless connection
    * Communication (Cables)
    * Telecommunications services
* **The Internet**
  * Hardware: Equipment, cables
  * Protocols (TCP/IP, DNS, etc.)
  * Optical fiber, satellite
  * Data transfer between devices
* **Network Structure**
  * Network Edge
    * Clients and Servers
    * Access networks
  * Network Core
    * Interconnected routers
    * Network of networks
  * Nodes
    * Routers, switches, modems
    * Intermediate nodes (access networks)
* **Access Technologies**
  * Home Networks
    * DSL (Asymmetric / Symmetric)
    * HFC / Cable (Coaxial & Fiber)
    * FTTH
  * Enterprise / Institutional
    * Ethernet
  * Mobile / Wireless
    * Wi-Fi
    * 4G / 5G
* **Physical Media**
  * Copper (coaxial and twisted pair)
  * Optical fiber (single-mode)
  * Satellite (Geostationary / LEO)
  * Wireless (terrestrial microwave)
* **Data Switching**
  * Information exchange
  * Packet & Circuit Switching
  * Packet forwarding
  * Routing algorithms
* **Basic Issues**
  * Addressing and naming
  * Routing
  * Error detection
  * Security and cryptography
