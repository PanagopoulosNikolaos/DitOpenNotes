# Computer Networks: Academic Resources & Tools

Curated study materials, presentation decks, interactive web application, and quizzes for **Computer Networks (Code: 403)**.

---

## Directory Contents

- [`Notes/`](Notes/): Granular topic study guides (Topics 1 through 7) and comprehensive exam preparation notes.
- [`Presentations/`](Presentations/): PowerPoint slide decks covering the Internet blueprint, physical layer, and core architecture.
- [`app/`](app/): Interactive NiceGUI web application for network delay modeling, scenario analysis, and visual network topology simulation.
- [`Quizzes/`](Quizzes/): Automated 184-question self-assessment quiz engine (`quiz_app.py`).
- [`Meta/`](Meta/): Course concept mindmap (`mindmap.md`).
- [`resources.md`](resources.md): Curated reference textbooks and official RFC standards bibliography.
