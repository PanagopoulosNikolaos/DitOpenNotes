## 1. Πολυμεταβλητές Τυχαίες Μεταβλητές - Θεμελιώδεις

Οι πολυμεταβλητές μοντελοποιούν την κοινή συμπεριφορά πολλαπλών μετρήσεων εκτέλεσης (π.χ. $T_1$ και $T_2$).

### Κοινό PDF και Κανονικοποίηση
$$\int_{-\infty}^{\infty} \int_{-\infty}^{\infty} f_{T_1, T_2}(t_1, t_2) \, dt_1 \, dt_2 = 1$$
Πιθανότητα σε μια περιοχή $R$: $P((T_1, T_2) \in R) = \iint_R f(t_1, t_2) \, dt_1 \, dt_2$.

### Οριακά και υπό όρους PDF
**Οριακό:** $f_{T_1}(t_1) = \int_{-\infty}^{\infty} f_{T_1, T_2}(t_1, t_2) \, dt_2$.
**Υπό όρους:** $f_{T_2 \mid T_1}(t_2 \mid t_1) = \frac{f_{T_1, T_2}(t_1, t_2)}{f_{T_1}(t_1)}$.

### Ανεξαρτησία
Τα $T_1$ και $T_2$ είναι ανεξάρτητα εάν $f(t_1, t_2) = f_{T_1}(t_1) \cdot f_{T_2}(t_2)$ για όλες τις περιοχές.

## 2. Πολυμεταβλητές Στιγμές, Συνδιακύμανση και Προσδοκία υπό όρους

### Συνδιακύμανση και συσχέτιση
Η **Συνδιακύμανση** μετρά τη γραμμική εξάρτηση:
$$\text{Cov}(T_1, T_2) = E[T_1 T_2] - E[T_1] E[T_2]$$
**Συσχέτιση ($\rho$):**
$$\rho_{T_1, T_2} = \frac{\text{Cov}(T_1, T_2)}{\sigma_{T_1} \sigma_{T_2}}$$

### Διακύμανση αθροισμάτων
Για σταθερές $a, b$:
$$V(a T_1 + b T_2) = a^2 V(T_1) + b^2 V(T_2) + 2 a b \text{Cov}(T_1, T_2)$$
Εάν το $T_1, T_2$ είναι ανεξάρτητο, $\text{Cov} = 0$, άρα $V(T_1 + T_2) = V(T_1) + V(T_2)$.

### Προσδοκία υπό όρους
Νόμος της συνολικής προσδοκίας: $E[T_1] = E_{T_2} \left[ E_{T_1 \mid T_2}(T_1 \mid T_2) \right]$.

## 3. Συναρτήσεις πολλαπλών τυχαίων μεταβλητών & στατιστικές παραγγελιών

### Συνέλιξη (Αθροίσματα)
Για ανεξάρτητο $T_1, T_2$, το PDF του $Y = T_1 + T_2$ είναι:
$$f_Y(y) = \int_{-\infty}^{\infty} f_{T_1}(t) \, f_{T_2}(y - t) \, dt$$

### Στατιστικά παραγγελιών (Ελάχιστο και μέγιστο)
Για $n$ i.i.d. μεταβλητές με CDF $F(t)$ και PDF $f(t)$:
* **Μέγ. (Παράλληλη συμφόρηση):** $F_{\max}(t) = [F(t)]^n$, $f_{\max}(t) = n[F(t)]^{n-1}f(t)$
* **Ελάχιστο (Πρώτος έως Τερματισμός):** $F_{\min}(t) = 1 - [1 - F(t)]^n$

## 4. Χρόνος-Specific Gotchas

1. **Εξαρτημένες περιοχές υποστήριξης:** Εάν τα όρια ενσωμάτωσης για $T_1$ εξαρτώνται από $T_2$ (π.χ. $0 \le t_1 \le t_2 \le 1$), οι μεταβλητές είναι **εξαρτώμενες**, ακόμα κι αν το PDF είναι σταθερό.
2. **Μη συσχετισμένη $\neq$ Ανεξάρτητη:** Για μη Gaussian μεταβλητές, η μηδενική συνδιακύμανση δεν εγγυάται την ανεξαρτησία.
3. **Διακύμανση της συνολικής επεξεργασίας:** Να συμπεριλαμβάνεται πάντα το $2\text{Cov}(T_1, T_2)$ κατά τον υπολογισμό του $V(T_1 + T_2)$ εάν τα στοιχεία μοιράζονται πόρους.
4. **Υποεκτίμηση παράλληλης καθυστέρησης:** Ο μέσος χρόνος παράλληλης εκτέλεσης $E[\max(T_1, \dots, T_n)]$ είναι αυστηρά μεγαλύτερος από τον μέσο όρο μιας εργασίας $E[T]$.
5. **Άθροισμα εκθετικών με διαφορετικούς ρυθμούς:** Είναι μια υποεκθετική κατανομή, όχι μια κατανομή Γάμμα.

## 5. Λυμένες Ασκήσεις

#### Άσκηση 1: Εύρεση κανονικοποιώντας σταθερά $k$ για κοινούς χρόνους επεξεργασίας
**Πρόβλημα:** $f(t_1, t_2) = k \cdot t_1 t_2$ για $0 \le t_1 \le 2$ και $0 \le t_2 \le 3$. Βρείτε $k$.
**Λύση:**
$$\int_{0}^{2} \int_{0}^{3} k t_1 t_2 \, dt_2 \, dt_1 = k \left[ \frac{t_1^2}{2} \right]_0^2 \left[ \frac{t_2^2}{2} \right]_0^3 = k (2) (4.5) = 9k = 1 \implies k = 1/9$$

#### Άσκηση 2: Υπολογισμός οριακών αρχείων PDF
**Πρόβλημα:** Βρείτε $f_{T_1}(t_1)$ για $f(t_1, t_2) = \frac{1}{9} t_1 t_2$ στο $[0, 2] \times [0, 3]$.
**Λύση:**
$$f_{T_1}(t_1) = \int_{0}^{3} \frac{1}{9} t_1 t_2 \, dt_2 = \frac{t_1}{9} \left[ \frac{t_2^2}{2} \right]_0^3 = \frac{4.5 t_1}{9} = \frac{t_1}{2}, \quad 0 \le t_1 \le 2$$

#### Άσκηση 3: Έλεγχος της ανεξαρτησίας των μεταβλητών χρόνου
**Πρόβλημα:** Είναι οι $T_1$ και $T_2$ ανεξάρτητα από την Άσκηση 2;
**Λύση:**
$f_{T_2}(t_2) = \frac{2t_2}{9}$. Προϊόν $= (\frac{t_1}{2})(\frac{2t_2}{9}) = \frac{t_1 t_2}{9} = f(t_1, t_2)$. Ναι, ανεξάρτητο.

#### Άσκηση 4: PDF υπό όρους $f_{T_1 \mid T_2}(t_1 \mid t_2)$
**Πρόβλημα:** $f(t_1, t_2) = 8 t_1 t_2$ σε $0 \le t_1 \le t_2 \le 1$. Βρείτε $f_{T_1 \mid T_2}(t_1 \mid 0.5)$.
**Λύση:**
$f_{T_2}(t_2) = \int_0^{t_2} 8 t_1 t_2 dt_1 = 4 t_2^3$.
$$f_{T_1 \mid T_2}(t_1 \mid t_2) = \frac{8 t_1 t_2}{4 t_2^3} = \frac{2 t_1}{t_2^2}$$Για $t_2 = 0.5$, $f(t_1 \mid 0.5) = \frac{2 t_1}{0.25} = 8 t_1$ για $0 \le t_1 \le 0.5$.

#### Άσκηση 5: Κοινή στιγμή προϊόντος $E[T_1 T_2]$
**Πρόβλημα:** $f(t_1, t_2) = \frac{1}{9} t_1 t_2$ σε $[0, 2] \times [0, 3]$. Υπολογίστε $E[T_1 T_2]$.
**Λύση:**
$$E[T_1 T_2] = \int_0^2 \int_0^3 t_1 t_2 \left( \frac{1}{9} t_1 t_2 \right) dt_2 dt_1 = \frac{1}{9} \left[\frac{t_1^3}{3}\right]_0^2 \left[\frac{t_2^3}{3}\right]_0^3 = \frac{1}{9} \times \frac{8}{3} \times 9 = \frac{8}{3}$$

#### Άσκηση 6: Συντελεστής συσχέτισης Pearson $\rho$
**Πρόβλημα:** $V(T_1) = 11/225$, $V(T_2) = 2/75$, $\text{Cov} = 11/300$. Βρείτε $\rho$.
**Λύση:**
$$\sigma_1 \sigma_2 = \sqrt{\frac{11}{225} \cdot \frac{2}{75}} \approx 0.036055$$
$$\rho = \frac{11/300}{0.036055} \approx \frac{0.036667}{0.036055} \approx 0.9574$$

#### Άσκηση 7: Διακύμανση αθροίσματος με θετική συσχέτιση
**Πρόβλημα:** $V(T_1) = 25$, $V(T_2) = 36$, $\text{Cov}(T_1, T_2) = 10$. Βρείτε $V(T_1 + T_2)$.
**Λύση:**
$$V(T_1 + T_2) = 25 + 36 + 2(10) = 81$$

#### Άσκηση 8: Προσδοκία υπό όρους για διμεταβλητή κανονική καθυστέρηση
**Πρόβλημα:** $T_1 \sim N(100, 100), T_2 \sim N(150, 400), \rho = 0.8$. Βρείτε $E[T_1 \mid T_2 = 170]$.
**Λύση:**
$$E[T_1 \mid T_2 = 170] = 100 + 0.8 \left(\frac{10}{20}\right) (170 - 150) = 100 + 8 = 108$$

#### Άσκηση 9: Συνέλιξη δύο ανεξάρτητων ομοιόμορφων σκηνικών χρόνων
**Πρόβλημα:** $T_1, T_2 \sim U(0, 1)$. Εύρεση PDF του $Y = T_1 + T_2$.
**Λύση:**
$f_Y(y) = \int_0^1 f_{T_1}(t) f_{T_2}(y - t) dt$.
$f_Y(y) = y$ για $0 \le y \le 1$ και $f_Y(y) = 2 - y$ για $1 < y \le 2$.

#### Άσκηση 10: Παράλληλη συμφόρηση εργασίας (μέγιστο 3 ομοιόμορφα RV)
**Πρόβλημα:** 3 εργασίες $T_i \sim U(0, 10)$. Βρείτε το PDF του $Y_{\max}$.
**Λύση:**
$F(t) = t/10$. $F_{(3)}(t) = (t/10)^3 = t^3/1000$.
$f_{(3)}(t) = 3t^2/1000$ για $0 \le t \le 10$.

#### Άσκηση 11: Αναμενόμενος χρόνος παράλληλης ολοκλήρωσης
**Πρόβλημα:** Βρείτε $E[Y_{\max}]$ από την Άσκηση 10.
**Λύση:**
$$E[Y_{\max}] = \int_0^{10} t \left(\frac{3t^2}{1000}\right) dt = \frac{3}{1000} \left[ \frac{t^4}{4} \right]_0^{10} = \frac{30}{4} = 7.5\text{ s}$$

#### Άσκηση 12: Διαφορά μεταξύ δύο κανονικών χρόνων εκτέλεσης
**Πρόβλημα:** $T_1 \sim N(100, 25)$ και $T_2 \sim N(90, 16)$, ανεξάρτητα. $P(T_1 < T_2)$;
**Λύση:**
$D = T_1 - T_2 \sim N(10, 41)$. $z = (0 - 10) / \sqrt{41} = -1.56$.
$P(D < 0) = \Phi(-1.56) = 0.0594 \text{ (5.94\%)}$.

#### Άσκηση 13: Επαλήθευση κωδικού R των στατιστικών παραγγελιών για παράλληλες εργασίες
**Πρόβλημα:** Υπολογίστε τον εμπειρικό μέσο όρο του μέγιστου 3 ομοιόμορφων μεταβλητών $U(0, 10)$.
**Διάλυμα:**```r
t1 <- runif(1000000, 0, 10)
t2 <- runif(1000000, 0, 10)
t3 <- runif(1000000, 0, 10)
t_max <- pmax(t1, t2, t3)
cat("Empirical E:", mean(t_max), "\n") # approx 7.5
```---

## Περίληψη Φάσης
Η Φάση 5Β επεκτείνει τη στατιστική εργαλειοθήκη σε Πολυμεταβλητές Τυχαίες Μεταβλητές, εστιάζοντας σε μεγάλο βαθμό στις αλληλεξαρτήσεις μεταξύ λειτουργικών μετρήσεων όπως διαδοχικές καθυστερήσεις φάσης ή παράλληλοι χρόνοι ολοκλήρωσης. Τα βασικά εργαλεία περιλαμβάνουν το κοινό PDF για τοπικές πιθανότητες και τις οριακές/συνθήκες πυκνότητες για την απομόνωση μεταβλητής συμπεριφοράς. Η συσχέτιση συνδιακύμανσης και Pearson ($\rho$) ποσοτικοποιούν οριστικά τη γραμμική συν-κίνηση, επηρεάζοντας άμεσα τη Διακύμανση των αθροισμάτων (το σύνολο του jitter του συστήματος αυξάνεται εάν τα στάδια συσχετίζονται θετικά). Τα στατιστικά στοιχεία παραγγελιών μοντελοποιούν ρητά τις κρίσιμες διαδρομές: το Μέγιστο ($Y_{\max}$) αντιστοιχίζει σε σημεία συμφόρησης παράλληλης εκτέλεσης, αποδεικνύοντας ότι ο μέσος χρόνος ολοκλήρωσης του συστήματος κλιμακώνεται αυστηρά χειρότερα από τους μέσους όρους μίας εργασίας. Τέλος, η συνέλιξη παρέχει απρόσκοπτα την πυκνότητα πιθανότητας των διαδοχικών χρόνων επεξεργασίας.
