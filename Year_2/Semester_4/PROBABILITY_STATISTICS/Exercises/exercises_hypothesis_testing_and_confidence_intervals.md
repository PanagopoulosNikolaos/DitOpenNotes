# Ασκήσεις Εμπέδωσης: Διαστήματα Εμπιστοσύνης και Έλεγχος Υποθέσεων

## Άσκηση 1: Διάστημα Εμπιστοσύνης για τη Μέση Τιμή

### Εκφώνηση:
Σε δείγμα $n = 64$ μετρήσεων καθυστέρησης δικτύου, βρέθηκε δειγματικός μέσος $\bar{x} = 34.5\text{ ms}$ και δειγματική τυπική απόκλιση $s = 8.0\text{ ms}$.
1. Κατασκευάστε διάστημα εμπιστοσύνης $95\%$ για την πραγματική μέση καθυστέρηση $\mu$.
2. Πόσο μεγάλο δείγμα $n'$ θα χρειαζόταν ώστε το περιθώριο σφάλματος (margin of error) να μειωθεί σε $E \le 1.0\text{ ms}$;

---

### Λύση:
1. Επειδή $n = 64 \ge 30$, βάσει του Κεντρικού Οριακού Θεωρήματος χρησιμοποιούμε την τυποποιημένη κανονική κατανομή.
   - Για στάθμη εμπιστοσύνης $95\%$, $\alpha = 0.05 \implies z_{\alpha/2} = z_{0.025} = 1.96$.
   - Περιθώριο σφάλματος:
     $$E = z_{\alpha/2} \frac{s}{\sqrt{n}} = 1.96 \times \frac{8.0}{\sqrt{64}} = 1.96 \times \frac{8.0}{8} = 1.96\text{ ms}$$
   - Διάστημα Εμπιστοσύνης $95\%$:
     $$\text{CI}_{95\%} = [34.5 - 1.96, \; 34.5 + 1.96] = \mathbf{[32.54\text{ ms}, \; 36.46\text{ ms}]}$$
2. Απαιτούμενο μέγεθος δείγματος για $E \le 1.0\text{ ms}$:
   $$n' \ge \left( \frac{z_{\alpha/2} \cdot s}{E} \right)^2 = \left( \frac{1.96 \times 8.0}{1.0} \right)^2 = (15.68)^2 \approx 245.86$$
   - Απαιτούνται τουλάχιστον $n' = \mathbf{246\text{ μετρήσεις}}$.

## Άσκηση 2: Έλεγχος Υποθέσεων για Έναν Μέσο

### Εκφώνηση:
Μια εταιρεία ισχυρίζεται ότι η μέση διάρκεια ζωής μιας μπαταρίας IoT αισθητήρα είναι τουλάχιστον 120 μήνες.
Σε ανεξάρτητο δείγμα $n = 36$ αισθητήρων, βρέθηκε μέση διάρκεια $\bar{x} = 117\text{ μήνες}$ με τυπική απόκλιση $s = 9\text{ μήνες}$.
Ελέγξτε τον ισχυρισμό της εταιρείας σε στάθμη σημαντικότητας $\alpha = 0.05$.

### Λύση:
1. **Διατύπωση Υποθέσεων:**
   - Μηδενική υπόθεση: $H_0: \mu \ge 120$ (ισχυρισμός εταιρείας).
   - Εναλλακτική υπόθεση: $H_1: \mu < 120$ (μονόπλευρος αριστερός έλεγχος).
2. **Στατιστική Συνάρτηση Ελέγχου:**
   $$z_{\text{calc}} = \frac{\bar{x} - \mu_0}{s / \sqrt{n}} = \frac{117 - 120}{9 / \sqrt{36}} = \frac{-3}{9 / 6} = \frac{-3}{1.5} = -2.00$$
3. **Κρίσιμη Τιμή και Απόφαση:**
   - Για στάθμη $\alpha = 0.05$ σε αριστερόπλευρο έλεγχο: $z_{\text{crit}} = -z_{0.05} = -1.645$.
   - Επειδή $z_{\text{calc}} = -2.00 < -1.645$ (η τιμή εμπίπτει στην περιοχή απόρριψης), **απορρίπτουμε τη μηδενική υπόθεση $H_0$**.
   - Υπάρχουν επαρκείς στατιστικές ενδείξεις ότι η μέση διάρκεια ζωής είναι μικρότερη από 120 μήνες ($p\text{-value} = P(Z \le -2.00) = 0.0228 < 0.05$).
