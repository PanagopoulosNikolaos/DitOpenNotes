# Μαθηματικές Συναρτήσεις στην R

* `log(x)` : Επιστρέφει τον λογάριθμο μιας μεταβλητής
* `exp(x)` : Επιστρέφει το εκθετικό μιας μεταβλητής
* `max(x)` : Επιστρέφει τη μέγιστη τιμή ενός διανύσματος
* `min(x)` : Επιστρέφει την ελάχιστη τιμή ενός διανύσματος
* `mean(x)` : Επιστρέφει τον μέσο όρο ενός διανύσματος
* `sum(x)` : Επιστρέφει το άθροισμα ενός διανύσματος
* `median(x)` : Επιστρέφει τη διάμεσο ενός διανύσματος
* `quantile(x)` : Ποσοστημόρια ποσοστών ενός διανύσματος
* `round(x, n)` : Στρογγυλοποίηση σε n δεκαδικά ψηφία
* `rank(x)` : Κατάταξη στοιχείων σε ένα διάνυσμα
* `signif(x, n)` : Στρογγυλοποίηση σε n σημαντικά ψηφία
* `var(x)` : Διακύμανση ενός διανύσματος
* `cor(x, y)` : Συσχέτιση μεταξύ δύο διανυσμάτων
* `sd(x)` : Τυπική απόκλιση ενός διανύσματος
