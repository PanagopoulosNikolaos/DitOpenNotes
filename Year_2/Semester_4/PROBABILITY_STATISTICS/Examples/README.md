# Probability and Statistics: Code Examples

This directory provides computational models and simulations in Python and R for exploratory data analysis, probability distribution synthesis, and statistical inference.

---

## Directory Contents

| File | Language | Focus | Description |
|:---|:---|:---|:---|
| [`examples_probability_distributions_and_clt.py`](examples_probability_distributions_and_clt.py) | Python 3 | Probability & CLT | Numerical PMF/PDF calculation for Binomial/Poisson/Normal distributions and Monte Carlo CLT verification across sample sizes |
| [`examples_descriptive_statistics_in_r.R`](examples_descriptive_statistics_in_r.R) | R | Descriptive Stats | Automated calculation of mean, median, variance, IQR, CV, and grouped frequency distribution tables with cumulative metrics |
| [`examples_probability_walkthrough.md`](examples_probability_walkthrough.md) | Markdown | Theory & Usage | Mathematical foundations of the CLT, formula definitions, and execution instructions |

---

## Execution Commands

```bash
# Run Python probability and CLT simulation
python3 examples_probability_distributions_and_clt.py

# Run R descriptive statistics
Rscript examples_descriptive_statistics_in_r.R
```
