## 1. Θεωρητικό Μέρος: Διάγνωση Σφαλμάτων Δικτύου
Ένα σύστημα επιτήρησης διακομιστών ανιχνεύει κυβερνοεπιθέσεις.
- Η πιθανότητα ένας τυχαίος server να δέχεται επίθεση σε δεδομένη στιγμή είναι $P(D) = 0.02$.
- Εάν ένας server δέχεται επίθεση, το σύστημα συναγερμού την ανιχνεύει σωστά με πιθανότητα $P(+ \mid D) = 0.98$ (Ευαισθησία).
- Εάν ένας server είναι ασφαλής, το σύστημα εσφαλμένα σημαίνει συναγερμό με πιθανότητα $P(+ \mid D^c) = 0.05$ (Ψευδώς Θετικό Αποτέλεσμα).

### Ζητούμενα:
1. Υπολογίστε τη συνολική πιθανότητα ενεργοποίησης συναγερμού $P(+)$ με το Θεώρημα Ολικής Πιθανότητας.
2. Εάν ηχήσει συναγερμός για έναν server, ποια είναι η πιθανότητα ο server πράγματι να δέχεται επίθεση $P(D \mid +)$; Σχολιάστε το αποτέλεσμα.

## 2. Υπολογιστικό Μέρος: Προσομοίωση Monte Carlo σε Python ή R
Υλοποιήστε προσομοίωση για τον εμπειρικό υπολογισμό της παραπάνω πιθανότητας:
- Προσομοιώστε $N = 100,000$ ανεξάρτητες δοκιμές.
- Καταγράψτε τον αριθμό των φορών που ήχησε συναγερμός και πόσες εξ αυτών αντιστοιχούσαν σε πραγματική επίθεση.
- Συγκρίνετε το αναλυτικό αποτέλεσμα με το πειραματικό και κατασκευάστε γράφημα σύγκλισης καθώς το $N$ αυξάνεται από $10^2$ σε $10^5$.
