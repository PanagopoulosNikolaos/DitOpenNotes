## 2. Ζητούμενα Ερωτήματα SQL
Συντάξτε τα ερωτήματα SQL για τις παρακάτω αναφορές:
1. Εμφανίστε τους πελάτες (ονοματεπώνυμο και πόλη) που έχουν συνολικές αγορές άνω των 5.000 ευρώ μέσα στο έτος 2024.
2. Βρείτε το δημοφιλέστερο προϊόν (αυτό με τη μεγαλύτερη συνολική πωληθείσα ποσότητα) ανά κατηγορία προϊόντος.
3. Εντοπίστε τους πελάτες που έχουν παραγγείλει **όλα** τα προϊόντα της κατηγορίας "Hardware" (υλοποίηση σχεσιακής διαίρεσης σε SQL με `NOT EXISTS` ή `COUNT(DISTINCT)`).
4. Δημιουργήστε μια ενημερώσιμη όψη (Updatable View) για τις παραγγελίες των τελευταίων 30 ημερών με χρήση `WITH CHECK OPTION`.
5. Γράψτε έναν κανόνα ακεραιότητας ή trigger που αποτρέπει την υποβολή παραγγελίας όταν το απόθεμα κάποιου προϊόντος είναι ανεπαρκές.
