# Database Systems: Curated Resources and Reference Guide

A curated reference guide of authoritative textbooks, database engines, query visualizers, and documentation for Database Systems (Course Code 404).

---

## 1. Foundational Textbooks

- **Fundamentals of Database Systems**  
  *Authors:* Ramez Elmasri and Shamkant B. Navathe.  
  *Annotation:* Standard reference for conceptual Entity-Relationship modeling, formal relational algebra, calculus, and normalization algorithms up to BCNF and 4NF.

- **Database System Concepts**  
  *Authors:* Abraham Silberschatz, Henry F. Korth, and S. Sudarshan.  
  *Annotation:* Comprehensive textbook covering relational algebra, SQL optimization, physical storage, indexing (B+ Trees, Hash Indexes), transactions, and concurrency control.

- **Database Management Systems**  
  *Authors:* Raghu Ramakrishnan and Johannes Gehrke.  
  *Annotation:* Known as the "Cow Book"; renowned for rigorous coverage of relational query evaluation, buffer management, crash recovery (ARIES), and schema refinement.

---

## 2. Interactive Tools and Query Analyzers

- **RelaX - Relational Algebra Calculator**  
  *URL:* `https://dbis-uibk.github.io/relax/`  
  *Description:* Online interactive calculator for executing formal relational algebra expressions on custom relational schemas with visual tree feedback.

- **SQLite CLI and Engine Documentation**  
  *URL:* `https://www.sqlite.org/docs.html`  
  *Description:* Authoritative specification of SQLite query syntax, query optimizer mechanics, and `EXPLAIN QUERY PLAN` output formats.

- **Use The Index, Luke!**  
  *URL:* `https://use-the-index-luke.com/`  
  *Description:* Essential guide to database indexing, multi-column index ordering, range scans, and execution plan profiling across SQL engines.

---

## 3. Reference Standards

- **ISO/IEC 9075: Information Technology - Database Languages - SQL**  
  *Description:* The international standard defining SQL syntax, transaction isolation levels (Read Uncommitted, Read Committed, Repeatable Read, Serializable), and integrity constraints.
