# Σημειώσεις Διαλέξεων Βάσεων Δεδομένων

## Περίληψη Καταλόγου
Αναλυτικές σημειώσεις για το σύνολο των 8 διαλέξεων του μαθήματος Βάσεις Δεδομένων (404). Καλύπτουν όλο το φάσμα από το μοντέλο ER και την SQL μέχρι τη θεωρία συναλλαγών, τα B+ Trees και το NoSQL.

## Περιεχόμενα Καταλόγου
- [lecture_01_introduction_to_databases.md](lecture_01_introduction_to_databases.md) — Εισαγωγή στα DBMS, επίπεδα αφαίρεσης δεδομένων, ανεξαρτησία δεδομένων.
- [lecture_02_entity_relationship_model.md](lecture_02_entity_relationship_model.md) — Μοντέλο Οντοτήτων-Συσχετίσεων (ER), γνωρίσματα, πρωτεύοντα κλειδιά, ασθενείς οντότητες.
- [lecture_03_relational_model_and_algebra.md](lecture_03_relational_model_and_algebra.md) — Σχεσιακό μοντέλο, περιορισμοί ακεραιότητας, τελεστές σχεσιακής άλγεβρας.
- [lecture_04_sql_ddl_dml_queries.md](lecture_04_sql_ddl_dml_queries.md) — Γλώσσα SQL, ορισμός σχημάτων DDL, χειρισμός δεδομένων DML, συναρτήσεις συνάθροισης.
- [lecture_05_relational_design_theory_and_normalization.md](lecture_05_relational_design_theory_and_normalization.md) — Λειτουργικές εξαρτήσεις, αξιώματα Armstrong, κανονικές μορφές 1NF, 2NF, 3NF, BCNF.
- [lecture_06_transaction_management_and_concurrency_control.md](lecture_06_transaction_management_and_concurrency_control.md) — Ιδιότητες ACID, σειριοποιησιμότητα, πρωτόκολλο κλειδώματος δύο φάσεων (2PL), αδιέξοδα.
- [lecture_07_storage_indexing_and_query_optimization.md](lecture_07_storage_indexing_and_query_optimization.md) — Οργάνωση αρχείων, ευρετήρια B+ δένδρων, αλγόριθμοι συνένωσης, βελτιστοποίηση ερωτημάτων.
- [lecture_08_nosql_distributed_databases_and_security.md](lecture_08_nosql_distributed_databases_and_security.md) — Θεώρημα CAP, μοντέλα NoSQL (Document, Key-Value, Column, Graph), έλεγχος πρόσβασης RBAC.
