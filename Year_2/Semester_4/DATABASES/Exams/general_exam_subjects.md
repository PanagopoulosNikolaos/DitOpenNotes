### Πίνακας 1: Αναλυτικό Πλάνο Ύλης ανά Θεματική Ενότητα

| Θεματική Ενότητα | Συγκεκριμένα Αντικείμενα / Εντολές | Περιγραφή & Πλαίσιο Εξέτασης |
| :--- | :--- | :--- |
| **1. Εννοιολογικός & Λογικός Σχεδιασμός** | • Μετάφραση κειμένου σε Σχεσιακό Μοντέλο<br>• Μοντέλα $ER$ (Entity-Relationship)<br>• Αντιστοίχιση $ER \rightarrow$ Σχεσιακό Μοντέλο | Σενάρια από τον πραγματικό κόσμο (περιγραφικό κείμενο) που πρέπει να μετατραπούν σε πίνακες, γνωρίσματα, και συσχετίσεις. |
| **2. Θεωρία Σχεσιακών Βάσεων** | • Σχέσεις (Relations)<br>• Λειτουργικές Εξαρτήσεις (Functional Dependencies)<br>• Κλειδιά (Πρωτεύοντα, Ξένα, Υποψήφια)<br>• Διάσπαση (Decomposition)<br>• Κανονικοποίηση (Normalization - 1NF, 2NF, 3NF, BCNF) | Θεωρητικοί κανόνες για τη σωστή σχεδίαση πινάκων, την αποφυγή πλεονασμού δεδομένων και την εξάλειψη ανωμαλιών. |
| **3. SQL - Γλώσσα Ορισμού Δεδομένων (DDL)** | • `CREATE DATABASE` / `CREATE TABLE`<br>• `ALTER TABLE` (`ADD`, `MODIFY`, `CHANGE`, `DROP COLUMN`)<br>• `DROP TABLE` / `DROP DATABASE`<br>• `TRUNCATE TABLE` | Εντολές που αφορούν τη δομή (σχήμα) της βάσης και των πινάκων, τους περιορισμούς ακεραιότητας, καθώς και τη μόνιμη διαγραφή δομών ή καθαρισμό δεδομένων. |
| **4. SQL - Χειρισμός & Ερωτήματα (DML & DQL)** | • `SELECT`, `FROM`, `WHERE`<br>• `INSERT INTO`<br>• `UPDATE ... SET ... WHERE`<br>• `DELETE FROM ... WHERE`<br>• `JOIN` (Inner, Left, Right)<br>• `GROUP BY` & Συναρτήσεις Συνάθροισης | **Εισαγωγή στα Ερωτήματα:** Ανάκτηση δεδομένων με φιλτράρισμα, εισαγωγή νέων εγγραφών, τροποποίηση υπαρχόντων και διαγραφή βάσει συνθηκών. Σύνδεση πινάκων και ομαδοποίηση. |
| **5. Προχωρημένα Θέματα Διαχείρισης (DBMS)** | • Ευρετήρια (Indexes)<br>• Συναλλαγές (Transactions - ACID)<br>• Συνδρομητικότητα (Concurrency)<br>• Ανάκαμψη (Recovery)<br>• Ασφάλεια (Security) | Μηχανισμοί του ΣΔΒΔ για τη βελτιστοποίηση της ταχύτητας, τη διατήρηση της ακεραιότητας σε ταυτόχρονες προσβάσεις, την επαναφορά μετά από σφάλματα και τα δικαιώματα χρηστών. |
| **6. Σύγχρονες Τεχνολογίες & Εργαλεία** | • SQL vs NoSQL (Βασικές ιδέες)<br>• MariaDB / MySQL<br>• phpMyAdmin / MySQL Workbench | Γενική κατανόηση των σχεσιακών έναντι των μη-σχεσιακών βάσεων και εξοικείωση με τα περιβάλλοντα διαχείρισης και ανάπτυξης. |

### Πίνακας 2: Χαρτογράφηση Ύλης ανά Τύπο Εξέτασης (Format)

| Τύπος Εξέτασης | Τι αναμένεται να ζητηθεί | Θέματα προς Προετοιμασία |
| :--- | :--- | :--- |
| **Πολλαπλής Επιλογής (Multiple Choice)** | • Βασικές έννοιες & ορισμοί<br>• Ιδιότητες ACID των συναλλαγών<br>• Διαφορές SQL vs NoSQL<br>• Αναγνώριση σωστού συντακτικού SQL<br>• Κανόνες Κανονικοποίησης | • Τι προσφέρει ένας δείκτης (Index);<br>• Διαφορά `DELETE` (DML) και `TRUNCATE`/`DROP` (DDL).<br>• Ποια ιδιότητα εξασφαλίζει ότι μια συναλλαγή εκτελείται πλήρως ή καθόλου (Atomicity). |
| **Θεωρητικά Θέματα / Ασκήσεις Ανάπτυξης** | • Εύρεση κλειδιών και λειτουργικών εξαρτήσεων<br>• Έλεγχος Μορφών Κανονικοποίησης (π.χ. σε ποια μορφή είναι ο πίνακας;)<br>• Διάσπαση πινάκων χωρίς απώλεια πληροφορίας<br>• Ανάλυση προβλημάτων συνδρομητικότητας | • Εφαρμογή αλγορίθμων κανονικοποίησης έως 3NF ή BCNF.<br>• Σχεδιασμός Σχεσιακού Μοντέλου από περιγραφικό κείμενο απαιτήσεων.<br>• Μετατροπή ενός διαγράμματος $ER$ σε πίνακες (προσδιορισμός Primary & Foreign Keys). |
| **Εργαστηριακό Μέρος / SQL Commands** | • Συγγραφή πλήρους κώδικα SQL<br>• Δημιουργία και τροποποίηση πινάκων<br>• Σύνθετα ερωτήματα ανάκτησης δεδομένων | • `CREATE TABLE` με ορισμό `FOREIGN KEY ... REFERENCES` και κανόνες `ON DELETE CASCADE / RESTRICT`.<br>• Χρήση `ALTER TABLE` για προσθήκη ή αλλαγή στήλης.<br>• Ερωτήματα `SELECT` με `JOIN` για συνένωση πινάκων και `GROUP BY` σε συνδυασμό με `COUNT()`, `SUM()`, `AVG()` κτλ. |

### Σημαντικές Επισημάνσεις για την εξέταση:

1. **Προσοχή στη διάκριση DDL και DML:** Στο εργαστήριο/SQL Commands, να είστε προετοιμασμένοι για τη διαφορά στη συμπεριφορά των εντολών (π.χ. η `DELETE FROM table` αδειάζει τα δεδομένα αλλά διατηρεί τη δομή και επιτρέπει Rollback, ενώ η `TRUNCATE` θεωρείται DDL και δεν αναιρείται).
2. **Σύνδεση $ER \rightarrow$ Σχεσιακό:** Δώστε έμφαση στο πώς οι σχέσεις *πολλά-προς-πολλά (N:M)* μετατρέπονται πάντα σε έναν **ενδιάμεσο πίνακα** με σύνθετο πρωτεύον κλειδί τα ξένα κλειδιά των δύο αρχικών πινάκων.Exams/general_exam_subjects.md
