# Εξαμηνιαίο Project 1: Σχεδίαση Σχεσιακής Βάσης και Ανάπτυξη REST API

## 1. Σκοπός του Project
Σχεδιασμός, κανονικοποίηση και υλοποίηση μιας ολοκληρωμένης σχεσιακής βάσης δεδομένων σε PostgreSQL, συνοδευόμενης από διεπαφή προγραμματισμού εφαρμογών (RESTful Web API) σε Python (FastAPI / SQLAlchemy) ή Node.js (Express / Prisma).

---

## 2. Θεματικό Πεδίο: Σύστημα Ηλεκτρονικού Εμπορίου (E-Commerce)
Το σύστημα πρέπει να υποστηρίζει:
- **Διαχείριση Χρηστών & Ρόλων:** Πελάτες, διαχειριστές καταστήματος, αποθηκάριοι.
- **Κατάλογος Προϊόντων:** Κατηγορίες, προϊόντα, χαρακτηριστικά (attributes), έλεγχος αποθέματος (stock).
- **Καλάθι Αγορών & Παραγγελίες:** Δημιουργία παραγγελίας, γραμμές παραγγελίας, ιστορικό καταστάσεων (`PENDING`, `PAID`, `SHIPPED`, `CANCELLED`).
- **Συναλλαγές (Transactions):** Διασφάλιση ACID ιδιοτήτων κατά την ολοκλήρωση πληρωμής και δέσμευσης αποθέματος.

---

## 3. Τεχνικές Απαιτήσεις
- **Εννοιολογικό Μοντέλο:** Διάγραμμα ER με οντότητες, συσχετίσεις, πληθικότητες.
- **Κανονικοποίηση:** Τεκμηρίωση ότι όλοι οι πίνακες βρίσκονται τουλάχιστον σε 3η Κανονική Μορφή (3NF).
- **Περιορισμοί Ακεραιότητας:** Χρήση ξένων κλειδιών με κατάλληλες πολιτικές διαγραφής (`ON DELETE RESTRICT/CASCADE`), `CHECK` constraints, μοναδικά ευρετήρια (indexes).
- **SQL Triggers & Stored Procedures:** Trigger για την αυτόματη ενημέρωση του αποθέματος προϊόντος κατά την εισαγωγή νέας γραμμής παραγγελίας.

---

## 4. Παραδοτέα
1. Τεχνική αναφορά (ER Diagram, Σχεσιακό Σχήμα, Απόδειξη Κανονικοποίησης).
2. Αρχείο σεναρίου αρχικοποίησης SQL (`schema.sql` και `seed_data.sql`).
3. Πηγαίος κώδικας του REST API με τεκμηρίωση Swagger / OpenAPI.
4. Unit & Integration tests για τα βασικά endpoints και τα transactions.
