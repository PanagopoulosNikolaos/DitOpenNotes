# Εξαμηνιαίο Project 1: Ανάπτυξη Διερμηνέα για Μικρο-Γλώσσα (MiniLang Interpreter)

## 1. Σκοπός του Project
Σχεδίαση και υλοποίηση ενός πλήρους διερμηνέα (Tree-Walking Interpreter) για μια προσαρμοσμένη εκπαιδευτική γλώσσα προγραμματισμού ("MiniLang") σε Haskell ή Python.

---

## 2. Προδιαγραφές Γλώσσας "MiniLang"

### Συντακτικά Χαρακτηριστικά:
- **Μεταβλητές και Αναθέσεις:** `var x = 10;`, `x = x + 5;`.
- **Αριθμητικές & Λογικές Εκφράσεις:** `+`, `-`, `*`, `/`, `==`, `!=`, `<`, `>`, `&&`, `||`, `!`.
- **Δομές Ελέγχου:**
  - `if (condition) { ... } else { ... }`
  - `while (condition) { ... }`
- **Συναρτήσεις Πρώτης Τάξης (First-Class Functions):**
  - `fun add(a, b) { return a + b; }`
  - Υποστήριξη αναδρομής και κλεισιμάτων (Closures).
- **Εντολή Εκτύπωσης:** `print(expr);`.

---

## 3. Φάσεις Υλοποίησης

### Φάση 1: Λεξική Ανάλυση (Lexer / Tokenizer)
Μετατροπή του πηγαίου κειμένου σε ακολουθία από tokens (αναγνωριστικά, δεσμευμένες λέξεις, αριθμοί, σύμβολα).

### Φάση 2: Συντακτική Ανάλυση (Recursive Descent Parser)
Κατασκευή του Αφηρημένου Συντακτικού Δέντρου (Abstract Syntax Tree - AST) βάσει της γραμματικής χωρίς συμφραζόμενα της γλώσσας.

### Φάση 3: Περιβάλλον και Σημασιολογική Αποτίμηση (Evaluator)
- Υλοποίηση πίνακα συμβόλων / περιβάλλοντος (Environment) με υποστήριξη ιεραρχικής λεξικής εμβέλειας (Nested Lexical Scopes).
- Αποτίμηση εκφράσεων και διαχείριση σφαλμάτων χρόνου εκτέλεσης (π.χ. διαίρεση με το μηδέν, αναφορά σε μη δηλωμένη μεταβλητή).

---

## 4. Παραδοτέα
1. Πηγαίος κώδικας του διερμηνέα (Lexer, Parser, AST, Evaluator).
2. Σουίτα δοκιμαστικών προγραμμάτων σε `MiniLang` (συμπεριλαμβανομένου υπολογισμού Fibonacci, παραγοντικού και ταξινόμησης).
3. Τεχνική αναφορά 5-8 σελίδων με την τυπική γραμματική EBNF και επεξήγηση της αρχιτεκτονικής του διερμηνέα.
