# Programming Languages: Interactive Python Assignment Notebooks

Welcome to the **Interactive Python Assignment Notebooks** directory for Principles of Programming Languages (Code: 401).

---

## Directory Overview

This directory provides structured assignment walkthroughs and problem-solving notebooks for language paradigm exploration:

- [`assignment_notebook_guide.md`](assignment_notebook_guide.md): Comprehensive instructions on setting up JupyterLab/VS Code, running cells, and submitting notebook assignments.
- Problem prompts in [`../../../Exercises/Python/Notebooks/Exam_Style/Exam_Style.ipynb`](../../../Exercises/Python/Notebooks/Exam_Style/Exam_Style.ipynb): University exam-style problem scenarios.
- Problem prompts in [`../../../Exercises/Python/Notebooks/General_Exercises/General_Exercises.ipynb`](../../../Exercises/Python/Notebooks/General_Exercises/General_Exercises.ipynb): General algorithmic problem sets covering 30 progressive exercises.

---

## Tooling Requirements

To open and run the interactive notebooks:

```bash
# Install Jupyter or JupyterLab if not already available
pip install jupyterlab notebook

# Launch JupyterLab server
jupyter lab
```
