# Laboratory Assignment Specifications (Units E1 to E7)

This document provides formal problem specifications for the seven practical Python laboratory units in **Principles of Programming Languages (Code: 401)**.

---

## Unit E1: Strings, Tuples, and Numeric Parsing
- **E1A1**: String normalization and character frequency counting without external libraries.
- **E1A2**: Tuple packing/unpacking and Euclidean distance between multi-dimensional coordinates.
- **E1A3**: Parsing formatted telemetry logs into structured records.
- **E1A4**: Palindrome verification ignoring whitespace, punctuation, and casing.
- **E1A5**: Decimal-to-binary string conversion using bitwise shift operators.
- **E1A6**: Matrix multiplication using nested list comprehensions.

---

## Unit E2: Higher-Order Functions, Dictionaries, and Hamming Distance
- **E2A1**: Computing bitwise and character-level Hamming distances between byte sequences.
- **E2A2**: Implementing custom `myMap` and `myFilter` higher-order functions.
- **E2A3**: Frequency analysis of words from raw text streams stored in dictionary accumulators.
- **E2A4**: Inverting dictionary mappings with list values for key collisions.
- **E2A5**: Composition of mathematical functions `f(g(x))` via lambda closures.
- **E2A6**: Automated test runner evaluating dictionary mutations.

---

## Unit E3: Search Algorithms & Approximations
- **E3A1**: Iterative and recursive Binary Search implementations with step logging.
- **E3A2**: Approximating $\pi$ using the Leibniz infinite series with error tolerance thresholds.
- **E3A3**: Prime number generation using the Sieve of Eratosthenes.
- **E3A4**: Merge sort implementation with recursive partitioning.
- **E3A5**: Finding duplicate elements in unsorted lists in $O(N)$ time using sets.
- **E3A6**: Peak element detection in arrays.

---

## Unit E4: File Processing & Object Sorting
- **E4A1**: Parsing structured comma-delimited vehicle records, validating schema, and sorting chronologically.
- **E4A2** to **E4A11**: Multi-field CSV transformations, student grade GPA calculations, text word-frequency histograms, and JSON serialization.

---

## Unit E5: Structural Recursion & Trees
- **E5A1** to **E5A9**: Binary Search Tree (BST) insertion, search, in-order, pre-order, and post-order traversals, height calculation, and leaf count verification.

---

## Unit E6: Object-Oriented Architecture
- **E6A1** to **E6A6**: Class hierarchies modeling academic entities (`Person`, `Student`, `Instructor`, `Department`), encapsulation via properties, class vs instance variables, and method overriding.

---

## Unit E7: Polymorphism & Robust Systems
- **E7A1** to **E7A4b**: Operator overloading (`__add__`, `__eq__`, `__repr__`), custom exception hierarchies (`CurriculumError`, `InvalidScoreError`), context managers (`__enter__`, `__exit__`), and XML document processing.
