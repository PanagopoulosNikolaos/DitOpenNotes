# Principles of Programming Languages: Laboratory Coursework

Welcome to the **Laboratory Coursework** directory for Principles of Programming Languages (Code: 401).

---

## Laboratory Units Structure

The laboratory curriculum consists of 7 progressive units implementing core computer science algorithms in Python:

| Lab Unit | Focus Area | Core Exercises | Reference Solutions |
|:---|:---|:---|:---|
| **E1** | Basic Data Structures & Strings | String transformations, numeric parsing, formatting | [`../../Exercises/Lab/E1A1_sol.py`](../../Exercises/Lab/E1A1_sol.py) – `E1A6_sol.py` |
| **E2** | Higher-Order Functions & Dictionaries | Hamming distance, lambda expressions, dictionary mapping | [`../../Exercises/Lab/E2A1_sol.py`](../../Exercises/Lab/E2A1_sol.py) – `E2A6_test.py` |
| **E3** | Search Algorithms & Iteration | Binary search, sequence approximations, list filtering | [`../../Exercises/Lab/E3A1_sol.py`](../../Exercises/Lab/E3A1_sol.py) – `E3A6_sol.py` |
| **E4** | File Processing & Object Sorting | Parsing CSV data, sorting multi-attribute objects | [`../../Exercises/Lab/E4A1_sol.py`](../../Exercises/Lab/E4A1_sol.py) – `E4A11_sol.py` |
| **E5** | Structural Recursion & Binary Trees | Tree construction, in-order/pre-order traversal, depth | [`../../Exercises/Lab/E5A1_sol.py`](../../Exercises/Lab/E5A1_sol.py) – `E5A9_sol.py` |
| **E6** | Object-Oriented Architecture | Classes, encapsulation, method dispatch, inheritance | [`../../Exercises/Lab/E6A1_sol.py`](../../Exercises/Lab/E6A1_sol.py) – `E6A6_sol.py` |
| **E7** | Polymorphism & Exception Handling | Operator overloading, custom exceptions, robust IO | [`../../Exercises/Lab/E7A1_sol.py`](../../Exercises/Lab/E7A1_sol.py) – `E7A4b_sol.py` |
