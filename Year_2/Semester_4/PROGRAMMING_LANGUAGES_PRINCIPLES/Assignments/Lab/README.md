# Εργαστηριακές Ασκήσεις Python (E1 έως E7)

## Περίληψη Καταλόγου
Συλλογή από 51 αρχεία ασκήσεων, υποδειγματικών λύσεων και αυτοματοποιημένων δοκιμών για τις 7 εργαστηριακές ενότητες του μαθήματος. Όλες οι συναρτήσεις ακολουθούν τις συμβάσεις camelCase, τεκμηρίωση Google Style docstrings και είναι πλήρως μεταγλωττίσιμες.

## Περιεχόμενα Καταλόγου
- [E1/](E1/) — Ενότητα 1: Βασικές δομές δεδομένων, συμβολοσειρές και απλοί υπολογισμοί (E1A1 έως E1A6).
- [E2/](E2/) — Ενότητα 2: Συναρτήσεις ανώτερης τάξης, υπολογισμός αποστάσεων Hamming και λεξικά (E2A1 έως E2A6).
- [E3/](E3/) — Ενότητα 3: Αλγόριθμοι αναζήτησης, προσεγγίσεις μαθηματικών σταθερών και διαχείριση λιστών (E3A1 έως E3A6).
- [E4/](E4/) — Ενότητα 4: Επεξεργασία αρχείων, ταξινόμηση και επεξεργασία δεδομένων αυτοκινήτων/φοιτητών (E4A1 έως E4A6).
- [E5/](E5/) — Ενότητα 5: Αναδρομικές συναρτήσεις, δυαδικά δένδρα και διασχίσεις (E5A1 έως E5A6).
- [E6/](E6/) — Ενότητα 6: Αντικειμενοστρεφής σχεδιασμός, κλάσεις, μέθοδοι και κληρονομικότητα (E6A1 έως E6A6).
- [E7/](E7/) — Ενότητα 7: Πολυμορφισμός, υπερφόρτωση τελεστών και διαχείριση εξαιρέσεων (E7A1 έως E7A6).
