# Principles of Programming Languages: Curated Resources and Reference Guide

A curated reference guide of authoritative textbooks, language documentation, compiler toolkits, and interactive platforms for Principles of Programming Languages (Course Code 401).

---

## 1. Foundational Textbooks

- **Concepts of Programming Languages**  
  *Author:* Robert W. Sebesta.  
  *Annotation:* The standard undergraduate textbook covering formal syntax (BNF/EBNF), parsing techniques, binding times, scoping, data types, and paradigm evolution.

- **Programming Language Pragmatics**  
  *Author:* Michael L. Scott.  
  *Annotation:* Renowned textbook bridging programming language design and compiler implementation, exploring runtime systems, activation records, control flow, and concurrency.

- **Types and Programming Languages (TAPL)**  
  *Author:* Benjamin C. Pierce.  
  *Annotation:* Advanced mathematical treatise on operational semantics, lambda calculus, and formal type systems.

## 2. Paradigm References and Official Documentation

### 2.1 Functional Programming (Haskell)
- **Learn You a Haskell for Great Good!**  
  *URL:* `http://learnyouahaskell.com/`  
  *Description:* Intuitive visual guide to pure functions, algebraic data types, pattern matching, and monadic I/O.
- **Haskell Language Documentation & GHC Manual**  
  *URL:* `https://www.haskell.org/documentation/`  
  *Description:* Authoritative standard libraries reference and GHC compiler documentation.

### 2.2 Logic Programming (Prolog)
- **SWI-Prolog Official Documentation & Manual**  
  *URL:* `https://www.swi-prolog.org/pldoc/`  
  *Description:* Comprehensive reference manual for SWI-Prolog built-in predicates, modules, debugging tools, and grammar rules (DCGs).
- **Learn Prolog Now!**  
  *URL:* `http://www.learnprolognow.org/`  
  *Description:* Practical introductory tutorial on Horn clauses, unification, resolution, and recursive list processing.

## 3. Parsing and Syntax Tools

- **Crafting Interpreters**  
  *Author:* Robert Nystrom.  
  *URL:* `https://craftinginterpreters.com/`  
  *Description:* Practical handbook detailing how to implement recursive-descent parsers, AST tree walkers, and bytecode virtual machines from scratch.
