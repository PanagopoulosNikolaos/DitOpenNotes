# Σημειώσεις Διαλέξεων Αρχών Γλωσσών Προγραμματισμού

## Περίληψη Καταλόγου
Πλήρεις ακαδημαϊκές σημειώσεις για το σύνολο των 8 διαλέξεων του μαθήματος. Καλύπτουν όλη την ύλη από τη συντακτική ανάλυση και τα παραδείγματα προγραμματισμού μέχρι τα περιβάλλοντα εκτέλεσης, τα vtables και το Garbage Collection.

## Περιεχόμενα Καταλόγου
- [lecture_01_introduction_and_language_evaluation.md](lecture_01_introduction_and_language_evaluation.md) — Κριτήρια αξιολόγησης γλωσσών (αναγνωσιμότητα, συντακτικότητα, αξιοπιστία, κόστος), μέθοδοι υλοποίησης.
- [lecture_02_syntax_and_context_free_grammars.md](lecture_02_syntax_and_context_free_grammars.md) — Τυπικές γλώσσες, γραμματικές χωρίς συμφραζόμενα (CFG), μορφή Backus-Naur (BNF/EBNF), ασάφεια.
- [lecture_03_names_bindings_type_checking_and_scopes.md](lecture_03_names_bindings_type_checking_and_scopes.md) — Χρόνοι σύνδεσης (binding times), στατική/δυναμική δέσμευση, στατική/δυναμική εμβέλεια, έλεγχος τύπων.
- [lecture_04_functional_and_logic_programming.md](lecture_04_functional_and_logic_programming.md) — Μαθηματικές συναρτήσεις, λάμδα λογισμός, Haskell (οκνηρή αποτίμηση, currying), Prolog (γεγονότα, ενοποίηση).
- [lecture_05_subprograms_parameter_passing_and_runtime_environments.md](lecture_05_subprograms_parameter_passing_and_runtime_environments.md) — Μηχανισμοί περάσματος παραμέτρων (by-value, by-reference, by-name), εγγραφές ενεργοποίησης, static/dynamic links.
- [lecture_06_object_oriented_programming_and_dynamic_dispatch.md](lecture_06_object_oriented_programming_and_dynamic_dispatch.md) — Αφαίρεση, ενθυλάκωση, πολυμορφισμός υποτύπων, πίνακες εικονικών μεθόδων (vtables, vptr), πολλαπλή κληρονομικότητα.
- [lecture_07_concurrency_models_and_parallel_programming.md](lecture_07_concurrency_models_and_parallel_programming.md) — Μοντέλα διαμοιραζόμενης μνήμης (mutexes, monitors), ανταλλαγής μηνυμάτων (Actor model, CSP), async/await, STM.
- [lecture_08_memory_management_and_garbage_collection.md](lecture_08_memory_management_and_garbage_collection.md) — Στοίβα vs Σωρός, μοντέλο ownership (Rust), αλγόριθμοι GC (Mark-Sweep, Stop-Copy, Generational GC).
