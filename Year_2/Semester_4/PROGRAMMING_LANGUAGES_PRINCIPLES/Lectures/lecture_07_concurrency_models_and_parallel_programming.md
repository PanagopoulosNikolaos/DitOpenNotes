# Διάλεξη 7: Μοντέλα Ταυτοχρονισμού και Παράλληλος Προγραμματισμός (Concurrency Models)

## 1. Θεμελιώδεις Έννοιες Ταυτοχρονισμού
- **Ταυτοχρονισμός (Concurrency):** Η δομή ενός προγράμματος όπου πολλαπλές εργασίες μπορούν να βρίσκονται σε εξέλιξη ταυτόχρονα (interleaved execution σε έναν επεξεργαστή).
- **Παραλληλισμός (Parallelism):** Η ταυτόχρονη φυσική εκτέλεση πολλαπλών υπολογισμών την ίδια ακριβώς χρονική στιγμή σε πολλαπλούς πυρήνες επεξεργαστή.
- **Συνθήκη Ανταγωνισμού (Race Condition):** Κατάσταση όπου το τελικό αποτέλεσμα εξαρτάται από τη σχετική σειρά χρονισμού ή εκτέλεσης των νημάτων.
- **Κρίσιμο Τμήμα (Critical Section):** Τμήμα κώδικα που προσπελαύνει διαμοιραζόμενους πόρους και πρέπει να εκτελείται με αμοιβαίο αποκλεισμό (Mutual Exclusion).

---

## 2. Μοντέλο Διαμοιραζόμενης Μνήμης (Shared Memory Model)
Όλα τα νήματα μοιράζονται έναν κοινό χώρο διευθύνσεων μνήμης.

### Πρωτόγονα Συγχρονισμού
1. **Δυαδικοί Σηματοφορείς & Mutexes (Mutual Exclusion Locks):**
   - Έλεγχος εισόδου σε κρίσιμο τμήμα: `lock()` και `unlock()`.
   - Κίνδυνοι: Αδιέξοδα (deadlocks), αναστροφή προτεραιότητας (priority inversion), διαρροή κλειδωμάτων.
2. **Μόνιτορς (Monitors):**
   - Δομή δεδομένων επιπέδου γλώσσας (προτάθηκε από Hoare/Brinch Hansen, υλοποιήθηκε σε Java/C#).
   - Ενθυλακώνει μεταβλητές κατάστασης, συναρτήσεις πρόσβασης και μεταβλητές συνθήκης (`wait()`, `notify()`, `notifyAll()`).
   - Εγγυάται αυτόματα ότι μόνο ένα νήμα μπορεί να εκτελεί μέθοδο του μόνιτορ ανά πάσα στιγμή.

---

## 3. Μοντέλο Ανταλλαγής Μηνυμάτων (Message Passing Model)
Δεν υπάρχει κοινή μνήμη. Οι διεργασίες επικοινωνούν αποκλειστικά αποστέλλοντας και λαμβάνοντας μηνύματα.

### 1. Το Μοντέλο Ηθοποιών (Actor Model - Erlang, Akka, Elixir)
- **Ηθοποιός (Actor):** Μια αυτόνομη υπολογιστική οντότητα.
- Διαθέτει ιδιωτική κατάσταση (πλήρως απομονωμένη από άλλους actors) και μια ουρά εισερχόμενων μηνυμάτων (mailbox).
- Σε απόκριση ενός μηνύματος, ένας actor μπορεί μόνο:
  1. Να στείλει πεπερασμένο αριθμό μηνυμάτων σε άλλους actors.
  2. Να δημιουργήσει νέους actors.
  3. Να ορίσει τη συμπεριφορά του για το επόμενο μήνυμα.
- **Πλεονέκτημα:** Πλήρης εξάλειψη των κλειδωμάτων και των race conditions. Υψηλή ανοχή σε σφάλματα ("Let it crash" φιλοσοφία με supervisors).

### 2. Σειριακές Επικοινωνούσες Διεργασίες (CSP - Communicating Sequential Processes)
- Προτάθηκε από τον Tony Hoare (υιοθετήθηκε σε Go, Occam).
- Οι διεργασίες επικοινωνούν μέσω **καναλιών (channels)** πρώτης τάξης:
  - *"Do not communicate by sharing memory; instead, share memory by communicating."*
  - Τα κανάλια μπορούν να είναι σύγχρονα (unbuffered / rendezvous) ή ασύγχρονα (buffered).
  - Υποστήριξη επιλογής πολλαπλών καναλιών (`select`).

---

## 4. Μοντέλα Ασύγχρονου Προγραμματισμού (Async / Await & Event Loops)
- Χρησιμοποιείται σε Node.js, Python (`asyncio`), Rust, JavaScript.
- **Μονονηματικός Βρόχος Συμβάντων (Single-Threaded Event Loop):** Εκτελεί εργασίες συνεργατικού πολυπρογραμματισμού (cooperative multitasking) χωρίς το κόστος εναλλαγής πλαισίου νημάτων επιπέδου λειτουργικού συστήματος.
- **Υποσχέσεις (Promises / Futures):** Αντικείμενα που αντιπροσωπεύουν το τελικό αποτέλεσμα μιας ασύγχρονης λειτουργίας.
- **Συνρουτίνες (Coroutines / Green Threads):** Ελαφριές συναρτήσεις που μπορούν να διακόψουν την εκτέλεσή τους (`yield` / `await`) και να συνεχίσουν αργότερα διατηρώντας την τοπική τους κατάσταση.

---

## 5. Μνήμη Συναλλαγών Λογισμικού (Software Transactional Memory - STM)
- Εφαρμόζει τις αρχές των συναλλαγών βάσεων δεδομένων (ACID) στη διαμοιραζόμενη μνήμη RAM (π.χ. Haskell STM, Clojure).
- Μπλοκ κώδικα εκτελούνται εντός ενός `atomically` περιβάλλοντος:
  - Αν δύο νήματα επιχειρήσουν ταυτόχρονη τροποποίηση του ίδιου στοιχείου μνήμης, η μία συναλλαγή αποτυγχάνει και επανεκτελείται αυτόματα (optimistic concurrency control).
  - Εξαλείφει την ανάγκη χειροκίνητων κλειδωμάτων και αποτρέπει τα αδιέξοδα.
