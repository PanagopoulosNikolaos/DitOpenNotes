# Διάλεξη 3: Συναρτησιακός Προγραμματισμός στη Γλώσσα Haskell

## 1. Αρχές του Συναρτησιακού Παραδείγματος
- **Αγνές Συναρτήσεις (Pure Functions):** Το αποτέλεσμα εξαρτάται αποκλειστικά από τα ορίσματα εισόδου. Μηδενικές παρενέργειες (no side effects) και αναφορική διαφάνεια (referential transparency).
- **Αμεταβλητότητα (Immutability):** Οι τιμές δεν τροποποιούνται μετά τον ορισμό τους.
- **Συναρτήσεις Πρώτης Τάξης (First-Class Functions):** Οι συναρτήσεις αντιμετωπίζονται ως κανονικές τιμές (μπορούν να περαστούν ως ορίσματα και να επιστραφούν από άλλες συναρτήσεις).
- **Οχετοποιημένη Εκτέλεση (Lazy Evaluation):** Οι εκφράσεις δεν υπολογίζονται παρά μόνο όταν η τιμή τους είναι απαραίτητη, επιτρέποντας τον ορισμό άπειρων δομών δεδομένων.

---

## 2. Βασική Σύνταξη και Ταίριασμα Προτύπων (Pattern Matching)

```haskell
-- Δήλωση τύπου και ορισμός αναδρομικής συνάρτησης παραγοντικού
factorial :: Integer -> Integer
factorial 0 = 1
factorial n = n * factorial (n - 1)

-- Μήκος λίστας με ταίριασμα κεφαλής (x) και ουράς (xs)
length' :: [a] -> Int
length' []     = 0
length' (_:xs) = 1 + length' xs
```

---

## 3. Συναρτήσεις Ανώτερης Τάξης (Higher-Order Functions)

- **`map`:** Εφαρμογή συνάρτησης σε κάθε στοιχείο λίστας:
  ```haskell
  map :: (a -> b) -> [a] -> [b]
  -- Παράδειγμα: map (*2) [1, 2, 3] ==> [2, 4, 6]
  ```
- **`filter`:** Επιλογή στοιχείων που ικανοποιούν ένα κατηγόρημα:
  ```haskell
  filter :: (a -> Bool) -> [a] -> [a]
  -- Παράδειγμα: filter even [1..10] ==> [2, 4, 6, 8, 10]
  ```
- **`foldr` / `foldl` (Αναδίπλωση / Reduction):**
  ```haskell
  sum' :: Num a => [a] -> a
  sum' = foldr (+) 0
  ```

## 4. Currying και Μερική Εφαρμογή (Partial Application)
Στη Haskell, κάθε συνάρτηση πολλαπλών ορισμάτων είναι ουσιαστικά μια αλυσίδα συναρτήσεων μονού ορίσματος:
$$f :: a \to b \to c \quad \iff \quad f :: a \to (b \to c)$$
```haskell
add :: Int -> Int -> Int
add x y = x + y

addFive :: Int -> Int
addFive = add 5  -- Μερική εφαρμογή
```
