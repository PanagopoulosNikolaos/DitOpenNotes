# Παραδείγματα: Κανόνες και ο Τελεστής Cut στην Prolog

## Παράδειγμα 1: Υπολογισμός Φορολογικής Κλίμακας με χρήση Cut

### Περιγραφή:
Υπολογισμός φόρου εισοδήματος βάσει κλιμακωτών συντελεστών. Η χρήση του τελεστή αποκοπής (`!`) αποτρέπει περιττές επαληθεύσεις επόμενων κλιμακίων αφού εντοπιστεί η σωστή κατηγορία.

### Πλήρης Κώδικας Prolog:
```prolog
% tax(Eisodhma, Foros)
% Κλίμακες:
% <= 10.000 -> 0%
% <= 20.000 -> 10%
% <= 40.000 -> 22%
% > 40.000  -> 35%

tax(Income, Tax) :-
    Income =< 10000,
    !,
    Tax is 0.

tax(Income, Tax) :-
    Income =< 20000,
    !,
    Tax is (Income - 10000) * 0.10.

tax(Income, Tax) :-
    Income =< 40000,
    !,
    Tax is (10000 * 0.10) + (Income - 20000) * 0.22.

tax(Income, Tax) :-
    Tax is (10000 * 0.10) + (20000 * 0.22) + (Income - 40000) * 0.35.

% Δοκιμαστικά ερωτήματα:
% ?- tax(8000, T).  --> T = 0.
% ?- tax(15000, T). --> T = 500.0.
% ?- tax(25000, T). --> T = 2100.0.
```
