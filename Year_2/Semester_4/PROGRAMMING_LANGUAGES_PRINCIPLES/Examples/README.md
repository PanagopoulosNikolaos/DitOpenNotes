# Principles of Programming Languages: Code Examples

Welcome to the **Principles of Programming Languages (Code: 401)** code demonstrations directory. This folder provides self-contained, executable code implementations illustrating pure functional, declarative logic, and multi-paradigm programming techniques.

---

## Directory Contents

| Path | Language | Paradigm Focus | Description |
|:---|:---|:---|:---|
| [`Haskell/examples_functional_paradigms.hs`](Haskell/examples_functional_paradigms.hs) | Haskell (GHC) | Pure Functional | Binary Search Trees, structural recursion, higher-order filtering (`squareEvens`), and list reversals with `foldl` |
| [`Prolog/examples_logic_programming.pl`](Prolog/examples_logic_programming.pl) | Prolog (SWI) | Declarative Logic | First-order facts and rules, transitive prerequisite resolution, recursive list algorithms, and the Cut (`!`) operator |
| [`Python/examples_multiparadigm_scripting.py`](Python/examples_multiparadigm_scripting.py) | Python 3 | Multi-Paradigm | Generator pipelines, lazy stream filtering, higher-order closures, and immutable dataclasses |
| [`examples_multiparadigm_walkthrough.md`](examples_multiparadigm_walkthrough.md) | Markdown | Theory & Practice | Step-by-step comparative walkthrough, execution commands, and paradigm feature matrices |
| [`examples_multiparadigm_comparison.md`](examples_multiparadigm_comparison.md) | Markdown | Reference | Comparative code side-by-side analysis for classic algorithmic challenges |

---

## Quick Execution Commands

```bash
# Run Haskell demonstrations
runghc Haskell/examples_functional_paradigms.hs

# Query Prolog knowledge base
swipl -s Prolog/examples_logic_programming.pl

# Run Python stream processing
python3 Python/examples_multiparadigm_scripting.py
```
