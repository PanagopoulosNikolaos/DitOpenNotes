# Παραδείγματα Προγραμματιστικών Παραδειγμάτων

## Περίληψη Καταλόγου
Συλλογή από ενδεικτικά προγράμματα σε διαφορετικά προγραμματιστικά παραδείγματα (Προστακτικό, Συναρτησιακό με Haskell, Λογικό με Prolog, Αντικειμενοστρεφές με C++/Python).

## Περιεχόμενα Καταλόγου
- [functional_haskell_examples.hs](functional_haskell_examples.hs) — Παραδείγματα αναδρομής, pattern matching, και συναρτήσεων ανώτερης τάξης (map, filter, fold) σε Haskell.
- [logic_prolog_examples.pl](logic_prolog_examples.pl) — Παραδείγματα κανόνων, γεγονότων και ερωτημάτων ενοποίησης (unification) σε Prolog.
