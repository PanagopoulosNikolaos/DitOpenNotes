# Λυμένες Ασκήσεις Αρχών Γλωσσών Προγραμματισμού

## Περίληψη Καταλόγου
Θεματικές ασκήσεις με αναλυτικά βήματα επίλυσης. Καλύπτει γραμματικές χωρίς συμφραζόμενα (CFG), ασάφεια γραμματικών, δένδρα συντακτικής ανάλυσης, στατική/δυναμική εμβέλεια, και εγγραφές ενεργοποίησης στοίβας.

## Περιεχόμενα Καταλόγου
- [bnf_grammars_and_parse_trees.md](bnf_grammars_and_parse_trees.md) — Ασκήσεις κατασκευής γραμματικών BNF και απόδειξης ασάφειας μέσω πολλαπλών δένδρων παραγωγής.
- [scoping_and_stack_frames.md](scoping_and_stack_frames.md) — Ασκήσεις προσδιορισμού τιμών μεταβλητών υπό στατική έναντι δυναμικής εμβέλειας και διαγραμματικής απεικόνισης activation records.
