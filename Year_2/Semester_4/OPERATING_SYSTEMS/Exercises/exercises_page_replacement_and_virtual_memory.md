# Ασκήσεις Εμπέδωσης: Αντικατάσταση Σελίδων και Εικονική Μνήμη

## Άσκηση 1: Σύγκριση Αλγορίθμων FIFO, LRU και OPT

### Εκφώνηση:
Δίνεται η ακολουθία αναφορών σελίδων (Reference String):
$$7, 0, 1, 2, 0, 3, 0, 4, 2, 3, 0, 3, 2$$
Έστω ότι το σύστημα διαθέτει $3$ φυσικά πλαίσια (frames) μνήμης, αρχικά κενά.
Υπολογίστε τον αριθμό των σφαλμάτων σελίδας (Page Faults) για:
1. **FIFO (First-In First-Out)**
2. **LRU (Least Recently Used)**
3. **Βέλτιστο (OPT)**

---

### Λύσεις:

#### 1. FIFO (3 Πλαίσια):
- `7`: [7, -, -] $\to$ Fault 1
- `0`: [7, 0, -] $\to$ Fault 2
- `1`: [7, 0, 1] $\to$ Fault 3
- `2`: αντικατάσταση παλαιότερου 7 $\to$ [2, 0, 1] $\to$ Fault 4
- `0`: Hit
- `3`: αντικατάσταση παλαιότερου 0 $\to$ [2, 3, 1] $\to$ Fault 5
- `0`: αντικατάσταση παλαιότερου 1 $\to$ [2, 3, 0] $\to$ Fault 6
- `4`: αντικατάσταση παλαιότερου 2 $\to$ [4, 3, 0] $\to$ Fault 7
- `2`: αντικατάσταση παλαιότερου 3 $\to$ [4, 2, 0] $\to$ Fault 8
- `3`: αντικατάσταση παλαιότερου 0 $\to$ [4, 2, 3] $\to$ Fault 9
- `0`: αντικατάσταση παλαιότερου 4 $\to$ [0, 2, 3] $\to$ Fault 10
- `3`: Hit
- `2`: Hit
- **Συνολικά Page Faults FIFO:** **10**.

#### 2. LRU (3 Πλαίσια):
- `7`: [7, -, -] $\to$ Fault 1
- `0`: [7, 0, -] $\to$ Fault 2
- `1`: [7, 0, 1] $\to$ Fault 3
- `2`: λιγότερο πρόσφατο είναι το 7 $\to$ [2, 0, 1] $\to$ Fault 4
- `0`: [2, 1, 0] $\to$ Hit
- `3`: λιγότερο πρόσφατο είναι το 1 $\to$ [2, 0, 3] $\to$ Fault 5
- `0`: [2, 3, 0] $\to$ Hit
- `4`: λιγότερο πρόσφατο είναι το 2 $\to$ [4, 3, 0] $\to$ Fault 6
- `2`: λιγότερο πρόσφατο είναι το 3 $\to$ [4, 0, 2] $\to$ Fault 7
- `3`: λιγότερο πρόσφατο είναι το 0 $\to$ [4, 2, 3] $\to$ Fault 8
- `0`: λιγότερο πρόσφατο είναι το 4 $\to$ [0, 2, 3] $\to$ Fault 9
- `3`: Hit
- `2`: Hit
- **Συνολικά Page Faults LRU:** **9**.

#### 3. Βέλτιστο (OPT - 3 Πλαίσια):
- `7`: [7, -, -] $\to$ Fault 1
- `0`: [7, 0, -] $\to$ Fault 2
- `1`: [7, 0, 1] $\to$ Fault 3
- `2`: το 7 δεν χρησιμοποιείται ξανά ποτέ $\to$ [2, 0, 1] $\to$ Fault 4
- `0`: Hit
- `3`: μεταξύ 2, 0, 1, το 1 δεν χρησιμοποιείται ξανά $\to$ [2, 0, 3] $\to$ Fault 5
- `0`: Hit
- `4`: μεταξύ 2, 0, 3, το 0 χρειάζεται αργότερα, το 2 και το 3 χρειάζονται $\to$ αντικατάσταση 2 ή 0. Το 0 χρησιμοποιείται μετά από 3 βήματα. Αντικατάσταση 2 $\to$ [4, 0, 3] $\to$ Fault 6
- `2`: αντικατάσταση 4 $\to$ [2, 0, 3] $\to$ Fault 7
- `3`: Hit
- `0`: Hit
- `3`: Hit
- `2`: Hit
- **Συνολικά Page Faults OPT:** **7**.
