# Εργαστηριακοί Οδηγοί Εργαλείων Ανάπτυξης C/Linux

## Περίληψη Καταλόγου
Πρακτικοί οδηγοί χρήσης του μεταγλωττιστή GCC, του αποσφαλματωτή GDB, των Makefiles, και του εργαλείου ανίχνευσης διαρροών μνήμης Valgrind.

## Περιεχόμενα Καταλόγου
- [gcc_make_compilation_guide.md](gcc_make_compilation_guide.md) — Οδηγός μεταγλώττισης πολυαρχειακών έργων C με GCC και Makefiles.
- [valgrind_memory_debugging.md](valgrind_memory_debugging.md) — Ανίχνευση διαρροών μνήμης (memory leaks) και μη-αρχικοποιημένων δεικτών με το Valgrind.
