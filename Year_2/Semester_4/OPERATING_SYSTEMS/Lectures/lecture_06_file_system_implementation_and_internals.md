# Διάλεξη 6: Υλοποίηση Συστημάτων Αρχείων και Εσωτερικές Δομές (File System Implementation)

## 1. Πολυεπίπεδη Αρχιτεκτονική Συστήματος Αρχείων
Η υλοποίηση του συστήματος αρχείων χωρίζεται σε λογικά επίπεδα αφαίρεσης:
1. **Εφαρμογές Χρήστη (User Applications):** Κλήσεις συστήματος I/O (`open`, `read`, `write`, `close`).
2. **Λογικό Σύστημα Αρχείων (Logical File System):** Διαχειρίζεται τα μεταδεδομένα, τη δομή καταλόγων και τα inodes/FCBs.
3. **Επίπεδο Οργάνωσης Αρχείων (File-Organization Module):** Μεταφράζει λογικές διευθύνσεις μπλοκ αρχείου ($0, 1, \dots, n$) σε φυσικές διευθύνσεις μπλοκ στο δίσκο. Διαχειρίζεται τον ελεύθερο χώρο.
4. **Βασικό Σύστημα Αρχείων (Basic File System):** Εκδίδει εντολές ανάγνωσης/εγγραφής φυσικών μπλοκ προς τους οδηγούς συσκευών (Device Drivers).
5. **Έλεγχος Ε/Ε & Οδηγοί Συσκευών (I/O Control / Drivers):** Μεταφέρει δεδομένα μεταξύ μνήμης και ελεγκτή συσκευής (DMA, IRQs).

## 2. Δομές Δεδομένων στο Δίσκο και στη Μνήμη

### Δομές στο Δίσκο (On-Disk Structures)
- **Μπλοκ Εκκίνησης (Boot Control Block / Boot Sector):** Περιέχει τον κώδικα εκκίνησης του λειτουργικού συστήματος (αν το partition είναι bootable).
- **Μπλοκ Ελέγχου Τόμου (Volume Control Block / Superblock):** Περιέχει στοιχεία τόμου: συνολικό αριθμό blocks, μέγεθος block, αριθμό ελεύθερων blocks και inodes, δείκτες ελεύθερου χώρου.
- **Δομή Καταλόγων (Directory Structure):** Οργανώνει τα ονόματα αρχείων και τα αντιστοιχίζει σε αναγνωριστικά (inode numbers).
- **Μπλοκ Ελέγχου Αρχείου (File Control Block - FCB / Inode):** Περιέχει όλα τα μεταδεδομένα του αρχείου και τους δείκτες προς τα μπλοκ δεδομένων.

### Δομές στη Μνήμη (In-Memory Structures)
- **Πίνακας Προσαρτήσεων (Mount Table):** Περιέχει πληροφορίες για κάθε προσαρτημένο σύστημα αρχείων.
- **Ενδιάμεση Μνήμη Καταλόγων (Directory Cache):** Επιταχύνει τη μετάφραση ονομάτων διαδρομών σε inodes.
- **Καθολικός Πίνακας Ανοικτών Αρχείων (System-wide Open-File Table):** Αντίγραφο των FCB/inodes για κάθε αρχείο που είναι ανοικτό από τουλάχιστον μία διεργασία.
- **Πίνακας Ανοικτών Αρχείων ανά Διεργασία (Per-process Open-File Table):** Αντιστοιχίζει τους περιγραφείς αρχείων (file descriptors: 0, 1, 2, ...) σε εγγραφές του καθολικού πίνακα.

## 3. Μέθοδοι Κατανομής Χώρου στο Δίσκο (Allocation Methods)

### 1. Συνεχόμενη Κατανομή (Contiguous Allocation)
- Κάθε αρχείο καταλαμβάνει ένα συνεχόμενο σύνολο φυσικών μπλοκ στο δίσκο.
- **Πλεονεκτήματα:** Εξαιρετική απόδοση σειριακής και άμεσης προσπέλασης ($O(1)$ μετατόπιση κεφαλής).
- **Μειονεκτήματα:** Εξωτερικός κατακερματισμός (external fragmentation), ανάγκη πρόβλεψης του μέγιστου μεγέθους αρχείου εκ των προτέρων.

### 2. Συνδεδεμένη Κατανομή (Linked Allocation)
- Κάθε αρχείο είναι μια συνδεδεμένη λίστα μπλοκ δίσκου. Κάθε μπλοκ περιέχει δείκτη προς το επόμενο μπλοκ.
- **Πλεονεκτήματα:** Μηδενικός εξωτερικός κατακερματισμός, δυναμική αύξηση μεγέθους αρχείου.
- **Μειονεκτήματα:** Αναποτελεσματική άμεση προσπέλαση (απαιτείται διάσχιση $O(k)$ δεικτών), σπατάλη χώρου για δείκτες, ευπάθεια σε απώλεια ενός δείκτη.
- *Παραλλαγή FAT (File Allocation Table):* Οι δείκτες αποθηκεύονται σε ξεχωριστό πίνακα στην αρχή του τόμου (επιταχύνει τις αναζητήσεις).

### 3. Ευρετηριασμένη Κατανομή (Indexed Allocation)
- Κάθε αρχείο έχει το δικό του **μπλοκ ευρετηρίου (Index Block)**, το οποίο περιέχει τους δείκτες προς όλα τα μπλοκ δεδομένων του αρχείου.
- **Πλεονεκτήματα:** Άμεση προσπέλαση σε οποιοδήποτε μπλοκ χωρίς σειριακή αναζήτηση, χωρίς εξωτερικό κατακερματισμό.
- **Μειονεκτήματα:** Υπερφόρτωση χώρου (overhead) index block ακόμη και για πολύ μικρά αρχεία.

## 4. Η Αρχιτεκτονική UNIX Inode (Πολυεπίπεδη Ευρετηρίαση)
Το κλασικό UNIX FFS (Fast File System) και ext2/ext3/ext4 χρησιμοποιεί συνδυαστική προσέγγιση:
Ένα Inode περιέχει συνήθως 15 δείκτες:
- **12 Άμεσοι Δείκτες (Direct Pointers):** Δείχνουν απευθείας σε 12 μπλοκ δεδομένων. Για μικρά αρχεία (< 48 KB με block 4 KB), η προσπέλαση γίνεται άμεσα.
- **1 Απλός Έμμεσος Δείκτης (Single Indirect Pointer):** Δείχνει σε ένα μπλοκ που περιέχει δείκτες προς μπλοκ δεδομένων (π.χ. $1024$ επιπλέον μπλοκ).
- **1 Διπλός Έμμεσος Δείκτης (Double Indirect Pointer):** Δείχνει σε ένα μπλοκ δεικτών που δείχνει σε μπλοκ δεικτών δεδομένων ($1024^2$ μπλοκ).
- **1 Τριπλός Έμμεσος Δείκτης (Triple Indirect Pointer):** Υποστηρίζει τεράστια αρχεία μεγέθους πολλών Terabytes ($1024^3$ μπλοκ).

## 5. Διαχείριση Ελεύθερου Χώρου (Free-Space Management)
- **Διάνυσμα Bits / Χάρτης Bits (Bit Vector / Bitmap):**
  - Κάθε block αντιπροσωπεύεται από 1 bit (0 = κατειλημμένο, 1 = ελεύθερο).
  - Ταχύτατη εύρεση του πρώτου ελεύθερου μπλοκ μέσω CPU εντολών bitwise.
- **Συνδεδεμένη Λίστα Ελεύθερων Μπλοκ (Linked Free Space List):**
  - Κρατά δείκτη προς το πρώτο ελεύθερο block, το οποίο δείχνει στο επόμενο.
- **Ομαδοποίηση (Grouping):**
  - Το πρώτο ελεύθερο block αποθηκεύει τις διευθύνσεις των επόμενων $n$ ελεύθερων blocks.
- **Καταμέτρηση (Counting):**
  - Αποθήκευση της διεύθυνσης του πρώτου ελεύθερου block και του αριθμού συνεχόμενων ελεύθερων blocks που ακολουθούν.
