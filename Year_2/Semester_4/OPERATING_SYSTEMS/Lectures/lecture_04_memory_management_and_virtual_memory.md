# Διάλεξη 4: Διαχείριση Μνήμης και Εικονική Μνήμη (Virtual Memory)

## 1. Μετάφραση Διευθύνσεων και Μονάδα MMU
Τα προγράμματα εκτελούνται χρησιμοποιώντας **Λογικές / Εικονικές Διευθύνσεις (Logical / Virtual Addresses)**.
Η Μονάδα Διαχείρισης Μνήμης (Memory Management Unit - MMU) στο υλικό μεταφράζει τις εικονικές διευθύνσεις σε **Φυσικές Διευθύνσεις (Physical Addresses)** στη RAM.

---

## 2. Σελιδοποίηση (Paging)
Η φυσική μνήμη διαιρείται σε μπλοκ σταθερού μεγέθους που ονομάζονται **Πλαίσια (Frames)**.
Ο λογικός χώρος διευθύνσεων διαιρείται σε μπλοκ ίδιου μεγέθους που ονομάζονται **Σελίδες (Pages)** (συνήθως 4 KB).

### Δομή Εικονικής Διεύθυνσης:
Μια εικονική διεύθυνση αποτελείται από:
- **Αριθμό Σελίδας ($p$):** Ευρετήριο στον Πίνακα Σελίδων (Page Table) για την εύρεση του αντίστοιχου πλαισίου $f$.
- **Μετατόπιση Εντός Σελίδας ($d$ - Offset):** Η ακριβής θέση του byte μέσα στο πλαίσιο:
$$\text{Φυσική Διεύθυνση} = f \times \text{Μέγεθος Σελίδας} + d$$

### Ρυθμιστική Μνήμη Μετάφρασης (Translation Lookaside Buffer - TLB)
Ειδική ταχύτατη μνήμη associative cache στο hardware που αποθηκεύει πρόσφατες μεταφράσεις σελίδων:
- **Χρόνος Πρόσβασης (Effective Access Time - EAT):**
$$\text{EAT} = h \times (t_{\text{TLB}} + t_{\text{RAM}}) + (1 - h) \times (t_{\text{TLB}} + 2 \times t_{\text{RAM}})$$
όπου $h$ είναι ο ρυθμός επιτυχίας (TLB Hit Ratio).

---

## 3. Εικονική Μνήμη και Σελιδοποίηση κατά Παραγγελία (Demand Paging)
Επιτρέπει την εκτέλεση διεργασιών των οποίων ο συνολικός χώρος διευθύνσεων υπερβαίνει τη διαθέσιμη φυσική μνήμη.

### Σφάλμα Σελίδας (Page Fault):
Συμβαίνει όταν η διεργασία αναφερθεί σε σελίδα που έχει bit εγκυρότητας $v = 0$ (μη παρούσα στη RAM):
1. Η MMU προκαλεί trap σφάλματος σελίδας στον πυρήνα.
2. Ο πυρήνας ελέγχει αν η διεύθυνση είναι έγκυρη.
3. Επιλέγεται ελεύθερο πλαίσιο στη RAM (αν δεν υπάρχει, εκτελείται αλγόριθμος αντικατάστασης σελίδας).
4. Εκκινείται ανάγνωση της σελίδας από το δίσκο (Swap space).
5. Ενημερώνεται ο πίνακας σελίδων ($v = 1$) και επανεκκινείται η εντολή που προκάλεσε το fault.

---

## 4. Αλγόριθμοι Αντικατάστασης Σελίδων (Page Replacement)
- **FIFO (First-In, First-Out):** Αντικατάσταση της παλαιότερης σελίδας. Εμφανίζει την **Ανωμαλία του Belady** (αύξηση πλαισίων μνήμης μπορεί να οδηγήσει σε αύξηση των page faults).
- **Βέλτιστος (Optimal - OPT):** Αντικατάσταση της σελίδας που δεν θα χρησιμοποιηθεί για το μεγαλύτερο χρονικό διάστημα στο μέλλον. Χρησιμεύει μόνο ως μέτρο σύγκρισης (αδύνατη η υλοποίηση σε πραγματικό χρόνο).
- **LRU (Least Recently Used):** Αντικατάσταση της σελίδας που δεν έχει χρησιμοποιηθεί για το μεγαλύτερο διάστημα στο παρελθόν. Πολύ καλή απόδοση, αλλά απαιτεί hardware υποστήριξη (καταχωρητές χρόνου ή στοίβα).
- **Αλγόριθμος Ρολογιού (Clock / Second-Chance):** Κυκλική λίστα πλαισίων με χρήση bit αναφοράς (reference bit) για προσεγγιστική υλοποίηση του LRU με ελάχιστο κόστος.
