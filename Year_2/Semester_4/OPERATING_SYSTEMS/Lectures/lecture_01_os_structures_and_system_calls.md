# Διάλεξη 1: Δομές Λειτουργικών Συστημάτων και Κλήσεις Συστήματος (System Calls)

## 1. Ρόλος και Σκοπός του Λειτουργικού Συστήματος
Το Λειτουργικό Σύστημα (ΛΣ - Operating System) δρα ως ενδιάμεσος μεταξύ του χρήστη/εφαρμογών και του φυσικού υλικού (hardware).
- **Διαχειριστής Πόρων (Resource Allocator):** Διαχειρίζεται την ΚΜΕ (CPU), τη μνήμη RAM, τις συσκευές Εισόδου/Εξόδου και τα μέσα αποθήκευσης.
- **Πρόγραμμα Ελέγχου (Control Program):** Επιβλέπει την εκτέλεση προγραμμάτων χρηστών για την αποφυγή λαθών και μη εξουσιοδοτημένης χρήσης.

---

## 2. Καταστάσεις Λειτουργίας της ΚΜΕ (Dual-Mode Operation)
Για την προστασία του συστήματος, οι σύγχρονοι επεξεργαστές υποστηρίζουν τουλάχιστον δύο καταστάσεις εκτέλεσης μέσω ενός bit κατάστασης (mode bit):
- **Κατάσταση Χρήστη (User Mode - bit = 1):** Περιορισμένη πρόσβαση σε πόρους, απαγόρευση εκτέλεσης προνομιούχων εντολών (privileged instructions).
- **Κατάσταση Πυρήνα (Kernel Mode / Supervisor Mode - bit = 0):** Πλήρης και απεριόριστη πρόσβαση σε όλο το υλικό και στις δομές μνήμης.

---

## 3. Κλήσεις Συστήματος (System Calls)
Μια κλήση συστήματος είναι η προγραμματιστική διεπαφή (API) μέσω της οποίας ένα πρόγραμμα χρήστη αιτείται υπηρεσίες από τον πυρήνα του ΛΣ.

### Μηχανισμός Εκτέλεσης:
1. Το πρόγραμμα προετοιμάζει τα ορίσματα (στους καταχωρητές ή στη στοίβα).
2. Εκτελείται εντολή λογισμικής διακοπής / παγίδας (Software Interrupt / Trap / `syscall` instruction).
3. Ο επεξεργαστής μεταβαίνει αυτόματα σε Kernel Mode και ανατρέχει στον **Πίνακα Διανυσμάτων Διακοπών (Interrupt Vector Table)**.
4. Εκτελείται ο κατάλληλος χειριστής συστήματος (system call handler).
5. Το αποτέλεσμα επιστρέφεται, η κατάσταση επανέρχεται σε User Mode και συνεχίζεται η εκτέλεση του προγράμματος.

### Κατηγορίες Κλήσεων Συστήματος (POSIX / UNIX):
- **Έλεγχος Διεργασιών:** `fork()`, `exec()`, `wait()`, `exit()`.
- **Διαχείριση Αρχείων:** `open()`, `read()`, `write()`, `close()`.
- **Διαχείριση Συσκευών:** `ioctl()`, `read()`, `write()`.
- **Πληροφορίες Συστήματος:** `getpid()`, `alarm()`, `sleep()`.
- **Επικοινωνία & Δικτύωση:** `pipe()`, `shmget()`, `socket()`.
