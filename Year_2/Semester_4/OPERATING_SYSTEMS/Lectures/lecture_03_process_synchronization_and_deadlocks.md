# Διάλεξη 3: Συγχρονισμός Διεργασιών και Αδιέξοδα (Deadlocks)

## 1. Το Πρόβλημα του Κρίσιμου Τμήματος (Critical Section Problem)
Όταν πολλαπλές διεργασίες ή νήματα μοιράζονται κοινή μνήμη, μπορεί να προκληθούν **Συνθήκες Ανταγωνισμού (Race Conditions)**.
Κάθε έγκυρη λύση στο πρόβλημα του κρίσιμου τμήματος πρέπει να ικανοποιεί τρεις προϋποθέσεις:
1. **Αμοιβαίος Αποκλεισμός (Mutual Exclusion):** Μόνο μία διεργασία μπορεί να βρίσκεται στο κρίσιμο τμήμα κάθε χρονική στιγμή.
2. **Πρόοδος (Progress):** Αν καμία διεργασία δεν είναι στο κρίσιμο τμήμα και κάποιες επιθυμούν να εισέλθουν, μόνο αυτές μπορούν να συμμετάσχουν στην απόφαση και η επιλογή δεν αναβάλλεται επ' άπειρον.
3. **Φραγμένη Αναμονή (Bounded Waiting):** Υπάρχει όριο στον αριθμό φορών που άλλες διεργασίες εισέρχονται στο κρίσιμο τμήμα αφού μια διεργασία έχει ζητήσει είσοδο, αποτρέποντας τη λιμοκτονία.

## 2. Μηχανισμοί Συγχρονισμού

### Σηματοφόροι (Semaphores)
Ακέραια μεταβλητή $S$ στην οποία επιτρέπεται πρόσβαση αποκλειστικά μέσω δύο ατομικών (atomic) λειτουργιών:
- **`wait(S)` (ή `P(S)`):**
  ```c
  wait(S) {
      while (S <= 0) ; // busy wait ή block
      S--;
  }
  ```
- **`signal(S)` (ή `V(S)`):**
  ```c
  signal(S) {
      S++;
  }
  ```

### Mutexes και Μεταβλητές Συνθήκης (Condition Variables)
- **Mutex (Mutual Exclusion Lock):** Δυαδικό κλείδωμα (`pthread_mutex_lock`, `pthread_mutex_unlock`) με σαφή έννοια ιδιοκτησίας νήματος.
- **Condition Variables (`pthread_cond_wait`, `pthread_cond_signal`):** Επιτρέπουν σε ένα νήμα να αναστείλει την εκτέλεσή του απελευθερώνοντας το mutex μέχρι να ικανοποιηθεί μια λογική συνθήκη.

## 3. Αδιέξοδα (Deadlocks)
Ένα σύνολο διεργασιών βρίσκεται σε κατάσταση αδιεξόδου όταν κάθε διεργασία του συνόλου περιμένει ένα γεγονός που μπορεί να προκληθεί μόνο από άλλη διεργασία του ίδιου συνόλου.

### Οι Τέσσερις Αναγκαίες Συνθήκες Coffman:
1. **Αμοιβαίος Αποκλεισμός (Mutual Exclusion):** Τουλάχιστον ένας πόρος μη διαμοιράσιμος.
2. **Κατοχή και Αναμονή (Hold and Wait):** Μια διεργασία κατέχει τουλάχιστον έναν πόρο και αναμένει επιπλέον πόρους.
3. **Μη Προεκτόπιση (No Preemption):** Οι πόροι απελευθερώνονται μόνο εκούσια από τη διεργασία που τους κατέχει.
4. **Κυκλική Αναμονή (Circular Wait):** Υπάρχει κλειστή αλυσίδα διεργασιών $\{P_0, P_1, \dots, P_n\}$ όπου η $P_0$ περιμένει πόρο της $P_1$ και η $P_n$ περιμένει πόρο της $P_0$.

### Μέθοδοι Αντιμετώπισης Αδιεξόδων:
- **Πρόληψη (Prevention):** Εξάλειψη μίας εκ των 4 συνθηκών (π.χ. αυστηρή ιεραρχική διάταξη πόρων).
- **Αποφυγή (Avoidance):** Αλγόριθμος του Τραπεζίτη (Banker's Algorithm) του Dijkstra με έλεγχο ασφαλούς κατάστασης (Safe State).
- **Ανίχνευση και Ανάκαμψη (Detection and Recovery):** Χρήση γράφου αναμονής πόρων (Wait-For Graph) και τερματισμός επιλεγμένων διεργασιών.
- **Αγνόηση (Ostrich Algorithm):** Συμπεριφορά σαν να μην υπάρχει πρόβλημα (τυπική προσέγγιση σε γενικά λειτουργικά όπως Linux/Windows).
