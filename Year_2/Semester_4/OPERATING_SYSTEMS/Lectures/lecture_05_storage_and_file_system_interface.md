# Διάλεξη 5: Διεπαφή Συστήματος Αρχείων και Αποθήκευση (File System Interface)

## 1. Η Έννοια του Αρχείου (The File Concept)
Το αρχείο είναι μια αφηρημένη λογική μονάδα αποθήκευσης πληροφοριών που ορίζεται από το λειτουργικό σύστημα και απεικονίζεται σε φυσικές μη-πτητικές συσκευές (HDD, SSD).
Από την οπτική γωνία του χρήστη, το αρχείο είναι η μικρότερη ονοματισμένη κατανομή λογικού δευτερεύοντος αποθηκευτικού χώρου.

### Ιδιότητες και Μεταδεδομένα Αρχείου (File Attributes)
- **Όνομα (Name):** Συμβολικό αναγνωριστικό σε αναγνώσιμη από τον άνθρωπο μορφή.
- **Αναγνωριστικό (Identifier):** Μοναδικός αριθμός (π.χ. inode number στο UNIX) που προσδιορίζει το αρχείο εντός του συστήματος αρχείων.
- **Τύπος (Type):** Απαιτείται για συστήματα που υποστηρίζουν διαφορετικές μορφές αρχείων (κατάληξη ή magic numbers).
- **Θέση (Location):** Δείκτης προς τη συσκευή και τα φυσικά μπλοκ στο δίσκο.
- **Μέγεθος (Size):** Τρέχον μέγεθος αρχείου σε bytes και δεσμευμένος αποθηκευτικός χώρος σε blocks.
- **Προστασία (Protection):** Πληροφορίες ελέγχου πρόσβασης (ποιος μπορεί να διαβάσει, γράψει ή εκτελέσει).
- **Χρονοσφραγίδες (Timestamps):** Ώρα δημιουργίας, τελευταίας τροποποίησης (mtime), τελευταίας προσπέλασης (atime) και αλλαγής μεταδεδομένων (ctime).

---

## 2. Μέθοδοι Προσπέλασης Αρχείων (Access Methods)
1. **Σειριακή Προσπέλαση (Sequential Access):**
   - Η πληροφορία επεξεργάζεται με τη σειρά, byte προς byte.
   - Λειτουργίες: `read_next()`, `write_next()`, `reset()`.
   - Βασικό μοντέλο για αρχεία κειμένου, εκτυπωτές, ταινίες και ροές δεδομένων.
2. **Άμεση ή Τυχαία Προσπέλαση (Direct / Random Access):**
   - Το αρχείο θεωρείται ως μια αριθμημένη ακολουθία λογικών μπλοκ ή εγγραφών.
   - Επιτρέπεται άμεση ανάγνωση ή εγγραφή σε οποιοδήποτε μπλοκ $n$ χωρίς σειριακή σάρωση: `read(n)`, `write(n)`, `seek(offset)`.
   - Θεμελιώδης για συστήματα βάσεων δεδομένων.

## 3. Δομές Καταλόγων (Directory Structures)
Ο κατάλογος είναι ένας πίνακας συμβόλων που μεταφράζει ονόματα αρχείων στις καταχωρίσεις των αντίστοιχων αρχείων (directory entries).

### Είδη Οργάνωσης Καταλόγων
1. **Κατάλογος Ενός Επιπέδου (Single-Level Directory):**
   - Όλα τα αρχεία βρίσκονται στον ίδιο κατάλογο. Προβλήματα συγκρούσεων ονομάτων μεταξύ διαφορετικών χρηστών.
2. **Κατάλογος Δύο Επιπέδων (Two-Level Directory):**
   - Κάθε χρήστης διαθέτει τον δικό του προσωπικό κατάλογο (User File Directory - UFD) κάτω από έναν κύριο κατάλογο (Master File Directory - MFD).
3. **Δενδροειδής Κατάλογος (Tree-Structured Directory):**
   - Το ευρέως χρησιμοποιούμενο μοντέλο (UNIX, Linux, Windows).
   - Επιτρέπει υποκαταλόγους οποιουδήποτε βάθους.
   - Διαδρομές: **Απόλυτη Διαδρομή (Absolute Path)** ξεκινά από τη ρίζα (`/`) και **Σχετική Διαδρομή (Relative Path)** ξεκινά από τον τρέχοντα κατάλογο εργασίας (`.` και `..`).
4. **Κατάλογος Άκυκλου Γράφου (Acyclic-Graph Directory):**
   - Επιτρέπει σε καταλόγους να διαμοιράζονται υποκαταλόγους και αρχεία μέσω συνδέσμων (Links).

## 4. Σύνδεσμοι στο UNIX: Σκληροί έναντι Συμβολικών (Hard vs Symbolic Links)

### Σκληροί Σύνδεσμοι (Hard Links)
- Δημιουργούν μια επιπλέον καταχώριση καταλόγου που δείχνει **στο ίδιο ακριβώς inode** με το αρχικό αρχείο.
- Αυξάνουν τον μετρητή συνδέσμων (`link count`) του inode κατά 1.
- Το αρχείο διαγράφεται φυσικά από το δίσκο μόνο όταν ο μετρητής συνδέσμων μηδενιστεί (`unlink()`) ΚΑΙ δεν υπάρχει ανοικτός file descriptor.
- Περιορισμοί: Δεν μπορούν να διασχίσουν διαφορετικά συστήματα αρχείων (cross-filesystem) και γενικά απαγορεύονται σε καταλόγους για αποφυγή βρόχων.

### Συμβολικοί / Μαλακοί Σύνδεσμοι (Symbolic / Soft Links)
- Ένα ανεξάρτητο νέο αρχείο (με δικό του ξεχωριστό inode) του οποίου το περιεχόμενο είναι απλώς η διαδρομή κειμένου (path) προς το αρχείο-στόχο.
- Μπορούν να δείχνουν σε καταλόγους και σε διαφορετικά συστήματα αρχείων.
- Εάν το αρχικό αρχείο διαγραφεί, ο συμβολικός σύνδεσμος παραμένει αλλά καθίσταται ορφανός/σπασμένος (dangling link).

## 5. Προσάρτηση Συστημάτων Αρχείων (File System Mounting)
Ένα σύστημα αρχείων πρέπει να προσαρτηθεί (mounted) προτού καταστεί διαθέσιμο στις διεργασίες του συστήματος:
- **Σημείο Προσάρτησης (Mount Point):** Ένας κενός κατάλογος στο υπάρχον δένδρο καταλόγων όπου συνδέεται το νέο σύστημα αρχείων.
- Κατά την προσάρτηση, το λειτουργικό σύστημα διαβάζει το υπερ-μπλοκ (Superblock) της συσκευής και ενσωματώνει τη δομή της στο ενιαίο λογικό δένδρο καταλόγων (π.χ. `mount /dev/sdb1 /mnt/data`).
