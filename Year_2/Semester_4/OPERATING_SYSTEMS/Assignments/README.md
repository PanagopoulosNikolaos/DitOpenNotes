# Εργαστηριακές Ασκήσεις Προγραμματισμού Συστήματος

## Περίληψη Καταλόγου
Σειρές εργαστηριακών ασκήσεων σε γλώσσα C για το περιβάλλον POSIX/Linux. Καλύπτουν κλήσεις συστήματος, διαχείριση διεργασιών, επικοινωνία μέσω pipes και διαχείριση σημάτων.

## Περιεχόμενα Καταλόγου
- [guidelines.md](guidelines.md) — Γενικές οδηγίες μεταγλώττισης και υποβολής εργαστηριακών ασκήσεων.
