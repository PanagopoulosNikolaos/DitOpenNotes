# Λειτουργικά Συστήματα (Mindmap)

## Θεωρία Λειτουργικών Συστημάτων

### Κεφάλαιο 1: Εισαγωγή
- **Ορισμός Λειτουργικού Συστήματος (ΛΣ)**
  - Ενδιάμεσος χρήστη και υλικού (ευκολία χρήσης, εκτέλεση προγραμμάτων)
  - Διαχειριστής ανάθεσης πόρων (Resource Allocator - CPU, μνήμη, I/O)
  - Πρόγραμμα ελέγχου (Control Program - έλεγχος εκτέλεσης και I/O)
  - Πυρήνας (Kernel) — το μόνο πρόγραμμα που τρέχει συνεχώς
- **Στοιχεία Υπολογιστικού Συστήματος (ΥΣ)**
  - Υλικό (Hardware) — CPU, μνήμη, συσκευές I/O
  - Λειτουργικό Σύστημα (OS)
  - Προγράμματα Εφαρμογών (Application Programs) — DBMS, compilers, κτλ.
  - Χρήστες (Users) — άνθρωποι, μηχανές, άλλοι υπολογιστές
- **Ιστορική Εξέλιξη ΛΣ**
  - Σειριακή Επεξεργασία (αρχές 1940 – μέσα 1950) — χωρίς ΛΣ, άμεση αλληλεπίδραση, σπατάλη χρόνου δρομολόγησης/εγκατάστασης
  - Απλά Μαζικά Συστήματα / Batch Processing (αρχές–μέσα 1960) — monitor (παρακολουθητής), Job Control Language (JCL), προστασία μνήμης, χρονιστής, προνομιούχες εντολές, διακοπές (interrupts)
  - Πολυπρογραμματισμός / Multiprogramming (1965–1980) — μεγιστοποίηση χρήσης CPU κατά την αναμονή I/O, διαμερισμός μνήμης, προστασία μνήμης μέσω υλικού
  - Καταμερισμός Χρόνου / Time-Sharing — κβάντο χρόνου (quantum / burst), ελαχιστοποίηση χρόνου απόκρισης, διαδραστικοί χρήστες
  - Τέταρτη Γενιά (1980–1990) — LSI ολοκληρωμένα κυκλώματα, φιλικά ΛΣ, ΛΣ δικτύων, Κατανεμημένα ΛΣ (Distributed OS), συστήματα πραγματικού χρόνου
  - Σύγχρονες Εξελίξεις (1990+) — Linux, Middleware, POSIX (τυποποίηση), Mobile computing

### Κεφάλαιο 2: Σκοποί και Εξέλιξη ΛΣ
- **Βασικοί Σκοποί**
  - Προστασία υλικού (Hardware protection)
  - Επικοινωνία με τον χρήστη (User abstraction)
  - Διαχείριση, αξιοποίηση και έλεγχος πόρων
  - Ικανότητα και ευκολία εξέλιξης (συμβατότητα νέου υλικού/υπηρεσιών, διορθώσεις)
- **Προστασία Υλικού (Hardware Protection)**
  - Dual-Mode λειτουργία — User Mode (bit = 1) και Monitor/Kernel Mode (bit = 0)
  - Προνομιούχες Εντολές (Privileged Instructions) — I/O, load base/limit, load timer, αλλαγή mode bit
  - Προστασία I/O — traps, system calls (έλεγχος ρουτινών εξυπηρέτησης από τον monitor)
  - Προστασία Μνήμης — Base & Limit registers (εύρος διευθύνσεων `[base, base + limit)`), MMU
  - Προστασία CPU — Timer (χρονιστής) & clock ticks (αποφυγή μονοπώλησης CPU)
- **Επικοινωνία με τον Χρήστη (User Abstraction)**
  - Επίπεδα αφαίρεσης (User/Programmer → Applications → Utilities → OS → Hardware)
  - Μικροπρογραμματισμός — διερμηνέας σε ROM (microcode) που μεταφράζει γλώσσα μηχανής
  - Πυρήνας ΛΣ (Kernel) — μόνιμα στην κύρια μνήμη
- **Διαχείριση Πόρων & Εξέλιξη**
  - Κατανομή επεξεργαστών, μνημών, I/O
  - 5 Άξονες εξέλιξης — Διεργασίες, Διαχείριση μνήμης, Ασφάλεια, Δρομολόγηση, Δομή
  - Ιεραρχία σχεδίασης ΛΣ (Layered Architecture — 13 επίπεδα, από κυκλώματα έως shell)
  - Χαρακτηριστικά σύγχρονων ΛΣ — Microkernel, Multithreading, SMP, Distributed, Real-time

### Κεφάλαιο 3: Διεργασίες (Processes)
- **Έννοια Διεργασίας**
  - Ορισμός διεργασίας — πρόγραμμα σε εκτέλεση (ενεργή οντότητα), PCB
  - Χώρος διευθύνσεων — Code (εκτελέσιμο), Data (μεταβλητές), Stack (κλήσεις/τοπικές), Heap (δυναμική μνήμη)
  - Διαφορά διεργασίας και προγράμματος (ενεργή vs παθητική οντότητα)
- **Καταστάσεις και Μεταβάσεις**
  - Βασικές καταστάσεις — Ready (Έτοιμη), Running (Σε εκτέλεση), Blocked (Σε αναμονή)
  - Καταστάσεις αναστολής (Suspend) — Blocked/Suspend, Ready/Suspend (ελευθέρωση κύριας μνήμης, backing store)
  - Μεταβάσεις καταστάσεων — Running -> Blocked (αίτημα I/O), Running -> Ready (timeout/quantum), Blocked -> Ready (ολοκλήρωση I/O), Ready -> Running (μέσω Dispatcher)
- **Διαχείριση Διεργασιών (Process Control)**
  - Process Control Block (PCB) — Program Counter, καταχωρητές, κατάσταση, UID, PID, προτεραιότητα
  - Πίνακας Διεργασιών — Linked list από PCBs
  - Context Switch (Εναλλαγή διεργασίας) — αποθήκευση/ανάκτηση καταστάσεων CPU
- **Δημιουργία και Έλεγχος (System Calls στο UNIX)**
  - `fork()` — δημιουργία νέας διεργασίας (αντιγραφή, επιστρέφει 0 στο παιδί, PID στο γονέα)
  - `exec()` — αντικατάσταση εικόνας μνήμης με νέο εκτελέσιμο πρόγραμμα
  - `exit()` — τερματισμός διεργασίας
  - `wait()` — αναμονή του γονέα για τον τερματισμό του παιδιού

### Κεφάλαιο 4: Αρχιτεκτονικές Λειτουργικών Συστημάτων
- **Δομή Πυρήνα**
  - Μονολιθικά Συστήματα (Monolithic Systems) — όλα τα τμήματα σε Kernel Mode, μέγιστη απόδοση, δύσκολο debugging
  - Στρωματοποιημένη Αρχιτεκτονική (Layered) — ιεραρχική οργάνωση, καθαρά interfaces, overhead λόγω περασμάτων
  - Αρχιτεκτονική Μικροπυρήνα (Microkernel) — ελάχιστες υπηρεσίες στον πυρήνα, modularity, server processes σε User Mode, αυξημένη αξιοπιστία
- **Νήματα (Threads / Multithreading)**
  - Πολυνημάτωση — πολλά νήματα εντός της ίδιας διεργασίας, κοινός χώρος διευθύνσεων, ταχύτερο context switch
  - User-Level Threads (ULT) — διαχείριση από βιβλιοθήκη σε user space, γρήγορη εναλλαγή, blocking call μπλοκάρει όλη τη διεργασία
  - Kernel-Level Threads (KLT) — διαχείριση από τον πυρήνα, αληθινή παράλληλη εκτέλεση, μεγαλύτερο overhead
- **Συστήματα και Επεξεργασία**
  - Πολυεπεξεργασία (Multiprocessing) — Symmetric (SMP) vs Asymmetric (AMP)
  - Παράλληλα Συστήματα — Tightly coupled (κοινή μνήμη) vs Loosely coupled (κατανεμημένη)
  - Συστήματα Πραγματικού Χρόνου — Hard real-time (αυστηρές προθεσμίες) vs Soft real-time
  - Κατανεμημένα Συστήματα (Distributed Systems)

### Κεφάλαιο 5: Αμοιβαίος Αποκλεισμός (Mutual Exclusion)
- **Βασικές Έννοιες**
  - Συνθήκη Ανταγωνισμού (Race Condition) — εξάρτηση αποτελέσματος από τη σειρά/χρονισμό εκτέλεσης
  - Κρίσιμο Τμήμα (Critical Section — CS) — τμήμα κώδικα με πρόσβαση σε κοινόχρηστο πόρο
  - 4 Συνθήκες ορθής λειτουργίας CS — Mutual Exclusion, όχι υποθέσεις για ταχύτητα/CPU, όχι μπλοκάρισμα εκτός CS, όχι αιώνια αναμονή (starvation)
- **Λύσεις Λογισμικού (Software Solutions)**
  - Αλγόριθμος Dekker
  - Αλγόριθμος Peterson — χρήση flag (επιθυμία εισόδου) και turn (παραχώρηση σειράς)
- **Υποστήριξη Υλικού (Hardware Support)**
  - Απενεργοποίηση διακοπών (Disable Interrupts) — μόνο σε μονοεπεξεργαστές
  - Ειδικές εντολές CPU — Test-and-Set-Lock (TSL), Exchange (XCHG) / Compare-and-Swap (ατομικές λειτουργίες)
- **Σημαφόροι (Semaphores)**
  - Ορισμός — Ακέραια μεταβλητή s με ατομικές λειτουργίες `wait()` (P) και `signal()` (V)
  - Δυαδικοί Σημαφόροι (Binary/Mutex) — τιμές 0 ή 1
  - Γενικοί/Μετρικοί Σημαφόροι (Counting Semaphores) — διαχείριση πολλαπλών πόρων
  - Υλοποίηση χωρίς ενεργό αναμονή (Busy waiting) — χρήση ουράς μπλοκαρισμένων διεργασιών

### Κεφάλαιο 6: Αδιέξοδο (Deadlock)
- **Έννοια Αδιεξόδου**
  - Ορισμός Deadlock — αμοιβαίο μπλοκάρισμα διεργασιών που αναμένουν πόρους που κρατούν άλλες
  - Είδη πόρων — Επαναχρησιμοποιήσιμοι (reusable) vs Αναλώσιμοι (consumable), Προεκτοπίσιμοι (preemptable) vs Μη προεκτοπίσιμοι
- **Μοντελοποίηση και Συνθήκες**
  - Γράφοι Εκχώρησης Πόρων (Resource Allocation Graphs — RAG) — κύκλοι υποδηλώνουν αδιέξοδα
  - Οι 4 αναγκαίες συνθήκες Coffman — Mutual Exclusion, Hold & Wait, No Preemption, Circular Wait (πρέπει να ισχύουν ταυτόχρονα)
- **Προσεγγίσεις Αντιμετώπισης**
  - Παράβλεψη (Ostrich Algorithm) — αγνόηση του προβλήματος (συχνή σε γενικά ΛΣ)
  - Πρόληψη (Prevention) — σχεδιαστικός αποκλεισμός μίας εκ των 4 συνθηκών Coffman (π.χ. ιεραρχική ζήτηση)
  - Αποφυγή (Avoidance) — δυναμικός έλεγχος ασφάλειας κατά την εκχώρηση πόρων
    - Αλγόριθμος του Τραπεζίτη (Banker's Algorithm) — Safe/Unsafe states, διανύσματα Available, Max, Allocation, Need
  - Ανίχνευση και Αποκατάσταση (Detection & Recovery) — έλεγχος RAG, τερματισμός διεργασιών, προεκτόπιση πόρων
- **Πρόβλημα Συνδαιτυμόνων Φιλοσόφων (Dining Philosophers)**
  - Deadlock σενάριο (όλοι παίρνουν το αριστερό πιρούνι)
  - Λύσεις συγχρονισμού — περιορισμός χρηστών, ατομική λήψη και των δύο πιρουνιών με σημαφόρους

### Κεφάλαιο 7: Διαχείριση Μνήμης (Memory Management)
- **Βασικές Έννοιες**
  - Memory Manager — καταγραφή, δέσμευση, αποδέσμευση, προστασία, relocation
  - Διευθυνσιοδότηση — Λογικές (Logical/Virtual) vs Φυσικές (Physical) διευθύνσεις
- **Τμηματοποίηση (Partitioning)**
  - Fixed Partitioning (Σταθερού μεγέθους) — Εσωτερικός κατακερματισμός (Internal Fragmentation)
  - Dynamic Partitioning (Δυναμική τμηματοποίηση) — Εξωτερικός κατακερματισμός (External Fragmentation)
  - Συμπίεση Μνήμης (Compaction) — μετακίνηση διεργασιών για συνένωση κενών (δαπανηρή για CPU)
- **Αλγόριθμοι Τοποθέτησης (Placement Algorithms)**
  - First-Fit — πρώτη κατάλληλη θέση (γρήγορη)
  - Next-Fit — πρώτη κατάλληλη μετά την τελευταία τοποθέτηση
  - Best-Fit — η θέση με το μικρότερο δυνατό υπόλοιπο (δημιουργεί μικρά άχρηστα κενά)
  - Worst-Fit — η μεγαλύτερη διαθέσιμη θέση
- **Swapping (Εναλλαγή)**
  - Roll-out / Roll-in διεργασιών στον Backing Store (δίσκο)
  - Καταγραφή ελεύθερου χώρου — Bitmaps vs Linked Lists

### Κεφάλαιο 8: Εικονική Μνήμη (Virtual Memory)
- **Σελιδοποίηση (Paging)**
  - Εικονικές Σελίδες (Pages) και Φυσικά Πλαίσια (Frames)
  - Πίνακας Σελίδων (Page Table) — χαρτογράφηση Virtual -> Physical
  - MMU (Memory Management Unit) — hardware μετατροπή διευθύνσεων
  - TLB (Translation Lookaside Buffer) — γρήγορη κρυφή μνήμη (cache) μετατροπών
  - Page Fault — διακοπή όταν η σελίδα δεν είναι φορτωμένη στη μνήμη (ροή: trap -> δίσκος -> φόρτωση frame -> update table -> επανεκκίνηση εντολής)
- **Τμηματοποίηση (Segmentation)**
  - Λογική οργάνωση προγράμματος σε τμήματα (Segments) μεταβλητού μεγέθους (code, stack, data)
  - Πίνακας Τμημάτων (Segment Table)
- **Αλγόριθμοι Αντικατάστασης Σελίδων**
  - Βέλτιστος Αλγόριθμος (Optimal / OPT / MIN) — αντικατάσταση σελίδας που θα χρησιμοποιηθεί αργότερα (θεωρητικός)
  - FIFO (First-In, First-Out) — αντικατάσταση παλαιότερης σελίδας (Belady's Anomaly: περισσότερα frames -> περισσότερα faults)
  - LRU (Least Recently Used) — αντικατάσταση σελίδας που έχει να χρησιμοποιηθεί περισσότερη ώρα (υψηλό κόστος)
  - Clock Algorithm (Second Chance) — προσέγγιση LRU με reference bit σε κυκλική λίστα

### Κεφάλαιο 9: Χρονοδρομολόγηση Διεργασιών (CPU Scheduling)
- **Κριτήρια Απόδοσης**
  - CPU Utilization (Χρησιμοποίηση CPU) — ποσοστό χρόνου απασχόλησης
  - Throughput (Ρυθμοαπόδοση) — αριθμός διεργασιών ανά μονάδα χρόνου
  - Turnaround Time (Χρόνος Ολοκλήρωσης) — συνολικός χρόνος από την υποβολή έως το τέλος
  - Waiting Time (Χρόνος Αναμονής) — χρόνος στην Ready ουρά
  - Response Time (Χρόνος Απόκρισης) — χρόνος από την υποβολή έως την πρώτη απόκριση
- **Τύποι Χρονοδρομολόγησης**
  - Μη προεκτοπιστική (Non-preemptive) — η διεργασία κρατά τη CPU μέχρι να τερματίσει ή να μπλοκαριστεί
  - Προεκτοπιστική (Preemptive) — ο πυρήνας μπορεί να διακόψει τη διεργασία (λήξη κβάντου, προτεραιότητα)
- **Αλγόριθμοι Χρονοδρομολόγησης**
  - FCFS (First-Come, First-Served) — μη προεκτοπιστικός (Convoy Effect)
  - SJF (Shortest Job First) — βέλτιστος για ελάχιστο μέσο χρόνο αναμονής, κίνδυνος λιμοκτονίας (Starvation)
  - SRTF (Shortest Remaining Time First) — προεκτοπιστική έκδοση του SJF
  - Round Robin (RR) — κυκλική εξυπηρέτηση με κβάντο χρόνου (time quantum)
  - Priority Scheduling — δρομολόγηση βάσει προτεραιότητας, λύση για λιμοκτονία με γήρανση (Aging)
  - Multilevel Queue & Multilevel Feedback Queue (MLFQ) — πολλαπλές ουρές με δυναμική μετακίνηση διεργασιών

## Εργαστήριο UNIX

### 1. Introduction to UNIX and Linux Terminal Basics
- **Φιλοσοφία UNIX**
  - Everything is a file (Όλα είναι αρχεία - regular, directories, devices, connections)
  - Do one thing and do it well (Μικρά, εξειδικευμένα εργαλεία)
  - Chaining programs (Συνδυασμός προγραμμάτων με pipes)
- **Λογαριασμοί Χρηστών & Ιδιότητες**
  - Username, Password (`/etc/shadow`), UID (Root is 0), GID, Home Directory, Default Shell
  - Σύστημα αρχείων: Root (`/`), `/bin` (binaries), `/etc` (config), `/home`, `/root`, `/tmp`
  - Shell Prompt (`$` για χρήστη, `#` για root)
- **Βασικές Εντολές**
  - `passwd` — αλλαγή κωδικού πρόσβασης
  - `date` — προβολή/μορφοποίηση ημερομηνίας και ώρας
  - `cal` — προβολή ημερολογίου (τρέχον μήνας, έτος, συγκεκριμένος μήνας)
  - `who`, `whoami`, `who am i` — πληροφορίες συνδεδεμένων χρηστών

### 2. UNIX File System Navigation
- **Τύποι Αρχείων στο UNIX**
  - Regular files (`-`), Directories (`d`), Symbolic links (`l`), Character devices (`c`), Block devices (`b`)
- **Διαδρομές Αρχείων (Pathnames)**
  - Absolute pathnames (ξεκινούν από τη ρίζα `/`)
  - Relative pathnames (ξεκινούν από τον τρέχοντα κατάλογο, `.` για τρέχοντα, `..` για γονικό, `~` για home)
- **Πλοήγηση και Διαχείριση Καταλόγων**
  - `pwd` — προβολή τρέχοντος καταλόγου (print working directory)
  - `cd` — αλλαγή καταλόγου (`cd ~` για home, `cd -` για προηγούμενο, `cd ..` για γονικό)
  - `mkdir` — δημιουργία καταλόγου (παράμετρος `-p` για δημιουργία γονικών καταλόγων)
  - `rmdir` — διαγραφή άδειου καταλόγου

### 3. UNIX File and Directory Management
- **Αντιγραφή, Μετακίνηση & Διαγραφή**
  - `rm` — διαγραφή αρχείων (`-r` για αναδρομική διαγραφή καταλόγων, `-f` για force)
  - `cp` — αντιγραφή αρχείων (`-r` για καταλόγους, `-i` για επιβεβαίωση)
  - `mv` — μετακίνηση ή μετονομασία αρχείων/καταλόγων
- **Προβολή Περιεχομένων**
  - `ls` — λίστα αρχείων καταλόγου
  - Παράμετροι `ls`: `-l` (long format, λεπτομέρειες), `-a` (όλα τα αρχεία, μαζί με κρυφά που ξεκινούν με `.`), `-R` (αναδρομικά), `-t` (ταξινόμηση κατά χρόνο τροποποίησης), `-S` (ταξινόμηση κατά μέγεθος)

### 4. UNIX Access Permissions
- **Μοντέλο Δικαιωμάτων**
  - Τρεις κατηγορίες: Owner/User (`u`), Group (`g`), Others (`o`), All (`a`)
  - Τρεις τύποι: Read (`r`), Write (`w`), Execute (`x`)
  - Συμβολική αναπαράσταση (π.χ. `rwxr-xr--` -> 9 χαρακτήρες)
- **Δικαιώματα Καταλόγων**
  - `r` (Read) — λίστα αρχείων καταλόγου (`ls`)
  - `w` (Write) — δημιουργία/διαγραφή αρχείων στον κατάλογο
  - `x` (Execute) — είσοδος/πρόσβαση στον κατάλογο (`cd`, εκτέλεση αρχείων εντός αυτού)
- **Αλλαγή Δικαιωμάτων & Ιδιοκτησίας**
  - `chmod` — τροποποίηση δικαιωμάτων
    - Συμβολική μέθοδος (π.χ. `chmod u+x,g-w file`)
    - Οκταδική / Αριθμητική μέθοδος (π.χ. `chmod 755 file` -> `rwxr-xr-x`, 4=read, 2=write, 1=execute)
  - `chown` — αλλαγή ιδιοκτήτη αρχείου (απαιτεί δικαιώματα root)
  - `chgrp` — αλλαγή ομάδας αρχείου
  - `umask` — καθορισμός προεπιλεγμένων δικαιωμάτων για νέα αρχεία/καταλόγους (π.χ. `umask 022`)

### 5. UNIX File Viewing and Linking
- **Προβολή Περιεχομένου Αρχείων**
  - `cat` — συνένωση και εμφάνιση αρχείου
  - `more` & `less` — σελιδοποιημένη προβολή (το `less` επιτρέπει πλοήγηση προς τα πίσω/αναζήτηση)
  - `head` — προβολή των πρώτων N γραμμών (προεπιλογή 10, παράμετρος `-n`)
  - `tail` — προβολή των τελευταίων N γραμμών (`-f` για real-time παρακολούθηση)
- **Ανάλυση Αρχείων**
  - `wc` — μέτρηση γραμμών (`-l`), λέξεων (`-w`), και χαρακτήρων (`-c`/`-m`)
  - `file` — αναγνώριση τύπου αρχείου/περιεχομένου
- **Σύνδεσμοι Αρχείων (Links)**
  - Hard Links (`ln file link`) — δείχνουν στο ίδιο inode, δεν μπορούν να διασχίσουν συστήματα αρχείων, ούτε να δείχνουν σε καταλόγους
  - Symbolic Links / Soft Links (`ln -s file link`) — δείχνουν στο όνομα της διαδρομής (shortcut), μπορούν να δείχνουν σε καταλόγους και να διασχίζουν συστήματα αρχείων

### 6. UNIX I/O Redirection and Pipes
- **Τυπικές Ροές I/O (Streams)**
  - Standard Input (stdin, fd 0) — πληκτρολόγιο
  - Standard Output (stdout, fd 1) — οθόνη
  - Standard Error (stderr, fd 2) — οθόνη (ξεχωριστό κανάλι σφαλμάτων)
- **Ανακατεύθυνση (Redirection)**
  - `>` — ανακατεύθυνση stdout σε αρχείο (υπεργραφή)
  - `>>` — ανακατεύθυνση stdout σε αρχείο (προσάρτηση/append)
  - `2>` — ανακατεύθυνση stderr σε αρχείο (υπεργραφή)
  - `2>>` — ανακατεύθυνση stderr σε αρχείο (append)
  - `&>` ή `> file 2>&1` — ανακατεύθυνση stdout και stderr στο ίδιο αρχείο
  - `<` — ανακατεύθυνση stdin από αρχείο
- **Διοχετεύσεις (Pipes)**
  - `|` — σύνδεση του stdout μιας εντολής με το stdin μιας άλλης (π.χ. `ls | wc -l`)

### 7. UNIX Wildcards and Glob Patterns
- **Globbing Patterns**
  - `*` — αντιστοιχεί σε οποιονδήποτε αριθμό χαρακτήρων (συμπεριλαμβανομένου κανενός)
  - `?` — αντιστοιχεί σε ακριβώς έναν οποιοδήποτε χαρακτήρα
  - `[...]` — αντιστοιχεί σε οποιονδήποτε μεμονωμένο χαρακτήρα εντός των αγκυλών (π.χ. `[a-z]`, `[0-9]`)
  - `[!...]` ή `[^...]` — αντιστοιχεί σε οποιονδήποτε χαρακτήρα εκτός αυτών στις αγκύλες
- **Ειδικές Περιπτώσεις & Gotchas**
  - Τα glob patterns δεν ταιριάζουν με κρυφά αρχεία (που ξεκινούν με `.`) εκτός αν δηλωθεί ρητά (π.χ. `.*`)
  - Η επέκταση (expansion) γίνεται από το shell πριν την εκτέλεση της εντολής
- **Διαφυγή (Escaping)**
  - Χρήση backslash (`\`) ή εισαγωγικών (`'`, `"`) για απενεργοποίηση της ειδικής σημασίας των wildcards
