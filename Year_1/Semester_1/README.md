# Year 1 - Semester 1

Welcome to the comprehensive academic course archive for **Year 1, Semester 1** of the Department of Informatics and Telecommunications at the University of Ioannina.

---

## Curriculum Overview

Semester 1 introduces foundational mathematical analysis, linear algebra, digital circuit design, physical electronics, and procedural systems programming in C.

| Code | Course Name | ECTS | Category | Primary Focus |
|:---|:---|:---:|:---|:---|
| **101** | [Mathematical Analysis](MATHEMATICAL_ANALYSIS) | 6 | Mandatory | Real single-variable calculus, limits, derivatives, integration |
| **102** | [Linear Algebra](LINEAR_ALGEBRA) | 6 | Mandatory | Vector spaces, matrix algebra, linear systems, eigenvalues |
| **103** | [C Programming I](C_PROGRAMMING_I) | 6 | Mandatory | Procedural programming, memory fundamentals, pointers, file I/O |
| **104** | [Logic Design](LOGIC_DESIGN) | 6 | Mandatory | Boolean algebra, K-maps, combinational and sequential digital logic |
| **105** | [Electronics](ELECTRONICS) | 6 | Mandatory | Circuit analysis theorems, semiconductor physics, diodes, BJT amplifiers |

Each course directory adheres strictly to the department's standard academic curriculum organization:

```text

├── README.md               # Course syllabus, prerequisites, outcomes, directory index

```

## Getting Started

1. **Prerequisites & Tooling**: Install GNU Compiler Collection (`gcc`), GNU Debugger (`gdb`), GNU Octave, and circuit simulation tooling (such as NGSPICE or Logisim-evolution).
2. **Recommended Study Order**: Begin each week by studying the theoretical concepts in `Lectures/` and `Resources/Notes/`, followed by hands-on execution of `Examples/` and drilling through `Exercises/`.
3. **Assessment Preparation**: Complete the graded assignments in `Assignments/` and self-evaluate with mock tests in `Exams/`.
