## Ενδεικτικές Λύσεις

### Λύση Θέματος 1
1. Το όριο είναι της μορφής $[1^\infty]$.
   $$\ln L_1 = \lim_{x \to 0} \frac{\ln(1 + 3x)}{x} \xrightarrow{\text{L'Hôpital}} \lim_{x \to 0} \frac{\frac{3}{1 + 3x}}{1} = 3 \implies L_1 = e^3$$
2. Συνέχεια στο $0$:
   $$\left|x^2 \sin(1/x)\right| \le x^2 \xrightarrow{x \to 0} 0 = f(0)$$
   Συνεπώς η $f$ είναι συνεχής στο $0$ από το κριτήριο παρεμβολής.
   Παραγωγισιμότητα στο $0$:
   $$f'(0) = \lim_{h \to 0} \frac{f(h) - f(0)}{h} = \lim_{h \to 0} \frac{h^2 \sin(1/h)}{h} = \lim_{h \to 0} h \sin\left(\frac{1}{h}\right) = 0$$
   Η $f$ είναι παραγωγίσιμη στο $0$ με $f'(0) = 0$.

### Λύση Θέματος 2
1. Πεδίο ορισμού: $D_g = \mathbb{R} \setminus \{1\}$.
   * Κατακόρυφη ασύμπτωτη: στο $x = 1$, καθώς $\lim_{x \to 1^\pm} g(x) = \mp\infty$.
   * Πλάγια ασύμπτωτη: με πολυωνυμική διαίρεση $x^2 - 4 = (x - 1)(x + 1) - 3$, άρα $g(x) = x + 1 - \frac{3}{x - 1}$.
     Καθώς $x \to \pm\infty$, $\frac{3}{x - 1} \to 0$. Η ευθεία $y = x + 1$ είναι πλάγια ασύμπτωτη.
2. Παράγωγος:
   $$g'(x) = 1 + \frac{3}{(x - 1)^2} > 0 \quad \forall x \ne 1$$
   Η συνάρτηση είναι γνησίως αύξουσα σε καθένα από τα διαστήματα $(-\infty, 1)$ και $(1, \infty)$. Δεν παρουσιάζει τοπικά ακρότατα.

### Λύση Θέματος 3
1. Ανάλυση σε απλά κλάσματα: $x^2 - 5x + 6 = (x - 2)(x - 3)$.
   $$\frac{x + 1}{(x - 2)(x - 3)} = \frac{A}{x - 2} + \frac{B}{x - 3}$$
   * $x + 1 = A(x - 3) + B(x - 2)$
   * Για $x = 2 \implies 3 = -A \implies A = -3$.
   * Για $x = 3 \implies 4 = B \implies B = 4$.
   $$I = -3 \int \frac{dx}{x - 2} + 4 \int \frac{dx}{x - 3} = -3\ln|x - 2| + 4\ln|x - 3| + C$$
2. Γενικευμένο ολοκλήρωμα:
   $$J = \lim_{b \to \infty} \int_1^b \frac{dx}{x^2 + 1} = \lim_{b \to \infty} [\arctan x]_1^b = \lim_{b \to \infty} \left(\arctan b - \arctan 1\right) = \frac{\pi}{2} - \frac{\pi}{4} = \frac{\pi}{4}$$

### Λύση Θέματος 4
1. Κριτήριο Λόγου:
   $$\lim_{n \to \infty} \left| \frac{a_{n+1}}{a_n} \right| = \lim_{n \to \infty} \frac{\frac{n+1}{2^{n+1}}}{\frac{n}{2^n}} = \lim_{n \to \infty} \frac{n+1}{2n} = \frac{1}{2}$$
   Επειδή $L = 1/2 < 1$, η σειρά συγκλίνει απολύτως.
2. Μιγαδικός $z = 1 + i\sqrt{3}$:
   Μέτρο $|z| = \sqrt{1 + 3} = 2$.
   Όρισμα $\theta = \arctan(\sqrt{3}) = \frac{\pi}{3}$.
   Τριγωνομετρική μορφή: $z = 2\left(\cos \frac{\pi}{3} + i \sin \frac{\pi}{3}\right)$.
   Από θεώρημα De Moivre:
   $$z^6 = 2^6 \left(\cos(6 \cdot \frac{\pi}{3}) + i \sin(6 \cdot \frac{\pi}{3})\right) = 64(\cos(2\pi) + i\sin(2\pi)) = 64(1 + 0) = 64$$
