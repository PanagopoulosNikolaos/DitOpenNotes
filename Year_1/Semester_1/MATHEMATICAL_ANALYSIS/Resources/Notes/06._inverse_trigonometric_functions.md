# Inverse Trigonometric Functions

Study of inverse trigonometric functions (arcsine, arccosine, arctangent, arccotangent), the domain restrictions required to make trigonometric functions one-to-one, their properties, and methods for simplifying trigonometric expressions using reference triangles.

---

## 1. Domain Restriction and Definitions

Trigonometric functions are periodic, therefore they are not one-to-one. To define their inverses, we restrict their domain to intervals of monotonicity.

### The Inverse Sine Function ($y = \sin^{-1}(x)$ or $y = \arcsin(x)$)
We restrict the sine to the interval $[-\frac{\pi}{2}, \frac{\pi}{2}]$, where it is strictly increasing.
$$
y = \sin^{-1}(x) \iff \sin(y) = x
$$
- **Domain:** $[-1, 1]$
- **Range (Principal Values):** $[-\frac{\pi}{2}, \frac{\pi}{2}]$

### The Inverse Cosine Function ($y = \cos^{-1}(x)$ or $y = \arccos(x)$)
We restrict the cosine to the interval $[0, \pi]$, where it is strictly decreasing.
$$
y = \cos^{-1}(x) \iff \cos(y) = x
$$
- **Domain:** $[-1, 1]$
- **Range:** $[0, \pi]$

### The Inverse Tangent Function ($y = \tan^{-1}(x)$ or $y = \arctan(x)$)
We restrict the tangent to the open interval $(-\frac{\pi}{2}, \frac{\pi}{2})$.
$$
y = \tan^{-1}(x) \iff \tan(y) = x
$$
- **Domain:** $\mathbb{R}$
- **Range:** $(-\frac{\pi}{2}, \frac{\pi}{2})$

### The Inverse Cotangent Function ($y = \cot^{-1}(x)$ or $y = \arccot(x)$)
We restrict the cotangent to the interval $(0, \pi)$.
$$
y = \cot^{-1}(x) \iff \cot(y) = x
$$
- **Domain:** $\mathbb{R}$
- **Range:** $(0, \pi)$

---

## 2. Properties and Cancellation Relations

By definition, the following cancellation relations hold **provided that** the variables belong to the appropriate intervals:
- $\sin(\sin^{-1}(x)) = x$ for $x \in [-1, 1]$
- $\sin^{-1}(\sin(\theta)) = \theta$ only if $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$
- $\cos(\cos^{-1}(x)) = x$ for $x \in [-1, 1]$
- $\cos^{-1}(\cos(\theta)) = \theta$ only if $\theta \in [0, \pi]$

---

## 3. Converting Trigonometric Expressions to Algebraic

To simplify expressions of the form $T_1(T_2^{-1}(x))$ (where $T_1, T_2$ are trigonometric functions), we use the **reference right triangle** method:
1. We set $\theta = T_2^{-1}(x)$, so $T_2(\theta) = x$.
2. We draw a right triangle with angle $\theta$ and place its sides so that the relation $T_2(\theta) = x$ is satisfied.
   - For example, if $\sin(\theta) = x = \frac{x}{1}$, we set the opposite vertical side equal to $x$ and the hypotenuse equal to $1$.
3. We calculate the third side using the Pythagorean Theorem.
4. We read the value $T_1(\theta)$ directly from the triangle.

## Solved Exercises

### Exercise 1: Computing Principal Values
**Problem:**
Compute the exact values of the expressions:
a) $\sin^{-1}\left(-\frac{1}{2}\right)$
b) $\cos^{-1}\left(-\frac{\sqrt{3}}{2}\right)$

**Solution:**
a) We seek an angle $\theta \in [-\frac{\pi}{2}, \frac{\pi}{2}]$ for which $\sin(\theta) = -\frac{1}{2}$.
   - We know that $\sin\left(\frac{\pi}{6}\right) = \frac{1}{2}$.
   - Due to odd symmetry: $\sin\left(-\frac{\pi}{6}\right) = -\frac{1}{2}$.
   - Since $-\frac{\pi}{6} \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, the answer is:
     $$
     \sin^{-1}\left(-\frac{1}{2}\right) = -\frac{\pi}{6}
     $$
b) We seek an angle $\theta \in [0, \pi]$ for which $\cos(\theta) = -\frac{\sqrt{3}}{2}$.
   - We know that $\cos\left(\frac{\pi}{6}\right) = \frac{\sqrt{3}}{2}$.
   - Since the cosine is negative, the angle is in the 2nd quadrant: $\theta = \pi - \frac{\pi}{6} = \frac{5\pi}{6}$.
   - Since $\frac{5\pi}{6} \in [0, \pi]$, the answer is:
     $$
     \cos^{-1}\left(-\frac{\sqrt{3}}{2}\right) = \frac{5\pi}{6}
     $$

### Exercise 2: Cancellation Relation Outside Bounds
**Problem:**
Compute the value of the expression:
$$
A = \tan^{-1}\left(\tan\left(\frac{3\pi}{4}\right)\right)
$$

**Solution:**
1. **Caution:** We cannot simply cancel the functions and write $\frac{3\pi}{4}$ because this angle does not belong to the range of $\tan^{-1}(x)$, which is $(-\frac{\pi}{2}, \frac{\pi}{2})$.
2. We first compute the inner value:
   $$
   \tan\left(\frac{3\pi}{4}\right) = \tan\left(\pi - \frac{\pi}{4}\right) = -\tan\left(\frac{\pi}{4}\right) = -1
   $$
3. Now we compute the outer function:
   $$
   \tan^{-1}(-1)
   $$
4. We seek the angle $\theta \in (-\frac{\pi}{2}, \frac{\pi}{2})$ with $\tan(\theta) = -1$. This is $\theta = -\frac{\pi}{4}$.
5. Therefore:
   $$
   A = -\frac{\pi}{4}
   $$

### Exercise 3: Simplification Using a Triangle
**Problem:**
Express the quantity $\cos(\tan^{-1}(x))$ as a purely algebraic expression in $x$.

**Solution:**
1. We set $\theta = \tan^{-1}(x)$, so $\tan(\theta) = x = \frac{x}{1}$.
2. We draw a right triangle with angle $\theta$:
   - Opposite vertical side = $x$
   - Adjacent vertical side = $1$
3. We calculate the hypotenuse $z$ using the Pythagorean Theorem:
   $$
   z^2 = 1^2 + x^2 \implies z = \sqrt{1 + x^2}
   $$
4. We calculate the cosine of the angle $\theta$:
   $$
   \cos(\theta) = \frac{\text{Adjacent}}{\text{Hypotenuse}} = \frac{1}{\sqrt{1 + x^2}}
   $$
5. Therefore:
   $$
   \cos(\tan^{-1}(x)) = \frac{1}{\sqrt{1 + x^2}}
   $$

### Exercise 4: Solving an Inverse Trigonometric Equation
**Problem:**
Solve the equation:
$$
\sin^{-1}(2x) = \frac{\pi}{3}
$$

**Solution:**
1. For the function to be defined, its argument must belong to the interval $[-1, 1]$:
   $$
   -1 \le 2x \le 1 \implies -\frac{1}{2} \le x \le \frac{1}{2}
   $$
2. We apply the sine function to both sides:
   $$
   \sin(\sin^{-1}(2x)) = \sin\left(\frac{\pi}{3}\right)
   $$
3. By the cancellation relation:
   $$
   2x = \frac{\sqrt{3}}{2}
   $$
4. We solve for $x$:
   $$
   x = \frac{\sqrt{3}}{4}
   $$
5. We check whether the solution satisfies the constraint: $\frac{\sqrt{3}}{4} \approx \frac{1.73}{4} \approx 0.43$. Since $-0.5 \le 0.43 \le 0.5$, the solution is accepted.

### Exercise 5: Proof of the Complementary Arcs Identity
**Problem:**
> **[Supplementary]**
> Prove that for every $x \in [-1, 1]$ the following holds:
> $$
> \sin^{-1}(x) + \cos^{-1}(x) = \frac{\pi}{2}
> $$

**Solution:**
> **[Supplementary]**
> 1. We set $y = \sin^{-1}(x)$, which means $\sin(y) = x$ with $y \in [-\frac{\pi}{2}, \frac{\pi}{2}]$.
> 2. We use the complementary angle relation:
>    $$
>    \cos\left(\frac{\pi}{2} - y\right) = \sin(y) = x
>    $$
> 3. Since $y \in [-\frac{\pi}{2}, \frac{\pi}{2}]$, we have:
>    $$
>    -\frac{\pi}{2} \le y \le \frac{\pi}{2} \implies -\frac{\pi}{2} \le -y \le \frac{\pi}{2} \implies 0 \le \frac{\pi}{2} - y \le \pi
>    $$
> 4. Since the angle $\frac{\pi}{2} - y$ belongs to the interval $[0, \pi]$, we can apply the inverse cosine function:
>    $$
>    \cos^{-1}(x) = \frac{\pi}{2} - y
>    $$
> 5. Substituting $y = \sin^{-1}(x)$:
>    $$
>    \cos^{-1}(x) = \frac{\pi}{2} - \sin^{-1}(x) \implies \sin^{-1}(x) + \cos^{-1}(x) = \frac{\pi}{2}
>    $$

### Exercise 6: Finding the Domain
**Problem:**
> **[Supplementary]**
> Find the domain of the function:
> $$
> f(x) = \sin^{-1}(2x - 3)
> $$

**Solution:**
> **[Supplementary]**
> 1. The domain of the function $y = \sin^{-1}(u)$ is the interval $[-1, 1]$.
> 2. Therefore, for $f(x)$ to be defined, we need:
>    $$
>    -1 \le 2x - 3 \le 1
>    $$
> 3. We add $3$ to all parts:
>    $$
>    2 \le 2x \le 4
>    $$
> 4. We divide by $2$:
>    $$
>    1 \le x \le 2
>    $$
> 5. Therefore, the domain of the function is:
>    $$
>    D(f) = [1, 2]
>    $$

### Exercise 7: Computing a Composite Trigonometric Expression
**Problem:**
> **[Supplementary]**
> Compute the exact value of the expression:
> $$
> B = \sin\left(\cos^{-1}\left(\frac{3}{5}\right) + \tan^{-1}(2)\right)
> $$

**Solution:**
> **[Supplementary]**
> 1. We set $u = \cos^{-1}(3/5)$ and $v = \tan^{-1}(2)$. So $\cos(u) = 3/5$ with $u \in [0, \pi]$ and $\tan(v) = 2$ with $v \in (0, \pi/2)$.
> 2. We draw two reference right triangles:
>    - For $u$: Hypotenuse = $5$, Adjacent = $3$. By Pythagoras, Opposite = $\sqrt{5^2 - 3^2} = 4$.
>      So, $\sin(u) = 4/5$.
>    - For $v$: Opposite = $2$, Adjacent = $1$. Hypotenuse = $\sqrt{2^2 + 1^2} = \sqrt{5}$.
>      So, $\sin(v) = 2/\sqrt{5}$ and $\cos(v) = 1/\sqrt{5}$.
> 3. We use the sine addition formula:
>    $$
>    \sin(u + v) = \sin(u)\cos(v) + \cos(u)\sin(v)
>    $$
> 4. We substitute the values:
>    $$
>    \sin(u + v) = \left(\frac{4}{5}\right)\left(\frac{1}{\sqrt{5}}\right) + \left(\frac{3}{5}\right)\left(\frac{2}{\sqrt{5}}\right) = \frac{4}{5\sqrt{5}} + \frac{6}{5\sqrt{5}} = \frac{10}{5\sqrt{5}} = \frac{2}{\sqrt{5}} = \frac{2\sqrt{5}}{5}
>    $$
> 5. The required value is:
>    $$
>    B = \frac{2\sqrt{5}}{5}
>    $$

### Exercise 8: Plotting the Arctangent in Octave
**Problem:**
> **[Supplementary]**
> Write Octave code to plot $y = \tan^{-1}(x)$ on the interval $[-5, 5]$, adding the horizontal asymptotes $y = \pm \pi/2$.

**Solution:**
> **[Supplementary]**
```octave
% Define x
x = -5:0.1:5;
y = atan(x);

% Plot the function
figure;
plot(x, y, 'b-', 'LineWidth', 2); hold on;

% Plot the asymptotes
plot([-5, 5], [pi/2, pi/2], 'r--', 'LineWidth', 1);
plot([-5, 5], [-pi/2, -pi/2], 'r--', 'LineWidth', 1);
hold off;

% Settings
grid on;
xlabel('x');
ylabel('y = arctan(x)');
title('Graph of Inverse Tangent Function with Asymptotes');
ylim([-2, 2]);
```

## Exam Tip: Be Careful with the Cancellation Relation

One of the most common mistakes in exams is applying the relation $\sin^{-1}(\sin(x)) = x$ without verification.
Remember: This relation holds **only** if $x$ is in the interval $[-\frac{\pi}{2}, \frac{\pi}{2}]$.
- If you are asked for $\sin^{-1}(\sin(3\pi/4))$, the answer is **not** $\frac{3\pi}{4}$ (since $\frac{3\pi}{4} > \frac{\pi}{2}$).
- You must convert the angle using the properties of trigonometric numbers: $\sin(3\pi/4) = \sin(\pi - \pi/4) = \sin(\pi/4)$.
- Then $\sin^{-1}(\sin(\pi/4)) = \frac{\pi}{4}$ because $\frac{\pi}{4}$ belongs to $[-\frac{\pi}{2}, \frac{\pi}{2}]$.
