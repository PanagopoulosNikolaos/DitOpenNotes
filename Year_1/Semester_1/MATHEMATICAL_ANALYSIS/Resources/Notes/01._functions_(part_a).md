# Functions (Part A)

An introduction to real functions of a real variable, the definition of the domain and range, the graphical representation, the identification of basic categories of functions, and the drawing of graphs using the Octave/Matlab software.

## 1. Definition and Basic Concepts

A real function of a real variable is a mapping from a set of values to another, where both the input and the output belong to the set of real numbers $\mathbb{R}$.

### Mathematical Definition of a Function
Let $X$ and $Y$ be two non-empty sets of real numbers. A function $f$ from $X$ to $Y$ is a rule (or relation) that maps each element $x \in X$ to exactly one element $y \in Y$.
We write:
$$
y = f(x)
$$
Where:
- $x$: the independent variable (input)
- $y$: the dependent variable (output)
- $f: A \to B$ denotes that the function has domain the set $A$ and range a subset of $B$.

### Domain
The domain of a function $f$, denoted by $D(f)$ or $A$, is the set of all real numbers $x$ for which the expression $f(x)$ is defined and yields a real number.
- For rational functions $\frac{P(x)}{Q(x)}$, it is required that $Q(x) \neq 0$.
- For even-order roots $\sqrt[2k]{g(x)}$, it is required that $g(x) \ge 0$.
- For logarithmic functions $\log_a(g(x))$, it is required that $g(x) > 0$.

### Range
The range (or codomain) of a function $f$, denoted by $R(f)$ or $f(A)$, is the set of all values $f(x)$ that the function takes as $x$ traverses the entire domain:
$$
R(f) = \{y \in Y \mid \exists x \in X \text{ such that } f(x) = y\}
$$

## 2. Graphical Representation and Vertical Line Test

The visualization of a function is achieved through its graphical representation on the Cartesian plane.

### Graph (Graphical Representation)
The graphical representation of a function $f$ is the set of all points $(x, y)$ of the plane for which $y = f(x)$ and $x \in D(f)$:
$$
G(f) = \{(x, f(x)) \mid x \in D(f)\}
$$

### Vertical Line Test
A curve in the Cartesian plane $xy$ is the graph of a function if and only if no vertical line intersects the curve at more than one point.
- If a vertical line intersects the curve at two or more points, then the same input value $x$ would correspond to multiple outputs $y$, which contradicts the definition of a function.
- If for a value $x_0$, the vertical line $x = x_0$ does not intersect the graph at all, then $x_0$ does not belong to the domain $D(f)$.

## 3. Characteristic Functions

There are certain basic functions that serve as building blocks for more complex expressions:

| Function Name | Formula | Domain | Range |
| :--- | :--- | :--- | :--- |
| Constant | $f(x) = k$ | $\mathbb{R}$ | $\{k\}$ |
| Identity | $f(x) = x$ | $\mathbb{R}$ | $\mathbb{R}$ |
| Power ($n$ positive even) | $f(x) = x^n$ | $\mathbb{R}$ | $[0, \infty)$ |
| Power ($n$ positive odd) | $f(x) = x^n$ | $\mathbb{R}$ | $\mathbb{R}$ |
| Square Root | $f(x) = \sqrt{x}$ | $[0, \infty)$ | $[0, \infty)$ |
| Cube Root | $f(x) = \sqrt[3]{x}$ | $\mathbb{R}$ | $\mathbb{R}$ |
| Reciprocal Power | $f(x) = \frac{1}{x^n}$ ($n$ odd) | $\mathbb{R} \setminus \{0\}$ | $\mathbb{R} \setminus \{0\}$ |
| Reciprocal Power | $f(x) = \frac{1}{x^n}$ ($n$ even) | $\mathbb{R} \setminus \{0\}$ | $(0, \infty)$ |

## 4. Graphs in Octave/Matlab

In Octave/Matlab, two-dimensional graphs are drawn using the `plot` command.

### The `plot` Command
The `plot` command accepts as arguments two vectors of equal length containing the $x$ and $y$ coordinates of the points.

**Parameter Table for the `plot` Command:**

| Parameter | Type | Required | Default | Description |
| :--- | :--- | :--- | :--- | :--- |
| `x` | Vector | Yes | — | The horizontal axis coordinates |
| `y` | Vector | Yes | — | The vertical axis coordinates |
| `style` | String | No | `'-'` (continuous line) | Specifies the color and style of the line/points (e.g. `'r--'`, `'g*'`) |

**Code Example:**
```octave
x = -10:0.1:10;
y = x.^2 + 1;
plot(x, y, 'b-', 'LineWidth', 2);
grid on;
xlabel('x');
ylabel('y');
title('Graph of f(x) = x^2 + 1');
```

## Solved Exercises

### Exercise 1: Finding the Domain of a Rational Function
**Problem:**
Find the domain of the function:
$$
f(x) = \frac{x^2 - 1}{x^2 - 4}
$$

**Solution:**
1. The function is rational, therefore it is defined for all values of $x$ except those that make the denominator zero.
2. We set the denominator equal to zero:
   $$
   x^2 - 4 = 0 \implies x^2 = 4 \implies x = 2 \quad \text{or} \quad x = -2
   $$
3. Therefore, the domain is all real numbers except $-2$ and $2$.
4. In set notation:
   $$
   D(f) = \mathbb{R} \setminus \{-2, 2\} = (-\infty, -2) \cup (-2, 2) \cup (2, \infty)
   $$

### Exercise 2: Finding the Domain with a Radical
**Problem:**
Find the domain of the function:
$$
f(x) = \sqrt{2x - 6}
$$

**Solution:**
1. The function contains a square root (even-order), so the radicand must be non-negative.
2. We solve the inequality:
   $$
   2x - 6 \ge 0 \implies 2x \ge 6 \implies x \ge 3
   $$
3. Consequently, the domain of the function is:
   $$
   D(f) = [3, \infty)
   $$

### Exercise 3: Domain and Range of a Polynomial
**Problem:**
Find the domain and range of the function:
$$
f(x) = x^2 + 1
$$

**Solution:**
1. The function is polynomial, so it is defined for every real number $x$. Therefore:
   $$
   D(f) = \mathbb{R}
   $$
2. To find the range, we observe that for every $x \in \mathbb{R}$:
   $$
   x^2 \ge 0
   $$
3. Adding $1$ to both sides of the inequality:
   $$
   x^2 + 1 \ge 1 \implies f(x) \ge 1
   $$
4. As $x$ tends to infinity, $f(x)$ increases without bound. Therefore the range is:
   $$
   R(f) = [1, \infty)
   $$

### Exercise 4: Real-World Projectile Problem
**Problem:**
At time $t = 0$ a stone is thrown vertically upward with a velocity of $30\text{ m/sec}$. Its height above the ground in meters is given by $h(t) = 30t - 5t^2$. Find the domain and range of $h$.

**Solution:**
1. Although the mathematical expression $h(t) = 30t - 5t^2$ is defined for every $t \in \mathbb{R}$, in the physical problem the height $h(t)$ must be non-negative ($h(t) \ge 0$) starting from the time $t = 0$.
2. We solve the equation $h(t) = 0$ to find when the stone returns to the ground:
   $$
   30t - 5t^2 = 0 \implies 5t(6 - t) = 0
   $$
   The solutions are $t = 0$ (start) and $t = 6$ (impact).
3. Therefore, the natural time of motion is the interval $[0, 6]$. The domain is:
   $$
   D(h) = [0, 6]
   $$
4. The maximum value of the quadratic function occurs at the vertex of the parabola, which by symmetry is at the midpoint of the interval, i.e. at $t = 3$ (or via the derivative $h'(t) = 30 - 10t = 0 \implies t = 3$).
5. We compute the maximum height:
   $$
   h(3) = 30(3) - 5(3^2) = 90 - 45 = 45\text{ m}
   $$
6. Since the minimum height is $0$, the range is:
   $$
   R(h) = [0, 45]
   $$

### Exercise 5: Complex Domain with Logarithm and Radical
**Problem:**
> **[Supplementary]**
> Find the domain of the function:
> $$
> f(x) = \ln(x - 2) + \frac{1}{\sqrt{5 - x}}
> $$

**Solution:**
> **[Supplementary]**
> For the function to be defined, the following restrictions must be simultaneously satisfied:
> 1. The logarithm $\ln(x - 2)$ requires:
>    $$
>    x - 2 > 0 \implies x > 2
>    $$
> 2. The square root in the denominator $\frac{1}{\sqrt{5 - x}}$ requires the radicand to be strictly positive (since the denominator cannot be zero):
>    $$
>    5 - x > 0 \implies x < 5
>    $$
> 3. We combine the two inequalities:
>    $$
>    2 < x < 5
>    $$
> 4. Therefore, the domain is:
>    $$
>    D(f) = (2, 5)
>    $$

### Exercise 6: Finding the Range by Solving for x
**Problem:**
> **[Supplementary]**
> Find the range of the function:
> $$
> f(x) = \frac{x}{1 + x^2}
> $$

**Solution:**
> **[Supplementary]**
> 1. The domain of $f$ is $D(f) = \mathbb{R}$, since the denominator $1 + x^2$ is always positive.
> 2. We set $y = f(x)$ and solve for $x$:
>    $$
>    y = \frac{x}{1 + x^2} \implies y(1 + x^2) = x \implies yx^2 - x + y = 0
>    $$
> 3. If $y = 0$, then $x = 0$, so $0$ belongs to the range.
> 4. If $y \neq 0$, the equation is quadratic in $x$. For $x$ to have real solutions, the discriminant $\Delta$ must be non-negative:
>    $$
>    \Delta = (-1)^2 - 4(y)(y) \ge 0 \implies 1 - 4y^2 \ge 0 \implies 4y^2 \le 1 \implies y^2 \le \frac{1}{4}
>    $$
>    $$
>    -\frac{1}{2} \le y \le \frac{1}{2}
>    $$
> 5. Consequently, the range is:
>    $$
>    R(f) = \left[-\frac{1}{2}, \frac{1}{2}\right]
>    $$

### Exercise 7: Domain with Logarithm in a Radical
**Problem:**
> **[Supplementary]**
> Determine the domain of the function:
> $$
> f(x) = \sqrt{1 - \log_{10}(x)}
> $$

**Solution:**
> **[Supplementary]**
> 1. For the logarithm $\log_{10}(x)$ to be defined, we require:
>    $$
>    x > 0
>    $$
> 2. For the square root to be defined, the radicand must be non-negative:
>    $$
>    1 - \log_{10}(x) \ge 0 \implies \log_{10}(x) \le 1
>    $$
> 3. Since the base is $10 > 1$, the logarithmic function is strictly increasing, so:
>    $$
>    x \le 10^1 \implies x \le 10
>    $$
> 4. Combining the restrictions $x > 0$ and $x \le 10$, we obtain:
>    $$
>    D(f) = (0, 10]
>    $$

### Exercise 8: Graphing with Octave
**Problem:**
> **[Supplementary]**
> Write Octave code to plot the function $f(x) = \sin(x)$ on the interval $[0, 2\pi]$ with step $0.05$, adding a grid, title, and axis labels.

**Solution:**
> **[Supplementary]**
> The required Octave code is as follows:
```octave
% Definition of the input interval x
x = 0:0.05:2*pi;

% Computation of y = sin(x)
y = sin(x);

% Plot with green continuous line
plot(x, y, 'g-', 'LineWidth', 1.5);

% Adding grid and labels
grid on;
xlabel('x (radians)');
ylabel('y = sin(x)');
title('Plot of Sine Function over [0, 2\pi]');
```

## Exam Tip: Systematic Domain Finding

In exams, finding the domain of a composite function requires creating a system of inequalities. Always check the three "red flags":
1. **Fractions:** Denominator $\neq 0$.
2. **Even-order roots:** Radicand $\ge 0$.
3. **Logarithms:** Argument $> 0$.
Solve each inequality separately and find the intersection (conjunction) of the individual intervals using a real number line to avoid errors.
