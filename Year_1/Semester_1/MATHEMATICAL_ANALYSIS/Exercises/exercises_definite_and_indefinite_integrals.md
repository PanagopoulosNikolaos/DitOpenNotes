# Ασκήσεις Εξάσκησης: Αόριστα και Ορισμένα Ολοκληρώματα

## Άσκηση 1: Ολοκλήρωση κατά Παράγοντες

### Εκφώνηση
Υπολογίστε το αόριστο ολοκλήρωμα:
$$I = \int x^2 e^{2x}\,dx$$

### Λύση
Θέτουμε:
* $u = x^2 \implies du = 2x\,dx$
* $dv = e^{2x}\,dx \implies v = \frac{1}{2} e^{2x}$

Εφαρμόζοντας τον τύπο $\int u\,dv = uv - \int v\,du$:
$$I = \frac{1}{2} x^2 e^{2x} - \int x e^{2x}\,dx$$
Για το νέο ολοκλήρωμα $\int x e^{2x}\,dx$, εφαρμόζουμε ξανά παραγοντική ολοκλήρωση:
* $u_1 = x \implies du_1 = dx$
* $dv_1 = e^{2x}\,dx \implies v_1 = \frac{1}{2} e^{2x}$
$$\int x e^{2x}\,dx = \frac{1}{2} x e^{2x} - \int \frac{1}{2} e^{2x}\,dx = \frac{1}{2} x e^{2x} - \frac{1}{4} e^{2x}$$

Συνδυάζοντας τα αποτελέσματα:
$$I = \frac{1}{2} x^2 e^{2x} - \frac{1}{2} x e^{2x} + \frac{1}{4} e^{2x} + C = e^{2x} \left( \frac{x^2}{2} - \frac{x}{2} + \frac{1}{4} \right) + C$$

## Άσκηση 2: Εμβαδόν μεταξύ Καμπυλών

### Εκφώνηση
Υπολογίστε το εμβαδόν του χωρίου που περικλείεται από τις καμπύλες $y = x^2$ και $y = 2x - x^2$.

### Λύση
1. **Σημεία Τομής:**
   $$x^2 = 2x - x^2 \iff 2x^2 - 2x = 0 \iff 2x(x - 1) = 0 \implies x_1 = 0, \; x_2 = 1$$
2. **Σύγκριση Συναρτήσεων:**
   Στο διάστημα $[0, 1]$, ισχύει $2x - x^2 \ge x^2$.
3. **Υπολογισμός Εμβαδού:**
   $$A = \int_0^1 \left( (2x - x^2) - x^2 \right)\,dx = \int_0^1 (2x - 2x^2)\,dx = \left[ x^2 - \frac{2x^3}{3} \right]_0^1 = 1 - \frac{2}{3} = \frac{1}{3}$$
