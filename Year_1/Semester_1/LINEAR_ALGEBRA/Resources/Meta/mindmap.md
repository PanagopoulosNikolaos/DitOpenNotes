## 2. Άλγεβρα Πινάκων (Ενότητα 02)



### 2.1 Ορισμός και Είδη Πινάκων
- 2.1.1 Πίνακας m×n
- 2.1.2 Τετραγωνικοί, διαγώνιοι, άνω/κάτω τριγωνικοί
- 2.1.3 Μηδενικός πίνακας, μοναδιαίος I
- 2.1.4 Συμμετρικός: A = Aᵀ, αντισυμμετρικός: A = -Aᵀ

### 2.2 Πράξεις Πινάκων
- 2.2.1 Πρόσθεση και αφαίρεση
- 2.2.2 Πολλαπλασιασμός με βαθμωτό
- 2.2.3 Πολλαπλασιασμός πινάκων: (AB)ᵢⱼ = ΣAᵢₖBₖⱼ
- 2.2.4 Μη αντιμεταθετικότητα: AB ≠ BA

### 2.3 Ανάστροφος Πίνακας
- 2.3.1 Ορισμός: (Aᵀ)ᵢⱼ = Aⱼᵢ
- 2.3.2 Ιδιότητες: (AB)ᵀ = BᵀAᵀ

### 2.4 Αντίστροφος Πίνακας
- 2.4.1 Ορισμός: AA⁻¹ = A⁻¹A = I
- 2.4.2 Ύπαρξη: iff det(A) ≠ 0
- 2.4.3 Τύπος 2×2: A⁻¹ = (1/det)·[d, -b; -c, a]
- 2.4.4 Εύρεση με Gauss-Jordan: [A|I] → [I|A⁻¹]
- 2.4.5 Ιδιότητες: (AB)⁻¹ = B⁻¹A⁻¹

### 2.5 Στοιχειώδεις Πίνακες
- 2.5.1 Αναπαράσταση row operations ως πολλαπλασιασμός
- 2.5.2 Παραγοντοποίηση A = LU (LU decomposition)

## 3. Ορίζουσες (Ενότητα 03)



### 3.1 Ορισμός Ορίζουσας
- 3.1.1 det(A) για τετραγωνικούς πίνακες
- 3.1.2 Ορίζουσα 2×2: ad - bc
- 3.1.3 Ανάπτυγμα κατά Laplace (cofactor expansion)

### 3.2 Ιδιότητες Οριζουσών
- 3.2.1 det(AB) = det(A)·det(B)
- 3.2.2 det(Aᵀ) = det(A)
- 3.2.3 det(A⁻¹) = 1/det(A)
- 3.2.4 Εναλλαγή γραμμών: αλλαγή πρόσημου
- 3.2.5 Γραμμή μηδενικών → det = 0

### 3.3 Κανόνας Cramer
- 3.3.1 xᵢ = det(Aᵢ)/det(A)
- 3.3.2 Πρακτική χρήση μόνο για μικρά συστήματα

### 3.4 Συμπληρωματικοί Πίνακες (Adjugate)
- 3.4.1 A⁻¹ = adj(A)/det(A)
- 3.4.2 Cofactors Cᵢⱼ = (-1)^(i+j) Mᵢⱼ

## 4. Ευκλείδιοι Διανυσματικοί Χώροι (Ενότητα 04)



### 4.1 Διανύσματα στον ℝⁿ
- 4.1.1 Πρόσθεση και βαθμωτός πολλαπλασιασμός
- 4.1.2 Νόρμα (μέτρο): ‖v‖ = √(v₁² + v₂² + ...)
- 4.1.3 Μοναδιαίο διάνυσμα: ‖v‖ = 1

### 4.2 Εσωτερικό Γινόμενο (Dot Product)
- 4.2.1 u·v = Σuᵢvᵢ = ‖u‖‖v‖cos(θ)
- 4.2.2 Ορθογωνιότητα: u·v = 0
- 4.2.3 Προβολή: proj_v(u) = (u·v/‖v‖²)·v

### 4.3 Γινόμενο Σταυρού (Cross Product, ℝ³)
- 4.3.1 u×v ⊥ u, u×v ⊥ v
- 4.3.2 ‖u×v‖ = ‖u‖‖v‖sin(θ)
- 4.3.3 Εφαρμογές: εμβαδόν παραλληλογράμμου, κανονικό επιπέδου

### 4.4 Γραμμικοί Μετασχηματισμοί ℝⁿ → ℝᵐ
- 4.4.1 Ορισμός: T(u+v) = T(u)+T(v), T(cu) = cT(u)
- 4.4.2 Πίνακας μετασχηματισμού A: T(x) = Ax
- 4.4.3 Kernel (πυρήνας) και Image (εικόνα)


***


## 5. Γενικοί Διανυσματικοί Χώροι (Ενότητα 05)



### 5.1 Αξιωματική Ορισμός
- 5.1.1 Κλειστότητα ως προς πρόσθεση και βαθμωτό πολ/σιασμό
- 5.1.2 10 αξιώματα διανυσματικού χώρου
- 5.1.3 Παραδείγματα: ℝⁿ, πολυώνυμα, πίνακες, συναρτήσεις

### 5.2 Υποχώροι
- 5.2.1 Συνθήκες: κλειστότητα + μηδενικό στοιχείο
- 5.2.2 Τετριμμένοι υποχώροι: {0} και V
- 5.2.3 Null space, column space, row space

### 5.3 Γραμμική Ανεξαρτησία
- 5.3.1 Ορισμός: c₁v₁ + ... + cₙvₙ = 0 → cᵢ = 0
- 5.3.2 Έλεγχος με ορίζουσα/rank
- 5.3.3 Σχέση με pivot columns

### 5.4 Βάση και Διάσταση
- 5.4.1 Βάση: γραμμικά ανεξάρτητο και παραγόν σύνολο
- 5.4.2 dim(V) = αριθμός στοιχείων βάσης
- 5.4.3 Τυπικές βάσεις: {e₁, ..., eₙ} για ℝⁿ
- 5.4.4 Θεώρημα βάσης: κάθε βάση έχει ίδιο πλήθος

### 5.5 Rank και Nullity
- 5.5.1 rank(A) = dim(column space)
- 5.5.2 nullity(A) = dim(null space)
- 5.5.3 Θεώρημα rank-nullity: rank + nullity = n
- 5.5.4 Row rank = column rank

### 5.6 Αλλαγή Βάσης
- 5.6.1 Πίνακας μετάβασης P
- 5.6.2 [v]_B = P⁻¹[v]_S
- 5.6.3 Εφαρμογή σε γραμμικούς μετασχηματισμούς

## 6. Γραμμικοί Μετασχηματισμοί (Ενότητα 06)



### 6.1 Ορισμός και Ιδιότητες
- 6.1.1 Γραμμικότητα, πρόσθεση και ομοιότητα
- 6.1.2 T(0) = 0

### 6.2 Πυρήνας και Εικόνα
- 6.2.1 Ker(T) = {v : T(v) = 0}
- 6.2.2 Im(T) = {T(v) : v ∈ V}
- 6.2.3 Θεώρημα πυρήνα-εικόνας: dim(Ker) + dim(Im) = dim(V)

### 6.3 Ισομορφισμός
- 6.3.1 1-1 (injective): Ker(T) = {0}
- 6.3.2 Onto (surjective): Im(T) = W
- 6.3.3 Ισομορφισμός: bijective + linear

### 6.4 Αναπαράσταση ως Πίνακας
- 6.4.1 [T]_B,C: πίνακας μετασχηματισμού ως προς βάσεις B, C
- 6.4.2 Ομοιότητα πινάκων: B = P⁻¹AP
- 6.4.3 Αλλαγή βάσης στον μετασχηματισμό

### 6.5 Σύνθεση Μετασχηματισμών
- 6.5.1 (S∘T)(v) = S(T(v))
- 6.5.2 [S∘T] = [S][T]

### 6.6 Γεωμετρικοί Μετασχηματισμοί
- 6.6.1 Στροφή, ανάκλαση, διάτμηση, ορθογώνια προβολή
- 6.6.2 Πίνακες στροφής: [cos θ, -sin θ; sin θ, cos θ]


***


## 7. Ορθογωνιότητα (Ενότητα 07)



### 7.1 Ορθογώνια Σύνολα και Βάσεις
- 7.1.1 Ορθογώνιο σύνολο: uᵢ·uⱼ = 0 (i ≠ j)
- 7.1.2 Ορθοκανονική βάση: ορθογώνια + μοναδιαία
- 7.1.3 Ανάπτυγμα Fourier: v = Σ(v·uᵢ/‖uᵢ‖²)uᵢ

### 7.2 Διαδικασία Gram-Schmidt
- 7.2.1 Μετατροπή οποιασδήποτε βάσης σε ορθοκανονική
- 7.2.2 v₁ = u₁, v₂ = u₂ - proj_{v₁}(u₂), ...
- 7.2.3 QR παραγοντοποίηση: A = QR

### 7.3 Ορθογώνιοι Πίνακες
- 7.3.1 QᵀQ = I ↔ Q⁻¹ = Qᵀ
- 7.3.2 Διατήρηση νόρμας και γωνίας
- 7.3.3 det(Q) = ±1

### 7.4 Ορθογώνια Προβολή
- 7.4.1 Προβολή στον υποχώρο W
- 7.4.2 Αποσύνθεση: v = proj_W(v) + (v - proj_W(v))
- 7.4.3 Πίνακας προβολής: P = A(AᵀA)⁻¹Aᵀ

### 7.5 Ελάχιστα Τετράγωνα (Least Squares)
- 7.5.1 Επίλυση υπερορισμένων συστημάτων (m > n)
- 7.5.2 Κανονικές εξισώσεις: AᵀAx = Aᵀb
- 7.5.3 Εφαρμογές: γραμμική παλινδρόμηση, προσαρμογή καμπύλης


***


## 8. Ιδιοτιμές και Ιδιοδιανύσματα (Ενότητα 08)



### 8.1 Ορισμός
- 8.1.1 Av = λv, v ≠ 0
- 8.1.2 Ιδιοτιμή λ (eigenvalue), ιδιοδιάνυσμα v (eigenvector)
- 8.1.3 Χαρακτηριστική εξίσωση: det(A - λI) = 0

### 8.2 Εύρεση Ιδιοτιμών και Ιδιοδιανυσμάτων
- 8.2.1 Χαρακτηριστικό πολυώνυμο p(λ) = det(A - λI)
- 8.2.2 Ιδιοχώρος Eλ = Ker(A - λI)
- 8.2.3 Γεωμετρική vs αλγεβρική πολλαπλότητα

### 8.3 Ιδιότητες
- 8.3.1 Ίχνος (trace): Σλᵢ = tr(A)
- 8.3.2 det(A) = Πλᵢ
- 8.3.3 Ιδιοτιμές τριγωνικού πίνακα: στοιχεία διαγωνίου
- 8.3.4 Συμμετρικοί πίνακες: πάντα πραγματικές ιδιοτιμές

### 8.4 Διαγωνοποίηση
- 8.4.1 A = PDP⁻¹ (D: διαγώνιος, P: ιδιοδιανύσματα)
- 8.4.2 Συνθήκη: n γραμμικά ανεξάρτητα ιδιοδιανύσματα
- 8.4.3 Aⁿ = PDⁿP⁻¹
- 8.4.4 Αποτυχία διαγωνοποίησης: ελλιπείς ιδιοχώροι

### 8.5 Ορθογώνια Διαγωνοποίηση
- 8.5.1 Συμμετρικοί πίνακες: A = QDQᵀ
- 8.5.2 Θεώρημα φάσματος (Spectral theorem)
- 8.5.3 Εφαρμογή: τετραγωνικές μορφές


***


## 9. Παραγοντοποιήσεις Πινάκων (Ενότητα 09)



### 9.1 LU Παραγοντοποίηση
- 9.1.1 A = LU (L: κάτω τριγωνικός, U: άνω τριγωνικός)
- 9.1.2 Επίλυση Ax = b μέσω Ly = b, Ux = y
- 9.1.3 Μερική/πλήρης στροφή (pivoting)
- 9.1.4 PA = LU (με ανταλλαγή γραμμών)

### 9.2 QR Παραγοντοποίηση
- 9.2.1 A = QR (Q: ορθογώνιος, R: άνω τριγωνικός)
- 9.2.2 Εφαρμογή σε ελάχιστα τετράγωνα
- 9.2.3 QR αλγόριθμος για ιδιοτιμές

### 9.3 SVD (Ανάλυση Ιδιάζουσων Τιμών)
- 9.3.1 A = UΣVᵀ
- 9.3.2 Ιδιάζουσες τιμές σᵢ = √λᵢ(AᵀA)
- 9.3.3 Pseudo-inverse: A⁺ = VΣ⁺Uᵀ
- 9.3.4 Εφαρμογές: συμπίεση εικόνας, PCA, rank-k προσέγγιση
  - 9.3.4.1 Best rank-k approximation
  - 9.3.4.2 Noise reduction

### 9.4 Cholesky Παραγοντοποίηση
- 9.4.1 A = LLᵀ (για θετικά ορισμένους πίνακες)
- 9.4.2 Αποδοτικότερη από LU για συμμετρικούς

## 10. Τετραγωνικές Μορφές και Θετικά Ορισμένοι Πίνακες (Ενότητα 10)



### 10.1 Τετραγωνικές Μορφές
- 10.1.1 Q(x) = xᵀAx (A συμμετρικός)
- 10.1.2 Κανονική μορφή: Q = λ₁y₁² + ... + λₙyₙ²
- 10.1.3 Ταξινόμηση: θετικά ορισμένη, αρνητικά ορισμένη, αόριστη

### 10.2 Θετικά Ορισμένοι Πίνακες
- 10.2.1 Ορισμός: xᵀAx > 0 για κάθε x ≠ 0
- 10.2.2 Κριτήρια Sylvester: leading principal minors > 0
- 10.2.3 Ισοδύναμα: όλες οι ιδιοτιμές > 0
- 10.2.4 Εφαρμογές: βελτιστοποίηση, covariance matrices

### 10.3 Θεώρημα Φάσματος
- 10.3.1 Κάθε πραγματικός συμμετρικός πίνακας ορθογώνια διαγωνοποιείται
- 10.3.2 Ιδιοδιανύσματα διαφορετικών ιδιοτιμών: κάθετα

### 11.1 Γραφήματα και Δίκτυα
- 11.1.1 Πίνακας γειτνίασης (adjacency matrix)
- 11.1.2 Laplacian matrix
- 11.1.3 Επίλυση δικτύων ρεύματος (Kirchhoff)

## 12. Σύνοψη Μαθήματος (Ενότητα 12)



### 12.1 Κεντρικές Ιδέες
- 12.1.1 Γραμμικά συστήματα ↔ πίνακες ↔ γεωμετρία
- 12.1.2 Rank-nullity ως θεμελιώδης σχέση
- 12.1.3 Ιδιοτιμές ως "DNA" τετραγωνικού πίνακα

### 12.2 Βασικοί Τύποι
- 12.2.1 det(A - λI) = 0 → ιδιοτιμές
- 12.2.2 rank(A) + nullity(A) = n
- 12.2.3 A = QDQᵀ (συμμετρικοί), A = UΣVᵀ (γενικοί)
- 12.2.4 Least squares: AᵀAx̂ = Aᵀb

### 12.3 Συνδέσεις Θεμάτων
- 12.3.1 Gauss → rank → βάσεις → ιδιοτιμές
- 12.3.2 Gram-Schmidt → QR → SVD
- 12.3.3 Διαγωνοποίηση → τετραγωνικές μορφές → βελτιστοποίηση
