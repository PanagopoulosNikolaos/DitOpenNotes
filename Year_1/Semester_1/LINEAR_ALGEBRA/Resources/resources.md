# Recommended Resources: Linear Algebra

This document compiles authoritative textbooks, computational software packages, interactive visualizers, and online courses for linear algebra.

---

## 1. Textbooks and Reference Manuals

* **Linear Algebra and Its Applications (5th Edition)**  
  *Authors:* David C. Lay, Steven R. Lay, Judi J. McDonald  
  *Description:* The primary undergraduate textbook for the course, balancing theoretical proofs with geometric visualizations and modern real-world applications.

* **Introduction to Linear Algebra (5th Edition)**  
  *Author:* Gilbert Strang (MIT)  
  *Description:* Renowned textbook focusing on the four fundamental subspaces, matrix factorizations ($LU, QR, SVD$), and computational problem-solving.

* **Linear Algebra Done Right (3rd Edition)**  
  *Author:* Sheldon Axler  
  *Description:* Pure mathematical treatment emphasizing coordinate-free linear operators, invariant subspaces, and the Spectral Theorem.

---

## 2. Computational Software & Environments

* **GNU Octave**  
  *Website:* [https://octave.org/](https://octave.org/)  
  *Description:* High-level mathematical programming language featuring native matrix syntax, $LU/QR$ matrix factorizations, and interactive 2D/3D plotting.

* **NumPy & SciPy (Python Scientific Stack)**  
  *Documentation:* [https://numpy.org/doc/stable/reference/routines.linalg.html](https://numpy.org/doc/stable/reference/routines.linalg.html)  
  *Description:* Python numerical linear algebra library (`np.linalg`) wrapping LAPACK and BLAS for matrix operations.

* **3Blue1Brown: Essence of Linear Algebra**  
  *Website:* [https://www.3blue1brown.com/topics/linear-algebra](https://www.3blue1brown.com/topics/linear-algebra)  
  *Description:* Visual animated geometric explanations of vector spaces, linear transformations, determinants, dot products, and eigenvalues.

---

## 3. Academic Video Lecture Archives

* **MIT 18.06: Linear Algebra (Prof. Gilbert Strang)**  
  *Platform:* MIT OpenCourseWare  
  *Description:* Complete 35-lecture video course covering matrix elimination, orthogonality, determinants, eigenvalues, and positive definite matrices.
