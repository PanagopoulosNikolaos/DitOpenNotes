# Σύνοψη Μαθήματος

Αυτή η σύνοψη ενοποιεί τις κεντρικές ιδέες της γραμμικής άλγεβρας σε ένα συνοχή πλαίσιο, συνδέοντας τις βασικές έννοιες των γραμμικών συστημάτων, των διανυσματικών χώρων, των ιδιοτιμών και των παραγοντοποιήσεων πινάκων. Οι θεμελιώδεις σχέσεις --- η απαλοιφή Gauss που συνδέεται με την τάξη, η τάξη που συνδέεται με τις βάσεις, η διαγωνοποίηση που συνδέεται με τις ιδιοτιμές και οι παραγοντοποιήσεις που συνδέονται με τις εφαρμογές --- αποτελούν τη ραχοκοκαλιά του αντικειμένου. Αυτή η ενότητα ανακεφαλαιώνει τους απαραίτητους τύπους και τις θεματικές συνδέσεις που εμφανίζονται σε όλο το μάθημα.

---

## 1. Κεντρικές Ιδέες

### 1.1 Η Ενοποιημένη Θεώρηση

Η γραμμική άλγεβρα περιστρέφεται γύρω από μία και μοναδική εξίσωση:

$$
A\mathbf{x} = \mathbf{b}
$$

Αυτή η εξίσωση αντιπροσωπεύει:
- Ένα σύστημα γραμμικών εξισώσεων (Κεφάλαιο 1)
- Έναν μετασχηματισμό πίνακα (Κεφάλαια 4, 6)
- Ένα πρόβλημα προσαρμογής δεδομένων μέσω ελαχίστων τετραγώνων (Κεφάλαιο 7)
- Ένα διαφορικό σύστημα μέσω της εξίσωσης $d\mathbf{x}/dt = A\mathbf{x}$ (Κεφάλαιο 11)

### 1.2 Το Θεώρημα Rank-Nullity ως Κεντρικό Θεώρημα

Το θεώρημα rank-nullity $\text{rank}(A) + \text{nullity}(A) = n$ συνδέει:
- Το πλήθος των στηλών με pivots (τάξη) με το πλήθος των ελεύθερων μεταβλητών (μηδενικότητα)
- Τη διάσταση της εικόνας με τη διάσταση του πυρήνα ενός γραμμικού μετασχηματισμού
- Τη διάσταση του χώρου στηλών με τη διάσταση του μηδενοχώρου (πυρήνα)

### 1.3 Οι Ιδιοτιμές ως το "DNA" ενός Πίνακα

Για έναν τετραγωνικό πίνακα $A$, οι ιδιοτιμές $\lambda_i$ και τα ιδιοδιανύσματα $\mathbf{v}_i$ ικανοποιούν τη σχέση $A\mathbf{v}_i = \lambda_i \mathbf{v}_i$. Κωδικοποιούν:
- Το ίχνος: $\sum \lambda_i = \text{tr}(A)$
- Την ορίζουσα: $\prod \lambda_i = \det(A)$
- Τη διαγωνοποιησιμότητα: ύπαρξη $n$ ανεξάρτητων ιδιοδιανυσμάτων
- Την ευστάθεια: το πρόσημο του πραγματικού μέρους καθορίζει τη μακροπρόθεσμη συμπεριφορά

## 2. Βασικοί Τύποι

### 2.1 Γραμμικά Συστήματα και Πίνακες

| Έννοια | Τύπος |
| :--- | :--- |
| Γραμμικό σύστημα | $A\mathbf{x} = \mathbf{b}$ |
| Απαλοιφή Gauss | $[A \mid \mathbf{b}] \to \text{REF} \to \text{RREF}$ |
| Πολλαπλασιασμός πινάκων | $(AB)_{ij} = \sum_k a_{ik} b_{kj}$ |
| Αντίστροφος (2x2) | $A^{-1} = \frac{1}{ad-bc}\begin{bmatrix} d & -b \\ -c & a \end{bmatrix}$ |

### 2.2 Ορίζουσες

| Έννοια | Τύπος |
| :--- | :--- |
| Ορίζουσα 2x2 | $\det(A) = ad - bc$ |
| Ανάπτυγμα Laplace | $\det(A) = \sum_j a_{ij}(-1)^{i+j}M_{ij}$ |
| Κανόνας γινομένου | $\det(AB) = \det(A)\det(B)$ |
| Κανόνας Cramer | $x_i = \det(A_i) / \det(A)$ |

### 2.3 Διανυσματικοί Χώροι

| Έννοια | Τύπος |
| :--- | :--- |
| Rank-nullity | $\text{rank}(A) + \text{nullity}(A) = n$ |
| Αλλαγή βάσης | $[\mathbf{v}]_C = P_{C \leftarrow B} [\mathbf{v}]_B$ |
| Εσωτερικό γινόμενο | $\mathbf{u} \cdot \mathbf{v} = \|\mathbf{u}\|\|\mathbf{v}\|\cos\theta$ |
| Προβολή | $\text{proj}_{\mathbf{v}}(\mathbf{u}) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{v}\|^2} \mathbf{v}$ |

### 2.4 Ορθογωνιότητα και Ελάχιστα Τετράγωνα

| Έννοια | Τύπος |
| :--- | :--- |
| Ορθογώνιος πίνακας | $Q^\mathsf{T} Q = I$, $Q^{-1} = Q^\mathsf{T}$ |
| Gram-Schmidt | $\mathbf{v}_k = \mathbf{a}_k - \sum_{i < k} \text{proj}_{\mathbf{v}_i}(\mathbf{a}_k)$ |
| Κανονικές εξισώσεις | $A^\mathsf{T} A \hat{\mathbf{x}} = A^\mathsf{T} \mathbf{b}$ |
| Πίνακας προβολής | $P = A(A^\mathsf{T} A)^{-1} A^\mathsf{T}$ |

### 2.5 Ιδιοτιμές

| Έννοια | Τύπος |
| :--- | :--- |
| Χαρακτηριστική εξίσωση | $\det(A - \lambda I) = 0$ |
| Διαγωνοποίηση | $A = PDP^{-1}$ |
| Φασματικό θεώρημα | $A = QDQ^\mathsf{T}$ (συμμετρικός $A$) |
| Δύναμη πίνακα | $A^k = PD^k P^{-1}$ |

### 2.6 Παραγοντοποιήσεις

| Παραγοντοποίηση | Μορφή | Εφαρμόζεται σε |
| :--- | :--- | :--- |
| LU | $A = LU$ | Τετραγωνικό αντιστρέψιμο |
| QR | $A = QR$ | Οποιονδήποτε πίνακα πλήρους τάξης στηλών |
| SVD | $A = U\Sigma V^\mathsf{T}$ | Οποιονδήποτε πίνακα |
| Cholesky | $A = LL^\mathsf{T}$ | Συμμετρικό θετικά ορισμένο |

## 3. Θεματικές Συνδέσεις

### 3.1 Από Gauss στις Ιδιοτιμές

Η ροή των ιδεών ακολουθεί μια σαφή διαδρομή:

$$
\text{Απαλοιφή Gauss} \to \text{Τάξη (Rank)} \to \text{Βάσεις} \to \text{Ιδιοτιμές}
$$

Η απαλοιφή Gauss παράγει τη μορφή REF, από την οποία διαβάζουμε την τάξη. Η τάξη καθορίζει τις διαστάσεις των θεμελιωδών υποχώρων. Οι βάσεις για αυτούς τους υποχώρους οδηγούν σε προβλήματα ιδιοτιμών για τετραγωνικούς πίνακες.

### 3.2 Από Gram-Schmidt στην SVD

$$
\text{Gram-Schmidt} \to \text{QR} \to \text{SVD}
$$

Η διαδικασία Gram-Schmidt ορθοκανονικοποιεί μια βάση, παράγοντας την παραγοντοποίηση QR. Ο αλγόριθμος QR τροφοδοτεί τον υπολογισμό ιδιοτιμών. Η SVD γενικεύει την αποσύνθεση ιδιοτιμών σε μη-τετραγωνικούς πίνακες.

### 3.3 Από τη Διαγωνοποίηση στη Βελτιστοποίηση

$$
\text{Διαγωνοποίηση} \to \text{Τετραγωνικές μορφές} \to \text{Βελτιστοποίηση}
$$

Η διαγωνοποίηση ενός συμμετρικού πίνακα αποκαλύπτει τη φύση της αντίστοιχης τετραγωνικής μορφής. Η θετική οριστικότητα (όλες οι ιδιοτιμές θετικές) προσδιορίζει τα τοπικά ελάχιστα σε προβλήματα βελτιστοποίησης του λογισμού πολλών μεταβλητών.

### 3.4 Από τη Θεωρία στις Εφαρμογές

| Θεωρητική Έννοια | Εφαρμογή |
| :--- | :--- |
| Ιδιοτιμές | PageRank, ευστάθεια ΣΔΕ |
| SVD | PCA, συμπίεση εικόνας, μείωση θορύβου |
| Ελάχιστα τετράγωνα | Γραμμική παλινδρόμηση, προσαρμογή δεδομένων |
| Παραγοντοποίηση LU | Επίλυση συστημάτων με πολλαπλά δεξιά μέλη |
| Laplacian γραφήματος | Ανάλυση δικτύων, φασματική συσταδοποίηση (spectral clustering) |

## 4. Βασικές Στρατηγικές Επίλυσης Προβλημάτων

### 4.1 Επίλυση Γραμμικών Συστημάτων
1. Σχηματίζουμε τον επαυξημένο πίνακα $[A \mid \mathbf{b}]$.
2. Κάνουμε αναγωγή σε REF (απαλοιφή Gauss) ή RREF (Gauss-Jordan).
3. Ελέγχουμε τη συμβατότητα: καμία γραμμή της μορφής $[0 \; \cdots \; 0 \mid c]$ με $c \neq 0$.
4. Προσδιορίζουμε τις βασικές και ελεύθερες μεταβλητές· γράφουμε τη παραμετρική λύση.

### 4.2 Εύρεση Βάσεων
- **Χώρος στηλών:** οι αρχικές στήλες που αντιστοιχούν στις στήλες pivots.
- **Μηδενοχώρος (Πυρήνας):** λύνουμε $A\mathbf{x} = \mathbf{0}$, εκφράζουμε τις βασικές μεταβλητές ως προς τις ελεύθερες.
- **Χώρος γραμμών:** οι μη-μηδενικές γραμμές της REF (ή οι αρχικές γραμμές που αντιστοιχούν σε στήλες pivots).

### 4.3 Έλεγχος Διαγωνοποιησιμότητας
1. Βρίσκουμε τις ιδιοτιμές λύνοντας την εξίσωση $\det(A - \lambda I) = 0$.
2. Για κάθε ιδιοτιμή $\lambda$, βρίσκουμε τη $\dim(E_\lambda) = \dim(\ker(A - \lambda I))$.
3. Αν η $\dim(E_\lambda)$ ισούται με την αλγεβρική πολλαπλότητα για όλα τα $\lambda$, ο $A$ είναι διαγωνοποιήσιμος.

### 4.4 Υπολογισμός Δυνάμεων Πίνακα
Αν ο $A$ είναι διαγωνοποιήσιμος, $A^k = P D^k P^{-1}$. Για μη-διαγωνοποιήσιμους πίνακες, χρησιμοποιούμε τη μορφή Jordan ή υπολογίζουμε απευθείας.

### 4.5 Επίλυση Ελαχίστων Τετραγώνων
1. Στήνουμε το $A\hat{\mathbf{x}} \approx \mathbf{b}$ με τον $A$ να περιέχει τις στήλες των χαρακτηριστικών.
2. Υπολογίζουμε τα $A^\mathsf{T} A$ και $A^\mathsf{T} \mathbf{b}$.
3. Λύνουμε τις κανονικές εξισώσεις $A^\mathsf{T} A \hat{\mathbf{x}} = A^\mathsf{T} \mathbf{b}$.

## 5. Συνηθισμένες Παγίδες

1. **Σειρά πολλαπλασιασμού πινάκων:** $AB \neq BA$ γενικά. Πάντα να επαληθεύετε ότι οι διαστάσεις συμφωνούν.
2. **Ύπαρξη αντιστρόφου:** $\det(A) = 0$ σημαίνει ότι ο $A^{-1}$ δεν υπάρχει. Μην επιχειρήσετε να τον υπολογίσετε.
3. **Χώρος στηλών vs. Χώρος γραμμών:** ο χώρος στηλών χρησιμοποιεί τις αρχικές στήλες του $A$ που αντιστοιχούν σε pivots· ο χώρος γραμμών χρησιμοποιεί τις γραμμές της REF.
4. **Ιδιοτιμές αθροισμάτων:** $\lambda_i(A + B) \neq \lambda_i(A) + \lambda_i(B)$ γενικά. Μόνο το ίχνος και η ορίζουσα έχουν απλούς τύπους.
5. **Κριτήριο Sylvester:** εφαρμόζεται μόνο σε συμμετρικούς πίνακες· δεν ανιχνεύει την ημιοριστικότητα.

## Συμβουλή Εξετάσεων: Η Συνολική Εικόνα

Σε μια εφ’ όλης της ύλης εξέταση, αναγνωρίστε ποια από τις τέσσερις κύριες πράξεις απαιτεί το πρόβλημα:

1. **Επίλυση συστήματος** $\to$ Απαλοιφή Gauss ή LU
2. **Εύρεση βάσης ή διάστασης** $\to$ REF, στήλες pivots, θεώρημα rank-nullity
3. **Διαγωνοποίηση ή υπολογισμός δυνάμεων** $\to$ Ιδιοτιμές, ιδιοδιανύσματα
4. **Προσέγγιση ή προσαρμογή δεδομένων** $\to$ Ελάχιστα τετράγωνα (κανονικές εξισώσεις) ή SVD

Τα περισσότερα προβλήματα αναγόνται σε μία από αυτές τις τέσσερις εργασίες. Η έγκαιρη αναγνώριση του μοτίβου εξοικονομεί χρόνο και μειώνει τα λάθη.
