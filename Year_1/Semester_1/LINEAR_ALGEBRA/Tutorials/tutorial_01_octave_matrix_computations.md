# Εργαστηριακός Οδηγός 1: Υπολογισμοί Πινάκων με το GNU Octave / MATLAB

## 1. Εισαγωγή στο Περιβάλλον GNU Octave

Το GNU Octave είναι γλώσσα υψηλού επιπέδου σχεδιασμένη κυρίως για αριθμητικούς υπολογισμούς και γραμμική άλγεβρα, πλήρως συμβατή με το MATLAB.

## 2. Ορισμός και Βασικές Πράξεις Πινάκων

```matlab
% Ορισμός πινάκων
A = [1, 2, 3; 4, 5, 6; 7, 8, 9];
B = [2, 0, -1; 1, 3, 2; 0, -1, 4];

% Άθροισμα και Πολλαπλασιασμός
C = A + B;
D = A * B;       % Γινόμενο πινάκων
E = A .* B;      % Στοιχείο-προς-στοιχείο πολλαπλασιασμός (Hadamard)

% Ανάστροφος και Ορίζουσα
A_trans = A';
det_B = det(B);

% Έλεγχος αντιστρεψιμότητας και αντίστροφος
if det_B ~= 0
    B_inv = inv(B);
    disp("Ο αντίστροφος του B είναι:");
    disp(B_inv);
end
```

## 3. Ανηγμένη Κλιμακωτή Μορφή (RREF)
Η συνάρτηση `rref()` εκτελεί τη μέθοδο απαλοιφής Gauss-Jordan στον επαυξημένο πίνακα:

```matlab
% Επαυξημένος πίνακας [A | b]
A_sys = [2, 1, -1; -3, -1, 2; -2, 1, 2];
b_sys = [8; -11; -3];
Aug = [A_sys, b_sys];

% Εύρεση RREF
R = rref(Aug);
disp("Ανηγμένη κλιμακωτή μορφή:");
disp(R);
```
