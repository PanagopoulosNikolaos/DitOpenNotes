# Εργαστηριακός Οδηγός 2: Επίλυση Συστημάτων και Ιδιοτιμές με το Octave

## 1. Επίλυση Γραμμικού Συστήματος με τον Τελεστή Backslash (`\`)

Η έκφραση `x = A \ b` χρησιμοποιεί βελτιστοποιημένους αλγορίθμους παραγοντοποίησης (LU για τετραγωνικούς πίνακες, QR για μη τετραγωνικούς).

```matlab
A = [3, 2, -1; 2, -2, 4; -1, 0.5, -1];
b = [1; -2; 0];

% Αριθμητική επίλυση
x = A \ b;
disp("Λύση συστήματος:");
disp(x);

% Επαλήθευση σφάλματος υπολοίπου
residual = norm(A * x - b);
fprintf("Υπόλοιπο σφάλματος: %e\n", residual);
```

## 2. Υπολογισμός Ιδιοτιμών και Ιδιοδιανυσμάτων (`eig`)

Η συνάρτηση `eig()` επιστρέφει τις ιδιοτιμές και τα κανονικοποιημένα ιδιοδιανύσματα.

```matlab
M = [4, -2; 1, 1];

% Υπολογισμός ιδιοτιμών και ιδιοδιανυσμάτων
[V, D] = eig(M);

disp("Πίνακας ιδιοδιανυσμάτων V:");
disp(V);
disp("Διαγώνιος πίνακας ιδιοτιμών D:");
disp(D);

% Επαλήθευση της σχέσης M * V = V * D
diff_norm = norm(M * V - V * D);
fprintf("Σφάλμα διαγωνιοποίησης: %e\n", diff_norm);
```
