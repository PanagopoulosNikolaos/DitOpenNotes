# Βιβλιογραφία και Πηγές: Προγραμματισμός C I

## 1. Προτεινόμενα Πανεπιστημιακά Συγγράμματα (Εύδοξος)
* **«Η Γλώσσα Προγραμματισμού C»** (The C Programming Language), Brian W. Kernighan, Dennis M. Ritchie (Κλασικό σύγγραμμα των δημιουργών της γλώσσας).
* **«Προγραμματισμός με C»**, Deitel Paul J., Deitel Harvey M., Εκδόσεις Χ. Γκιούρδας.
* **«C: Από τη Θεωρία στην Εφαρμογή»**, Γ. Σ. Τσελίκης, Ν. Δ. Νικολός.

## 2. Επίσημη Τεκμηρίωση και Πρότυπα
* [cppreference.com - C Reference](https://en.cppreference.com/w/c) — Πλήρης και επικαιροποιημένη αναφορά της γλώσσας C και της τυπικής βιβλιοθήκης.
* [GNU C Library Documentation](https://www.gnu.org/software/libc/manual/) — Επίσημο εγχειρίδιο της glibc.

## 3. Εργαλεία Ανάπτυξης και Αποσφαλμάτωσης
* **GCC (GNU Compiler Collection):** Ο τυποποιημένος μεταγλωττιστής ανοικτού κώδικα.
* **GDB (GNU Debugger):** Διαδραστικός αποσφαλματωτής γραμμής εντολών.
* **Valgrind:** Εργαλείο εντοπισμού διαρροών μνήμης και αντικανονικής προσπέλασης.

## 4. Διαδικτυακές Πλατφόρμες Εξάσκησης
* [Exercism (C Track)](https://exercism.org/tracks/c) — Στοχευμένες ασκήσεις με αυτόματο έλεγχο κώδικα.
* [LeetCode](https://leetcode.com/) — Αλγοριθμικά προβλήματα δομημένου προγραμματισμού.
