# Σημειώσεις Μαθήματος: Δείκτες και Δυναμική Διαχείριση Μνήμης

## 1. Μοντέλο Μνήμης στη C
Η μνήμη ενός εκτελούμενου προγράμματος διαιρείται σε διακριτά τμήματα:
* **Τμήμα Κώδικα (Text Segment):** Περιέχει τις εκτελέσιμες εντολές μηχανής.
* **Τμήμα Δεδομένων (Data / BSS Segment):** Περιέχει καθολικές (global) και στατικές (static) μεταβλητές.
* **Στοίβα (Stack):** Αποθηκεύει τοπικές μεταβλητές συναρτήσεων και πλαίσια κλήσεων (stack frames). Διαχειρίζεται αυτόματα.
* **Σωρός (Heap):** Περιοχή για δυναμική δέσμευση μνήμης κατά τον χρόνο εκτέλεσης. Απαιτεί ρητή διαχείριση από τον προγραμματιστή.

## 2. Συναρτήσεις Δυναμικής Δέσμευσης (`<stdlib.h>`)

| Συνάρτηση | Περιγραφή |
|---|---|
| `malloc(size)` | Δεσμεύει `size` bytes χωρίς αρχικοποίηση (περιέχει σκουπίδια μνήμης). |
| `calloc(num, size)` | Δεσμεύει χώρο για `num` στοιχεία μεγέθους `size` και αρχικοποιεί όλα τα bits σε μηδέν. |
| `realloc(ptr, new_size)` | Αλλάζει το μέγεθος προηγουμένως δεσμευμένου μπλοκ μνήμης. |
| `free(ptr)` | Αποδεσμεύει τη μνήμη και την επιστρέφει στο σύστημα. |

## 3. Κανόνες Ασφαλούς Διαχείρισης Μνήμης
1. **Έλεγχος έναντι του `NULL`:** Κάθε κλήση της `malloc`/`calloc` πρέπει να ελέγχεται άμεσα.
2. **Αποφυγή Memory Leaks:** Κάθε δεσμευμένο μπλοκ μνήμης πρέπει να αποδεσμεύεται με `free` όταν δεν χρειάζεται πλέον.
3. **Αποφυγή Dangling Pointers:** Μετά την `free(ptr)`, θέτουμε πάντα `ptr = NULL;`.
4. **Αποφυγή Double Free:** Ποτέ μην καλείτε τη `free` δύο φορές στον ίδιο δείκτη.
