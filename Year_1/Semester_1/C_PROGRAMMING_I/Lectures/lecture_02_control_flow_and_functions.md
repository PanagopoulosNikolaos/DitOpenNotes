# Διάλεξη 2: Έλεγχος Ροής Εκτέλεσης και Συναρτήσεις

## 1. Δομές Επιλογής

Οι δομές επιλογής επιτρέπουν την εκτέλεση διαφορετικών τμημάτων κώδικα ανάλογα με τη λογική αποτίμηση συνθηκών.

### Η εντολή `if-else`
```c
#include <stdio.h>

int main(void) {
    int grade = 75;

    if (grade >= 50) {
        printf("Επιτυχία στο μάθημα.\n");
    } else {
        printf("Αποτυχία, απαιτείται επανεξέταση.\n");
    }

    return 0;
}
```

### Η εντολή πολλαπλής επιλογής `switch`
Χρησιμοποιείται για έλεγχο ισότητας μιας ακέραιας έκφρασης ή χαρακτήρα έναντι διακριτών σταθερών τιμών (`case`).

```c
#include <stdio.h>

int main(void) {
    char operator = '+';
    int a = 10, b = 5;

    switch (operator) {
        case '+':
            printf("Αποτέλεσμα: %d\n", a + b);
            break;
        case '-':
            printf("Αποτέλεσμα: %d\n", a - b);
            break;
        default:
            printf("Μη έγκυρος τελεστής.\n");
            break;
    }

    return 0;
}
```

## 2. Δομές Επανάληψης (Loops)

### Ο βρόχος `for`
Ιδανικός όταν ο αριθμός των επαναλήψεων είναι προκαθορισμένος.

```c
for (int i = 0; i < 10; i++) {
    printf("Επανάληψη: %d\n", i);
}
```

### Ο βρόχος `while`
Ελέγχει τη συνθήκη στην αρχή κάθε επανάληψης.
```c
int count = 1;
while (count <= 5) {
    printf("Τιμή: %d\n", count);
    count++;
}
```

### Ο βρόχος `do-while`
Εγγυάται τουλάχιστον μία εκτέλεση του σώματος του βρόχου, καθώς ο έλεγχος πραγματοποιείται στο τέλος.
```c
int input;
do {
    printf("Δώστε θετικό ακέραιο: ");
    scanf("%d", &input);
} while (input <= 0);
```

## 3. Συναρτήσεις και Εμβέλεια Μεταβλητών

Μια συνάρτηση είναι μια αυτόνομη ενότητα κώδικα που επιτελεί έναν συγκεκριμένο σκοπό.

### Πρωτότυπο και Ορισμός Συνάρτησης
```c
#include <stdio.h>

/* Πρωτότυπο συνάρτησης */
int calculate_power(int base, int exp);

int main(void) {
    int result = calculate_power(2, 4);
    printf("2^4 = %d\n", result);
    return 0;
}

/* Ορισμός συνάρτησης */
int calculate_power(int base, int exp) {
    int total = 1;
    for (int i = 0; i < exp; i++) {
        total *= base;
    }
    return total;
}
```

### Πέρασμα Παραμέτρων κατ' Αξία (Call by Value)
Στη C, όλες οι παράμετροι μεταβιβάζονται στις συναρτήσεις κατ' αξία: η συνάρτηση λαμβάνει αντίγραφο των τιμών εισόδου και τυχόν τροποποιήσεις δεν επηρεάζουν τις αρχικές μεταβλητές του καλούντος.
