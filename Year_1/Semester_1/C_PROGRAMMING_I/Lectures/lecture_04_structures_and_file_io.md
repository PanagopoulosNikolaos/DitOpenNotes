# Διάλεξη 4: Δομές Δεδομένων και Διαχείριση Αρχείων

## 1. Δομές (`struct`) και Συνώνυμα Τύπων (`typedef`)

Μια δομή επιτρέπει την ομαδοποίηση μεταβλητών διαφορετικών τύπων δεδομένων υπό ένα ενιαίο όνομα.

```c
#include <stdio.h>
#include <string.h>

typedef struct {
    int id;
    char name[50];
    double gpa;
} Student;

int main(void) {
    Student s1;
    s1.id = 1042;
    strncpy(s1.name, "Γεώργιος Παπαδόπουλος", sizeof(s1.name) - 1);
    s1.name[sizeof(s1.name) - 1] = '\0';
    s1.gpa = 8.45;

    printf("Φοιτητής: %s (AM: %d) - Μέσος Όρος: %.2f\n", s1.name, s1.id, s1.gpa);
    return 0;
}
```

## 2. Διαχείριση Αρχείων (File I/O)

Η διαχείριση αρχείων πραγματοποιείται μέσω του δείκτη τύπου `FILE *` που ορίζεται στο `<stdio.h>`.

### Βασικές Λειτουργίες
1. **Άνοιγμα αρχείου:** `fopen("filename.txt", "mode")` όπου οι τρόποι είναι:
   * `"r"`: Ανάγνωση κειμένου
   * `"w"`: Εγγραφή κειμένου (υπεργράφει υπάρχον περιεχόμενο)
   * `"a"`: Προσάρτηση κειμένου στο τέλος
   * `"rb"`, `"wb"`: Δυαδική ανάγνωση και εγγραφή
2. **Έλεγχος επιτυχίας:** Ο δείκτης πρέπει πάντα να ελέγχεται έναντι του `NULL`.
3. **Ανάγνωση/Εγγραφή:** `fprintf()`, `fscanf()`, `fgets()`, `fputs()`, `fread()`, `fwrite()`.
4. **Κλείσιμο αρχείου:** `fclose(file_pointer)`.

```c
#include <stdio.h>

int main(void) {
    FILE *fp = fopen("output.txt", "w");
    if (fp == NULL) {
        perror("Σφάλμα ανοίγματος αρχείου");
        return 1;
    }

    fprintf(fp, "Αποτελέσματα Εργαστηρίου Προγραμματισμού C\n");
    fclose(fp);
    return 0;
}
```
