# Διάλεξη 3: Πίνακες, Συμβολοσειρές και Δείκτες

## 1. Μονοδιάστατοι και Πολυδιάστατοι Πίνακες

Ο πίνακας είναι μια δομή δεδομένων συνεχόμενων θέσεων μνήμης ίδιου τύπου δεδομένων.

```c
#include <stdio.h>

int main(void) {
    int numbers[5] = {10, 20, 30, 40, 50};

    for (int i = 0; i < 5; i++) {
        printf("Στοιχείο [%d] = %d (Διεύθυνση: %p)\n", i, numbers[i], (void*)&numbers[i]);
    }

    return 0;
}
```

## 2. Συμβολοσειρές (Strings)

Στη C, οι συμβολοσειρές αναπαρίστανται ως πίνακες χαρακτήρων που τερματίζονται με τον μηδενικό χαρακτήρα `\0` (null terminator).

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char greeting[32] = "Καλημέρα";
    printf("Μήνυμα: %s, Μήκος: %lu χαρακτήρες\n", greeting, strlen(greeting));
    return 0;
}
```

## 3. Θεμελιώδεις Έννοιες Δεικτών (Pointers)

Ο δείκτης είναι μια μεταβλητή που αποθηκεύει τη διεύθυνση μνήμης μιας άλλης μεταβλητής.

* Τελεστής διεύθυνσης `&`: Επιστρέφει τη διεύθυνση μνήμης της μεταβλητής.
* Τελεστής αποπαραπομπής `*`: Προσπελαύνει την τιμή που βρίσκεται στη διεύθυνση που δείχνει ο δείκτης.

```c
#include <stdio.h>

int main(void) {
    int value = 42;
    int *ptr = &value;

    printf("Τιμή: %d\n", value);
    printf("Διεύθυνση: %p\n", (void*)ptr);
    printf("Τιμή μέσω δείκτη: %d\n", *ptr);

    *ptr = 100; // Τροποποίηση της τιμής μέσω του δείκτη
    printf("Νέα τιμή: %d\n", value);

    return 0;
}
```

### Πέρασμα κατ' Αναφορά (Call by Reference μέσω Δεικτών)
Χρησιμοποιώντας δείκτες, οι συναρτήσεις μπορούν να τροποποιούν απευθείας τις μεταβλητές του καλούντος:

```c
void swap_numbers(int *a, int *b) {
    int temp = *a;
    *a = *b;
    *b = temp;
}
```
