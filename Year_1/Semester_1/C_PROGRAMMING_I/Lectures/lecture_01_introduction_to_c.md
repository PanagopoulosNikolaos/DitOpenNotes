# Διάλεξη 1: Εισαγωγή στη Γλώσσα Προγραμματισμού C

## 1. Ιστορική Αναδρομή και Χαρακτηριστικά της C

Η γλώσσα προγραμματισμού C αναπτύχθηκε στις αρχές της δεκαετίας του 1970 από τον Dennis Ritchie στα εργαστήρια Bell Telephone Laboratories (Bell Labs). Σχεδιάστηκε αρχικά για την υλοποίηση του λειτουργικού συστήματος UNIX.

### Βασικά Χαρακτηριστικά
* **Γλώσσα Μέσου Επιπέδου (Middle-Level Language):** Συνδυάζει στοιχεία γλωσσών υψηλού επιπέδου (δομημένος προγραμματισμός, τύποι δεδομένων) με δυνατότητες χαμηλού επιπέδου (απευθείας διαχείριση μνήμης μέσω δεικτών, πράξεις σε επίπεδο bit).
* **Δομημένος Προγραμματισμός (Structured Programming):** Χρήση συναρτήσεων, μπλοκ κώδικα και αποφυγή άναρχων αλμάτων.
* **Φορητότητα (Portability):** Ο πηγαίος κώδικας μπορεί να μεταγλωττιστεί σε διαφορετικές αρχιτεκτονικές με ελάχιστες ή μηδενικές τροποποιήσεις.
* **Υψηλή Αποδοτικότητα και Ταχύτητα:** Παράγει συμπαγή και ταχύτατο εκτελέσιμο κώδικα μηχανής.

## 2. Δομή ενός Προγράμματος C

Ένα τυπικό πρόγραμμα C αποτελείται από οδηγίες προεπεξεργαστή, ορισμούς τύπων/σταθερών, δηλώσεις συναρτήσεων και τη βασική συνάρτηση εκκίνησης `main()`.

```c
#include <stdio.h>

/* Κύρια συνάρτηση του προγράμματος */
int main(void) {
    printf("Καλώς ήρθατε στον Προγραμματισμό C!\n");
    return 0;
}
```

* `#include <stdio.h>`: Οδηγία προεπεξεργαστή που ενσωματώνει το αρχείο επικεφαλίδας για λειτουργίες τυπικής εισόδου/εξόδου (Standard Input/Output).
* `int main(void)`: Το σημείο εισόδου κάθε προγράμματος C. Επιστρέφει ακέραιο κωδικό κατάστασης στο λειτουργικό σύστημα.
* `return 0;`: Δηλώνει επιτυχή τερματισμό του προγράμματος.

## 3. Βασικοί Τύποι Δεδομένων και Τροποποιητές

Η C παρέχει θεμελιώδεις τύπους δεδομένων των οποίων το ακριβές μέγεθος εξαρτάται από την αρχιτεκτονική του συστήματος (συνήθως 32-bit ή 64-bit).

| Τύπος | Περιγραφή | Τυπικό Μέγεθος (Bytes) | Προσδιοριστής Μορφοποίησης |
|---|---|---|---|
| `char` | Χαρακτήρας ASCII / Μικρός ακέραιος | 1 | `%c` / `%d` |
| `int` | Ακέραιος αριθμός | 4 | `%d` ή `%i` |
| `float` | Αριθμός κινητής υποδιαστολής μονής ακρίβειας | 4 | `%f` |
| `double` | Αριθμός κινητής υποδιαστολής διπλής ακρίβειας | 8 | `%lf` |

### Τροποποιητές (Type Modifiers)
* `signed` / `unsigned`: Καθορίζει αν ο τύπος αναπαριστά προσημασμένες ή μη προσημασμένες τιμές.
* `short` / `long`: Τροποποιεί το μέγεθος αποθήκευσης και το εύρος τιμών.

## 4. Μεταβλητές, Σταθερές και Είσοδος/Έξοδος

### Δήλωση και Αρχικοποίηση Μεταβλητών
```c
int student_age = 20;
const double pi_constant = 3.14159265;
```

### Μορφοποιημένη Είσοδος και Έξοδος (`printf` και `scanf`)
Η συνάρτηση `printf` εκτυπώνει μορφοποιημένο κείμενο, ενώ η `scanf` διαβάζει δεδομένα από την είσοδο απαιτώντας τη διεύθυνση μνήμης της μεταβλητής (τελεστής `&`).

```c
#include <stdio.h>

int main(void) {
    int student_id;
    float grade;

    printf("Εισάγετε αριθμό μητρώου και βαθμό: ");
    if (scanf("%d %f", &student_id, &grade) == 2) {
        printf("Φοιτητής: %d, Βαθμός: %.2f\n", student_id, grade);
    } else {
        printf("Σφάλμα κατά την ανάγνωση δεδομένων.\n");
    }

    return 0;
}
```

## 5. Βασικοί Τελεστές

1. **Αριθμητικοί:** `+`, `-`, `*`, `/`, `%` (υπόλοιπο ακέραιας διαίρεσης).
2. **Σχεσιακοί:** `==`, `!=`, `<`, `>`, `<=`, `>=`.
3. **Λογικοί:** `&&` (Λογικό ΚΑΙ), `||` (Λογικό Ή), `!` (Λογικό ΟΧΙ).
4. **Ανάθεσης:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`.
5. **Αύξησης / Μείωσης:** `++`, `--` (προθεματική και επιθεματική μορφή).
