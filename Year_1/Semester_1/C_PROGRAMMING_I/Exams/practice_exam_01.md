## Μέρος Β: Ανάλυση Κώδικα και Εντοπισμός Σφαλμάτων (35 Μονάδες)

Δίνεται το ακόλουθο απόσπασμα κώδικα:

```c
#include <stdio.h>
#include <stdlib.h>

char* duplicate_string(const char *src) {
    char copy[50];
    int i = 0;
    while (src[i] != '\0') {
        copy[i] = src[i];
        i++;
    }
    copy[i] = '\0';
    return copy;
}
```

1. Εντοπίστε το σοβαρό λογικό σφάλμα διαχείρισης μνήμης στη συνάρτηση `duplicate_string`.
2. Διορθώστε τον κώδικα χρησιμοποιώντας δυναμική δέσμευση μνήμης.

## Ενδεικτικές Λύσεις

### Λύση Μέρους Α
* **1.1:** Ο τελεστής `&` (address-of) επιστρέφει τη διεύθυνση μνήμης της μεταβλητής, ενώ ο `*` (dereference) ανακτά ή τροποποιεί την τιμή στη διεύθυνση που δείχνει ο δείκτης.
* **1.2:** Δεσμεύεται χώρος στη στοίβα (stack). Ο χρόνος ζωής του περιορίζεται στη διάρκεια εκτέλεσης της συνάρτησης και η εμβέλεια είναι τοπική στο μπλοκ δήλωσης.
* **1.3:** Το `"w"` διαγράφει το προϋπάρχον περιεχόμενο του αρχείου (ή το δημιουργεί εκ νέου), ενώ το `"a"` προσθέτει νέα δεδομένα στο τέλος του χωρίς να διαγράψει τα παλιά.

### Λύση Μέρους Β
Η συνάρτηση επιστρέφει δείκτη σε τοπικό πίνακα (`copy`) που δεσμεύτηκε στη στοίβα. Με τον τερματισμό της συνάρτησης, η μνήμη αυτή αποδεσμεύεται, οδηγώντας σε Dangling Pointer και Undefined Behavior.

Διορθωμένη έκδοση:
```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char* duplicate_string(const char *src) {
    if (src == NULL) return NULL;
    char *copy = (char*)malloc(strlen(src) + 1);
    if (copy == NULL) return NULL;
    strcpy(copy, src);
    return copy;
}
```

### Λύση Μέρους Γ
```c
#include <stdio.h>
#include <stdlib.h>

typedef struct {
    char flight_code[10];
    char destination[40];
    int seats;
} Flight;

void print_available_flights(Flight flights[], int count, int min_seats) {
    printf("\n--- Πτήσεις με τουλάχιστον %d διαθέσιμες θέσεις ---\n", min_seats);
    for (int i = 0; i < count; i++) {
        if (flights[i].seats >= min_seats) {
            printf("Πτήση: %s | Προορισμός: %s | Θέσεις: %d\n",
                   flights[i].flight_code, flights[i].destination, flights[i].seats);
        }
    }
}
```
