# Εργαστηριακός Οδηγός 2: Αποσφαλμάτωση με GDB και Έλεγχος Μνήμης με Valgrind

## 1. Χρήση του Αποσφαλματωτή GDB (GNU Debugger)

### Μεταγλώττιση με Πληροφορίες Αποσφαλμάτωσης
```bash
gcc -g -Wall program.c -o program
```

### Εκκίνηση και Βασικές Εντολές GDB
```bash
gdb ./program
```

* `run [args]`: Ξεκινά την εκτέλεση του προγράμματος με τυχόν ορίσματα.
* `break <line_number>` ή `break <function>`: Ορίζει σημείο διακοπής (breakpoint).
* `next` (`n`): Εκτελεί την επόμενη γραμμή κώδικα χωρίς να εισέλθει σε συναρτήσεις (step over).
* `step` (`s`): Εκτελεί την επόμενη γραμμή εισερχόμενο στη συνάρτηση (step into).
* `print <variable>` (`p`): Εκτυπώνει την τρέχουσα τιμή μιας μεταβλητής ή έκφρασης.
* `backtrace` (`bt`): Εμφανίζει τη στοίβα κλήσεων (call stack) κατά την εμφάνιση Segmentation Fault.
* `quit` (`q`): Έξοδος από το GDB.

---

## 2. Εντοπισμός Διαρροών Μνήμης με Valgrind

Το εργαλείο Valgrind αναλύει την εκτέλεση του προγράμματος και εντοπίζει μη αρχικοποιημένες μεταβλητές, προσπελάσεις εκτός ορίων μνήμης και διαρροές (memory leaks).

```bash
valgrind --leak-check=full --show-leak-kinds=all --track-origins=yes ./program
```
