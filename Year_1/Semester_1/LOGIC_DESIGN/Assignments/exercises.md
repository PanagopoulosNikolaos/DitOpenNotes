# Ασκήσεις και Προβλήματα Εξάσκησης: Σχεδίαση Λογικής

Συλλογή θεμάτων και ασκήσεων εξάσκησης με αναλυτικές λύσεις για την προετοιμασία των φοιτητών στο μάθημα της Σχεδίασης Λογικής.

## Ενότητα 1: Άλγεβρα Boole και Κανονικές Μορφές

### Άσκηση 1.1: Απλοποίηση Λογικής Συνάρτησης
**Εκφώνηση:**
Δίνεται η λογική συνάρτηση:
$$F(A, B, C) = A'BC + AB'C + ABC' + ABC$$
Απλοποιήστε τη συνάρτηση $F$ στην ελάχιστη μορφή Sum of Products (SOP) χρησιμοποιώντας αποκλειστικά τα αξιώματα και τα θεωρήματα της Άλγεβρας Boole.

**Λύση:**
1. Εφαρμόζουμε την ιδιότητα ταυτοδυναμίας $X + X = X$ για να αναπαράγουμε τον όρο $ABC$:
   $$F = (A'BC + ABC) + (AB'C + ABC) + (ABC' + ABC)$$
2. Παραγοντοποιούμε ανά ζεύγη:
   $$F = BC(A' + A) + AC(B' + B) + AB(C' + C)$$
3. Εφαρμόζουμε το συμπλήρωμα $X + X' = 1$ και την ταυτότητα $X \cdot 1 = X$:
   $$F = BC(1) + AC(1) + AB(1) = AB + BC + AC$$

Η ελάχιστη μορφή SOP είναι:
$$F = AB + BC + AC$$

## Ενότητα 2: Ελαχιστοποίηση με Χάρτες Karnaugh

### Άσκηση 2.1: Χάρτης K 4 Μεταβλητών με Αδιάφορες Συνθήκες (Don't Cares)
**Εκφώνηση:**
Δίνεται η συνάρτηση 4 μεταβλητών:
$$F(A, B, C, D) = \sum m(1, 3, 7, 11, 15) + \sum d(0, 2, 5)$$
Βρείτε την απλοποιημένη συνάρτηση σε μορφή SOP αξιοποιώντας τις αδιάφορες συνθήκες.

**Λύση:**
1. Τοποθετούμε τους άσσους ($1$) και τις συνθήκες don't care ($X$) στον χάρτη Karnaugh 4x4 (γραμμές $AB$, στήλες $CD$):
   - $m(1): (0001) \rightarrow 1$
   - $m(3): (0011) \rightarrow 1$
   - $m(7): (0111) \rightarrow 1$
   - $m(11): (1011) \rightarrow 1$
   - $m(15): (1111) \rightarrow 1$
   - $d(0): (0000) \rightarrow X$
   - $d(2): (0010) \rightarrow X$
   - $d(5): (0101) \rightarrow X$

2. Σχηματισμός ομάδων:
   - **Ομάδα 1 (Τετράδα στη στήλη $CD = 11$):** Καλύπτει τα κελιά $m(3), m(7), m(15), m(11)$.
     Κοινές μεταβλητές: $C = 1, D = 1 \Rightarrow CD$.
   - **Ομάδα 2 (Τετράδα πρώτης γραμμής $AB = 00$):** Συνδυάζει $d(0), m(1), m(3), d(2)$.
     Κοινές μεταβλητές: $A = 0, B = 0 \Rightarrow A'B'$.

3. Ελάχιστη συνάρτηση SOP:
   $$F(A, B, C, D) = CD + A'B'$$

## Ενότητα 3: Συνδυαστικά Κυκλώματα με Πολυπλέκτες

### Άσκηση 3.1: Υλοποίηση Συνάρτησης με Πολυπλέκτη 4:1
**Εκφώνηση:**
Υλοποιήστε τη συνάρτηση $F(A, B, C) = \sum m(1, 2, 4, 7)$ χρησιμοποιώντας έναν πολυπλέκτη $4:1$ με εισόδους επιλογής $S_1 = A$ και $S_0 = B$, καθώς και βασικές λογικές πύλες (αν απαιτούνται).

**Λύση:**
1. Κατασκευάζουμε τον πίνακα αληθείας και ομαδοποιούμε ανά ζεύγη τιμών $(A, B)$:

| $A$ | $B$ | $C$ | $m$ | $F$ | Έκφραση εισόδου $I_k$ |
|:---:|:---:|:---:|:---:|:---:|:---|
| 0 | 0 | 0 | 0 | 0 | $I_0 = C$ (γιατί $F = C$) |
| 0 | 0 | 1 | 1 | 1 | |
| 0 | 1 | 0 | 2 | 1 | $I_1 = C'$ (γιατί $F = C'$) |
| 0 | 1 | 1 | 3 | 0 | |
| 1 | 0 | 0 | 4 | 1 | $I_2 = C'$ (γιατί $F = C'$) |
| 1 | 0 | 1 | 5 | 0 | |
| 1 | 1 | 0 | 6 | 0 | $I_3 = C$ (γιατί $F = C$) |
| 1 | 1 | 1 | 7 | 1 | |

2. Συνδέσεις Πολυπλέκτη $4:1$:
   - Είσοδοι επιλογής: $S_1 = A$, $S_0 = B$
   - Είσοδοι δεδομένων:
     - $I_0 = C$
     - $I_1 = C'$ (μέσω αντιστροφέα NOT)
     - $I_2 = C'$
     - $I_3 = C$

## Ενότητα 4: Ακολουθιακά Κυκλώματα & Flip-Flops

### Άσκηση 4.1: Σχεδιασμός Σύγχρονου Απαριθμητή Modulo-4 με D Flip-Flops
**Εκφώνηση:**
Σχεδιάστε σύγχρονο κυκλικό απαριθμητή με ακολουθία καταστάσεων $00 \rightarrow 01 \rightarrow 11 \rightarrow 10 \rightarrow 00$ χρησιμοποιώντας δύο D Flip-Flops ($Q_1, Q_0$).

**Λύση:**
1. Πίνακας μετάβασης καταστάσεων και διεγέρσεων D Flip-Flop (όπου $D = Q_{\text{next}}$):

| Παρούσα Κατάσταση ($Q_1 Q_0$) | Επόμενη Κατάσταση ($Q_1^+ Q_0^+$) | Είσοδος $D_1$ | Είσοδος $D_0$ |
|:---:|:---:|:---:|:---:|
| 00 | 01 | 0 | 1 |
| 01 | 11 | 1 | 1 |
| 11 | 10 | 1 | 0 |
| 10 | 00 | 0 | 0 |

2. Εξαγωγή λογικών εξισώσεων:
   - Για το $D_1$:
     $D_1 = 1$ στις καταστάσεις $01$ και $11$.
     $$D_1 = Q_1' Q_0 + Q_1 Q_0 = (Q_1' + Q_1) Q_0 = Q_0$$
   - Για το $D_0$:
     $D_0 = 1$ στις καταστάσεις $00$ και $01$.
     $$D_0 = Q_1' Q_0' + Q_1' Q_0 = Q_1'(Q_0' + Q_0) = Q_1'$$

3. Τελικές εξισώσεις εισόδων:
   $$D_1 = Q_0$$
   $$D_0 = Q_1'$$
