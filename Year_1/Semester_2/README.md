# Year 1 - Semester 2

Welcome to the comprehensive academic course archive for **Year 1, Semester 2** of the Department of Informatics and Telecommunications at the University of Ioannina.

---

## Curriculum Overview

Semester 2 advances students into discrete mathematics, computer network architectures, advanced procedural C systems, digital switching electronics and VHDL modeling, and vector electromagnetics.

| Code | Course Name | ECTS | Category | Primary Focus |
|:---|:---|:---:|:---|:---|
| **201** | [Electromagnetics](ELECTROMAGNETICS) | 6 | Mandatory | Vector calculus, electrostatics, magnetostatics, Maxwell's equations, plane waves |
| **202** | [Networking](NETWORKING) | 6 | Mandatory | OSI/TCP-IP models, IPv4 subnetting, routing, transport layer, packet analysis |
| **203** | [Discrete Mathematics](DISCRETE_MATHEMATICS) | 6 | Mandatory | Mathematical induction, formal logic, set theory, combinatorics, graph theory |
| **204** | [C Programming II](C_PROGRAMMING_II) | 6 | Mandatory | Dynamic memory allocation, pointer indirection, binary file I/O, abstract data types |
| **205** | [Digital Electronics](DIGITAL_ELECTRONICS) | 6 | Mandatory | Boolean minimization, combinational/sequential logic, counters, FSMs, VHDL synthesis |

## Getting Started

1. **Tooling Environment**:
   * **C Programming II**: GNU Compiler Collection (`gcc`), GNU Debugger (`gdb`), and Valgrind (`valgrind`) for memory leak analysis.
   * **Digital Electronics**: GHDL for VHDL simulation, GTKWave for signal inspection, and Python/Streamlit for interactive waveform suites.
   * **Networking**: Wireshark, `tcpdump`, and Python socket programming libraries.
   * **Discrete Mathematics & Electromagnetics**: Python 3 with NumPy, SciPy, SymPy, and NetworkX.
2. **Recommended Study Order**: Begin each week by studying the theoretical concepts in `Lectures/` and `Resources/Notes/`, followed by hands-on execution of `Examples/` and drilling through `Exercises/`.
3. **Assessment Preparation**: Complete the graded assignments in `Assignments/` and self-evaluate with mock tests in `Exams/`.
