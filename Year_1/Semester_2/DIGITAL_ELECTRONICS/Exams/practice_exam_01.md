# Επαναληπτικό Θέμα Εξετάσεων: Ψηφιακά Ηλεκτρονικά

## Οδηγίες
- Διάρκεια εξέτασης: 2.5 ώρες.
- Όλα τα θέματα βαθμολογούνται με 2.5 μονάδες.

---

## Θέμα 1: Αριθμητική Συμπληρώματος ως προς 2
1. Μετατρέψτε τους δεκαδικούς αριθμούς $A = +43$ και $B = -27$ σε δυαδική αναπαράσταση συμπληρώματος ως προς 2 μήκους 8-bit.
2. Εκτελέστε την πράξη πρόσθεσης $A + B$ σε δυαδική μορφή 8-bit και ελέγξτε για τυχόν υπερχείλιση (overflow).
3. Εξηγήστε πώς ανιχνεύεται η υπερχείλιση κατά την πρόσθεση δύο προσημασμένων αριθμών.

---

## Θέμα 2: Απλοποίηση Boole και Συνδυαστική Σύνθεση
Δίνεται η λογική συνάρτηση:
$$F(A, B, C, D) = \sum m(1, 3, 7, 11, 15) + d(0, 2, 5)$$
1. Απλοποιήστε τη συνάρτηση σε ελάχιστη μορφή SOP χρησιμοποιώντας χάρτη Karnaugh.
2. Υλοποιήστε την απλοποιημένη συνάρτηση χρησιμοποιώντας **μόνο πύλες NOR 2-εισόδων**.

---

## Θέμα 3: Σχεδίαση Σύγχρονου Ακολουθιακού Κυκλώματος
Σχεδιάστε σύγχρονο ακολουθιακό κύκλωμα με D Flip-Flops το οποίο αναγνωρίζει την ακολουθία `101` σε μια σειριακή είσοδο $X$. Μόλις ανιχνευθεί η ακολουθία, η έξοδος $Z$ γίνεται '1' για έναν κύκλο ρολογιού. Επιτρέπεται η επικάλυψη.

---

## Θέμα 4: Περιγραφή Υλικού σε VHDL
Γράψτε πλήρη κώδικα VHDL (Entity και Behavioral Architecture) για έναν πολυπλέκτη 4-σε-1 (4-to-1 MUX) με διαύλους δεδομένων πλάτους 8-bit (`STD_LOGIC_VECTOR(7 downto 0)`), σήμα ενεργοποίησης `enable` (active-high) και 2 γραμμές επιλογής `sel`.

---

## Ενδεικτικές Λύσεις

### Λύση Θέματος 1
1. $+43_{10} = 00101011_2$.
   $+27_{10} = 00011011_2 \Rightarrow 1's = 11100100 \Rightarrow [-27]_2 = 11100101_2$.
2. Πρόσθεση:
   ```text
     00101011  (+43)
   + 11100101  (-27)
   -----------
   (1)00010000  (+16)
   ```
   Το κρατούμενο εξόδου απορρίπτεται. Το αποτέλεσμα $00010000_2 = 16_{10}$ είναι σωστό.
3. Υπερχείλιση συμβαίνει όταν προσθέτουμε αριθμούς ίδιου προσήμου και το αποτέλεσμα έχει αντίθετο πρόσημο ($C_{in} \neq C_{out}$ στο MSB). Εδώ τα πρόσημα είναι αντίθετα, άρα δεν υπάρχει υπερχείλιση.

### Λύση Θέματος 2
1. Μετά την τοποθέτηση των minterms και των don't cares στον K-Map:
   - Μεγάλη ομάδα 8 κελιών: $m(0, 1, 2, 3, 5, 7) \Rightarrow \overline{A}\overline{B} + \overline{A}D$ ή συνδυασμός.
   - Βέλτιστη κάλυψη: $F = CD + \overline{A}\overline{B} + \overline{A}D$.
2. Μετατροπή σε πύλες NOR μέσω διπλού συμπληρώματος και De Morgan.

### Λύση Θέματος 4
```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity mux4to1_8bit is
    Port (
        d0, d1, d2, d3 : in  STD_LOGIC_VECTOR(7 downto 0);
        sel            : in  STD_LOGIC_VECTOR(1 downto 0);
        enable         : in  STD_LOGIC;
        y              : out STD_LOGIC_VECTOR(7 downto 0)
    );
end mux4to1_8bit;

architecture Behavioral of mux4to1_8bit is
begin
    process(d0, d1, d2, d3, sel, enable)
    begin
        if enable = '0' then
            y <= (others => '0');
        else
            case sel is
                when "00" => y <= d0;
                when "01" => y <= d1;
                when "10" => y <= d2;
                when "11" => y <= d3;
                when others => y <= (others => '0');
            end case;
        end if;
    end process;
end Behavioral;
```
