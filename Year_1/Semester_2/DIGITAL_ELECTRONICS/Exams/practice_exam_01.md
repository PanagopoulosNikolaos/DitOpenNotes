## Αναλυτικές Βηματικές Λύσεις

### Λύση Θέματος 1: Αριθμητική Συμπληρώματος ως προς 2

#### 1. Μετατροπή σε Συμπλήρωμα ως προς 2 (8-bit)

- **Αριθμός $A = +43_{10}$:**
  Αναλύουμε σε δυνάμεις του 2:
  $$43 = 32 + 8 + 2 + 1 = 2^5 + 2^3 + 2^1 + 2^0$$
  Σε δυαδική μορφή 8-bit (με bit προσήμου MSB = 0 για θετικό αριθμό):
  $$A = 00101011_2$$

- **Αριθμός $B = -27_{10}$:**
  Πρώτα αναλύουμε το θετικό μέγεθος $+27_{10}$:
  $$27 = 16 + 8 + 2 + 1 = 2^4 + 2^3 + 2^1 + 2^0 = 00011011_2$$
  Βρίσκουμε το συμπλήρωμα ως προς 1 (αντιστροφή όλων των bits):
  $$\text{1's complement} = 11100100_2$$
  Προσθέτουμε 1 στο LSB για το συμπλήρωμα ως προς 2:
  $$[-27]_{C2} = 11100100_2 + 1 = 11100101_2$$
  Το MSB είναι 1, επιβεβαιώνοντας ότι πρόκειται για αρνητικό αριθμό.

#### 2. Εκτέλεση Πρόσθεσης $A + B$ και Έλεγχος

Εκτελούμε τη δυαδική πρόσθεση bit προς bit, παρακολουθώντας τα κρατούμενα:

```text
Δείκτης Bit:   7 6 5 4 3 2 1 0
Κρατούμενα:  1 0 1 0 1 1 1 1 0
A (+43):       0 0 1 0 1 0 1 1
B (-27):     + 1 1 1 0 0 1 0 1
-------------------------------
Άθροισμα:   (1)0 0 0 1 0 0 0 0
```

- **Αποτέλεσμα 8-bit:** $00010000_2$.
- **Κρατούμενο εξόδου (Carry Out, $C_{out} = C_8$):** Το $C_8 = 1$ απορρίπτεται στην αριθμητική συμπληρώματος ως προς 2.
- **Επαλήθευση στο δεκαδικό σύστημα:**
  $$00010000_2 = 2^4 = +16_{10}$$
  Από τον δεκαδικό έλεγχο: $A + B = (+43) + (-27) = +16$, το αποτέλεσμα είναι απολύτως ακριβές.

#### 3. Θεωρία Ανίχνευσης Υπερχείλισης (Overflow Detection)

Στην προσημασμένη αριθμητική συμπληρώματος ως προς 2, η υπερχείλιση σημαίνει ότι το αποτέλεσμα υπερβαίνει το εύρος αναπαράστασης του μήκους λέξης ($[-2^{n-1}, +2^{n-1}-1]$, δηλ. $[-128, +127]$ για $n=8$ bits).

Η ανίχνευση γίνεται με δύο ισοδύναμους κανόνες:
1. **Κανόνας Προσήμων:** Υπερχείλιση μπορεί να συμβεί **μόνο** όταν προσθέτουμε δύο αριθμούς ίδιου προσήμου (θετικό με θετικό, ή αρνητικό με αρνητικό) και το αποτέλεσμα καταλήγει να έχει αντίθετο πρόσημο.
   - Εδώ έχουμε έναν θετικό αριθμό ($A > 0$, MSB = 0) και έναν αρνητικό αριθμό ($B < 0$, MSB = 1). Επομένως, είναι μαθηματικά αδύνατον να προκληθεί υπερχείλιση.
2. **Κανόνας Κρατουμένων στο Υλικό (Hardware XOR Gate):**
   Στη βαθμίδα MSB (bit 7), παρατηρούμε το κρατούμενο εισόδου $C_{in} = C_7$ και το κρατούμενο εξόδου $C_{out} = C_8$:
   $$V = C_7 \oplus C_8$$
   Από τον υπολογισμό μας: $C_7 = 1$ και $C_8 = 1$.
   $$V = 1 \oplus 1 = 0$$
   Εφόσον $V = 0$, επιβεβαιώνεται ότι δεν υπάρχει υπερχείλιση.

### Λύση Θέματος 2: Απλοποίηση Boole και Συνδυαστική Σύνθεση

#### 1. Απλοποίηση μέσω Χάρτη Karnaugh 4 Μεταβλητών

Δίνεται:
$$F(A, B, C, D) = \sum m(1, 3, 7, 11, 15) + d(0, 2, 5)$$

Κατασκευάζουμε τον χάρτη Karnaugh $4 \times 4$ με γραμμές $AB \in \{00, 01, 11, 10\}$ και στήλες $CD \in \{00, 01, 11, 10\}$:

| $AB \backslash CD$ | 00 ($C'D'$) | 01 ($C'D$) | 11 ($CD$) | 10 ($CD'$) |
| :---: | :---: | :---: | :---: | :---: |
| **00 ($A'B'$)** | $d$ (0) | 1 (1) | 1 (3) | $d$ (2) |
| **01 ($A'B$)** | 0 (4) | $d$ (5) | 1 (7) | 0 (6) |
| **11 ($AB$)** | 0 (12) | 0 (13) | 1 (15) | 0 (14) |
| **10 ($AB'$)** | 0 (8) | 0 (9) | 1 (11) | 0 (10) |

Ανάλυση Πρωτευόντων Όρων (Prime Implicants):
- **Ομάδα 1 (Ολόκληρη η 3η στήλη $CD = 11$):**
  Καλύπτει τα κελιά $m(3, 7, 11, 15)$.
  Οι μεταβλητές $A$ και $B$ παίρνουν όλους τους συνδυασμούς και απαλείφονται.
  $$\text{Όρος 1} = C D$$
  Αυτός ο όρος είναι **ουσιώδης (essential prime implicant)** διότι αποτελεί τη μοναδική κάλυψη για τα minterms $m(11)$ και $m(15)$.
- **Κάλυψη του εναπομείναντος minterm $m(1)$:**
  Το κελί $m(1)$ μπορεί να ομαδοποιηθεί με δύο τρόπους αξιοποιώντας τις συνθήκες don't care:
  - *Επιλογή Α:* Ομάδα 4 κελιών στην 1η γραμμή ($AB = 00$): $d(0), m(1), m(3), d(2) \implies \overline{A}\overline{B}$.
  - *Επιλογή Β:* Ομάδα 4 κελιών $m(1), m(3), d(5), m(7) \implies \overline{A}D$.

Και οι δύο επιλογές έχουν το ίδιο κόστος (όρος 2 μεταβλητών). Επιλέγουμε:
$$F(A, B, C, D) = C D + \overline{A} D = D (C + \overline{A})$$
(Ισοδύναμα αποδεκτή είναι και η έκφραση $F = C D + \overline{A}\overline{B}$).

#### 2. Υλοποίηση Αποκλειστικά με Πύλες NOR 2-Εισόδων

Υπενθυμίζεται ότι η συνάρτηση NOR ορίζεται ως:
$$\text{NOR}(x, y) = \overline{x + y}$$
Επομένως:
- Αντιστροφέας (NOT): $\overline{x} = \text{NOR}(x, x)$.
- Πύλη OR: $x + y = \overline{\overline{x + y}} = \text{NOR}(\text{NOR}(x, y), \text{NOR}(x, y))$.
- Πύλη AND: $x \cdot y = \overline{\overline{x} + \overline{y}} = \text{NOR}(\overline{x}, \overline{y})$.

Ξεκινάμε από τη μορφή:
$$F = D (C + \overline{A})$$
Εφαρμόζουμε διπλό συμπλήρωμα και θεώρημα De Morgan:
$$F = \overline{\overline{D \cdot (C + \overline{A})}} = \overline{\overline{D} + \overline{(C + \overline{A})}}$$
Παρατηρούμε ότι:
$$\overline{\overline{D} + \overline{C + \overline{A}}} = \text{NOR}\Big(\overline{D}, \; \overline{C + \overline{A}}\Big)$$

Αναλυτική σύνθεση βαθμίδα προς βαθμίδα με πύλες NOR 2-εισόδων:
1. **Πύλη 1 (Inverter για το $A$):**
   $$U_1 = \text{NOR}(A, A) = \overline{A}$$
2. **Πύλη 2 (Inverter για το $D$):**
   $$U_2 = \text{NOR}(D, D) = \overline{D}$$
3. **Πύλη 3 (NOR μεταξύ $C$ και $\overline{A}$):**
   $$U_3 = \text{NOR}(C, U_1) = \overline{C + \overline{A}}$$
4. **Πύλη 4 (Τελική έξοδος NOR μεταξύ $U_2$ και $U_3$):**
   $$F = \text{NOR}(U_2, U_3) = \overline{U_2 + U_3} = \overline{\overline{D} + \overline{C + \overline{A}}} = \overline{\overline{D \cdot (C + \overline{A})}} = D(C + \overline{A})$$

Το κύκλωμα υλοποιείται πλήρως με **ακριβώς 4 πύλες NOR 2-εισόδων**.

### Λύση Θέματος 3: Σχεδίαση Σύγχρονου Ακολουθιακού Κυκλώματος

#### 1. Διάγραμμα Καταστάσεων (Mealy FSM)

Επιλέγουμε μοντέλο Mealy (απαιτεί λιγότερες καταστάσεις, άμεση απόκριση εξόδου).
Ορίζουμε τις καταστάσεις με βάση το ιστορικό εισόδου:
- $S_0$: Αρχική κατάσταση / Δεν υπάρχει συμβατό πρόθεμα (ιστορικό: κανένα bit ή `...0`).
- $S_1$: Έχει ανιχνευθεί '1' (ιστορικό: `...1`).
- $S_2$: Έχουν ανιχνευθεί '10' (ιστορικό: `...10`).

Μεταβάσεις και έξοδος $Z$ (συμβολισμός: $X / Z$):
- Από $S_0$:
  - Αν $X=0 \implies S_0 / 0$
  - Αν $X=1 \implies S_1 / 0$
- Από $S_1$:
  - Αν $X=0 \implies S_2 / 0$ (έχουμε `10`)
  - Αν $X=1 \implies S_1 / 0$ (το νέο '1' αποτελεί νέο πρόθεμα)
- Από $S_2$:
  - Αν $X=0 \implies S_0 / 0$ (ακολουθία `100`, αποτυχία, επαναφορά)
  - Αν $X=1 \implies S_1 / 1$ (ανιχνεύθηκε `101`! Έξοδος $Z=1$. Λόγω επικάλυψης, το τελευταίο '1' μπορεί να ξεκινήσει νέα ακολουθία, άρα μετάβαση στο $S_1$).

#### 2. Κωδικοποίηση και Πίνακας Μεταβάσεων

Χρησιμοποιούμε 2 D Flip-Flops με καταστάσεις $Q_1 Q_0$:
- $S_0 \equiv 00$
- $S_1 \equiv 01$
- $S_2 \equiv 10$
- $S_3 \equiv 11$ (Αχρησιμοποίητη / Don't Care)

Πίνακας Καταστάσεων και Διεγέρσεων ($D_1 = Q_1^+, D_0 = Q_0^+$):

| Παρούσα Κατάσταση $Q_1 Q_0$ | Είσοδος $X$ | Επόμενη Κατάσταση $Q_1^+ Q_0^+$ | Διεγέρσεις $D_1 D_0$ | Έξοδος $Z$ |
| :---: | :---: | :---: | :---: | :---: |
| 00 ($S_0$) | 0 | 00 | 00 | 0 |
| 00 ($S_0$) | 1 | 01 | 01 | 0 |
| 01 ($S_1$) | 0 | 10 | 10 | 0 |
| 01 ($S_1$) | 1 | 01 | 01 | 0 |
| 10 ($S_2$) | 0 | 00 | 00 | 0 |
| 10 ($S_2$) | 1 | 01 | 01 | 1 |
| 11 ($S_3$) | 0 | XX | XX | X |
| 11 ($S_3$) | 1 | XX | XX | X |

#### 3. Εξαγωγή Ελάχιστων Εξισώσεων Διέγερσης και Εξόδου

Χρησιμοποιούμε χάρτες Karnaugh 3 μεταβλητών ($Q_1 Q_0, X$):

- **Για το $D_1$:**
  - $m(Q_1, Q_0, X) = 1$ μόνο στο κελί $010$ (δηλ. $Q_1=0, Q_0=1, X=0$).
  - Don't cares στα κελιά $110, 111$.
  - Δεν υπάρχει δυνατότητα ομαδοποίησης με don't care χωρίς να επηρεαστεί το $X=0$.
  $$D_1 = \overline{Q_1} \cdot Q_0 \cdot \overline{X}$$

- **Για το $D_0$:**
  - $m(Q_1, Q_0, X) = 1$ στα κελιά $001, 011, 101$.
  - Don't care στο κελί $111$.
  - Ομαδοποιώντας τα κελιά $001, 011, 101, 111$ (ολόκληρη η στήλη $X=1$):
  $$D_0 = X$$

- **Για την έξοδο $Z$:**
  - $Z=1$ μόνο όταν είμαστε στο $S_2$ ($10$) και έρθει $X=1$, δηλαδή στο κελί $101$.
  - Don't care στο κελί $111$.
  - Ομαδοποιώντας τα κελιά $101$ και $111$:
  $$Z = Q_1 \cdot X$$

#### 4. Έλεγχος Αυτοδιόρθωσης (Self-Correction)

Ελέγχουμε τι συμβαίνει εάν το κύκλωμα εκκινήσει τυχαία στην αχρησιμοποίητη κατάσταση $11$ ($S_3$):
- Αν $X=0$: $D_1 = 0 \cdot 1 \cdot 1 = 0$, $D_0 = 0 \implies Q_1^+ Q_0^+ = 00$ ($S_0$).
- Αν $X=1$: $D_1 = 0 \cdot 1 \cdot 0 = 0$, $D_0 = 1 \implies Q_1^+ Q_0^+ = 01$ ($S_1$).
Σε κάθε περίπτωση, το κύκλωμα μεταβαίνει άμεσα σε έγκυρη κατάσταση μέσα σε 1 κύκλο ρολογιού, άρα είναι πλήρως αυτοδιορθούμενο.

### Λύση Θέματος 4: Περιγραφή Υλικού σε VHDL

#### 1. Πλήρης Κώδικας VHDL

```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

-- Οντότητα (Entity): Καθορισμός θυρών εισόδου/εξόδου
entity mux4to1_8bit is
    Port (
        d0     : in  STD_LOGIC_VECTOR(7 downto 0); -- Είσοδος δεδομένων 0
        d1     : in  STD_LOGIC_VECTOR(7 downto 0); -- Είσοδος δεδομένων 1
        d2     : in  STD_LOGIC_VECTOR(7 downto 0); -- Είσοδος δεδομένων 2
        d3     : in  STD_LOGIC_VECTOR(7 downto 0); -- Είσοδος δεδομένων 3
        sel    : in  STD_LOGIC_VECTOR(1 downto 0); -- Γραμμές επιλογής
        enable : in  STD_LOGIC;                    -- Σήμα ενεργοποίησης (active-high)
        y      : out STD_LOGIC_VECTOR(7 downto 0)  -- Έξοδος δεδομένων
    );
end mux4to1_8bit;

-- Αρχιτεκτονική Συμπεριφοράς (Behavioral Architecture)
architecture Behavioral of mux4to1_8bit is
begin
    -- Συνδυαστική διεργασία: πλήρης λίστα ευαισθησίας
    process(d0, d1, d2, d3, sel, enable)
    begin
        if enable = '0' then
            -- Όταν το κύκλωμα είναι απενεργοποιημένο, η έξοδος μηδενίζεται
            y <= (others => '0');
        else
            -- Δομή επιλογής case για ανάθεση εξόδου βάσει sel
            case sel is
                when "00" =>
                    y <= d0;
                when "01" =>
                    y <= d1;
                when "10" =>
                    y <= d2;
                when "11" =>
                    y <= d3;
                when others =>
                    y <= (others => '0');
            end case;
        end if;
    end process;
end Behavioral;
```

#### 2. Τεχνική Ανάλυση & Αποτροπή Δημιουργίας Μανδαλωτών (Latches)

- **Πλήρης Λίστα Ευαισθησίας:** Η διεργασία περιλαμβάνει όλα τα σήματα εισόδου `(d0, d1, d2, d3, sel, enable)`. Αν παραλειπόταν κάποιο σήμα (π.χ. το `d0`), ο προσομοιωτής δεν θα ενημέρωνε την έξοδο κατά τη μεταβολή του, προκαλώντας ασυμφωνία προσομοίωσης και σύνθεσης (simulation-synthesis mismatch).
- **Αποτροπή Δημιουργίας Latch:**
  Σε συνδυαστικά κυκλώματα VHDL, ένα ανεπιθύμητο latch παράγεται από τα εργαλεία σύνθεσης όταν υπάρχει διαδρομή εκτέλεσης στην οποία η τιμή μιας εξόδου δεν ανατίθεται ρητά, αναγκάζοντας το κύκλωμα να διατηρήσει την προηγούμενη τιμή του.
  Στον παραπάνω κώδικα:
  1. Το `if enable = '0'` καλύπτει τη συνθήκη απενεργοποίησης με ρητή ανάθεση `y <= (others => '0')`.
  2. Το αντίστοιχο `else` καλύπτει όλες τις περιπτώσεις `enable = '1'`.
  3. Η εντολή `case` καλύπτει και τις 4 δυνατές τιμές του διανύσματος 2-bit (`"00"`, `"01"`, `"10"`, `"11"`), ενώ ο κλάδος `when others =>` εξασφαλίζει κάλυψη για τυχόν μετασταθείς καταστάσεις του `STD_LOGIC` (`'U'`, `'X'`, `'Z'`, κτλ.).
  Συνεπώς, σε κάθε πιθανό συνδυασμό εισόδων υπάρχει πλήρης και σαφής ανάθεση τιμής στο `y`, διασφαλίζοντας 100% καθαρή συνδυαστική σύνθεση πολυπλέκτη.
