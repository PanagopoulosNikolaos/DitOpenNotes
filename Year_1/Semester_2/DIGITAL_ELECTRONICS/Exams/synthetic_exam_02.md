## Αναλυτικές Βηματικές Λύσεις

### Λύση Θέματος 1: Ανάλυση Κινδύνων (Hazards) και Θεώρημα Συναίνεσης

#### 1. Ανάλυση Στατικού Κινδύνου 1 (Static-1 Hazard)

Ένα συνδυαστικό κύκλωμα παρουσιάζει **Static-1 Hazard** όταν, κατά τη μετάβαση μιας εισόδου μεταξύ δύο συνδυασμών που κανονικά διατηρούν την έξοδο στο λογικό '1', η έξοδος στιγμιαία μηδενίζεται (παράγεται ανεπιθύμητος παλμός σφάλματος / glitch $1 \rightarrow 0 \rightarrow 1$) λόγω άνισων καθυστερήσεων διάδοσης στα λογικά μονοπάτια.

Δίνεται η συνάρτηση:
$$F = A B + \overline{A} C$$
Έστω ότι $B = 1$ και $C = 1$. Τότε:
$$F = A \cdot 1 + \overline{A} \cdot 1 = A + \overline{A} = 1$$
Θεωρητικά η έξοδος πρέπει να είναι σταθερά '1' ανεξάρτητα από την τιμή του $A$.

Εξετάζουμε τη μετάβαση του $A$ από $1 \rightarrow 0$:
- Αρχικά $A = 1 \implies A B = 1, \overline{A} C = 0 \implies F = 1$.
- Τη χρονική στιγμή $t_0$, το σήμα $A$ μεταβαίνει από $1 \rightarrow 0$.
- Η πύλη AND του όρου $A B$ απενεργοποιείται σχεδόν άμεσα, οπότε $A B \rightarrow 0$.
- Ωστόσο, το σήμα $\overline{A}$ παράγεται μέσω ενός αντιστροφέα (NOT gate) που εισάγει καθυστέρηση διάδοσης $\Delta t$.
- Κατά το χρονικό διάστημα $[t_0, t_0 + \Delta t]$, ισχύει $A = 0$ αλλά ακόμα $\overline{A} = 0$.
- Συνεπώς, και οι δύο όροι γίνονται μηδέν: $A B = 0$ και $\overline{A} C = 0$.
- Η έξοδος της πύλης OR γίνεται στιγμιαία $F = 0 + 0 = 0$, δημιουργώντας έναν παλμό σφάλματος διάρκειας $\Delta t$.

#### 2. Εντοπισμός στον Χάρτη Karnaugh

Στον χάρτη Karnaugh 3 μεταβλητών ($A$ στις γραμμές $\{0, 1\}$, $BC$ στις στήλες $\{00, 01, 11, 10\}$):
- Ο όρος $A B$ καλύπτει τα minterms $m(6) = 110_2$ και $m(7) = 111_2$.
- Ο όρος $\overline{A} C$ καλύπτει τα minterms $m(1) = 001_2$ και $m(3) = 011_2$.

Παρατηρούμε τα κελιά $m(7) = 111$ ($A=1, B=1, C=1$) και $m(3) = 011$ ($A=0, B=1, C=1$):
- Και τα δύο κελιά έχουν τιμή 1 και είναι λογικά γειτονικά (διαφέρουν μόνο στο bit $A$).
- Ωστόσο, ανήκουν σε **διαφορετικούς πρωτεύοντες όρους** ($m(7) \in AB$, ενώ $m(3) \in \overline{A}C$).
- Κάθε φορά που η είσοδος μεταβαίνει ανάμεσα σε δύο γειτονικά minterms που δεν περικλείονται σε κοινή ομάδα (κοινό κύβο), εμφανίζεται στατικός κίνδυνος.

#### 3. Εξάλειψη Κινδύνου με τον Όρο Συναίνεσης

Σύμφωνα με το **Θεώρημα Συναίνεσης (Consensus Theorem)**:
$$X Y + \overline{X} Z + Y Z = X Y + \overline{X} Z$$
Ο όρος $Y Z$ ονομάζεται όρος συναίνεσης (consensus term) των $X Y$ και $\overline{X} Z$.

Εδώ, με $X = A, Y = B, Z = C$, ο όρος συναίνεσης είναι το $B C$.
Προσθέτοντας τον όρο $B C$ στη συνάρτηση:
$$F_{hazard\_free} = A B + \overline{A} C + B C$$

**Απόδειξη Ισοδυναμίας:**
$$A B + \overline{A} C + B C = A B + \overline{A} C + B C (A + \overline{A}) = A B + A B C + \overline{A} C + \overline{A} B C = A B (1 + C) + \overline{A} C (1 + B) = A B + \overline{A} C$$

**Γιατί εξαλείφεται ο κίνδυνος:**
Όταν $B = 1$ και $C = 1$, ο νέος όρος $B C = 1 \cdot 1 = 1$ διατηρεί ανεξάρτητα την έξοδο στο '1', γεφυρώνοντας τη μετάβαση του $A$ και αποτρέποντας πλήρως τον παλμό σφάλματος.

### Λύση Θέματος 2: Σύνθεση Συνδυαστικών Κυκλωμάτων MSI

#### 1. Υλοποίηση με Πολυπλέκτη 8-σε-1 (74151)

Δίνεται:
$$F(A, B, C, D) = \sum m(1, 3, 4, 11, 12, 13, 14, 15)$$
Συνδέουμε τις 3 πιο σημαντικές μεταβλητές στις γραμμές επιλογής του MUX:
$$S_2 = A, \quad S_1 = B, \quad S_0 = C$$
Κάθε είσοδος $I_k$ ($k \in [0, 7]$) αντιστοιχεί στο ζεύγος minterms $m(2k)$ (για $D=0$) και $m(2k+1)$ (για $D=1$).

Κατασκευάζουμε τον πίνακα αντιστοίχισης:

| Είσοδος MUX | Επιλογή $ABC$ | Minterm για $D=0$ | Minterm για $D=1$ | Τιμή Εξόδου $F$ | Σύνδεση Εισόδου $I_k$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $I_0$ | 000 | $m(0) = 0$ | $m(1) = 1$ | $F = D$ | $D$ |
| $I_1$ | 001 | $m(2) = 0$ | $m(3) = 1$ | $F = D$ | $D$ |
| $I_2$ | 010 | $m(4) = 1$ | $m(5) = 0$ | $F = \overline{D}$ | $\overline{D}$ |
| $I_3$ | 011 | $m(6) = 0$ | $m(7) = 0$ | $F = 0$ | $0$ (GND) |
| $I_4$ | 100 | $m(8) = 0$ | $m(9) = 0$ | $F = 0$ | $0$ (GND) |
| $I_5$ | 101 | $m(10) = 0$ | $m(11) = 1$ | $F = D$ | $D$ |
| $I_6$ | 110 | $m(12) = 1$ | $m(13) = 1$ | $F = 1$ | $1$ ($V_{CC}$) |
| $I_7$ | 111 | $m(14) = 1$ | $m(15) = 1$ | $F = 1$ | $1$ ($V_{CC}$) |

**Συνδεσμολογία MUX 8:1:**
- Γραμμές επιλογής: $S_2 = A$, $S_1 = B$, $S_0 = C$.
- Είσοδοι δεδομένων:
  $$I_0 = D, \quad I_1 = D, \quad I_2 = \overline{D}, \quad I_3 = 0, \quad I_4 = 0, \quad I_5 = D, \quad I_6 = 1, \quad I_7 = 1$$
- Απαιτείται μόνο ένας εξωτερικός αντιστροφέας για την παραγωγή του $\overline{D}$.

#### 2. Υλοποίηση με Αποκωδικοποιητή 3:8 (Active-Low) και μία πύλη NAND

Δίνεται:
$$G(A, B, C) = \sum m(0, 2, 6, 7)$$
Ένας αποκωδικοποιητής 3-σε-8 με ενεργές χαμηλές εξόδους παράγει:
$$\overline{Y_k} = \overline{m_k}$$
Δηλαδή, η έξοδος $\overline{Y_k}$ γίνεται '0' όταν η είσοδος αντιστοιχεί στον αριθμό $k$, και '1' σε κάθε άλλη περίπτωση.

Η συνάρτηση $G$ εκφράζεται ως άθροισμα minterms:
$$G = m_0 + m_2 + m_6 + m_7$$
Εφαρμόζουμε διπλό συμπλήρωμα και θεώρημα De Morgan:
$$G = \overline{\overline{m_0 + m_2 + m_6 + m_7}} = \overline{\overline{m_0} \cdot \overline{m_2} \cdot \overline{m_6} \cdot \overline{m_7}}$$
Αντικαθιστούμε τις εξόδους του αποκωδικοποιητή $\overline{m_k} = \overline{Y_k}$:
$$G = \overline{\overline{Y_0} \cdot \overline{Y_2} \cdot \overline{Y_6} \cdot \overline{Y_7}} = \text{NAND}\Big(\overline{Y_0}, \overline{Y_2}, \overline{Y_6}, \overline{Y_7}\Big)$$

**Συνδεσμολογία:**
- Οι είσοδοι του αποκωδικοποιητή $A_2, A_1, A_0$ συνδέονται στα σήματα $A, B, C$.
- Οι γραμμές εξόδου $\overline{Y_0}, \overline{Y_2}, \overline{Y_6}, \overline{Y_7}$ οδηγούνται απευθείας στις 4 εισόδους μιας πύλης NAND.
- Η έξοδος της πύλης NAND παράγει ακριβώς τη συνάρτηση $G$.

### Λύση Θέματος 3: Σχεδίαση Σύγχρονου Μετρητή Modulo-6 με JK Flip-Flops

#### 1. Πίνακας Διεγέρσεων

Υπενθυμίζεται ο πίνακας διέγερσης του JK Flip-Flop:

| Μετάβαση $Q \rightarrow Q^+$ | Απαιτούμενες Είσοδοι $J, K$ |
| :---: | :---: |
| $0 \rightarrow 0$ | $J = 0, \quad K = X$ |
| $0 \rightarrow 1$ | $J = 1, \quad K = X$ |
| $1 \rightarrow 0$ | $J = X, \quad K = 1$ |
| $1 \rightarrow 1$ | $J = X, \quad K = 0$ |

Η ακολουθία μέτρησης είναι: $000 \rightarrow 001 \rightarrow 010 \rightarrow 011 \rightarrow 100 \rightarrow 101 \rightarrow 000$.
Οι καταστάσεις $110$ (6) και $111$ (7) είναι Don't Cares.

Πλήρης Πίνακας Μεταβάσεων και Διεγέρσεων:

| Κατάσταση | Παρούσα $Q_2 Q_1 Q_0$ | Επόμενη $Q_2^+ Q_1^+ Q_0^+$ | $J_2, K_2$ | $J_1, K_1$ | $J_0, K_0$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 0 | 0 0 0 | 0 0 1 | 0, X | 0, X | 1, X |
| 1 | 0 0 1 | 0 1 0 | 0, X | 1, X | X, 1 |
| 2 | 0 1 0 | 0 1 1 | 0, X | X, 0 | 1, X |
| 3 | 0 1 1 | 1 0 0 | 1, X | X, 1 | X, 1 |
| 4 | 1 0 0 | 1 0 1 | X, 0 | 0, X | 1, X |
| 5 | 1 0 1 | 0 0 0 | X, 1 | 0, X | X, 1 |
| 6 | 1 1 0 | X X X | X, X | X, X | X, X |
| 7 | 1 1 1 | X X X | X, X | X, X | X, X |

#### 2. Απλοποίηση με Χάρτες Karnaugh

- **Για το $J_0$ και $K_0$:**
  - $J_0$: Έχει 1 στα κελιά 0, 2, 4 και $X$ στα κελιά 1, 3, 5, 6, 7. Όλος ο χάρτης είναι 1 ή $X$.
    $$J_0 = 1$$
  - $K_0$: Έχει 1 στα κελιά 1, 3, 5 και $X$ στα κελιά 0, 2, 4, 6, 7. Όλος ο χάρτης είναι 1 ή $X$.
    $$K_0 = 1$$
  (Το Flip-Flop 0 λειτουργεί ως T Flip-Flop αναστρέφοντας σε κάθε παλμό ρολογιού).

- **Για το $J_1$ και $K_1$:**
  - $J_1$: 1 στο κελί 1 ($001$). Don't cares στα κελιά 2, 3, 6, 7.
    Ομαδοποιούμε τα κελιά 1 και 3 (με $Q_2 = 0$ και $Q_0 = 1$):
    $$J_1 = \overline{Q_2} \cdot Q_0$$
  - $K_1$: 1 στο κελί 3 ($011$). Don't cares στα κελιά 0, 1, 4, 5, 6, 7.
    Ομαδοποιούμε τα κελιά 3 και 7 ($Q_1=1, Q_0=1$):
    $$K_1 = Q_0$$

- **Για το $J_2$ και $K_2$:**
  - $J_2$: 1 στο κελί 3 ($011$). Don't cares στα κελιά 4, 5, 6, 7.
    Ομαδοποιούμε τα κελιά 3 και 7:
    $$J_2 = Q_1 \cdot Q_0$$
  - $K_2$: 1 στο κελί 5 ($101$). Don't cares στα κελιά 0, 1, 2, 3, 6, 7.
    Ομαδοποιούμε τα κελιά 5 και 7:
    $$K_2 = Q_0$$

#### 3. Έλεγχος Αυτοδιόρθωσης (Self-Starting Verification)

Υπολογίζουμε τις τιμές των διεγέρσεων και την επόμενη κατάσταση για τις μη χρησιμοποιούμενες καταστάσεις:

- **Αρχική Κατάσταση $Q_2 Q_1 Q_0 = 110$ (Κατάσταση 6):**
  - $J_0 = 1, K_0 = 1 \implies Q_0^+ = \overline{Q_0} = 1$.
  - $J_1 = \overline{Q_2} Q_0 = 0 \cdot 0 = 0, \quad K_1 = Q_0 = 0 \implies Q_1^+ = Q_1 = 1$ (διατήρηση).
  - $J_2 = Q_1 Q_0 = 1 \cdot 0 = 0, \quad K_2 = Q_0 = 0 \implies Q_2^+ = Q_2 = 1$ (διατήρηση).
  - Επόμενη κατάσταση: $Q_2^+ Q_1^+ Q_0^+ = 111$ (Κατάσταση 7).

- **Κατάσταση $Q_2 Q_1 Q_0 = 111$ (Κατάσταση 7):**
  - $J_0 = 1, K_0 = 1 \implies Q_0^+ = \overline{Q_0} = 0$.
  - $J_1 = \overline{Q_2} Q_0 = 0 \cdot 1 = 0, \quad K_1 = Q_0 = 1 \implies Q_1^+ = 0$ (μηδενισμός).
  - $J_2 = Q_1 Q_0 = 1 \cdot 1 = 1, \quad K_2 = Q_0 = 1 \implies Q_2^+ = \overline{Q_2} = 0$ (αναστροφή).
  - Επόμενη κατάσταση: $Q_2^+ Q_1^+ Q_0^+ = 000$ (Κατάσταση 0).

**Συμπέρασμα:**
Από την κατάσταση 6 το κύκλωμα μεταβαίνει στην 7, και από την 7 μεταβαίνει απευθείας στην έγκυρη κατάσταση 0 του κανονικού κύκλου. Δεν υπάρχει κλειστός βρόχος εκτός ακολουθίας, άρα ο μετρητής είναι **πλήρως αυτοδιορθούμενος (self-starting)**.

### Λύση Θέματος 4: Περιγραφή Σύγχρονης Μηχανής Moore σε VHDL

#### 1. Διάγραμμα Καταστάσεων Moore

Σε μια μηχανή Moore, η έξοδος εξαρτάται **αποκλειστικά από την παρούσα κατάσταση** και όχι άμεσα από την είσοδο.
Για την ανίχνευση της ακολουθίας `110` με επικάλυψη απαιτούνται 4 καταστάσεις:
- $S_0$ (Κατάσταση Reset / Κανένα έγκυρο bit): Έξοδος $Z = 0$.
- $S_1$ (Έχει ανιχνευθεί '1'): Έξοδος $Z = 0$.
- $S_2$ (Έχουν ανιχνευθεί '11'): Έξοδος $Z = 0$.
- $S_3$ (Έχει ανιχνευθεί πλήρως '110'): Έξοδος $Z = 1$.

Μεταβάσεις Καταστάσεων:
- Από $S_0$: Αν $X=1 \rightarrow S_1$, αν $X=0 \rightarrow S_0$.
- Από $S_1$: Αν $X=1 \rightarrow S_2$, αν $X=0 \rightarrow S_0$.
- Από $S_2$: Αν $X=1 \rightarrow S_2$ (το δεύτερο '1' διατηρεί το πρόθεμα `11`), αν $X=0 \rightarrow S_3$ (ολοκλήρωση `110`).
- Από $S_3$:
  - Αν $X=0 \rightarrow S_0$ (ακολουθία `1100`, επανεκκίνηση).
  - Αν $X=1 \rightarrow S_1$ (λόγω επικάλυψης, το '1' αποτελεί την αρχή νέας πιθανής ακολουθίας).

#### 2. Πλήρης Συνθέσιμος Κώδικας VHDL (Two-Process Model)

```vhdl
library IEEE;
use IEEE.STD_LOGIC_1164.ALL;

entity fsm_moore_110 is
    Port (
        clk   : in  STD_LOGIC; -- Ρολόι συστήματος
        reset : in  STD_LOGIC; -- Ασύγχρονη επαναφορά (active-high)
        x     : in  STD_LOGIC; -- Σειριακή είσοδος δεδομένων
        z     : out STD_LOGIC  -- Έξοδος ανίχνευσης Moore
    );
end fsm_moore_110;

architecture Behavioral of fsm_moore_110 is
    -- Ορισμός απαριθμητού τύπου (enumerated type) για τις καταστάσεις
    type state_type is (S0, S1, S2, S3);
    signal current_state, next_state : state_type;
begin

    -- Διεργασία 1: Σύγχρονος Καταχωρητής Κατάστασης με Ασύγχρονο Reset
    process(clk, reset)
    begin
        if reset = '1' then
            current_state <= S0;
        elsif rising_edge(clk) then
            current_state <= next_state;
        end if;
    end process;

    -- Διεργασία 2: Συνδυαστική Λογική Επόμενης Κατάστασης & Εξόδου Moore
    process(current_state, x)
    begin
        -- Προεπιλεγμένες τιμές για αποφυγή latch
        next_state <= current_state;
        z <= '0';

        case current_state is
            when S0 =>
                z <= '0';
                if x = '1' then
                    next_state <= S1;
                else
                    next_state <= S0;
                end if;

            when S1 =>
                z <= '0';
                if x = '1' then
                    next_state <= S2;
                else
                    next_state <= S0;
                end if;

            when S2 =>
                z <= '0';
                if x = '1' then
                    next_state <= S2;
                else
                    next_state <= S3;
                end if;

            when S3 =>
                z <= '1'; -- Η έξοδος είναι ενεργή αποκλειστικά στην κατάσταση S3
                if x = '1' then
                    next_state <= S1; -- Επικάλυψη: το '1' εκκινεί νέα ακολουθία
                else
                    next_state <= S0;
                end if;

            when others =>
                next_state <= S0;
                z <= '0';
        end case;
    end process;

end Behavioral;
```
