# Ασκήσεις Εμπέδωσης: Άλγεβρα Boole και Χάρτες Karnaugh

## Άσκηση 1: Ελαχιστοποίηση με Χάρτη Karnaugh 4 Μεταβλητών

### Εκφώνηση
Δίνεται η λογική συνάρτηση τεσσάρων μεταβλητών $F(A, B, C, D) = \sum m(0, 2, 5, 7, 8, 10, 13, 15)$.
1. Σχεδιάστε τον χάρτη Karnaugh.
2. Βρείτε τους πρωτεύοντες όρους (Prime Implicants).
3. Βρείτε την ελάχιστη μορφή Αθροίσματος Γινομένων (SOP).

### Λύση
1. **Διάταξη K-Map:**
   - Στις γραμμές $AB \in \{00, 01, 11, 10\}$ και στις στήλες $CD \in \{00, 01, 11, 10\}$.
   - Τα minterms $0, 2, 8, 10$ βρίσκονται στις 4 γωνίες του K-Map.
   - Τα minterms $5, 7, 13, 15$ βρίσκονται στο εσωτερικό τετράγωνο $B=1, D=1$.

2. **Ομαδοποίηση:**
   - Ομάδα 1 (4 γωνίες): $m(0, 2, 8, 10) \Rightarrow \overline{B}\overline{D}$.
   - Ομάδα 2 (μεσαία τετράδα): $m(5, 7, 13, 15) \Rightarrow B D$.

3. **Ελάχιστη Έκφραση:**
   $$F(A, B, C, D) = \overline{B}\overline{D} + B D = \overline{B \oplus D}$$

## Άσκηση 2: Υλοποίηση Συνάρτησης με Πολυπλέκτη (MUX 4:1)

### Εκφώνηση
Υλοποιήστε τη συνάρτηση $F(A, B, C) = \sum m(1, 2, 6, 7)$ χρησιμοποιώντας έναν πολυπλέκτη 4-σε-1 με γραμμές επιλογής $S_1 = A, S_0 = B$.

### Λύση
Αναλύουμε τις εισόδους δεδομένων $I_0, I_1, I_2, I_3$ ως συνάρτηση της μεταβλητής $C$:
- Για $AB = 00$ ($I_0$): $m(0)=0, m(1)=1 \Rightarrow I_0 = C$.
- Για $AB = 01$ ($I_1$): $m(2)=1, m(3)=0 \Rightarrow I_1 = \overline{C}$.
- Για $AB = 10$ ($I_2$): $m(4)=0, m(5)=0 \Rightarrow I_2 = 0$.
- Για $AB = 11$ ($I_3$): $m(6)=1, m(7)=1 \Rightarrow I_3 = 1$.

**Συνδεσμολογία:**
- $S_1 = A$, $S_0 = B$.
- $I_0 = C$, $I_1 = \overline{C}$, $I_2 = 0$, $I_3 = 1$.
