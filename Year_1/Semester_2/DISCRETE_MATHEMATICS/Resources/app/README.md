# Course 203: Διακριτά Μαθηματικά — Εκπαιδευτική Εφαρμογή & Διαδραστικό Εργαστήριο

Μία σύγχρονη, διαδραστική εκπαιδευτική εφαρμογή και πίνακας ελέγχου (dashboard) σε Python με χρήση του framework NiceGUI, ειδικά σχεδιασμένη για το μάθημα **203: Διακριτά Μαθηματικά** του Τμήματος Πληροφορικής και Τηλεπικοινωνιών (Πανεπιστήμιο Ιωαννίνων).

---

## 1. Βασικά Χαρακτηριστικά

1. **Διαδραστικό Αλγοριθμικό Εργαστήριο (Algorithmic Workbench)**:
   - **Γράφοι & Επίπεδη Σχεδίαση**: Οπτικοποίηση κορυφών και ακμών σε SVG, βήμα-προς-βήμα διάσχιση BFS / DFS, υπολογισμός βαθμών κορυφών, επαλήθευση του Θεωρήματος Χειραψιών ($\sum \deg(v) = 2|E|$) και του τύπου του Euler ($V - E + R = 2$).
   - **Αυτόματος Παραγωγός Πινάκων Αληθείας**: Δυναμική κατασκευή πινάκων αληθείας για προτασιακούς τύπους (Υποθετικός Συλλογισμός, De Morgan, Modus Ponens, κ.ά.) με έλεγχο ταυτολογίας ή ενδεχόμενου τύπου.
   - **Διαγράμματα Venn & Αρχή Εγκλεισμού - Αποκλεισμού (PIE)**: Οπτικοποίηση συνόλων, επιλογή πράξεων ($A \cup B, A \cap B, A \setminus B, A \oplus B, (A \cup B)^c$) και υπολογισμός πληθικοτήτων.
   - **Προσομοιωτής Αυτομάτων DFA**: Έλεγχος συμβολοσειρών εισόδου σε πραγματικό χρόνο, ιχνηλάτηση διαδρομής καταστάσεων και απόφαση αποδοχής / απόρριψης.
   - **Διαδραστικό Carousel Μαθηματικής Επαγωγής**: Βήμα-προς-βήμα παρουσίαση αποδείξεων (Βασικό Βήμα, Επαγωγική Υπόθεση, Επαγωγικό Βήμα με αλγεβρική αντικατάσταση, Συμπέρασμα).

2. **Πλήρεις Λύσεις Εξετάσεων ανά Ομάδα (A, B, C, D)**:
   - **Τελική Εξέταση Ιουνίου 2025**: Πλήρης ανάλυση και των 9 θεμάτων με KaTeX μαθηματικές εξισώσεις και επισήμανση καθηγητικών παγίδων.
   - **Τελική Εξέταση Ιουνίου 2026**: Πλήρης ανάλυση και των 10 θεμάτων (Συλλογισμοί, PIE μηχανογραφικών, Συνδυαστική ηθοποιών, Bayes για LLM hallucinations, Διαγράμματα Hasse, Επιπεδότητα).
   - **Προσομοίωση 1 (Foundations)**: Σύνολα, πίνακες αληθείας, θεώρημα χειραψιών, επαγωγή.
   - **Προσομοίωση 2 (Automata & Relations)**: Κλειστότητες σχέσεων, σχεδιασμός DFA, κυκλώματα Euler/Hamilton, συνδυαστικές πιθανότητες.

3. **Οδηγός Θεωρίας & Ύλης (Master Theory Handbook)**:
   - Συνοπτική καταγραφή θεωρητικών ορισμών, θεωρημάτων, κανόνων συμπερασμού και τυπολογίου και για τις 7 θεματικές ενότητες του μαθήματος.

4. **Διπλό Θέμα & Εξαγωγή A4**:
   - Υποστήριξη Orange Light (προεπιλογή) και Soft Dark θεμάτων.
   - Μενού εξαγωγής σε εκτυπώσιμο A4 PDF.

## 3. Οδηγίες Εγκατάστασης & Εκτέλεσης

### Βήμα 1: Μετάβαση στον κατάλογο της εφαρμογής

```bash
cd Year_1/Semester_2/DISCRETE_MATHEMATICS/Resources/app
```

### Βήμα 2: Εγκατάσταση Εξαρτήσεων

```bash
pip install -r requirements.txt
```

### Βήμα 3: Εκτέλεση της Εφαρμογής

```bash
python3 main.py
```

Η εφαρμογή θα ανοίξει αυτόματα στον περιηγητή στη διεύθυνση `http://localhost:8080`.
