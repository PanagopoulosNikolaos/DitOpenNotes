## Ενδεικτικές Λύσεις

### Λύση Θέματος 1
1. **Αντιστοίχιση Επιπέδων:**
   - Επίπεδο Εφαρμογής OSI (Application, Presentation, Session) $\leftrightarrow$ Application Layer (TCP/IP).
   - Επίπεδο Μεταφοράς (Transport) $\leftrightarrow$ Transport Layer (TCP, UDP).
   - Επίπεδο Δικτύου (Network) $\leftrightarrow$ Internet Layer (IP, ICMP, ARP).
   - Επίπεδο Ζεύξης & Φυσικό (Data Link, Physical) $\leftrightarrow$ Network Access / Link Layer.
2. **PDUs και Ενθυλάκωση:** Data $\rightarrow$ Segment (TCP) / Datagram (UDP) $\rightarrow$ Packet (IP) $\rightarrow$ Frame (Ethernet) $\rightarrow$ Bits.
3. **MAC vs IP:** Η MAC είναι φυσική/σταθερή διεύθυνση 48-bit για τοπική παράδοση στο επίπεδο ζεύξης (L2), ενώ η IP είναι λογική/ιεραρχική διεύθυνση 32-bit (IPv4) για δρομολόγηση μεταξύ διαφορετικών δικτύων (L3).
