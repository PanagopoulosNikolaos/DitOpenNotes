# Recommended Resources: Computer Networking and Telecommunications

This document compiles authoritative textbooks, RFC protocol standards, online packet inspection tools, and network simulation platforms for computer networking.

---

## 1. Classical Textbooks and Academic References

* **Computer Networking: A Top-Down Approach (8th Edition)**  
  *Authors:* James F. Kurose, Keith W. Ross  
  *Description:* Renowned top-down pedagogy beginning at the application layer and descending to physical transport, featuring interactive Wireshark lab assignments.

* **Computer Networks (6th Edition)**  
  *Authors:* Andrew S. Tanenbaum, David J. Wetherall, Nick Feamster  
  *Description:* Comprehensive treatise covering hardware layer physical mediums, link layer framing, protocol verification, and distributed routing algorithms.

* **TCP/IP Illustrated, Volume 1: The Protocols (2nd Edition)**  
  *Authors:* W. Richard Stevens, Kevin R. Fall  
  *Description:* The gold-standard practical reference for understanding TCP/IP header interactions through packet traces and operating system kernel implementations.

## 2. Standards and Technical Specifications (IETF RFCs)

* **RFC 791**: Internet Protocol (IPv4 Specification)  
  *Reference:* [https://www.rfc-editor.org/rfc/rfc791](https://www.rfc-editor.org/rfc/rfc791)
* **RFC 793 / RFC 9293**: Transmission Control Protocol (TCP Specification)  
  *Reference:* [https://www.rfc-editor.org/rfc/rfc9293](https://www.rfc-editor.org/rfc/rfc9293)
* **RFC 1034 & RFC 1035**: Domain Names - Concepts, Facilities, and Implementation  
  *Reference:* [https://www.rfc-editor.org/rfc/rfc1035](https://www.rfc-editor.org/rfc/rfc1035)
* **RFC 4632**: Classless Inter-domain Routing (CIDR) Address Allocation  
  *Reference:* [https://www.rfc-editor.org/rfc/rfc4632](https://www.rfc-editor.org/rfc/rfc4632)

## 3. Network Analysis and Simulation Tooling

* **Wireshark and TShark (Network Protocol Analyzer)**  
  *Website:* [https://www.wireshark.org/](https://www.wireshark.org/)  
  *Documentation:* [https://www.wireshark.org/docs/](https://www.wireshark.org/docs/)  
  *Usage:* Industry standard packet capture and deep protocol inspection utility.

* **tcpdump & libpcap**  
  *Website:* [https://www.tcpdump.org/](https://www.tcpdump.org/)  
  *Usage:* Powerful command-line packet capture tool utilizing BPF kernel filtering.

* **Cisco Packet Tracer & GNS3**  
  *Websites:* [https://www.netacad.com/courses/packet-tracer](https://www.netacad.com/courses/packet-tracer) / [https://www.gns3.com/](https://www.gns3.com/)  
  *Usage:* Network simulation and emulation environments for configuring virtual routers, switches, and complex internetworks.
