## OSI Model Levels

**1. Physical Layer:**

- Converts data to electrical signals
- Provides interface

**2. Data Link Layer:**

- Provides connection to the Network Adapter
- Maintains logical connections

**3. Network Layer:**

- Supports logical addressing
- Handles routing

**4. Transport Layer:**

- Provides error control
- Provides flow control for the network

**5. Session Layer:**

- Defines sessions between communicating applications

**6. Presentation Layer:**

- Translates data to a standard format
- Manages encryption and compression

**7. Application Layer:**

- Supports network applications

## Basic TCP/IP Levels

**1. Network Access Layer:**

- Provides physical connection to the network
- Formats data accordingly

**2. Internet Layer:**

- Provides logical addressing for routing data

**3. Transport Layer (TCP):**

- Provides flow and error control
- Offers notification services

**4. Application Layer:**

- Supports network applications
- Provides API for network access

## Basic Functions of TCP/IP

- Segmentation of messages into complete data sections
- Connection to the network adapter
- Addressing of data and host computer
- Sending data to the network
- Routing data to the destination
- Receiving data
- Performing error control, flow control and notification

## Data Packets in TCP/IP

|   |   |   |
|---|---|---|
|Packet Type|Level|Description|
|message|Application Layer|Data packet created at the application layer|
|segment|TCP Transport Layer|Data packet from TCP's action|
|datagram|UDP Transport Layer|Data packet from UDP's action|
|datagram|Internet Layer|Data packet from IP's action|
|frame|Access Layer|Frame containing datagram before it is converted to bits|

## Data Flow in the TCP/IP Stack

```Plain
Sending:
Application Layer → H + message
    ↓
Transport Layer → H + segment/datagram
    ↓
Internet Layer → H + datagram
    ↓
Network Access Layer → H + frame → 101011100010...
```

```Plain
Receiving:
Network Access Layer → H + frame → 101011100010...
    ↑
Internet Layer → H + datagram
    ↑
Transport Layer → H + segment/datagram
    ↑
Application Layer → H + message
```
