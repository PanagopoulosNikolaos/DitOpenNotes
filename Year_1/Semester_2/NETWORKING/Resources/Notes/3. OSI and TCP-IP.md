# Network Access Layer Protocols

## OSI and TCP/IP Reference Models

The TCP/IP network access level corresponds to the Data Link and Physical levels of the OSI model.

|   |   |
|---|---|
|OSI Model|TCP/IP Model|
|Application Layer|Application Layer|
|Presentation Layer||
|Session Layer||
|Transport Layer|Transport Layer|
|Network Layer|Network Layer|
|Data Link Layer|Network Access Layer|
|Physical Layer||

## Sub-levels of the Access Layer

The access layer is divided into three basic sub-levels:

```Mermaid
graph TD
    A[Access Layer] --> B[LLC - Logical Link Control]
    A --> C[MAC - Media Access Control]
    A --> D[PHY - Physical]
```

## Basic Functions of the Access Layer

|   |   |
|---|---|
|Function|Sub-level|
|Access Method (Ethernet, Token Ring, IEEE 802.11)|MAC|
|Frame Format/Assembly|MAC|
|Cable type|PHY|
|Wiring rules (max distance, etc.)|PHY|
|Frame to signal conversion (electrical, optical, wireless)|PHY|
|Error control of incoming/outgoing frames|LLC|

**Basic functions in detail:**

- Connection of the computer to the Network Adapter (NIC)
- Data preparation according to network access methods
- Attempt to avoid packet collisions
- Conversion of frames to electrical signals
- Packet error checking

## Wireless Networks (IEEE 802.11)

The IEEE 802.11 specifications provide for wireless networking within the TCP/IP stack and operate at the Network Access Level.

```Mermaid
graph TD
    A[802.11 - Sub-level MAC] --- B[802.2 - Sub-level LLC]
    A --- C[Different PHY applications]
    C --- D[802.11 FHSS PHY]
    C --- E[802.11 DSSS PHY]
    C --- F[802.11a OFDM PHY]
    C --- G[802.11b HR/DSSS PHY]
```

**Different wireless PHY transmission forms of IEEE 802.11:**

- Frequency Hopping Spread Spectrum (FHSS)
- Direct Sequence Spread Spectrum (DSSS)
- Orthogonal Frequency Division Multiplexing (OFDM)
- High Rate Direct Sequence Multiplexing (HR/DSSS)

## Other Network Technologies

**Token Ring Technology:**

- Logical data path in a ring

**TCP/IP via Telephone Connection:**

- Point-to-point connections
- Use of Modems
- Protocols: SLIP, PPP

**FDDI Technology (Fiber Distributed Data Interface):**

- Uses two pairs of optical fibers
- Based on the token ring access method
- Ability to locate and correct errors
- Supports large data volumes and long distances
- Disadvantage: Expensive technology

## Network Mathematical Calculations

### Signal to Noise Ratio (SNR)

$SN R(d b) = 10 \log_{10}(\frac{S}{N})$

Examples:

- When $\frac{S}{N} = 10$ then $SNR = 10db$
- When $\frac{S}{N} = 100$ then $SNR = 20db$
- When $\frac{S}{N} = 1000$ then $SNR = 30db$

### Maximum Data Transmission Rate

The maximum data transmission rate in a channel with noise is calculated:

$Max(\frac{b i t s}{s e c}) = B \log_2(1 + \frac{S}{N})$

Where B is the bandwidth in Hz.

**ADSL Example:**  
With frequency $1 MHz$, $SNR=40 db$:  
$Max(\frac{b i t s}{s e c}) = B \log_2(1 + 10^4) ≈ 10.7 Mbps$
