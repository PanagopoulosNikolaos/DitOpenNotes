## Basic Definitions

**Computer Network**
A network is a set of computers or computer-like devices, and these elements can communicate with each other through one or more common transmission media.

**Network Protocol**
A Network Protocol is a system of common rules that facilitate the process of transmitting data between network resources.

**TCP/IP**
TCP/IP and its related protocols constitute a complete system, which defines the way data processing, transmission, and reception will be carried out in a network that implements these protocols.

## Basic Functions of TCP/IP

||  |
|---|---|
|Function|Description|
|Logical addressing|Each network device interface (port) has a unique IP address (32 bits in IPv4)|
|Routing|Routers direct data to their destination and segment large networks|
|Name resolution service|Conversion of domain names to IP addresses (DNS) and NetBIOS names to IP addresses (WINS)|
|Error and flow control|Ensuring reliability of data transfer using control functions|
|Application support|Identification of each packet's application using ports|
