# Network Layer: Internet - Basic Principles and Functions

The Internet Layer (Internet Layer) constitutes the core of modern network operation, providing the fundamental methods of addressing and packet routing. The IP protocol is the basic protocol that allows communication between different networks and devices.

## IP Addressing

### Basic Concepts

- An IP address uniquely identifies a network or a host (computer)
- A host may have multiple interfaces
- An IP address consists of two parts: **network ID** and **host ID**
- The separation of the two parts is done with the help of the **Subnet Mask**

### IPv4 and IPv6 Comparison

|   |   |   |
|---|---|---|
|Feature|IPv4|IPv6|
|Address Length|32 bits (4 bytes)|128 bits (16 bytes)|
|Format|193.210.18.18|2001:0db8:85a3:0000:0000:8a2e:0370:7334|
|Number of Addresses|Approximately 4.3 billion|340 undecillion|

```Mermaid
    B -->|"No"| D["Sending to Gateway"]
    D -->|"2 Hop-by-hop routing"| E["Destination Gateway"]
    E -->|"3 Delivery to destination"| F["Destination Computer"]
```

### Datagram Routing Diagram

The method of packet routing depends on the location of the destination:

1. **Destination in the same local network:** Direct sending with ARP
2. **Destination outside the local network:** Sending to the Gateway and hop-by-hop routing
3. **Final delivery:** The destination Gateway uses ARP for delivery to the final node

## ARP Protocol (Address Resolution Protocol)

### ARP Function

The ARP protocol is used when the IP address is known but the physical address (MAC) of a device is not.

```Mermaid
sequenceDiagram
    participant A as Computer A
    participant B as Computer B
    A->>B: ARP Request: IP 192.168.1.5;
    Note over A,B: Broadcast message
    B->>A: ARP Reply: MAC=AA:BB:CC:DD:EE:FF
    Note over A: ARP table update
```

### IP Header

```Plain
+--------+--------+--------+--------+
|Version | IHL    |Type of Service   |
+--------+--------+--------+--------+
|        Total Length             |
+--------+--------+--------+--------+
|        Identification           |
+--------+--------+--------+--------+
|Flags   |    Fragment Offset      |
+--------+--------+--------+--------+
|  Time to Live  |   Protocol      |
+--------+--------+--------+--------+
|        Header Checksum          |
+--------+--------+--------+--------+
|        Source Address           |
+--------+--------+--------+--------+
|      Destination Address        |
+--------+--------+--------+--------+
|   Options (if any) + Padding |
+--------+--------+--------+--------+
|        Data (Data Payload)     |
+--------+--------+--------+--------+
```

### IP Header Field Analysis

|   |   |
|---|---|
|Field|Description|
|Version|IP4 (0100) or IP6 (0110)|
|IHL|Internet Header Length, minimum 5 (20 bytes)|
|Type of Service|Routing information, QoS|
|Total Length|Total length of the datagram in bytes|
|Identification|Unique identifier of the datagram|
|Flags|Fragmentation check|
|Fragment Offset|For reassembly of fragmented packets|
|Time to Live (TTL)|Lifetime of the packet in hops|
|Protocol|Upper-level protocol (TCP=6, UDP=17, ICMP=1)|
|Header Checksum|Header validity check|
|Source Address|IP address of the sender|
|Destination Address|IP address of the receiver|
|Options|Additional options (security, routing, etc.)|

## ICMP Protocol

### ICMP Message Types

|   |   |   |   |
|---|---|---|---|
|Message Type|Description|Use|
|Echo Request/Reply|Request and reply echo|For connectivity check (ping)|
|Source Quench|Flow control|Sync of fast hosts with slow routers|
|Destination Unreachable|Unable to deliver|When a router cannot deliver a datagram|
|Time Exceeded|Time exceeded|When the TTL reaches zero|
|Fragmentation Needed|Need for fragmentation|When datagram fragmentation is required|

### ICMP Packet Format

```Plain
+--------+--------+--------+--------+
|  Type  |  Code  |  Checksum      |
+--------+--------+--------+--------+
|       Data (content)         |
+--------+--------+--------+--------+
```

## Binary-Decimal Conversion

### From Binary to Decimal

|   |   |   |   |   |   |   |   |
|---|---|---|---|---|---|---|---|
|2⁷|2⁶|2⁵|2⁴|2³|2²|2¹|2⁰|
|128|64|32|16|8|4|2|1|

Example: 10110111 = 128 + 32 + 16 + 4 + 2 + 1 = 183

### From Decimal to Binary

Method of successive divisions by 2:

```Plain
Number: 207
207 ÷ 2 = 103 remainder 1
103 ÷ 2 = 51  remainder 1
51  ÷ 2 = 25  remainder 1
25  ÷ 2 = 12  remainder 1
12  ÷ 2 = 6   remainder 0
6   ÷ 2 = 3   remainder 0
3   ÷ 2 = 1   remainder 1
1   ÷ 2 = 0   remainder 1
```

Answer: 11001111

## Practical Applications and Questions

### Practice Questions

1. What kind of information does the ARP protocol return when it receives an IP address?  
    **Answer**: Returns the physical address (MAC address) corresponding to the IP address.
2. A router cannot track traffic volume, what kind of ICMP message does it send?  
    **Answer**: Sends "Source Quench" message.
3. To which Class does the IP address belong that starts with binary 110 in the three leftmost digits?  
    **Answer**: Belongs to Class C.
4. Convert the binary numbers:
    - 00101011 = 43
    - 01010010 = 82
5. Convert the decimal numbers:
    - 184 = 10111000
    - 37 = 00100101

### ARP Process Example

1. Computer A wants to communicate with Computer C
2. It checks the ARP table for C's MAC address
3. If not found, it sends an ARP broadcast query: "Who has IP 192.168.1.12;"
4. Computer C responds with its MAC address
5. Computer A stores the mapping in its ARP table
6. Communication begins
