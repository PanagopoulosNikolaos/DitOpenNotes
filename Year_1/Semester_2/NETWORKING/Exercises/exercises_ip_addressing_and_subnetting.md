# Ασκήσεις Εμπέδωσης: Διευθυνσιοδότηση IPv4, Μάσκες και Υποδικτύωση (Subnetting)

## Άσκηση 1: Υπολογισμός Παραμέτρων Υποδικτύου

### Εκφώνηση
Δίνεται η διεύθυνση IP ενός υπολογιστή: `172.16.45.130/22`.
1. Ποια είναι η μάσκα υποδικτύου (Subnet Mask) σε δεκαδική μορφή;
2. Ποια είναι η διεύθυνση δικτύου (Network Address);
3. Ποια είναι η διεύθυνση εκπομπής (Broadcast Address);
4. Ποιο είναι το εύρος των έγκυρων διευθύνσεων για υπολογιστές (Usable Host Range);
5. Πόσοι συνολικά υπολογιστές μπορούν να συνδεθούν σε αυτό το υποδίκτυο;

### Λύση
1. **Μάσκα Υποδικτύου:**
   - Πρόθεμα `/22` σημαίνει 22 άσους: `11111111.11111111.11111100.00000000`
   - Σε δεκαδική μορφή: `255.255.252.0`.

2. **Διεύθυνση Δικτύου:**
   - 3ο byte διεύθυνσης IP: $45 = 00101101_2$.
   - 3ο byte μάσκας: $252 = 11111100_2$.
   - Bitwise AND: $00101101_2 \text{ AND } 11111100_2 = 00101100_2 = 44_{10}$.
   - Άρα Network Address: `172.16.44.0`.

3. **Διεύθυνση Broadcast:**
   - Αντιστρέφουμε τα 10 bits των hosts (τα κάνουμε όλα '1'):
   - 3ο byte: $00101100_2 \text{ OR } 00000011_2 = 00101111_2 = 47_{10}$.
   - 4ο byte: $255_{10}$.
   - Broadcast Address: `172.16.47.255`.

4. **Έγκυρο Εύρος Διευθύνσεων (Host Range):**
   - Από `172.16.44.1` έως `172.16.47.254`.

5. **Μέγιστος Αριθμός Hosts:**
   - $2^{(32 - 22)} - 2 = 2^{10} - 2 = 1024 - 2 = 1022$ hosts.

## Άσκηση 2: Σχεδίαση VLSM

### Εκφώνηση
Ένας οργανισμός λαμβάνει το μπλοκ διευθύνσεων `10.0.0.0/16`. Απαιτείται να σχεδιάσετε 4 υποδίκτυα με τις εξής ανάγκες:
- Υποδίκτυο A: 1000 hosts
- Υποδίκτυο B: 500 hosts
- Υποδίκτυο C: 200 hosts
- Υποδίκτυο D: 50 hosts

### Λύση
1. **Υποδίκτυο A (1000 hosts):**
   - Χρειαζόμαστε $2^h - 2 \ge 1000 \implies h = 10$ bits $\rightarrow$ Μάσκα $/22$.
   - Δίκτυο: `10.0.0.0/22` (Εύρος: `10.0.0.1` - `10.0.3.254`, Broadcast: `10.0.3.255`).
2. **Υποδίκτυο B (500 hosts):**
   - Χρειαζόμαστε $2^h - 2 \ge 500 \implies h = 9$ bits $\rightarrow$ Μάσκα $/23$.
   - Επόμενη διαθέσιμη: `10.0.4.0/23` (Εύρος: `10.0.4.1` - `10.0.5.254`, Broadcast: `10.0.5.255`).
3. **Υποδίκτυο C (200 hosts):**
   - Χρειαζόμαστε $2^h - 2 \ge 200 \implies h = 8$ bits $\rightarrow$ Μάσκα $/24$.
   - Επόμενη διαθέσιμη: `10.0.6.0/24` (Εύρος: `10.0.6.1` - `10.0.6.254`, Broadcast: `10.0.6.255`).
4. **Υποδίκτυο D (50 hosts):**
   - Χρειαζόμαστε $2^h - 2 \ge 50 \implies h = 6$ bits $\rightarrow$ Μάσκα $/26$.
   - Επόμενη διαθέσιμη: `10.0.7.0/26` (Εύρος: `10.0.7.1` - `10.0.7.62`, Broadcast: `10.0.7.63`).
