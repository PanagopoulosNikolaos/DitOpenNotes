# Ασκήσεις Εμπέδωσης: Έλεγχος Συμφόρησης TCP και Αλγόριθμοι Δρομολόγησης

## Άσκηση 1: Εξέλιξη Παραθύρου Συμφόρησης TCP (Tahoe vs Reno)

### Εκφώνηση
Έστω ότι μια σύνδεση TCP λειτουργεί με μέγεθος μέγιστου τμήματος MSS = 1 KB. Το αρχικό κατώφλι αργής εκκίνησης είναι $\text{ssthresh} = 16\text{ KB}$ και το παράθυρο συμφόρησης ξεκινά από $\text{cwnd} = 1\text{ MSS}$.
Κατά τον 7ο γύρο RTT παρατηρείται απώλεια πακέτου λόγω λήψης 3 διπλότυπων ACK (3 duplicate ACKs).
1. Ποια είναι η τιμή του `cwnd` στον 6ο γύρο RTT;
2. Πώς αντιδρά το TCP Tahoe μετά την απώλεια;
3. Πώς αντιδρά το TCP Reno (Fast Recovery);

### Λύση
1. **Εξέλιξη cwnd:**
   - Γύρος 1: cwnd = 1 (Slow Start)
   - Γύρος 2: cwnd = 2
   - Γύρος 3: cwnd = 4
   - Γύρος 4: cwnd = 8
   - Γύρος 5: cwnd = 16 (φτάνει το ssthresh)
   - Γύρος 6: cwnd = 17 (Congestion Avoidance: γραμμική αύξηση κατά +1 MSS ανά RTT)
   - Γύρος 7: cwnd = 18 (συμβαίνει η απώλεια).

2. **TCP Tahoe:**
   - $\text{ssthresh} = \lfloor \text{cwnd} / 2 \rfloor = \lfloor 18 / 2 \rfloor = 9\text{ KB}$.
   - $\text{cwnd} = 1\text{ KB}$ (επιστροφή σε Slow Start).

3. **TCP Reno (Fast Retransmit & Fast Recovery):**
   - $\text{ssthresh} = \lfloor \text{cwnd} / 2 \rfloor = 9\text{ KB}$.
   - $\text{cwnd} = \text{ssthresh} + 3 = 9 + 3 = 12\text{ KB}$ (ή μετά την ανάκαμψη $\text{cwnd} = 9\text{ KB}$ και απευθείας μετάβαση σε Congestion Avoidance χωρίς επιστροφή στο 1).

## Άσκηση 2: Αλγόριθμος Δρομολόγησης Dijkstra (Link-State)

### Εκφώνηση
Δίνεται τοπολογία 5 δρομολογητών $(u, v, w, x, y)$ με κόστη ζεύξεων:
- $c(u, v) = 2, \ c(u, w) = 5, \ c(u, x) = 1$
- $c(x, v) = 2, \ c(x, w) = 3, \ c(x, y) = 1$
- $c(v, w) = 3$
- $c(y, w) = 1$

Εκτελέστε τον αλγόριθμο Dijkstra με αρχικό κόμβο $u$ και προσδιορίστε τον πίνακα δρομολόγησης του $u$.

### Λύση
1. **Βήμα 0:** $N' = \{u\}$, $D(v)=2, D(w)=5, D(x)=1, D(y)=\infty$. Ελάχιστο: $x$ ($D(x)=1$).
2. **Βήμα 1:** $N' = \{u, x\}$.
   - $D(v) = \min(2, 1 + 2) = 2$.
   - $D(w) = \min(5, 1 + 3) = 4$ (μέσω $x$).
   - $D(y) = \min(\infty, 1 + 1) = 2$ (μέσω $x$).
   - Ελάχιστα: $v$ ή $y$ ($D=2$). Επιλέγουμε $y$.
3. **Βήμα 2:** $N' = \{u, x, y\}$.
   - $D(w) = \min(4, 2 + 1) = 3$ (μέσω $y$).
   - $D(v) = 2$.
   - Ελάχιστο: $v$ ($D(v)=2$).
4. **Βήμα 3:** $N' = \{u, x, y, v\}$.
   - $D(w) = \min(3, 2 + 3) = 3$.
   - Ελάχιστο: $w$ ($D(w)=3$).
5. **Βήμα 4:** $N' = \{u, x, y, v, w\}$ (Ολοκληρώθηκε).

**Πίνακας Δρομολόγησης του $u$:**
| Προορισμός | Ελάχιστο Κόστος | Επόμενο Άλμα (Next Hop) |
|---|---|---|
| $v$ | 2 | $(u, v)$ |
| $x$ | 1 | $(u, x)$ |
| $y$ | 2 | $(u, x)$ |
| $w$ | 3 | $(u, x)$ |
