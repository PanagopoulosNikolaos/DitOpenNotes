# Project 01: Multi-Protocol Network Packet Analyzer and Sniffer

## Project Overview
Design, architect, and implement a modular network packet sniffer and traffic analysis engine in Python or C using raw network sockets (`AF_PACKET` on Linux) or standard PCAP file ingestion. The tool decodes Ethernet frames, IPv4/IPv6 headers, TCP/UDP transport segments, and application protocols (DNS and HTTP), reconstructing TCP conversation flows and detecting anomalous patterns (such as port scanning and ARP spoofing).

---

## 1. Functional Specifications

### 1.1 Live Capture and PCAP Ingestion
The engine must support two execution modes:
1. **Live Interface Capture**: Binds to a local interface (e.g., `eth0`, `wlp4s0`) with administrative privileges:
   ```bash
   sudo python3 sniffer.py --interface eth0 --filter "tcp port 80 or port 53"
   ```
2. **Offline Trace Ingestion**: Reads standard `.pcap` files generated by `tcpdump` or Wireshark:
   ```bash
   python3 sniffer.py --read capture.pcap --output-summary
   ```

### 1.2 Protocol Dissection and Header Parsing
Implement byte-level unpackers using Python's `struct` module or C binary structures:
1. **Ethernet II Frame**:
   * Destination MAC, Source MAC, EtherType (`0x0800` for IPv4, `0x0806` for ARP, `0x86DD` for IPv6).
2. **ARP Datagram**:
   * Hardware Type, Protocol Type, Hardware/Protocol Size, Opcode (1: Request, 2: Reply), Sender MAC/IP, Target MAC/IP.
3. **IPv4 Header**:
   * Version, IHL, Type of Service, Total Length, Identification, Flags (DF, MF), Fragment Offset, TTL, Protocol, Header Checksum, Source IP, Destination IP.
4. **TCP Segment**:
   * Source Port, Destination Port, Sequence Number, Acknowledgment Number, Data Offset, Flags (URG, ACK, PSH, RST, SYN, FIN), Window Size, Checksum, Urgent Pointer.
5. **UDP Datagram**:
   * Source Port, Destination Port, Length, Checksum.
6. **DNS Parser**:
   * Transaction ID, Flags (QR, Opcode, AA, TC, RD, RA, RCODE), Questions count, Answers count, Query name and type.

### 1.3 Flow Reconstruction and Security Detection
1. **TCP Flow Tracker**:
   * Reassembles bidirectional byte streams keyed by 4-tuple `(src_ip, src_port, dst_ip, dst_port)`.
   * Tracks connection state transitions (`SYN_SENT`, `ESTABLISHED`, `CLOSED`).
2. **Security Anomaly Heuristics**:
   * **SYN Flood / Port Scan Detector**: Triggers an alert when a single IP addresses more than 20 unique ports or transmits $>50$ unaccompanied SYN packets within a 5-second window.
   * **ARP Spoofing Detector**: Flags instances where a single IP address claims multiple distinct MAC addresses over time.

## 2. Project Architecture

* `packet_analyzer/`
  * `sniffer.py`: Socket listener and live packet capture loop.
  * `parser/`
    * `ethernet.py`: Link layer frame decoder.
    * `ip.py`: Network layer header parsing and validation.
    * `transport.py`: TCP/UDP header decoding and flag extraction.
    * `application.py`: DNS query decoding and HTTP method/header extraction.
  * `tracker/`
    * `flow.py`: Connection tracking and TCP stream reconstruction.
    * `detector.py`: Heuristic security analysis (SYN scans, ARP spoofing).
  * `reporter.py`: Tabular CLI output formatting and JSON export.
  * `tests/`: Automated unit tests evaluating parser output on known mock raw byte arrays.
