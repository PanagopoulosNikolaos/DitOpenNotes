# Εξαμηνιαία Εργασία: Ανάπτυξη Πολυνηματικής Εφαρμογής Chat Πελάτη-Εξυπηρετητή (Multi-threaded Socket Chat)

## 1. Σύνοψη Εργασίας
Σκοπός της εργασίας είναι η υλοποίηση μιας εφαρμογής ανταλλαγής μηνυμάτων σε πραγματικό χρόνο (Chat Room) βασισμένης σε TCP Sockets (σε C ή Python), με αρχιτεκτονική Client-Server και υποστήριξη πολλαπλών ταυτόχρονων χρηστών μέσω πολυνηματικότητας (multi-threading) ή ασύγχρονου I/O multiplexing (`select` / `epoll` / `asyncio`).

---

## 2. Λειτουργικές Προδιαγραφές

### 2.1 Εξυπηρετητής (Server)
- Ακρόαση σε προκαθορισμένη θύρα TCP (π.χ. `8888`).
- Αποδοχή πολλαπλών συνδέσεων πελατών και διαχείριση λίστας ενεργών χρηστών.
- Αναμετάδοση (broadcast) μηνυμάτων σε όλους τους συνδεδεμένους χρήστες.
- Υποστήριξη ιδιωτικών μηνυμάτων (Direct Messaging: `/msg <username> <message>`).
- Υποστήριξη εντολών διαχείρισης: `/list` (προβολή συνδεδεμένων χρηστών), `/quit` (αποσύνδεση).

### 2.2 Πελάτης (Client)
- Σύνδεση στον Server με IP και θύρα.
- Καταχώρηση μοναδικού ψευδωνύμου (nickname).
- Ταυτόχρονη αποστολή μηνυμάτων από το πληκτρολόγιο και εμφάνιση εισερχόμενων μηνυμάτων στην κονσόλα (χωρίς blocking).

---

## 3. Παραδοτέα και Βαθμολόγηση

| Κριτήριο | Ποσοστό |
|---|---|
| Σωστή διαχείριση TCP Sockets και επικεφαλίδων μηνυμάτων (Framing) | 35% |
| Πολυνηματικός χειρισμός και αποφυγή race conditions / deadlocks | 30% |
| Υποστήριξη εντολών (`/list`, `/msg`, graceful disconnect) | 20% |
| Τεκμηρίωση, οδηγός εκτέλεσης και test suite | 15% |
