# Σημειώσεις Μελέτης: Δυναμική Μνήμη και Δομές Δεδομένων στη C

## 1. Μοντέλο Μνήμης και Alignment

Στη γλώσσα C, τα δεδομένα στη μνήμη ευθυγραμμίζονται (memory alignment) με βάση το μέγεθος των τύπων τους:
- Ένας ακέραιος 32-bit (`int`) ευθυγραμμίζεται σε πολλαπλάσιο του 4.
- Ένας αριθμός διπλής ακρίβειας 64-bit (`double`) ευθυγραμμίζεται σε πολλαπλάσιο του 8.
- Η διάταξη των πεδίων σε ένα `struct` μπορεί να εισάγει padding bytes, επηρεάζοντας το συνολικό μέγεθος `sizeof(struct)`.

```c
struct PaddedStruct {
    char a;      // 1 byte
    // 3 bytes padding
    int b;       // 4 bytes
    char c;      // 1 byte
    // 7 bytes padding
    double d;    // 8 bytes
}; // Total: 24 bytes
```

## 2. Δυναμικές Δομές Δεδομένων

### Απλά Συνδεδεμένη Λίστα (Singly Linked List)
- Χρονική πολυπλοκότητα εισαγωγής στην αρχή: $O(1)$.
- Χρονική πολυπλοκότητα αναζήτησης/προσπέλασης: $O(n)$.
- Δεν απαιτεί συνεχόμενο χώρο μνήμης.

### Δυαδικό Δέντρο Αναζήτησης (Binary Search Tree - BST)
- Ιδιότητα BST: Για κάθε κόμβο $X$, όλα τα στοιχεία στο αριστερό υποδέντρο έχουν τιμή $< X$, και στο δεξί $> X$.
- Μέση πολυπλοκότητα αναζήτησης, εισαγωγής, διαγραφής: $O(\log n)$.
- Χειρότερη πολυπλοκότητα (εκφυλισμένο δέντρο σε λίστα): $O(n)$.

## 3. Σύγκριση Μεθόδων Προσπέλασης Αρχείων

| Μέθοδος | Πλεονεκτήματα | Μειονεκτήματα | Τυπική Χρήση |
|---|---|---|---|
| Sequential Access | Απλή υλοποίηση, κατάλληλη για streaming | Αργή αναζήτηση $O(n)$ | Parsing logs, CSV |
| Random Access (`fseek`) | Ταχεία πρόσβαση $O(1)$ σε σταθερό record size | Απαιτεί σταθερή δομή αρχείου | Ενσωματωμένες DBs, B-Trees |
