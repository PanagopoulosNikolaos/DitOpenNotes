# Εργαστηριακή Εργασία 3: Διαχείριση Αρχείων Κειμένου και Ροών Δεδομένων (File Streams I/O)

## 1. Σκοπός και Περιγραφή
Η εργασία πραγματεύεται την επικοινωνία προγραμμάτων C με το σύστημα αρχείων μέσω ροών (`FILE*`). Καλύπτονται οι καταστάσεις λειτουργίας (`"r"`, `"w"`, `"a"`, `"r+"`), η ασφαλής ανάγνωση/εγγραφή και η επεξεργασία γραμμών.

## 2. Ευρετήριο Ασκήσεων (`File_Handling/src/`)
- `exercise1.c`: Εγγραφή σταθερού κειμένου σε αρχείο (`data1.txt`) με `fwrite`.
- `exercise2.c`: Ανάγνωση και εκτύπωση περιεχομένου αρχείου (`data2.txt`) με `fread`.
- `exercise3.c`: Προσάρτηση (append mode `"a"`) δεδομένων στο τέλος αρχείου.
- `exercise4.c`: Ανάγνωση χαρακτήρα προς χαρακτήρα (`fgetc`) και μέτρηση μήκους.
- `exercise5.c`: Μορφοποιημένη εγγραφή ακεραίων (`fprintf`) με έλεγχο σφαλμάτων.
- `exercise6.c`: Μορφοποιημένη ανάγνωση αριθμών (`fscanf`) και άθροιση.
- `exercise7.c`: Αντιγραφή αρχείου κειμένου block-by-block.
- `exercise8.c`: Καταμέτρηση συνολικών γραμμών σε αρχείο κειμένου.
- `exercise9.c`: Αντιστροφή γραμμών αρχείου και αποθήκευση σε νέο αρχείο εξόδου.
- `exercise10.c`: Αναζήτηση συγκεκριμένης λέξης σε αρχείο και καταγραφή αριθμού γραμμής.
- `exercise11.c`: Ανάγνωση γραμμών με `fgets` και αποφυγή buffer overflows.
- `exercise12.c`: Συγχώνευση δύο αρχείων κειμένου σε ένα τρίτο.
- `exercise13.c`: Διαχωρισμός αρχείου σε περιττές και άρτιες γραμμές.
- `exercise14.c`: Αντικατάσταση λέξης εντός αρχείου.
- `exercise15.c`: Στατιστική ανάλυση κειμένου (χαρακτήρες, λέξεις, γραμμές).

## 3. Δεδομένα Εισόδου/Εξόδου
Τα αρχεία δοκιμής (`data1.txt` έως `data9.txt`, `greeting.txt`) βρίσκονται στον κατάλογο:
`File_Handling/`

## 4. Μεταγλώττιση και Εκτέλεση
```bash
cd File_Handling/src
gcc -Wall -Wextra -std=c11 exercise1.c -o exercise1
./exercise1
```
