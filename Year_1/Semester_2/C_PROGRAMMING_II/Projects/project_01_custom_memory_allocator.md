# Εξαμηνιαία Εργασία: Ανάπτυξη Προσαρμοσμένου Διαχειριστή Μνήμης (Custom Memory Allocator)

## 1. Σύνοψη Εργασίας
Σκοπός της εργασίας είναι η υλοποίηση ενός απλοποιημένου δυναμικού διαχειριστή μνήμης σε επίπεδο χρήστη (User-space Memory Allocator), ο οποίος διαχειρίζεται ένα μεγάλο στατικό buffer (π.χ. 1MB) και παρέχει τις δικές του εκδόσεις των συναρτήσεων `my_malloc`, `my_free`, `my_realloc`, καθώς και συνάρτηση αναφοράς κατακερματισμού (fragmentation report).

---

## 2. Λειτουργικές Απαιτήσεις

### 2.1 Δομή Header Blocks
Κάθε δεσμευμένο ή ελεύθερο block μνήμης πρέπει να διαθέτει επικεφαλίδα (header):
```c
typedef struct BlockHeader {
    size_t size;               // Μέγεθος του payload σε bytes
    int is_free;               // 1 αν είναι ελεύθερο, 0 αν είναι δεσμευμένο
    struct BlockHeader *next;  // Δείκτης στο επόμενο block
} BlockHeader;
```

### 2.2 Στρατηγικές Επιλογής Ελεύθερου Block
Η υλοποίηση πρέπει να υποστηρίζει τουλάχιστον μία από τις ακόλουθες στρατηγικές:
- **First Fit:** Επιλογή του πρώτου ελεύθερου block που επαρκεί.
- **Best Fit:** Επιλογή του ελεύθερου block με το μικρότερο μέγεθος που υπερβαίνει ή ισούται με το ζητούμενο μέγεθος (μείωση εσωτερικού κατακερματισμού).

### 2.3 Συγχώνευση Συνεχόμενων Ελεύθερων Blocks (Coalescing)
Κατά την κλήση της `my_free(void *ptr)`, εάν τα γειτονικά blocks είναι επίσης ελεύθερα, πρέπει να συγχωνεύονται σε ένα ενιαίο μεγαλύτερο block προς αποφυγή εξωτερικού κατακερματισμού.

## 3. Παραδοτέα και Βαθμολόγηση

| Κριτήριο | Ποσοστό |
|---|---|
| Ορθότητα `my_malloc` και ευθυγράμμιση μνήμης (alignment) | 30% |
| Ορθότητα `my_free` και συγχώνευση (coalescing) | 30% |
| Υλοποίηση `my_realloc` και στατιστικά κατακερματισμού | 20% |
| Πλήρες test suite και έλεγχος με Valgrind χωρίς σφάλματα | 20% |
