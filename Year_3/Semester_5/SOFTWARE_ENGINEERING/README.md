# Τεχνολογία Λογισμικού (505)

## Επισκόπηση Μαθήματος
Το μάθημα πραγματεύεται τις αρχές, μεθοδολογίες, εργαλεία και πρότυπα για τη συστηματική, πειθαρχημένη και αποδοτική ανάπτυξη σύνθετων συστημάτων λογισμικού βιομηχανικής κλίμακας. Εξετάζονται: Μοντέλα κύκλου ζωής λογισμικού (Waterfall, V-Model, Prototyping, Agile μεθοδολογίες: Scrum, Sprint Planning, Kanban, XP), Μηχανική Απαιτήσεων (καταγραφή, ανάλυση, προδιαγραφές SRS κατά IEEE 830, Use Cases, User Stories), Μοντελοποίηση συστημάτων με UML (Use Case Diagrams, Class Diagrams, Sequence Diagrams, State Diagrams, Activity Diagrams), Αρχιτεκτονική Λογισμικού και Σχεδίαση (Layered, Client-Server, Microservices, Event-Driven, σχεδιαστικά πρότυπα GoF Creational, Structural, Behavioral), Έλεγχος και Διασφάλιση Ποιότητας Λογισμικού (Unit Testing, Integration Testing, System Testing, Regression Testing, Black-box & White-box τεχνικές, κάλυψη κώδικα, TDD), Συνεχής Ενοποίηση και Παράδοση (CI/CD Pipelines, Git Workflows), Συντήρηση, Refactoring και Τεχνικό Χρέος (Technical Debt), Διαχείριση Έργων Λογισμικού (εκτίμηση κόστους COCOMO, Function Points, PERT/CPM), και Μοντέλα Ωριμότητας Διεργασιών (CMMI).

## Θεματικές Ενότητες Μαθήματος

1. **Εισαγωγή στην Τεχνολογία Λογισμικού: Η Κρίση του Λογισμικού, Ορισμοί, Αρχές και Επαγγελματική Ηθική (ACM/IEEE)**
2. **Μοντέλα Κύκλου Ζωής Λογισμικού (SDLC): Μοντέλο Καταρράκτη (Waterfall), Επαναληπτικό (Iterative), Σπειροειδές (Spiral), Ευέλικτες Μεθοδολογίες (Agile, Scrum, Kanban, XP)**
3. **Μηχανική Απαιτήσεων (Requirements Engineering): Λειτουργικές και Μη Λειτουργικές Απαιτήσεις, Καθορισμός Προδιαγραφών SRS (IEEE 830), Περιπτώσεις Χρήσης (Use Cases), Ιστορίες Χρηστών (User Stories)**
4. **Μοντελοποίηση με τη Γλώσσα UML: Διαγράμματα Περιπτώσεων Χρήσης, Διαγράμματα Κλάσεων, Διαγράμματα Αλληλουχίας, Διαγράμματα Καταστάσεων και Δραστηριοτήτων**
5. **Αρχιτεκτονική Λογισμικού: Αρχιτεκτονικά Στυλ (Επίπεδα/Layered, Πελάτη-Διακομιστή, Μικροϋπηρεσίες/Microservices, MVC/MVVM)**
6. **Αντικειμενοστρεφής Σχεδίαση και Πρότυπα GoF (Design Patterns): Δημιουργικά (Singleton, Factory), Δομικά (Adapter, Decorator, Facade), Συμπεριφοράς (Observer, Strategy, Command)**
7. **Έλεγχος και Δοκιμές Λογισμικού (Software Testing): Δοκιμές Μονάδας (Unit Testing), Δοκιμές Ενοποίησης (Integration), Δοκιμές Συστήματος, Έλεγχος Λευκού Κουτιού (White-box, Path Coverage) και Μαύρου Κουτιού (Black-box, Equivalence Partitioning, Boundary Value Analysis)**
8. **Ανάπτυξη Καθοδηγούμενη από Δοκιμές (Test-Driven Development - TDD) και Αυτοματοποιημένος Έλεγχος**
9. **Συνεχής Ενοποίηση και Συνεχής Παράδοση (CI/CD), Έλεγχος Εκδόσεων (Git Workflows), Αυτοματοποιημένη Δόμηση (Build Automation)**
10. **Συντήρηση Λογισμικού, Ανασχεδιασμός (Refactoring), Τεχνικό Χρέος (Technical Debt) και Μετρικές Ποιότητας Κώδικα (Cyclomatic Complexity, Coupling, Cohesion)**
11. **Διαχείριση Έργων Λογισμικού (Project Management), Εκτίμηση Μεγέθους και Κόστους (COCOMO, Function Points), Διασφάλιση Ποιότητας (QA) και Μοντέλο Ωριμότητας CMMI**
