# Βιβλιογραφία και Συγγράμματα: Τεχνολογία Λογισμικού (505)

## Περίληψη Καταλόγου
Περιλαμβάνει λίστες προτεινόμενων ακαδημαϊκών συγγραμμάτων, άρθρων και ψηφιακών αναφορών για το μάθημα Τεχνολογία Λογισμικού.

## Προτεινόμενα Συγγράμματα
* Ian Sommerville, 'Software Engineering', Pearson (Τεχνολογία Λογισμικού).
* Roger S. Pressman, Bruce R. Maxim, 'Software Engineering: A Practitioner's Approach', McGraw-Hill.
* Erich Gamma, Richard Helm, Ralph Johnson, John Vlissides, 'Design Patterns: Elements of Reusable Object-Oriented Software', Addison-Wesley.
