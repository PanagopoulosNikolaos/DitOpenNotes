# Ασκήσεις και Εργαστήρια: Ψηφιακές Τηλεπικοινωνίες (503)

## Περίληψη Καταλόγου
Ο κατάλογος αυτός περιέχει τις σειρές ασκήσεων (assignments), εργαστηριακές αναφορές και πρακτικά προβλήματα για το μάθημα Ψηφιακές Τηλεπικοινωνίες.

## Δομή Ασκήσεων
Κάθε εκτενής άσκηση ή εργαστηριακή ενότητα οργανώνεται σε αυτόνομο υποφάκελο:
```
Exercise_X/
├── README.md       # Εκφώνηση και προδιαγραφές
└── src/            # Πηγαίος κώδικας, δεδομένα και δοκιμές
```

## Ειδική Εργασία / Παρουσίαση Εξαμήνου
- **Θέμα:** Ψηφιακό τηλεπικοινωνιακό σύστημα – πομπός, κανάλι, δέκτης (Παρουσίαση 03/11)
- **Σχετικός Σύνδεσμος:** Αναλυτικό πλάνο και διαφάνειες στο [Resources/Presentations/](../Resources/Presentations/presentation_digital_communication_system.md).

## Θεματικοί Άξονες Ασκήσεων
* Θεωρητικές υπολογιστικές ασκήσεις και μαθηματική μοντελοποίηση.
* Πρακτικές υλοποιήσεις, προσομοιώσεις και ανάλυση αποτελεσμάτων.
* Εργαστηριακές δοκιμές και επικύρωση ορθότητας.
