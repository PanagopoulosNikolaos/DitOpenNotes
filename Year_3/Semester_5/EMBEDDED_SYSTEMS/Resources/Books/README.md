# Βιβλιογραφία και Συγγράμματα: Ενσωματωμένα Συστήματα (501)

## Περίληψη Καταλόγου
Περιλαμβάνει λίστες προτεινόμενων ακαδημαϊκών συγγραμμάτων, άρθρων και ψηφιακών αναφορών για το μάθημα Ενσωματωμένα Συστήματα.

## Προτεινόμενα Συγγράμματα
* Frank Vahid, Tony Givargis, 'Embedded System Design: A Unified Hardware/Software Introduction', John Wiley & Sons.
* Peter Marwedel, 'Embedded System Design: Embedded Systems Foundations of Cyber-Physical Systems', Springer.
* Joseph Yiu, 'The Definitive Guide to ARM Cortex-M3 and Cortex-M4 Processors', Newnes.
