### 2. Τελεστές μετάβασης

## Μέρος Ε — Παρουσίαση αποτελεσμάτων και ερμηνεία (10%)
### Απαντήσεις στις ερωτήσεις

1. **Ποια διαδρομή λύσης επέστρεψε ο DFS;**
   `S => A => B => D => G`

2. **Ποια διαδρομή λύσης επέστρεψε ο BFS;**
   `S => A => D => G`

3. **Βρήκαν την ίδια λύση; Αν όχι, εξηγήστε γιατί.**
   **Όχι.** Ο DFS ακολουθεί στρατηγική στοίβας (LIFO) με αλφαβητική σειρά διαδόχων, οπότε από τον `A` επιλέγει πρώτα τον `B` αντί του `D` και καταλήγει στον στόχο μέσω του βαθύτερου μονοπατιού `S => A => B => D => G` (4 ακμές). Αντίθετα, ο BFS εξερευνά τους κόμβους ανά επίπεδο βάθους (FIFO), βρίσκοντας τη συντομότερη διαδρομή `S => A => D => G` (3 ακμές).

4. **Ποιος από τους δύο επέκτεινε λιγότερους κόμβους στο συγκεκριμένο instance;**
   Ο **DFS** επέκτεινε λιγότερους κόμβους στο instance `3323` (**5** επεκτάσεις έναντι **12** του BFS).

5. **Σε ποιο όριο εμβάθυνσης βρήκε λύση ο IDS;**
   Στο όριο εμβάθυνσης **3** (`found_depth = 3`), επιστρέφοντας τη διαδρομή `S => A => D => G`.
