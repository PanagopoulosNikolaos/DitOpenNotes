## Μέρος Β — Αναζήτηση Πρώτα κατά Βάθος (DFS) (25%)

Υλοποιήστε:

```python
def dfs(graph, start, goal):
    ...
```

Η συνάρτηση πρέπει να εκτελεί DFS με αλφαβητική σειρά διαδόχων και να επιστρέφει ένα λεξικό με:

```python
{
    "path": ...,
    "expanded": ...,
    "trace": ...
}
```

όπου:

- `path`: η διαδρομή λύσης από την αρχική μέχρι την τελική κατάσταση,
- `expanded`: η Σειρά επέκτασης κόμβων,
- `trace`: η καταγραφή των βημάτων εκτέλεσης.

Κάθε βήμα εκτέλεσης πρέπει να περιλαμβάνει:

- `frontier`: το Σύνορο πριν από την επέκταση,
- `current`: τον κόμβο που θα επεκταθεί,
- `new_paths`: τις νέες διαδρομές που δημιουργήθηκαν και προστέθηκαν στο Σύνορο.

### Κανόνες εκτέλεσης

- Χρησιμοποιήστε συμπεριφορά στοίβας (LIFO).
- Οι διάδοχοι επεκτείνονται αλφαβητικά.
- Δεν επιτρέπεται ένας κόμβος να δημιουργεί κύκλο μέσα στην ίδια διαδρομή.
- Ο αλγόριθμος ελέγχει αν μία κατάσταση είναι στόχος όταν αφαιρείται από το Σύνορο για εξέταση, όχι όταν εμφανίζεται για πρώτη φορά ως παιδί.
- Αν δεν υπάρχει λύση, `path` πρέπει να είναι `None`.

## Μέρος Δ — Αναζήτηση Περιορισμένου Βάθους και IDS (25%)

Υλοποιήστε:

```python
def depth_limited_search(graph, start, goal, limit):
    ...

def ids(graph, start, goal, max_depth=20):
    ...
```

Η `depth_limited_search` πρέπει να εκτελεί DFS χωρίς να επεκτείνει κόμβους σε βάθος μεγαλύτερο από `limit`.

Η `ids` πρέπει να εκτελεί διαδοχικά Αναζήτηση Περιορισμένου Βάθους για:

```text
limit = 0, 1, 2, ...
```

μέχρι να βρεθεί λύση ή να φτάσει στο `max_depth`.

Η `ids` πρέπει να επιστρέφει:

```python
{
    "path": ...,
    "found_depth": ...,
    "iterations": ...
}
```

όπου:

- `path`: διαδρομή λύσης,
- `found_depth`: το όριο εμβάθυνσης στο οποίο βρέθηκε η λύση,
- `iterations`: για κάθε όριο εμβάθυνσης, η σειρά κόμβων που εξερευνήθηκαν.
