# Διαδραστικός Οδηγός Προετοιμασίας Προόδου — Αλγόριθμοι και Πολυπλοκότητα (504)

Εκπαιδευτική εφαρμογή ιστού (`HTML / CSS / JS` χωρίς εξωτερικές εξαρτήσεις) σε γραμμική διδακτική διάταξη τύπου W3Schools, σχεδιασμένη με την παλέτα **Editorial Paper** (60% `#F8F5EE`, 30% `#18181B`, 10% `#C85A17`) και καθαρή ονοματολογία κώδικα.

## Δομή Διδασκαλίας & Χαρακτηριστικά

- **Προαπαιτούμενα & Γρήγορη Επανάληψη (`Βασικά`):** Αυτόνομο εισαγωγικό κεφάλαιο για φοιτητές που ξεκινούν από το μηδέν ή θέλουν άμεσο φρεσκάρισμα (λογάριθμοι βάσης 2, αθροίσματα σειρών, 1-indexed πίνακες, αναδρομή, δυαδικά δέντρα, `mod` και βασική Python).
- **Γραμμική Ροή W3Schools ανά Ενότητα (`00`–`07`):** Κουμπιά `Προηγούμενο` / `Επόμενο` στην κορυφή και το τέλος, άμεσοι σύνδεσμοι ενοτήτων, 2-λεπτη «Γρήγορη Επανάληψη», αναλυτική θεωρία σε απλά ελληνικά και **Λυμένο Παράδειγμα αμέσως κάτω από κάθε έννοια**.
- **Τρία Επίπεδα Ασκήσεων:**
  1. **Λυμένες Ασκήσεις:** Ενσωματωμένα παραδείγματα θεωρίας + εξεταστικές ασκήσεις Σημειώσεων & Φροντιστηρίων A/B.
  2. **Ασκήσεις για Επίλυση:** Διαδραστικά πεδία συμπλήρωσης (`Έλεγχος`, `Υπόδειξη`, `Λύση`, `Επαναφορά`), Σωστό/Λάθος και Ερωτήσεις Πολλαπλής Επιλογής.
  3. **Παιχνιδοποιημένες Ασκήσεις:** Χειροκίνητοι κατασκευαστές (Σωροί, Hash Tables, Maze Union-Find, Δέντρα Αποφάσεων, Huffman, Pareto/Master Theorem) + ασκήσεις Python Drop-In με ζωντανούς πόντους και σερί συνεδρίας.
- **Καθαρή Κατάσταση Συνεδρίας:** Καμία απάντηση δεν αποθηκεύεται μόνιμα σε `localStorage`· κάθε επαναφορά ή επανεκκίνηση της εφαρμογής ξεκινά με όλες τις ασκήσεις άλυτες.

## Περιεχόμενα Καταλόγου

- `index.html` — Κύρια διεπαφή της εφαρμογής.
- `css/styles.css` — Σύστημα σχεδίασης (`Editorial Paper`) και κινήσεις διεπαφής.
- `js/icons.js` — Μονοχρωματικά εικονίδια SVG (χωρίς emoji).
- `js/data/prerequisites_data.js` — Κεφάλαιο Προαπαιτούμενων Γνώσης.
- `js/data/units_part1.js`, `js/data/units_part2.js` — Περιεχόμενο διδασκαλίας, γρήγορες επαναλήψεις, θεωρία με ενσωματωμένα παραδείγματα, πίνακες, λυμένες ασκήσεις, ασκήσεις συμπλήρωσης, παγίδες και SOS (`00`–`07`).
- `js/data/quiz_bank.js` — Τράπεζα 52 εξεταστικών ερωτήσεων (συμπεριλαμβανομένων Προαπαιτούμενων & Φροντιστηρίων A/B).
- `js/data/code_and_games_data.js` — Παραδείγματα κώδικα Python, ασκήσεις Drop-In και Σωστό/Λάθος με περιγραφική ονοματολογία μεταβλητών.
- `js/labs/labs_part1.js`, `js/labs/labs_part2.js` — Διαδραστικά εργαστήρια και προσομοιωτές (`00`–`07`).
- `js/games/dropin_engine.js` — Μηχανή συμπλήρωσης κώδικα Python (`Drag-and-Drop` & κλικ-τοποθέτηση).
- `js/games/builder_games_part1.js`, `js/games/builder_games_part2.js` — Διαδραστικά παιχνίδια κατασκευής (`00`–`07`).
- `js/app.js` — Κεντρικός ελεγκτής πλοήγησης, καθαρής συνεδρίας (`SessionTracker`), ασκήσεων και προσομοίωσης Προόδου.

## Τρόπος Εκτέλεσης

1. **Άμεσο άνοιγμα (offline):** Ανοίξτε το αρχείο `index.html` απευθείας σε οποιονδήποτε σύγχρονο φυλλομετρητή.
2. **Τοπικός διακομιστής HTTP:**
   ```bash
   cd Year_3/Semester_5/ALGORITHMS_AND_COMPLEXITY/Resources/Scripts/midterm
   conda run -n py14 python -m http.server 8000
   ```
   και επισκεφθείτε τη διεύθυνση `http://localhost:8000/`.
