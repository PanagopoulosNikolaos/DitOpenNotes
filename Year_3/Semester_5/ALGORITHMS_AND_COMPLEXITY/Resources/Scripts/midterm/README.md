# Διαδραστική Εφαρμογή Προετοιμασίας Προόδου — Αλγόριθμοι και Πολυπλοκότητα (504)

Εκπαιδευτική εφαρμογή ιστού (`HTML / CSS / JS` χωρίς εξωτερικές εξαρτήσεις) για τη μελέτη, οπτικοποίηση και εξεταστική εξάσκηση στις Ενότητες `00`–`07` της Προόδου.

## Περιεχόμενα Καταλόγου

- `TEACHING_PLAN.md` — Αναλυτικό διδακτικό πλάνο (στόχοι, εξαιρέσεις ύλης, θεωρία, εργαστήρια, ασκήσεις) ανά αρχείο σημειώσεων (`00`–`07`).
- `index.html` — Κύρια διεπαφή της εφαρμογής.
- `css/styles.css` — Σύστημα σχεδίασης (`Architectural Draft`) και κινήσεις διεπαφής.
- `js/icons.js` — Μονοχρωματικά εικονίδια SVG (χωρίς emoji).
- `js/data/units_part1.js`, `js/data/units_part2.js` — Περιεχόμενο διδασκαλίας, θεωρητικές κάρτες, αποδείξεις, πίνακες, λυμένες ασκήσεις (Σημειώσεις + Φροντιστήρια A/B), παγίδες και SOS για τις ενότητες `00`–`07`.
- `js/data/quiz_bank.js` — Τράπεζα 48 εξεταστικών ερωτήσεων (θεωρία, ιχνηλάτηση, πολυπλοκότητες με περίπτωση, θέματα Φροντιστηρίων A/B).
- `js/data/code_and_games_data.js` — Παραδείγματα κώδικα Python 3.10+, ασκήσεις συμπλήρωσης κώδικα (`Drop-In`) και γρήγορα Σωστό/Λάθος από τα Φροντιστήρια A & B (Κεφ. 1, 5, 6, 7, 8, 10, 11).
- `js/labs/labs_part1.js`, `js/labs/labs_part2.js` — Διαδραστικά εργαστήρια και προσομοιωτές αλγορίθμων για κάθε ενότητα (`00`–`07`).
- `js/games/dropin_engine.js` — Διαδραστική μηχανή συμπλήρωσης κώδικα Python (`Drag-and-Drop` & κλικ-τοποθέτηση).
- `js/games/builder_games_part1.js`, `js/games/builder_games_part2.js` — Χειροκίνητα διαδραστικά παιχνίδια κατασκευής (`Growth Order Sorter`, `O(n^2) Classifier`, `Manual Heap Tree Swapper`, `Hash Slot Placer`, `Maze Union-Find`, `Decision Tree Leaf Builder`, `Manual Huffman Builder`, `Pareto & Master Theorem Matcher`).
- `js/app.js` — Κεντρικός ελεγκτής πλοήγησης, κατάστασης μελέτης (`localStorage`), εξάσκησης και προσομοίωσης Προόδου.

## Τρόπος Εκτέλεσης

1. **Άμεσο άνοιγμα (offline):** Ανοίξτε το αρχείο `index.html` απευθείας σε οποιονδήποτε σύγχρονο φυλλομετρητή.
2. **Τοπικός διακομιστής HTTP (προαιρετικά):**
   ```bash
   cd Year_3/Semester_5/ALGORITHMS_AND_COMPLEXITY/Resources/Scripts/midterm
   conda run -n py14 python -m http.server 8000
   ```
   και επισκεφθείτε τη διεύθυνση `http://localhost:8000/`.
